# 选题模板库

从爆款案例反向提取的选题规律，用于自媒体内容创作。

---

## 核心原则

**实事求是 + 包装加工 = 大众想看但真实的内容**

- 不能为了流量编造假内容
- 但可以把真实内容包装成更吸引人的形式
- 真实性是底线，吸引力是手段

---

## 选题类型模板

### 1. 痛点解决型
**公式**：[具体人群] + [具体痛点] + [解决方案]

**爆款案例**：
- **案例1**：「张雪：辞职前问了自己三个问题」（抖音热度880万）
  - 类型：痛点共鸣型
  - 分析：张雪（职场博主背书）+ 辞职是很多人的痛点场景 + "三个问题"具体化增加可信度
  - 标题公式：**人物/身份 + 痛点场景 + 具体数字/动作**

**选题模板**：
```
[有背书的人物/身份] + [高共鸣痛点场景] + [具体数字/关键动作]
例如：XX辞职前做了XX件事、我靠XX解决了XX问题、XX前必看的XX清单...
```

---

### 2. 信息差型
**公式**：[大众不知道的信息] + [价值暗示]

**爆款案例**：
- **案例1**：「金饰价格一夜跌了11元」（抖音热度924万）
  - 类型：信息差型
  - 分析：用"具体数字11元"制造信息差，"一夜跌了"制造紧迫感，触发用户好奇心
  - 标题公式：**数字 + 悬念词 + 热点事件**

**选题模板**：
```
[具体数字/百分比变化] + [一夜/突然/刚刚] + [与钱/生活相关的事件]
例如：金饰一夜跌了XX元、房价环比涨了XX%、工资又调整了...
```

---

### 3. 对比冲击型
**公式**：[前后对比] + [极端差异] + [戏剧张力]

**爆款案例**：
- **案例1**：「@变成护肝片：月初风华正茂 vs 月末鸡精拌饭」（小红书单月涨粉45万）
  - 类型：对比冲击型
  - 分析：留学生真实生活，有钱炫饭vs没钱对付吃，极端对比制造反差
  - 标题公式：**极端状态A vs 极端状态B + 身份标签**
  - 内容核心：真实记录，不要剧本，越极端越有流量

**选题模板**：
```
[身份/状态A] + [vs] + [身份/状态B] + [戏剧性结果]
例如：留学前vs留学后、月初vs月末、有钱vs没钱、减肥前vs减肥后...
关键：极端对比 + 真实记录 + 情绪起伏
```

---

### 4. 认知刷新型
**公式**：[大众误区/标准] + [反常识观点] + [真实案例]

**爆款案例**：
- **案例1**：「乘风2026：撕掉滤镜，不完美才是真正的乘风破浪」（抖音热度6.5亿）
  - 类型：认知刷新型
  - 分析：打破"完美舞台"标准，用"真实瑕疵"替代"精修人设"，直击用户对虚伪内容的审美疲劳
  - 标题公式：**反常识观点 + [热搜事件/人物] + 情绪钩子**
  - 情绪钩子：「这才是真正的XX」「别再XX了」「终于有人说实话」

**选题模板**：
```
[反常识观点/颠覆认知] + [具体案例] + [证据/数据]
例如：不完美才是真正的XX、别再追求XX了、终于有人说出真相...
关键：找准被过度美化的标准，用真实去打破它
```

---

### 5. 情绪共鸣型
**公式**：[共同经历/感受] + [情绪触发] + [行动指引/出口]

**爆款案例**：
- **案例1**：「爱情鸟舞蹈挑战：和最爱的人，跳最简单的舞」（抖音773万热度，21.5万评论）
  - 类型：情绪共鸣型
  - 分析：戳中"忙碌情侣忘记怎么相爱"的痛点，用简单行动唤醒仪式感
  - 情绪点：遗憾感（"再不做就来不及了"）+ 治愈感（"现在就可以开始"）
  - 标题公式：**痛点场景 + 情绪词 + 简单行动**

- **案例2**：「独居不做人：端锅吃饭、厕所嗦粉、满地蛄蛹」（小红书2亿+浏览）
  - 类型：情绪共鸣型
  - 分析：卸下"精致独居"人设的表演压力，接纳真实的摆烂状态
  - 情绪点：释放感（终于可以不用端着）+ 归属感（原来不止我这样）
  - 标题公式：**反叛"应该" + 接纳"真实" + 群体认同**

**选题模板**：
```
[共同痛点/经历] + [情绪词：遗憾/释然/共情] + [简单行动/出口]
例如：
- 再不做就来不及了：XX前必看的XX、别等XX才XX...
- 终于可以做自己：不用再XX了、允许自己XX...
- 你不是一个人：原来大家都在XX、原来不止我XX...
关键：说中用户不好意思说出口的感受，给一个"被允许"的理由
```

## 选题判断标准

### 四问法则（必须全过）
- [ ] 人群大不大？
- [ ] 用户痛不痛？
- [ ] 站内有没有热搜/爆款？
- [ ] 我有没有资格写？（经历/测试/案例/观点）

### 真实性检查
- [ ] 内容是否真实可验证？
- [ ] 是否有夸大或编造？
- [ ] 是否能对读者负责？

### 6. 趋势玩法型（新增 2026-04-14）
**公式**：[热点趋势/玩法] + [实用攻略] + [情绪价值]

**爆款案例**：
- **案例1**：「Colorwalk爆火出圈：4.6亿次曝光的春日拍照秘笈」（小红书）
  - 类型：趋势玩法型
  - 分析：以"选一种颜色出门遛自己"为核心创意，提供拍照技巧和打卡攻略，击中用户的春日出游情绪
  - 选题公式：**热点玩法 + 具体攻略 + 情绪共鸣**

**选题模板**：
```
[热点趋势/新玩法] + [具体操作指南/攻略] + [情绪触发点]
例如：以XX为向导的遛娃攻略、XX岁孩子最爱的XX玩法、亲子版ColorWalk...
关键：找到平台热点 + 结合目标人群的具体场景 + 提供可落地的执行指南
```

### 7. 炸裂数据+反转视角型（新增 2026-04-14）
**公式**：[炸裂数据] + [反转/争议视角] + [深层问题揭示]

**爆款案例**：
- **案例1**：「AI玩具春节同比增长500倍，但情感的生意比想象中难做」（抖音/头条）
  - 类型：炸裂数据+反转视角
  - 分析：用"500倍"炸裂数据吸引眼球，再用反转视角揭示"新鲜感几小时耗尽、沦为电子垃圾"的深层问题，引发讨论
  - 选题公式：**数据炸裂 + 反转揭示 + 争议性话题**

**选题模板**：
```
[炸裂数据/惊人现象] + [但是/其实/没想到] + [反转/深层真相]
例如：XX增长500%的背后是XX、为什么爆款总是火不过XX天、XX的秘密终于被发现了...
关键：数据要真实可查，反转要有据可依，不是为了反转而反转
```

### 6. 真实失败后的逆袭型
**公式**：[真实失败/困境] + [情感流露] + [意外转机/网友救援]

**爆款案例**：
- **案例1**：「一条视频让烤肉店20天营收38万，网友组团"抢救小店"」（抖音，2026年2月）
  - 类型：真实失败后的逆袭型
  - 分析：北京烤肉店老板刘振东，创业失败濒临倒闭，一条没有脚本、没有剪辑的真诚视频打动了网友，尤其是东北老乡自发帮忙宣传
  - 核心要素：
    - 真实困境（创业失败、客流稀少）
    - 真实情感（困惑、疲惫、不放弃的坚持）
    - 意外转机（网友自发"抢救"）
    - 结果反转（20天38万营业额）
  - 标题公式：**结果/结果 + 身份标签 + 戏剧性结果**
  - 内容关键：不需要表演，只需要真实呈现你的困境和坚持

- **案例2**：「从80万亏到离婚，再到40万东山再起」（微博热搜，2026年4月）
  - 类型：真实失败后的逆袭型
  - 分析：26岁小伙朱俊锋，创业失败、婚姻破裂，蛰伏两年后重新出发
  - 核心要素：
    - 具体失败数字（80万亏损、离婚）
    - 真实努力（打工攒钱、复盘教训）
    - 最终逆袭（新店日营业额过万）
  - 标题公式：**具体失败 + 真实转变 + 可验证结果**
  - 内容关键：不要卖惨，要展示"失败后的行动"

**选题模板**：
```
[具体失败/困境] + [真实情感流露] + [行动/转变] + [可验证结果]
例如：
- XX万亏损后，我用XX方法重新开始...
- 被嘲笑XX后，我用XX证明了自己...
- XX次失败后，终于发现XX...
关键要素：
1. 具体数字/事件（增加可信度）
2. 真实情感（不是表演，是真的疲惫和坚持）
3. 行动细节（你是怎么做的）
4. 可验证结果（最好有数据支撑）
注意：不要变成"卖惨"，重点是"失败后的行动和结果"
```

### 7. 信任红利型（2026新趋势）
**公式**：[反常识观点] + [具体数据] + [方法论]

**爆款案例**：
- **案例1**：「别再痴迷10w+了，2026年的搞钱逻辑正在发生变化」
  - 类型：信任红利型
  - 分析：2026年平台算法转向，从"流量思维"转向"信任思维"
  - 核心观点：1000个铁粉 > 100万路人粉
  - 标题公式：**反常识观点 + 明确时间/趋势**
  - 金句："爆款是烟花，绚烂但短暂；长尾是路灯，不亮但一直亮"

- **案例2**：「16人公司全是AI，月入15万」（网易，2026年4月）
  - 类型：信任红利型
  - 分析：用AI工具实现"一人公司"，强调效率提升而非流量
  - 核心数据：传统公司利润率20-30%，AI公司利润率75%
  - 标题公式：**颠覆认知的数字 + 具体领域**

**选题模板**：
```
[反常识/反趋势观点] + [具体案例/数据] + [新方法论]
例如：
- 不是10w+，而是XX个铁粉...
- 不是追热点，而是XX...
- 不是XX，而是XX...
关键要素：
1. 明确的反常识观点（打破旧认知）
2. 具体可验证的数据（增加说服力）
3. 可操作的新方法（给用户行动指南）
4. 金句收尾（方便转发和记忆）
适用场景：知识干货、商业洞察、创业分享
```
