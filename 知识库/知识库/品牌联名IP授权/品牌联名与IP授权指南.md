## 一、品牌联名与IP授权总览

### 1.1 基本概念定义

```
┌─────────────────────────────────────────────────────────────┐
│                   品牌联名 vs IP授权                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  品牌联名                                                    │
│  ├── 定义：两个或多个品牌联合推出产品/内容/活动              │
│  ├── 核心：品牌价值叠加，制造话题                             │
│  ├── 目的：流量互导，品牌破圈                               │
│  └── 周期：通常有明确合作期限                               │
│                                                             │

│  ├── 定义：将IP（形象/名称/内容）授权给合作方使用           │
│  ├── 核心：IP价值变现，规模化复制                           │
│  ├── 目的：IP商业化扩张，轻资产运营                         │
│  └── 周期：可长可短，视合同约定                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、品牌联名类型与模式

### 2.1 四大联名类型

```
┌─────────────────────────────────────────────────────────────┐
│                     品牌联名四大类型                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 产品联名                                                │
│     ├── 定义：联合开发新产品                                │
│     ├── 形式：联名款/限量版/独家定制                       │
│     ├── 案例：瑞幸×茅台（酱香拿铁）                        │
│     └── 周期：通常3-6个月                                  │
│                                                             │
│  2. 内容联名                                                │
│     ├── 定义：共同创作内容                                  │
│     ├── 形式：共创视频/直播/栏目                           │
│     ├── 案例：博主×品牌联合内容                            │
│     └── 周期：通常1-3个月                                  │
│                                                             │
│  3. 活动联名                                                │
│     ├── 定义：联合举办活动                                  │
│     ├── 形式：快闪店/发布会/嘉年华                        │
│     ├── 案例：博主×品牌线下活动                            │
│     └── 周期：通常1-2周                                    │
│                                                             │
│  4. 渠道联名                                                │
│     ├── 定义：共享渠道资源                                 │
│     ├── 形式：联名店铺/专区/小程序                        │
│     ├── 案例：博主×电商品牌专区                            │
│     └── 周期：通常6-12个月                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 产品联名详解

**产品联名形式**

| 形式 | 定义 | 案例 | 适合场景 |
|------|------|------|----------|
| 联名款 | 双方品牌元素融合的新品 | 蜜雪雪王×冰杯 | 高知名度IP |
| 限量版 | 限定数量/时间发售 | 博主×美妆品牌限定色 | 稀缺性营造 |
| 独家定制 | 专为合作定制的产品 | 博主×零食品牌专属口味 | 粉丝福利 |
| 礼盒装 | 联名包装礼盒 | 博主×品牌联名礼盒 | 节日营销 |
| 周边联名 | 联名周边产品 | 博主×服饰品牌联名T恤 | 粉丝经济 |

**产品联名定价策略**

```yaml
# 产品联名定价策略

定价原则:
  价值感知 > 成本加成
  ├── 联名溢价：通常比普通款溢价20-100%
  ├── 限量溢价：限量款可溢价50-200%
  └── 粉丝买单：粉丝愿意为情怀付费

定价模型:
  联名售价 = 基础款成本 × (1+基础利润率) × (1+联名溢价率)
  
  示例:
    基础款成本: 30元
    基础利润率: 50%
    联名溢价率: 50%
    联名售价 = 30 × 1.5 × 1.5 = 67.5元

联名收益分配:
  ├── 固定授权费：品牌支付固定金额
  ├── 销售分成：按销售额比例分成（通常5-20%）
  ├── 保底+分成：固定保底+销售分成
  └── 纯分成：无保底，按销量结算
```

### 2.3 内容联名详解

**内容联名形式**

| 形式 | 定义 | 时长 | 适合场景 |
|------|------|------|----------|
| 品牌定制视频 | 按品牌要求创作内容 | 1-10分钟 | 产品推广 |
| 联名直播 | 双方联合直播 | 1-3小时 | 带货/品宣 |
| 共创栏目 | 长期合作栏目 | 持续更新 | 深度合作 |
| 挑战活动 | 联合发起话题挑战 | 1-4周 | 品牌曝光 |
| 知识共创 | 共同创作知识内容 | 不限 | 专业背书 |

**内容联名报价参考**

```yaml
# 内容联名报价参考（2026年市场行情）

短视频合作:
  ├── 头部博主（粉丝100万+）
  │   ├── 定制视频：5-30万元/条
  │   ├── 植入广告：2-10万元/条
  │   └── 直播带货：坑位费+佣金
  │
  ├── 腰部博主（粉丝10-100万）
  │   ├── 定制视频：1-5万元/条
  │   ├── 植入广告：0.5-2万元/条
  │   └── 直播带货：坑位费+佣金
  │
  └── 素人博主（粉丝1-10万）
      ├── 定制视频：0.2-1万元/条
      ├── 植入广告：0.1-0.5万元/条
      └── 直播带货：低坑位费+高佣金

报价影响因素:
  - 粉丝数量和质量
  - 互动率（高互动=高溢价）
  - 内容形式（定制>植入）
  - 传播范围（全平台>单平台）
  - 独家授权（独家>非独家）
  - 品牌调性匹配度
```

### 5.1 授权定价方法

**IP授权定价模型**

```
┌─────────────────────────────────────────────────────────────┐
│                   IP授权定价公式                            │
├─────────────────────────────────────────────────────────────┤

│                                                             │
│  其中:                                                      │
│  IP价值系数 = 粉丝量级 × 互动率 × 商业价值 × 垂类系数     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**IP价值评估维度**

```yaml
# IP价值评估表

一、粉丝价值（权重30%）
├── 粉丝量级
│   ├── 1-10万：系数1.0
│   ├── 10-50万：系数1.5
│   ├── 50-100万：系数2.0
│   ├── 100-500万：系数3.0
│   └── 500万+：系数5.0
│
└── 粉丝质量
    ├── 活跃度：日活/月活比
    ├── 互动率：点赞+评论+收藏/播放
    └── 精准度：目标人群占比

二、内容价值（权重25%）
├── 内容质量
│   ├── 平均播放/阅读量
│   ├── 爆款率
│   └── 内容原创度
│
└── 内容稳定度
    ├── 更新频率
    ├── 内容质量稳定性
    └── 粉丝期待度

└── 商业潜力

四、IP稳定性（权重20%）
├── 人设稳定性
├── 舆情风险
└── 续约可能性

综合评估:
├── A级（90+分）：系数2.0+，可溢价50-100%
```
