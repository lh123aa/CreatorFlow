> 版本：1.0 | 适用：多哈单人创作者 | 更新：2025年5月

## 一、文档概述

### 1.1 AI工具在创作中的价值

AI工具正在深刻改变内容创作的方式。对于在多哈的单人创作者来说，AI工具是提升效率、弥补资源短板的关键武器。合理使用AI工具，可以将创作效率提升3-5倍，同时保持内容质量。但AI只是工具，核心价值仍然来自创作者的选题能力、审美判断和人文洞察。

本文档将详细介绍如何构建完整的AI辅助创作工作流，覆盖创意生成、脚本撰写、视觉设计、音频处理、视频剪辑等全流程。通过这套工作流，单人创作者可以在有限时间内完成更大量的内容创作。

## 二、ChatGPT/Claude创意工作流

### 2.1 选题与创意生成

**使用场景**：当缺乏选题灵感时，使用AI辅助发散创意。

**工作流步骤**：

```
步骤1：输入选题背景
  - "我是一个在多哈生活的创作者，做海外华人生活内容"
  - "主要受众是中东地区的华人"
  - "我的内容风格是真实接地气"

步骤2：请求创意发散
  - "请给出20个适合的选题方向"
  - "每个选题包含：主题、角度、预期效果"

步骤3：精选与深化
  - 从AI给出的选题中筛选2-3个感兴趣的方向
  - 要求AI深化每个选题，提供更多细节
```

**提示词模板**：

```
【创意发散提示词模板】

请作为资深内容策划，帮助我进行选题创意发散。

【背景】
- 我是：[创作者身份描述]
- 我的受众：[目标受众描述]
- 我的风格：[内容风格描述]
- 我的目标：[创作目标描述]

【任务】
请给出[N]个选题创意，每个选题包含：
1. 选题主题
2. 内容角度（独特的切入视角）
3. 预期效果（为什么能吸引用户）
4. 核心信息点（要传达的关键信息）

【要求】
- 选题要有差异化和独特性
- 要符合目标受众的需求和兴趣
- 要有可执行性，适合单人创作
```

### 2.2 脚本撰写辅助

**使用场景**：撰写视频脚本时，使用AI辅助完善结构、丰富内容。

**工作流步骤**：

```
步骤1：提供脚本框架
  - 将自己的脚本大纲输入ChatGPT
  - "请帮我完善这个脚本的结构和内容"

步骤2：细化脚本内容
  - "请为开场钩子提供5个不同版本"
  - "请为结尾互动引导提供建议"

步骤3：口语化优化
  - AI生成的文案通常偏书面
  - 要求AI进行口语化改写
  - "请将以下文案改写为口语化表达"
```

**提示词模板**：

```
【脚本撰写提示词模板】

请帮我完善以下视频脚本。

【基本信息】
- 视频主题：
- 视频时长：X分钟
- 内容类型：[口播/图文/测评等]
- 目标受众：

【已有内容】
[粘贴已有的大纲或内容]

【任务】
请帮我完善：
1. 开场钩子（3-5秒，吸引用户继续观看）
2. 内容展开（丰富每个部分的内容）
3. 结尾引导（引导点赞、评论、关注）

【要求】
- 语言口语化，适合视频表达
- 节奏明快，不拖沓
- 有情感温度，不生硬
```

### 2.3 标题与文案优化

**使用场景**：优化视频标题和文案，提升点击率。

**工作流**：

```
步骤1：提供原始标题
  - 将原始标题发给AI
  - "请帮我优化以下标题"

步骤2：获取多个版本
  - "请提供10个不同风格的优化版本"
  - 包括：疑问型、数字型、情绪型、悬念型等

步骤3：选择与微调
  - 从中选择最喜欢的版本
  - 根据自己的理解进行微调
```

**提示词模板**：

```
【标题优化提示词模板】

请帮我优化以下内容的标题。

【原始标题】
[粘贴原始标题]

【背景信息】
- 内容主题：
- 目标受众：
- 期望效果：

【任务】
请提供15个优化后的标题，涵盖以下类型：
1. 疑问型（引发好奇）
2. 数字型（具体明确）
3. 情绪型（有情感共鸣）
4. 悬念型（引发好奇）
5. 冲突型（制造反差）

【要求】
- 每个标题不超过30字
- 标题要有吸引力，能引发点击
- 符合平台标题规范
```

## 三、Midjourney视觉创作工作流

### 3.1 封面设计

**使用场景**：生成吸引人的视频封面图片。

**工作流**：

```
步骤1：确定封面风格
  - 根据内容类型确定封面风格
  - 口播类：人物近景为主
  - 干货类：信息图风格
  - 生活类：场景氛围图

步骤2：撰写Midjourney提示词
  - 包含：主体、风格、光线、构图、氛围
  - 示例："a confident Asian woman in Doha, wearing casual clothes,
    modern office background, warm lighting, portrait style,
    high quality, 4k"

步骤3：生成与筛选
  - 生成4-9张候选图
  - 选择最符合预期的1-2张
  - 使用Vary功能微调

步骤4：后期处理
  - 添加文字标题
  - 调整颜色和对比度
  - 导出最终版本
```

**提示词模板**：

```
【Midjourney封面提示词模板】

[主体描述], [着装风格], [场景描述], 
[光线描述], [拍摄角度], 
[风格描述：摄影/插画/3D等],
[画质要求], --ar 9:16 --s 200 --v 6

示例：
A professional Asian woman with warm smile, wearing smart casual,
standing in front of Doha cityscape at sunset, golden hour lighting,
half body portrait, editorial photography style, shot on Sony A7III,
high quality, 4k --ar 9:16 --s 200 --v 6
```

### 3.2 配图与素材生成

**使用场景**：为图文内容生成配图。

**工作流**：

```
步骤1：明确配图需求
  - 配图要传达什么信息
  - 什么风格/色调
  - 是否需要文字

步骤2：生成素材图
  - 使用Midjourney生成
  - 或使用DALL-E更适合有文字的图片

步骤3：组合与编辑
  - 在Canva或PS中组合
  - 添加文字、箭头等元素
  - 统一整体风格
```

### 3.3 Midjourney参数说明

**常用参数**：

| 参数 | 作用 | 推荐值 |
|------|------|--------|
| --ar | 宽高比 | 9:16（竖屏）、16:9（横屏） |
| --s | 风格化程度 | 100-300，越高越艺术化 |
| --v | 模型版本 | 6（最新版本） |
| --niji | 动漫风格 | 适合插画类内容 |
| --style | 风格参数 | raw（写实）、photography（摄影） |

## 四、剪映AI工作流

### 4.1 AI配音

**使用场景**：快速生成视频配音。

**功能介绍**：

- 内置多种AI音色可选
- 支持中文、英文、阿拉伯语
- 可调节语速和音调

**工作流**：

```
步骤1：导入视频或音频
步骤2：选择AI配音功能
步骤3：输入要配音的文字
步骤4：选择音色和参数
  - 音色：磁性男声、温柔女声等
  - 语速：0.8-1.2倍速
  - 音调：根据内容调整
步骤5：预览与调整
步骤6：导出配音音频
```

### 4.2 AI字幕

**使用场景**：自动生成视频字幕。

**功能介绍**：

- 自动识别语音生成字幕
- 支持多种语言
- 可一键翻译

**工作流**：

```
步骤1：导入视频
步骤2：选择自动字幕功能
步骤3：选择识别语言
步骤4：自动生成字幕
步骤5：校对修正（AI识别有误差）
步骤6：调整字幕样式
步骤7：导出
```

### 4.3 AI成片

**使用场景**：一键生成完整视频。

**功能介绍**：

- 输入文字稿，自动匹配素材生成视频
- 适合快速产出

**工作流**：

```
步骤1：输入文字稿
  - 可以是完整脚本或要点
步骤2：选择视频风格
  - 知识讲解、生活记录等
步骤3：AI自动生成
  - 自动匹配素材、配乐、字幕
步骤4：人工审核与调整
步骤5：导出发布
```

**注意**：AI成片适合快速产出初版，正式发布前需要人工审核和调整。

## 五、ElevenLabs音频工作流

### 5.1 AI语音克隆

**使用场景**：创建专属AI声音，用于配音。

**功能介绍**：

- 克隆真实声音
- 支持多语言
- 可调整情绪和风格

**工作流**：

```
步骤1：准备声音样本
  - 录制10-30分钟的清晰语音
  - 涵盖不同情感和语速
步骤2：上传并训练模型
  - 在ElevenLabs平台操作
  - 等待模型训练完成
步骤3：使用克隆声音
  - 输入文字，选择克隆音色
  - 生成配音
```

### 5.2 多语言配音

**使用场景**：为视频生成多语言版本。

**功能介绍**：

- 支持30+语言
- 保持原声音色特点
- 可用于拓展海外市场

**工作流**：

```
步骤1：准备原文配音或文字
步骤2：选择目标语言
  - 英文、阿拉伯语等
步骤3：生成配音
步骤4：人工审核语调
步骤5：替换或添加字幕
```

## 六、AI工作流整合

### 6.1 完整AI创作工作流

```
完整AI辅助创作工作流：

【创意阶段】
1. 使用ChatGPT进行选题发散
2. 确定选题方向
3. 使用ChatGPT完善脚本框架

【内容创作阶段】
4. 人工拍摄/录制素材
5. 使用剪映AI生成字幕
6. 使用Midjourney生成封面/配图

【后期处理阶段】
7. 使用剪映专业版剪辑
8. 导出最终版本

【发布阶段】
9. 使用ChatGPT优化标题和文案
10. 发布并监控数据
```

### 6.2 各环节AI介入程度

| 环节 | AI介入程度 | 人工介入程度 |
|------|------------|--------------|
| 选题创意 | 高（80%） | 低（20%） |
| 脚本撰写 | 中（50%） | 高（50%） |
| 封面设计 | 高（70%） | 中（30%） |
| 视频剪辑 | 中（50%） | 高（50%） |
| 字幕生成 | 高（90%） | 低（10%） |
| 标题优化 | 高（70%） | 中（30%） |

### 6.3 AI使用注意事项

**质量把控**：

- AI生成内容必须人工审核
- 避免AI生成的错误信息
- 保持个人风格和特色

**效率平衡**：

- AI是效率工具，不是替代工具
- 核心创意和判断仍需人工
- 找到AI和人工的最佳平衡点

**持续学习**：

- AI工具快速迭代，持续学习新功能
- 关注效率提升和效果优化
- 保持对工具的敏感度
