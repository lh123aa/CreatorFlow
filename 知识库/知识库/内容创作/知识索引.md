## 二、知识模块清单

### 模块1：选题模板库

**路径**：`./知识库/选题规范/选题模板库.md`

**触发关键词**：选题、确定主题、写什么内容、内容方向

**核心内容**：7种选题类型

| 类型 | 公式 | 适用场景 |
|------|------|----------|
| 痛点型 | `[具体痛点] + [情绪词] + [解决方案预告]` | 解决问题类 |
| 信息差型 | `[反常识观点] + [具体数据] + [新方法论]` | 认知刷新类 |
| 对比型 | `[A vs B] + [反差结果] + [原因分析]` | 产品测评类 |
| 认知刷新型 | `[常见误区] + [真相揭示] + [行动建议]` | 知识科普类 |
| 情绪共鸣型 | `[场景描述] + [情绪共鸣] + [价值升华]` | 情感故事类 |
| 真实失败逆袭型 | `[具体失败] + [真实情感] + [行动转变] + [可验证结果]` | 创业故事类 |
| 信任红利型 | `[反常识观点] + [具体数据] + [新方法论]` | 商业洞察类 |

**使用建议**：选题时先确定内容类型，再套用对应公式

### 模块2：标题模板库

**路径**：`./知识库/标题规范/标题模板库.md`

**触发关键词**：标题、封面文字、标题怎么写、吸引眼球

**核心内容**：9种标题类型

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | `[数字] + [时间/结果] + [利益点]` | "3个月从0到10万粉" |
| 痛点型 | `[具体痛点] + [情绪词] + [反转/解决方案]` | "AI写不出爆款？一个技巧解决" |
| 反常识型 | `[常见认知] + [反转事实] + [证据]` | "99%的人都用错AI" |
| 悬念型 | `[现象/结果] + [悬念提问]` | "为什么他只用3个工具就月入过万？" |
| 对比型 | `[A vs B] + [惊人差距]` | "普通人 vs AI用户，差距有多大" |
| 谐音反转自我宣言型 | `[谐音/反转词] + [核心价值主张]` | "爱你老己" |
| 紧急号召型 | `[感叹词] + [事件] + [紧迫感] + [数字]` | "扩散！紧急寻找100位记录者" |
| 反差自嘲型 | `[认知预期] vs [现实反差] + [自我调侃]` | "我以为..., 实际上..." |
| 情绪化反转型 | `[矛盾体] + [反问] + [情绪词] + [悬念]` | "手机越贵越好？高价陷阱你踩了吗" |

**使用建议**：标题控制在15字内，加情绪词，口语化表达

### 模块3：正文模板库

**路径**：`./知识库/正文规范/正文模板库.md`

**触发关键词**：正文、内容、文章结构、怎么写、写作

**核心内容**：9种正文结构

| 类型 | 结构 | 适用场景 |
|------|------|----------|
| 爆款万能结构 | `痛点引入(1-2句) → 价值输出(3-4句) → 细节拆解 → 引导互动(1句)` | 通用 |
| AIDA种草结构 | `注意 → 兴趣 → 欲望 → 行动` | 产品推荐 |
| 漏斗四段法 | `场景引入 → 痛点放大 → 方案呈现 → 行动号召` | 转化导向 |
| SCQA结构 | `情境 → 冲突 → 问题 → 答案` | 故事讲述 |
| 清单式 | `问题 → 要点1、2、3... → 总结` | 干货分享 |
| 避坑指南式 | `误区1/2/3 → 正确做法 → 总结` | 知识科普 |
| 情绪锚点式 | `短句独立成段 + 情绪浓度高 + 并列排比 + 留白收尾` | 情感共鸣 |
| 收入对比式 | `[收入数字] + [地域/身份] + [反差/悬念]` | 创业故事 |
| 抖音情感文案 | 扎心遗憾/温柔治愈/人间清醒/暧昧心动 | 短视频文案 |

**写作技巧**：
- 每句话≤15字
- 短句 > 长句
- 情绪克制 > 情绪宣泄
- 留白 > 说透

### 模块4：设计模板库

**路径**：`./知识库/设计规范/设计模板库.md`

**触发关键词**：封面、配图、设计、图片、视觉

**核心内容**：封面设计规范

**封面设计要点**：
- 文字控制在5-8字内
- 字体颜色用1-2种对比色
- 莫兰迪色系 + 亮色点缀
- 文字占比约30%
- 标题用粗体无衬线，副标题用细体

**配色方案**：
- 主色：莫兰迪色系（低饱和度）
- 点缀：亮色（提高视觉冲击）
- 文字：与背景形成对比

**布局类型**：
- 左文右图
- 上下分区
- 中心聚焦

**视觉元素**：
- emoji图标点缀
- 简约几何装饰线
- 高质量配图

### 模块5：钩子文案规范

**路径**：`./知识库/自媒体创作规范/钩子文案创作规范.md`

**触发关键词**：钩子、开头、吸引眼球、黄金3秒

**核心内容**：7种钩子类型 + 公式

**核心公式**：`钩子 + 价值/痛点 + 触发词`

| 钩子类型 | 公式 | 示例 |
|---------|------|------|
| 痛点暴击 | `[用户痛点] + [情绪词] + [解决方案预告]` | "你的AI每次都从零开始？" |
| 颠覆认知 | `[常见误区] + [反直觉事实]` | "90%的人用AI都是一次性的" |
| 结果前置 | `[惊人结果] + [方法预告]` | "从0到10万粉，我只用了3个工具" |
| 悬念提问 | `[反常现象] + [为什么?]` | "为什么有人AI越用越聪明？" |
| 身份宣称 | `[目标人群] + [专属价值]` | "创业者的AI搭档，该长什么样？" |
| 高能片段 | `[精彩瞬间] + [悬念延伸]` | "这是我见过最聪明的AI..." |
| 利益承诺 | `[具体利益] + [时间限制]` | "3分钟学会，立刻能用" |

**使用建议**：
- 每句话≤15字
- 加情绪词（震惊、没想到、终于）
- 口语化表达
- 黄金3秒原则：前3秒必须抓住注意力

## 三、创作流程（强制执行）

```
┌─────────────────────────────────────────────────────────┐
│ 步骤1：确定主题                                          │
│ - 用户给出主题/自己选题                                   │
│ - 明确要写什么                                           │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 步骤2：主题分析（关键环节）                               │
│ - 读取：./知识库/自媒体创作规范/主题分析模板.md            │
│ - 解析主题核心（受众、痛点、调性）                         │
│ - 匹配适合的选题/标题/正文/钩子类型                       │
│ - 输出知识加载清单                                       │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 步骤3：读取知识索引（此文件）                             │
│ - 根据主题分析结果确定需要的模块                          │
│ - 确认模块路径                                          │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 步骤4：精确加载知识模块                                   │
│ - 按主题分析结果加载对应模块                              │
│ - 不全量加载所有文件                                      │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 步骤5：套用公式创作                                       │
│ - 按选定模板创作                                         │
│ - 逐项应用公式                                           │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 步骤6：检查清单确认                                       │
│ - 各环节是否按要求应用知识                                │
│ - 质量检查                                               │
└─────────────────────────────────────────────────────────┘
```

```
分析结果：

需要加载：选题模板库 + 标题模板库 + 正文模板库 + 钩子文案规范
```
