## 一、小红书图文笔记创作SOP

### 1.1 小红书图文特点

#### 图文vs视频对比

| 维度 | 图文笔记 | 视频笔记 |
|------|----------|----------|
| 生产成本 | 低 | 高 |
| 内容深度 | 可深度表达 | 适合轻量内容 |
| 传播周期 | 长尾效应强 | 短期爆发 |
| 搜索流量 | 占60%+ | 占30% |
| 收藏率 | 高 | 中 |
| 适合垂类 | 攻略/测评/教程 | 体验/过程/动态 |

#### 小红书用户行为

```
用户路径:
发现页浏览 → 点击感兴趣封面 → 阅读正文 → 收藏/评论/关注
     ↑                                              ↓
     ←←←←←←←←← 搜索补充 ←←←←←←←←←←←←←←←←←←←←←←←
```

### 1.2 封面设计SOP

#### 封面设计原则

```yaml
【黄金法则】
1. 主体突出: 产品/人物清晰可见
2. 信息明确: 一眼看懂内容价值
3. 色彩对比: 与平台背景区分开
4. 留白适当: 重要信息不被遮挡

【常见封面结构】
┌────────────────────────────────────────┐
│  【大标题区】核心信息，15字以内         │
│  ────────────────────────────────────  │
│                                        │
│  【主体区】产品/人物/场景图             │
│                                        │
│  ────────────────────────────────────  │
│  【副标题区】补充信息/价格/效果         │
└────────────────────────────────────────┘
```

#### 不同类型封面模板

| 类型 | 封面特点 | 适用场景 | 示例 |
|------|----------|----------|------|
| 种草清单型 | 多产品拼图+清单感 | 好物推荐 | "这10件好物后悔没早买" |
| 对比测评型 | Before/After对比 | 测评笔记 | "用了1个月皮肤变化" |
| 教程攻略型 | 成品图+步骤感 | 教程类 | "保姆级XX教程" |
| 场景氛围型 | 整体场景+情绪感 | 生活方式 | "周末治愈系早餐" |
| 文字为主型 | 大字标题为主 | 干货分享 | "99%的人都踩过这个坑" |
| 产品特写型 | 单品精致特写 | 护肤品等 | "这瓶精华我用空了3瓶" |

### 1.3 标题撰写技巧

#### 标题公式库

```yaml
【痛点+解决方案】
公式: "XXX人群/问题+解决方法+效果"
示例: "油皮姐妹！这套护肤流程夏天用绝了"

【数字清单型】
公式: "数字+核心卖点"
示例: "整理了20件提升幸福感的家居好物"

【对比反差型】
公式: "反差对比+悬念"
示例: "花100和花1000的面霜有什么区别"

【情绪共鸣型】
公式: "情绪词+场景描述"
示例: "救命！这个收纳方法太绝了"

【实用干货型】
公式: "人群+场景+价值"
示例: "租房党必看！500块改造出租屋"

【蹭热点型】
公式: "热点+关联内容"
示例: "《繁花》同款穿搭，复古又高级"
```

#### 标题优化检查表

```yaml
□ 字数控制在15-25字
□ 包含关键词（搜索词）
□ 有数字或情绪词
□ 与封面风格统一
□ 无违规敏感词
□ 引发好奇心或共鸣
```

### 1.4 正文创作SOP

#### 正文结构模板

```yaml
【开篇吸引】(50-100字)
├── 痛点共鸣: 描述目标用户痛点
├── 场景带入: 描述具体使用场景
└── 价值预告: 预告内容价值

【正文展开】(300-800字)
├── 核心内容1: 第一个要点/产品/步骤
├── 核心内容2: 第二个要点/产品/步骤
└── 核心内容3: 第三个要点/产品/步骤

【结尾引导】(50-100字)
├── 总结回顾: 强调核心价值
├── 互动引导: 引导评论互动
└── 关注引导: 引导关注账号
```

#### 正文写作技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 分段清晰 | 每段不超过3行 | 留白增加可读性 |
| emoji点缀 | 适量使用emoji | 表情符号标注重点 |
| 列表形式 | 方便扫描阅读 | "① ② ③"或"•" |
| 亲身经历 | 增加真实感 | "我用了XX天实测" |
| 数据支撑 | 增加可信度 | "XX数据显示" |

### 1.5 图片制作规范

#### 图片数量与比例

| 图片数量 | 适用场景 | 说明 |
|----------|----------|------|
| 3-4张 | 简单攻略 | 精华版 |
| 5-6张 | 标准笔记 | 最常见 |
| 7-9张 | 详细教程 | 完整版 |

#### 图片内容规划

```yaml
【第1张: 封面图】
- 核心视觉冲击
- 包含标题文字
- 高清精美

【第2-3张: 概览/对比】
- 整体展示
- Before/After对比
- 效果预览

【第4-6张: 详细内容】
- 分点展示
- 细节特写
- 步骤说明

【最后1张: 总结/引导】
- 精华总结
- 互动引导
- 收藏提示
```

#### 图片质量标准

| 标准 | 要求 | 说明 |
|------|------|------|
| 分辨率 | 1080×1350以上 | 竖版3:4 |
| 清晰度 | 无模糊/噪点 | 避免压缩失真 |
| 色调统一 | 整体风格一致 | 调色统一 |
| 水印处理 | 避免大面积遮挡 | 可小logo |
| 文字可读 | 字体清晰 | 字号适中 |

## 二、公众号长文创作方法论

### 2.1 公众号内容定位

#### 内容定位矩阵

| 内容类型 | 占比 | 目的 | 示例 |
|----------|------|------|------|
| 干货价值型 | 50% | 涨粉/留存 | 深度分析/教程 |
| 热点评论型 | 20% | 传播/曝光 | 热点解读 |
| 品牌故事型 | 20% | 信任建立 | 创始人故事 |
| 活动促销型 | 10% | 转化变现 | 限时福利 |

#### 选题策略

```yaml
【选题来源】
1. 行业热点: 政策/事件/趋势
2. 用户痛点: 后台问题/评论区反馈
3. 竞品分析: 爆款选题延伸
4. 节日节点: 提前规划节点内容
5. 数据洞察: 阅读量高的选题复盘

【选题评估维度】
1. 粉丝需求度: 是否是粉丝关心的话题
2. 传播潜力: 是否有分享价值
3. 差异化: 能否做出不同角度
4. 时效性: 是否需要快速发布
5. 变现关联: 能否自然带产品
```

### 2.2 标题撰写技巧

#### 爆款标题公式

```yaml
【数字型】
公式: "数字+核心价值+悬念"
示例: "做了100场直播后，我总结了3条最关键的认知"

【疑问型】
公式: "引发好奇+直击痛点"
示例: "为什么你写的文案总是不够吸引人？"

【对比型】
公式: "反差/冲突+悬念"
示例: "同样做自媒体，有人月入10万，有人月入1千"

【利益型】
公式: "明确收益+具体方法"
示例: "学会这个技巧，转化率提升300%"

【情绪型】
公式: "情绪词+场景"
示例: "扎心了！这5个运营误区90%的人都在犯"

【悬念型】
公式: "制造悬念+引导点击"
示例: "揭秘：头部账号都在用的这个方法"
```

#### 标题优化检查

| 检查项 | 要求 | 说明 |
|--------|------|------|
| 字数 | 15-30字 | 太短信息不足，太长显示不全 |
| 关键词 | 包含核心词 | 便于搜索收录 |
| 情绪词 | 适量使用 | 引发点击欲望 |
| 悬念感 | 留有悬念 | 引导点击 |

### 2.3 文章结构设计

#### 常见结构模板

```yaml
【总-分-总结构】
开头: 提出观点/问题
展开: 分点论证/案例说明
结尾: 总结升华/行动指引

【故事线结构】
开场: 讲一个故事/案例
发展: 故事背后的逻辑
高潮: 核心观点揭示
收尾: 总结升华

【清单列表结构】
开场: 引出主题
展开: 逐条列出要点
结尾: 总结强调

【问题解决结构】
问题: 提出痛点问题
分析: 分析问题原因
方案: 给出解决方案
验证: 证明方案有效
```

#### 开篇写法

```yaml
【痛点开篇】
"你是不是也有这样的困扰：XXX"
"XX的问题困扰了很多人，包括曾经的我"

【故事开篇】
"上周，一个学员问我一个问题..."
"三年前，我还是个月薪5000的普通员工"

【数据开篇】
"数据显示，XX%的XX都存在XX问题"
"一份针对XX人的调查报告显示..."

【名言开篇】
"XX曾说：'XXX'"
"网上有句话：'XXX'，说得太对了"
```

### 2.4 正文写作技巧

#### 段落写作规范

```yaml
【段落长度】
- 手机阅读每段不超过5行
- 电脑阅读每段不超过8行
- 关键信息单独成段

【句子长度】
- 短句为主，避免长句
- 每句话一个意思
- 可读性优先

【重点标注】
- 加粗关键词
- 引用可斜体
- 重要数据单独标注
```

#### 增加可读性的技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 小标题 | 分段引导阅读 | "一、XXX 二、XXX" |
| 配图 | 图文并茂 | 每300字配图 |
| 金句 | 提炼核心观点 | 可单独成段 |
| 互动 | 引导评论 | "你怎么看？" |
| 表情 | 适当使用 | 轻松活泼 |

### 2.5 排版设计规范

#### 排版基础规范

```yaml
【字体设置】
- 正文字号: 15-16px
- 标题字号: 18-22px
- 行间距: 1.5-1.8倍
- 字间距: 1px

【颜色设置】
- 正文色: #3f3f3f (深灰，不纯黑)
- 强调色: #2f88ff (品牌蓝)
- 辅助色: #888888 (灰色)
- 背景色: #ffffff (纯白)

【留白规范】
- 段间距: 1倍行高
- 页边距: 8-16px
- 两端缩进: 8-16px
```

#### 排版模板推荐

| 类型 | 风格 | 适用场景 |
|------|------|----------|
| 简洁商务 | 黑白灰为主 | 商业/职场 |
| 清新文艺 | 浅色系/插画 | 生活/情感 |
| 专业深度 | 大段留白 | 干货/分析 |
| 活泼有趣 | 彩色/表情 | 年轻品牌 |

## 三、知乎回答创作策略

### 3.1 知乎内容生态

#### 知乎用户特点

| 特点 | 说明 | 内容应对 |
|------|------|----------|
| 高学历 | 本科及以上占比高 | 内容要有深度 |
| 求真知 | 追求真实有价值内容 | 避免空洞 |
| 爱分析 | 喜欢逻辑分析 | 结构化表达 |
| 理性消费 | 决策理性 | 客观分析 |

#### 知乎内容偏好

```
优质内容特征:
├── 专业深度: 有真知灼见
├── 逻辑清晰: 结构化表达
├── 证据支撑: 数据/案例支撑
├── 客观中立: 多角度分析
└── 实用价值: 能解决实际问题
```

### 3.2 回答策略

#### 选题选择

```yaml
【高价值问题特征】
1. 搜索量高: 问题关注人数多
2. 回答少: 竞争不激烈
3. 搜索友好: 关键词明确
4. 持续热度: 长期有人关注

【问题筛选公式】
价值 = 关注人数 × 回答数^-1 × 时效性
     ↑                    ↑
     需求大            竞争小
```

#### 回答结构

```yaml
【开篇】
├── 明确结论: 先给答案
├── 背景铺垫: 补充背景信息
└── 阅读预期: 预告内容价值

【正文展开】
├── 观点/方法1 + 论据
├── 观点/方法2 + 论据
└── 观点/方法3 + 论据

【结尾】
├── 总结要点: 强化记忆
├── 延伸阅读: 推荐相关回答
└── 互动引导: 引导讨论
```

### 3.3 专业度构建

#### 增加可信度的方法

| 方法 | 说明 | 示例 |
|------|------|----------|
| 数据引用 | 权威数据支撑 | "根据XX数据显示" |
| 案例展示 | 真实案例说明 | "比如XX公司/XX人" |
| 亲身经历 | 第一视角验证 | "我曾经也遇到过" |
| 专业术语 | 适度使用专业词 | 增加专业感 |
| 引用来源 | 标注参考来源 | 提升可信度 |
| 身份背书 | 展示相关经历 | "作为XX年从业者" |

#### 知乎特有技巧

```yaml
【冷启动技巧】
1. 选择合适时间发布 (晚8-10点)
2. 开头要吸引人 (直接给结论)
3. 善用段落小标题
4. 结尾引导点赞评论

【持续曝光技巧】
1. 持续更新回答内容
2. 定期回复评论
3. 关联相关问题
4. 善用知乎专栏
```

## 五、图文排版与视觉设计原则

### 5.1 视觉设计基础

#### 设计四要素

| 要素 | 说明 | 在图文中的应用 |
|------|------|----------------|
| 对比 | 差异化的视觉呈现 | 标题vs正文/重点vs普通 |
| 对齐 | 视觉元素的秩序感 | 文字对齐/图片对齐 |
| 重复 | 视觉元素的一致性 | 配色/字体/风格统一 |
| 亲密 | 相关内容的视觉关联 | 分组/间距/层次 |

#### 色彩心理学

```yaml
【常见色彩含义】
红色: 热情/冲动/促销
橙色: 活力/温暖/年轻
黄色: 快乐/警示/注意
绿色: 自然/健康/安全
蓝色: 专业/信任/科技
紫色: 高贵/神秘/女性
粉色: 温柔/可爱/少女
黑色: 专业/高级/神秘
白色: 简洁/干净/纯净

【平台配色偏好】
小红书: 暖色调/清新感
公众号: 商务/专业感
知乎: 简洁/学术感
微博: 多样/活泼感
```

### 5.2 排版设计原则

#### 易读性原则

```yaml
【文字排版】
1. 字号适中: 正文15-16px
2. 行距适当: 1.5-1.8倍
3. 段落分明: 关键信息单独段
4. 留白充足: 避免拥挤

【图片排版】
1. 清晰度: 高清无压缩
2. 风格统一: 色调/滤镜一致
3. 尺寸合适: 不拉伸不变形
4. 留白适当: 避免过于拥挤
```

#### 视觉层次

```yaml

第一层级: 标题/核心观点 (最大/最突出)
第二层级: 小标题/重要信息 (中等)

【视觉引导】
- 字号大小区分层级
- 颜色深浅区分重点
- 位置上下区分主次
```

## 六、SEO文案写作技巧

### 6.1 SEO基础原理

#### 搜索引擎工作原理

```
爬虫抓取 → 索引建库 → 质量评估 → 排名展现
     ↓
   发现内容   判断内容   计算权重   用户搜索
```

#### 关键词策略

```yaml
【关键词类型】
1. 核心关键词: 主题词，搜索量大
   示例: "护肤教程"

2. 长尾关键词: 具体需求，搜索量小
   示例: "油皮敏感肌护肤教程"

3. 品牌关键词: 品牌名相关
   示例: "雅诗兰黛精华"

4. 竞品关键词: 竞争对手相关
   示例: "平替 XXX"
```

### 6.2 关键词布局

#### 关键词布局原则

| 位置 | 权重 | 说明 | 建议密度 |
|------|------|------|----------|
| 标题 | ★★★★★ | 最重要位置 | 必须包含 |
| 首段 | ★★★★☆ | 前100字 | 包含1-2次 |
| 正文 | ★★★☆☆ | 自然分布 | 2-5% |
| 结尾 | ★★★☆☆ | 总结强化 | 包含1次 |
| 标签 | ★★★☆☆ | 内容归类 | 3-5个 |

#### 关键词布局示例

```yaml
【标题】
"2024年最新 | 油皮敏感肌护肤教程（含产品推荐）"

【首段】
"油皮敏感肌是很多女生都面临的护肤难题，
本文将分享一套适合油皮敏感肌的护肤流程，
帮助大家改善肌肤问题。"

【正文】
在文章不同位置自然融入关键词

【结尾】
"以上就是油皮敏感肌护肤教程的全部内容，
希望对大家有帮助。"

【标签】
油皮护肤 | 敏感肌 | 护肤教程 | 护肤步骤
```

### 6.3 各平台SEO差异

#### 平台SEO特点

| 平台 | 搜索权重 | 特点 | 优化重点 |
|------|----------|------|----------|
| 小红书 | 高(60%+) | 搜索流量大 | 标题/正文关键词 |
| 公众号 | 中 | 微信搜索 | 标题/正文/标签 |
| 知乎 | 高 | 专业内容 | 回答质量/点赞 |
| 百度 | 高 | 长尾搜索 | 内容深度/外链 |
| B站 | 中 | 关键词匹配 | 标题/简介/标签 |
