## 架构原则

1. **产品层**：面向用户的独立产品，每个可单独售卖
2. **技术层**：内部能力，支持产品层，不直接售卖
3. **知识层**：知识库资产，支撑技术层和产品层

## 产品开发流程

```
1. 框架建立 → 创建Skill目录结构
2. 核心功能 → 实现最小可用版本
3. 进化引擎介入 → 自动评估+迭代
4. 用户验证 → 收集反馈，定向学习
5. 成熟封装 → 产品化，独立售卖
```

## 售卖模式（规划）

### 单品售卖
- 每个产品独立定价
- 按使用次数/按月订阅

### 组合套餐
- 创作者套装：小红书创作 + AI清洗
- 安全套装：AI安全体检 + 提示词遗产
- 记忆套装：私人自传 + 家族记忆库

### 技术授权
- 进化引擎：授权给其他开发者
- AI清洗模块：授权给其他创作工具
