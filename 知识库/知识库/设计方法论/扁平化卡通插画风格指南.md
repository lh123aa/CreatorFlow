# 扁平化卡通插画风格指南

> 更新时间：2026-04-20
> 来源：小红书爆款案例 + AI生成技术研究

---

## 一、风格特征

**核心要素**：
- 扁平化造型，无立体感
- 干净轮廓线，无毛边
- 纯色填充，无渐变
- 方格纸/网格背景
- 卡通人物+场景描绘
- 手绘装饰元素

**参考案例**：
- 越努力越累？系列海报
- 知识科普类海报

---

## 二、AI生成提示词

### 2.1 基础结构

**英文提示词模板**：
```
flat illustration, minimalist, vector art, [主体描述], bold lines, pastel color scheme, clean composition, white background, --ar 3:4 --s 750 --v 6.2
```

**中文提示词模板**（搜狐简单AI）：
```
生成一张小红书风格的扁平插画海报，画面主体是[描述人物/IP]，正在[动作]，旁边有[关键元素1]和[关键元素2]，背景是[颜色/场景]，整体氛围[清新/热闹/高级/治愈]，主标题写上'[你的文案]'
```

### 2.2 关键词汇表

| 类型 | 英文关键词 | 说明 |
|------|-----------|------|
| 风格 | flat illustration, minimalist, vector art | 扁平插画风格 |
| 线条 | bold lines, clean lines, thick outline | 粗线条、干净轮廓 |
| 颜色 | flat color, solid colors, pastel palette | 纯色、柔和色调 |
| 背景 | white background, simple background, grid background | 白底/网格背景 |
| 排除 | no shading, no gradient, no texture | 无阴影/渐变/纹理 |

### 2.3 Midjourney参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| --ar | 3:4 或 4:5 | 小红书竖版比例 |
| --stylize / --s | 750-800 | 高风格化 |
| --chaos | 20-35 | 创意探索 |
| --v | 6.2 | 最新版本 |
| --style | raw | 减少默认美化（可选） |

## 三、配色系统

### 3.1 小红书爆款配色

| 色系 | 色值 | 适用场景 |
|------|------|----------|
| 温柔治愈 | 米白#FAF7F2 + 珊瑚橘#FF6B6B | 生活、情感类 |
| 科技干货 | 浅灰#F5F5F5 + 科技蓝#4A90D9 | 知识、效率类 |
| 清新自然 | 天空蓝#87CEEB + 暖橙#FFB347 | 旅行、美食类 |
| 高级灰调 | 莫兰迪色系 | 时尚、穿搭类 |

### 3.2 撞色设计

**标题撞色**：
- 黄底白边 + 蓝底白边 + 粉底白边
- 每段标题用不同底色
- 文字用白色+描边

## 四、构图法则

### 4.1 模块化布局

```
┌─────────────────────────┐
│      主标题区（撞色）      │
├─────────────┬───────────┤
│             │           │
│   左侧模块   │  右侧模块  │
│   （色块1）  │  （色块2） │
│             │           │
├─────────────┴───────────┤
│        结论/总结区        │
└─────────────────────────┘
```

### 4.2 卡通人物场景

**位置**：画面左侧或右侧，面向留白区
**动作**：与内容相关的动作（看书、打字、思考）
**比例**：占画面1/3-1/2

## 五、制作流程

### 5.1 素材准备

1. **生成卡通人物**：
   - 工具：搜狐简单AI / Midjourney
   - 提示词：`flat cartoon character, [描述], pastel colors, white background`

2. **生成场景元素**：
   - 工具：同上
   - 提示词：`flat illustration of [场景元素], minimalist, vector style`

3. **生成背景**：
   - 工具：同上或手动制作
   - 提示词：`grid paper background, subtle lines, pastel color`

### 5.2 合成制作

**工具选择**：
- **稿定设计**：搜索"小红书封面"模板，上传素材
- **Canva**：选择社交媒体尺寸，拖拽组合
- **醒图APP**：手机端快速合成

**步骤**：
1. 设置画布尺寸：1242×1660px（小红书封面）
2. 放置背景（网格/纯色）
3. 放置卡通人物和装饰元素
4. 添加撞色标题
5. 添加内容模块
6. 导出PNG
