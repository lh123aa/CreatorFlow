# 排版安全边距与文字占比控制

> 学习时间：2026-04-30
> 来源：CSS排版实战 + 小红书平台规范研究
> 解决什么问题：小红书封面底部被平台标签遮挡、文字占比过高缺乏呼吸感
> 可作为什么评估标准：内容完整展示率、视觉呼吸感、留白美学度

---

## 一、小红书平台安全边距规范

### 底部安全区（关键！）
小红书App底部有平台标签区域（约10%画面高度），封面底部内容会被遮挡。

### 解决方案
```css
.cover-container {
  /* 预留底部安全区 */
  padding-bottom: 10%;
  /* 或者使用固定值 */
  padding-bottom: 130px; /* 适用于1080高度图片 */
}

.cover-content {
  /* 内容区限制在上部90% */
  max-height: 90%;
  bottom: 65px; /* 约10%安全区 */
}
```

### 实际应用参数（基于1080x1440封面）
| 区域 | 像素值 | 占比 |
|------|--------|------|
| 顶部安全区 | 54px | 5% |
| 内容区 | 1260px | 87.5% |
| 底部安全区 | 126px | 8.75% |
| 平台标签区 | ~100px | ~7% |

## 二、文字占比控制原理

### 核心原则：留白即呼吸
- 文字占比控制在 **15-20%** 为最佳
- 超过30%会显得拥挤
- 低于10%信息量不足

### 测量方法
```
文字占比 = 文字区域像素数 / 总画面像素数 × 100%
```

### 视觉比例法则
| 法则 | 说明 | 应用 |
|------|------|------|
| 60-30-10法则 | 主色60%、辅助30%、点缀10% | 背景/文字/装饰色 |
| 黄金比例 | 1:1.618 | 内容区与装饰区划分 |
| 安全边距 | ≥10% | 四边留白 |

## 三、CSS实现文字占比控制

### 方法1：固定文字区域尺寸
```css
.text-area {
  /* 文字区域固定宽度 */
  max-width: 70%; /* 文字最多占70%宽度 */
  /* 文字区域高度 */
  max-height: 25%; /* 文字最多占25%高度 */
  /* 居中定位 */
  margin: auto;
  top: 50%;
  transform: translateY(-50%);
}
```

### 方法2：基于视口单位
```css
.text-content {
  /* 使用vw/vh单位响应式控制 */
  font-size: clamp(24px, 5vw, 48px);
  /* 文字块最大尺寸 */
  max-width: 80vw;
}
```

### 方法3：内边距撑开法
```css
.card {
  /* 大内边距 = 小文字区域 */
  padding: 15% 10%;
  /* 控制内容不要撑满 */
  max-width: 80%;
}
```

## 四、排版留白美学

### 留白的三个层次
| 层次 | 占比 | 作用 |
|------|------|------|
| 微留白 | 5-10% | 细节精致感 |
| 呼吸留白 | 15-25% | 视觉舒适感 |
| 大留白 | 30%+ | 极简高级感 |

### 小红书封面推荐：呼吸留白
- 文字区域占15-20%
- 装饰元素占10-15%
- 纯留白占65-75%

## 五、Auto-RedNote Skill 具体修改方案

### 当前问题
- 卡片占画面60%+，文字占比偏高
- 底部无安全区预留

### 修改参数
```css
/* 封面容器 */
.cover-inner {
  /* 预留底部安全区 */
  bottom: 65px; /* 原来是65px，需调整为130px */
  top: auto;
  /* 限制高度 */
  max-height: 1200px; /* 原来是1310px */
}

/* 文字区域 */
.text-block {
  /* 减小内边距 */
  padding: 8% 6%; /* 原来是12% 10% */
  /* 减小字体 */
  max-width: 85%; /* 原来是100% */
}

/* 标题 */
.main-title {
  font-size: clamp(28px, 6vw, 52px); /* 原来是clamp(36px, 8vw, 64px) */
}
```

### 修改前后对比
| 参数 | 修改前 | 修改后 | 效果 |
|------|--------|--------|------|
| 内容区高度 | 1310px | 1200px | 减少8.4% |
| 底部边距 | 65px | 130px | 增加100% |
| 文字内边距 | 12% | 8% | 减少33% |
| 标题字号 | 36-64px | 28-52px | 减少22% |

## 六、评估标准

### 排版质量评估表
| 维度 | 评分标准 | 权重 |
|------|----------|------|
| 内容完整展示 | 底部内容是否被遮挡 | 30% |
| 文字占比 | 是否在15-20%区间 | 25% |
| 视觉呼吸感 | 留白是否充足 | 25% |
