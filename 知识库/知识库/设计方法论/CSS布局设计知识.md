## 一、CSS Grid非对称布局

### 核心原理
**非对称网格的本质**：放弃自动排列，为每个 grid-item 单独设置 grid-row/grid-column 起止线。浏览器按你写的行号列号硬放，不校验重叠、留空或越界。

### 关键语法
```css
/* 手动控制每个格子位置 */
.item1 {
  grid-row: 2 / 4;      /* 从第2条横线到第4条横线 */
  grid-column: 1 / span 3;  /* 从第1列开始，跨3列 */
}

/* 用命名线提高可读性 */
.container {
  grid-template-columns: [start] 1fr [mid] 2fr [wide-end] 1fr;
}
.item {
  grid-column: start / wide-end;
}
```

### 设计原则
| 原则 | 说明 | 小红书应用 |
|------|------|-----------|
| 视觉权重 | 大/深色/高对比度 = 更重 | 标题区权重最高 |
| 负空间 | 留白引导视线，防止混乱 | 边缘留白呼吸感 |
| 层次 | 用z-index控制叠加 | 装饰元素叠加 |

### 实践要点
1. **避免 grid-auto-flow: dense** — 它只对自动放置生效，手动指定坐标后完全失效
2. **用 span 而非绝对终点** — `grid-column: 2 / span 2` 比 `grid-column: 2 / 4` 更鲁棒
3. **调试技巧** — 加 `outline: 1px solid red` 看网格线是否正确

## 二、黄金分割（三分法）

### 核心原理
把画面从上到下、从左到右划成三等分，四条线相交的四个点是"视觉甜蜜点"。

### 为什么有效
- **直觉层面**：人眼天然被交叉点吸引
- **行为层面**：符合F型浏览模式
- **美学层面**：非对称但平衡

### 在小红书封面中的应用
```
┌─────┬─────┬─────┐
│     │     │     │  ← 横线1 (1/3)
│     │  ●  │     │  ← 交叉点是焦点
├─────┼─────┼─────┤
│     │     │     │
│     │  ●  │     │  ← 主标题放这里
├─────┼─────┼─────┤
│     │     │     │  ← 横线2 (2/3)
│     │  ●  │     │
└─────┴─────┴─────┘
      ↑
   竖线位置
```

### 布局类型对比

| 布局类型 | 卡片位置 | 视觉重心 | 适合内容 |
|----------|----------|----------|----------|
| **center** | 顶部中央 | 上 | 简洁信息、快速阅读 |
| **diagonal** | 底部偏右 | 下 | 引导视线向下 |
| **asymmetric** | 右侧偏上 | 中右 | 打破常规、强调个性 |
| **thirds** | 黄金分割点 | 交叉点 | 视觉焦点明确 |
| **minimal** | 顶部小卡 | 上 | 极简风格 |

## 三、非对称布局vs黄金分割

### 非对称布局（Asymmetric）
- **特点**：打破平衡，追求动态感
- **适合**：创意内容、强调个性化
- **要点**：用grid-column/row手动控制位置

### 黄金分割布局（Thirds）
- **特点**：3x3网格，焦点明确
- **适合**：信息传递、焦点明确的内容
- **要点**：把关键元素放在交叉点

### 设计选择建议
```
内容类型 → 推荐布局
─────────────────────
故事叙述 → diagonal（引导视线）
干货清单 → center（快速扫描）
情感表达 → asymmetric（打破常规）
方法论/教程 → thirds（焦点清晰）
极简风格 → minimal（少即是多）
```

## 四、响应式布局策略

### PC端
- 坚持手动坐标 grid-row/grid-column
- 用 @container 做局部调整

### 移动端（小红书主要场景）
- 直接切回 `display: block` 或 `display: flex`
- 用 `order` 控制顺序
- 放弃位置精确性，换可维护性

### 混合策略
```css
/* 基础布局（PC） */
.card {
  grid-column: 2 / 4;
  grid-row: 1 / 3;
}

/* 移动端适配 */
@media (max-width: 768px) {
  .card {
    grid-column: 1 / -1;
    grid-row: auto;
  }
}
```

## 六、评估标准

### 布局差异化评分
| 维度 | 5分 | 4分 | 3分 | 2分 |
|------|-----|-----|-----|-----|
| 卡片位置差异 | 5种完全不同 | 4种不同 | 3种不同 | <3种 |
| 视觉重心分布 | 上中下均有 | 上中或中下 | 上中或中下 | 集中在某处 |
| 非对称感 | 明显有张力 | 略有张力 | 基本对称 | 完全对称 |

### 黄金分割应用评分
| 维度 | 达标 | 不达标 |
|------|------|--------|
| 焦点位置 | 主内容在交叉点附近 | 主内容偏离交叉点 |
| 视线引导 | 有明确引导路径 | 视线分散 |
