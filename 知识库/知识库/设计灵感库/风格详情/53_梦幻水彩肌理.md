# 梦幻水彩肌理

## 适用内容
- 季节主题、春夏秋冬
- 诗意浪漫、文艺内容
- 婚礼邀请、艺术沙龙
- 情感表达、心情随笔

## 背景提示词
```
Dreamy watercolor texture style, semi-transparent gradient colors with soft blending, natural feathered edges, layered translucent effect, hand-brushed watercolor strokes, petal-shaped color blocks, pink-orange-yellow-green-blue interweaving for spring, blue-pink-yellow for summer, flowing brush textures, calligraphy typography as visual center, delicate sans-serif supporting text, romantic poetic atmosphere
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 主标题 | 书法黑/粗黑 | #1F2937 |
| 英文 | 纤细无衬线 | #6B7280 |
| 春日背景 | 粉橙黄绿蓝渐变 | 多色 |
| 夏日背景 | 蓝粉黄渐变 | 多色 |
| 文字装饰 | 白色星光 | #FFFFFF |

## 装饰元素建议
- 半透明花瓣状色块
- 水波纹肌理
- 星光装饰
- 曲线分隔线
- 晕染边缘

## 注意事项
- 半透明叠加，自然晕染
- 书法字体+纤细英文形成对比
- 视觉中心聚焦式构图
- 保持通透感和梦幻氛围
