# 浮世绘松树风格

## 适用内容
- 东方美学、自然意境
- 茶文化、禅意空间
- 高端中式品牌
- 文化艺术内容

## 背景提示词
```
Ukiyo-e style pine tree illustration, layered blue-green color palette, gray-green sky with fine curling textures, multiple pine trees with twisted brown trunks and detailed bark texture, fan-shaped pine needle clusters in gradient from dark green to white, fine line work creating intricate textures, dense natural composition, serene oriental aesthetic, flat perspective with slight upward angle, traditional Japanese woodblock print influence
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 主标题 | 深墨绿 | #1E3A3A |
| 副标题 | 灰绿 | #6B8E8E |
| 背景 | 灰绿 | #A8C0C0 |
| 松针 | 墨绿-米白渐变 | #2D4A4A → #F5F5DC |
| 树干 | 深棕褐 | #5C4033 |

## 装饰元素建议
- 卷曲纹理云朵
- 松针团簇
- 虬曲枝干
- 纵向纹理树皮
- 坡面岩石

## 注意事项
- 线条精致繁复，层层叠叠
- 颜色从深到浅渐变
- 保持静谧雅致的东方意境
- 文字叠加要克制
