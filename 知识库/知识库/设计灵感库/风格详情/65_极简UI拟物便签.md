# 极简UI拟物便签

## 适用内容
- 极简清新、互动挑战
- 活动征集、话题引导
- 产品功能介绍
- 轻松有趣的互动内容

## 背景提示词
```
Minimalist UI skeuomorphic note style, deep green solid background, two layered rounded rectangle cards with offset shadow, bottom layer mint green with slight misalignment, top layer pure white with soft rounded corners simulating phone note interface, three light green dots as ellipsis icon at top-left, "Text Note" label at top-right, bold sans-serif black text centered with quotation marks, clean and fresh color contrast, light and fun interactive atmosphere
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 深绿 | #166534 |
| 卡片底层 | 薄荷绿 | #86EFAC |
| 卡片顶层 | 纯白 | #FFFFFF |
| 文字 | 纯黑 | #111827 |
| 装饰 | 浅绿 | #4ADE80 |

## 装饰元素建议
- 圆角矩形便签
- 三点省略号图标
- Text Note标签
- 细横线分隔

## 注意事项
- 居中对称构图
- 悬浮阴影感
- 深绿、浅绿、白清新撞色
- 模拟手机便签界面质感
