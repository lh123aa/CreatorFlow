# 网格式海报合集

## 适用内容
- 活动合集、多主题展示
- 作品集、设计展览
- 品牌形象、机构宣传
- 学院毕业展、艺术节

## 背景提示词
```
Grid layout poster collection style, dark gray background as base, 3x3 grid of individual posters with clean edges, each poster with distinct theme and color scheme, modern experimental graphic design, geometric shapes, bold typography, vibrant contrasting colors, strong visual order and matrix arrangement, diverse styles unified by grid structure
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 深灰 | #374151 |
| 各海报底 | 白/米白 | #FFFFFF/#FAFAF5 |
| 标题 | 黑粗体 | #111827 |
| 装饰 | 彩色撞色 | 多色 |

## 装饰元素建议
- 几何图形
- 渐变色块
- 手绘插画元素
- 排版文字组合
- 肌理质感

## 注意事项
- 3×3规整网格，形成秩序感
- 每张海报独立风格，整体统一
- 撞色搭配、几何元素
- 现代实验性设计语言
