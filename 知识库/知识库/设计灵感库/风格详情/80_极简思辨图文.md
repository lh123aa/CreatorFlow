# 极简思辨图文

## 适用内容
- 思辨文章、行业反思
- 焦虑表达、职业困惑
- AI冲击、时代变化
- 深度阅读、观点输出

```
Minimalist contemplative text poster, cream-white background with subtle texture, light green irregular abstract lines as decoration, large serif font title in deep green occupying upper half, dark gray body text in sans-serif with generous line spacing, left-aligned layout, hierarchical typography with size and color contrast, calm yet sharp reflective atmosphere, expressing anxiety about AI impact on professions
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 米白肌理 | #FFFBEB |
| 主标题 | 深绿衬线 | #166534 |
| 正文 | 深灰无衬线 | #374151 |
| 装饰线 | 淡绿手绘 | #86EFAC |

## 装饰元素建议
- 抽象手绘线条
- 细淡绿色边框线
- 段落标题编号

## 注意事项
- 垂直居中对称布局
- 标题字号远大于正文
- 行间距宽松
- 传递冷静克制的思辨氛围
- 适合深度内容、观点文章
