# 卡通圆角框堆叠

## 适用内容
- 萌宠卡通、人物合集
- IP形象展示
- 活泼可爱、年轻向
- 角色介绍、头像合集

## 背景提示词
```
Cartoon rounded frame stack style, pure light gray background, seven vertically stacked rounded rectangles with orange borders, each frame containing cute cartoon characters (chickens, cats, dogs, people), bright vivid colors, round and playful lines, various expressions (surprised, eating, angry, curious), cute萌系 aesthetic, cheerful and lively atmosphere,童趣 illustration style
```

- 圆角矩形框
- 萌宠卡通角色
- 人物头像
- 创意帽子/装饰

- 纵向堆叠排列

- 鲜艳活泼色调
- 充满童趣的萌系风格
