# 极简文字反思

## 适用内容
- 文字为主、反思内容
- 职业困惑、现实认知
- 冷静表达、尖锐观点
- 纯文字排版、极简主义


## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 米白微肌理 | #FAFAF5 |
| 主文字 | 深灰 | #374151 |
| 装饰 | 浅灰绿 | #86EFAC |

## 装饰元素建议
- 抽象线条装饰
- 箭头符号→
- 段落换行呼吸感

## 注意事项
- 左对齐排版逻辑
- 字号差异化设置层级
- 纵向线性构图
- 冷静克制却尖锐反思
- 适合纯文字深度内容
