### 3. 集成方案设计

**方案A：先生成背景图 → 再渲染卡片叠加**
```
1. 调用 image_generate() 生成水彩背景
2. 保存背景图到本地
3. 修改HTML模板，添加背景图路径
4. Playwright截图
```

**方案B：直接生成完整图片**
```
1. AI生图生成完整封面（背景+卡片）
2. 缺点：文字渲染控制差
```

**推荐方案A**，原因：
- 文字排版可控
- 背景和卡片分离，便于调整
- 复用现有HTML/CSS渲染逻辑

### 4. 装饰元素AI生成策略

**需要的装饰元素类型**：
- 花枝/叶片（配合主题色）
- 光斑/气泡
- 几何装饰（圆点、线条）

**生成方式**：
- 单独生成装饰元素PNG
- 使用CSS定位叠加到封面
- 保持透明度，与背景协调
