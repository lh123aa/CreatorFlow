## 一、2025年小红书ACE评分模型（CQS）

### 1.1 核心评分体系

| 指标 | 权重 | 标准 | 违规后果 |
|------|------|------|---------|
| **原创性** | 35-60% | ≥60% | 低于60%直接降权；AI生成内容需人工修改≥30%+标注"AI辅助创作"，否则限流50% |
| **信息密度** | 核心指标 | 每100字≥1个有效信息点 | 流水账式内容判定为"低质内容" |
| **实用性** | 重要指标 | 实用信息占比>40% | 推荐权重+20% |
| **专业深度** | 加分项 | 垂直领域专业内容+权威数据 | 获得额外流量倾斜 |

### 1.2 CES评分公式（互动权重）

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

**权重逻辑**：关注(8分) > 评论/转发(4分) > 点赞/收藏(1分)

**流量晋级门槛**：
| 流量池 | 曝光量 | CES要求 | 点击率要求 |
|--------|--------|---------|-----------|
| 冷启动池 | 200-500 | ≥600 | >5% |
| 初级池 | 5k-2万 | ≥1500 | >8% |

**黄金2小时法则**：发布后2小时内，高权重互动对流量增长推动最显著

## 二、封面设计6大类型规范

### 2.1 六大封面类型

| 类型 | 特征 | 适用场景 | 示例 |
|------|------|---------|------|
| **对比图型** | Before/After 冲突感 | 改造、效果展示 | "出租屋秒变ins风" |
| **新奇特型** | 反套路、意外元素 | 吸引眼球、差异化 | "被闺蜜追问100次的香水" |
| **文字为主型** | 居中大字标题 | 干货、方法论 | "3步搞定小红书定位" |
| **人物+标题型** | 人物展示"doing"状态 | 个人IP、生活方式 | "油皮打工人亲测" |
| **合集拼图型** | 左侧清单+右侧场景 | 教程、清单类 | "4款粉底液对比" |
| **场景氛围型** | 场景+情绪 | 生活、美学内容 | "周末早晨的阳光" |

### 2.2 视觉标准

| 标准 | 要求 |
|------|------|
| **比例** | 3:4比例（信息流最大曝光面积） |
| **高对比** | 色差>50%（深色背景+浅色字 或 反之） |
| **文字位置** | 画面上方1/3处 |
| **文字占比** | 15-20%（避免>50%被判定视觉杂乱） |
| **0.8秒法则** | 用户停留不足1.3秒，封面需在0.8秒内传递核心价值 |

## 三、2025年标签策略

### 3.1 标签数量标准

**最多5个标签**（原10-15个已过时）

### 3.2 标签组合公式

```
1个年度热点标签 + 2个精准词 + 2个圈层词
```

| 类型 | 说明 | 示例 |
|------|------|------|
| 年度热点标签 | 平台当前热门话题 | #AI副业 |
| 精准词 | 直接描述内容主题 | #中年人转型 |
| 圈层词 | 精准人群定位 | #副业探索 |

### 3.3 标签选择原则

- 避免泛标签（如#日常流量过亿）
- 贴合内容+适配账号定位
- 核心词置前，场景词断后
- 避免重复标签变形（如#护肤 vs #护肤心得视为同质）

## 四、金字塔结构正文写作

### 4.1 核心公式：先结论，后展开

```
顶层：核心结论（一句话结论先行）
中层：3-5个关键论点（支撑结论）
底层：证据与细节（数据、案例、方法）
```

### 4.2 小红书正文结构

```
开头：3秒留人（痛点共鸣 + 反常识断言 + 唯一性价值）
    ↓
中间：金字塔分段（核心结论→分点验证→细节佐证）
    ↓
结尾：可复刻动作指令（降低行动门槛）
```

### 4.3 关键词埋入：3-7-2法则

| 位置 | 要求 |
|------|------|
| 标题 | 出现1次主关键词，前8个汉字内 |
| 正文前100字 | 出现2次主关键词，1次与数字组合 |
| 全文 | 共出现7次主关键词，第3、5、7次位于段首句开头 |

### 4.4 排版规范

- 每段≤3行，段落之间空一行
- 每篇笔记≥600字（深度内容）
- 实用价值：≥3个具体信息点
