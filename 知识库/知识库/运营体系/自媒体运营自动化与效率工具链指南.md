```yaml

  角色: "你是一位资深自媒体主编，专注于[垂类]领域"
  
  能力要求:
    - 热点追踪: 实时监控微博/抖音/小红书热搜
    - 竞品分析: 分析同领域爆款选题规律
    - 用户洞察: 基于粉丝画像生成选题方向
    - 趋势预测: 预判未来1-2周热门话题
  
  输出格式:
    - 高热度选题（热度>80）: 3-5个
    - 中热度选题（热度60-80）: 5-8个
```

```python
        self.ai_auditor = AIAuditor()
        self.scheduler = Scheduler()
        self.dashboard = Dashboard()
    
    async def create_content_flow(self, topic: str, platform: Platform):
        """创建内容流程"""
        # 1. AI选题扩展
        expanded_topics = await self.ai_auditor.expand_topic(topic)
        
        # 2. AI生成初稿
        draft = await self.ai_auditor.generate_draft(
            topic=expanded_topics[0],
            platform=platform,
            persona=self.get_persona()
        )
        
        # 3. AI合规审核
        audit_result = await self.ai_auditor.audit(draft)
        if audit_result.risk_score > 80:
            raise ValueError(f"内容风险过高: {audit_result.risk_points}")
        
        # 4. 人工确认（异步）
        confirmed = await self.request_human_approval(draft)
        if not confirmed:
            return None
        
        # 5. 发布
        content = await self.publish_to_platform(draft, platform)
        
        # 6. 数据追踪
        await self.track_content_performance(content)
        
        return content
    
    async def batch_create_content(self, topics: List[str], platform: Platform):
        """批量创建内容"""
        tasks = [
            self.create_content_flow(topic, platform)
            for topic in topics
        ]
        return await asyncio.gather(*tasks)

class AIAuditor:
    """AI审核模块"""
    
    async def audit(self, content: Content) -> AuditResult:
        """审核内容"""
        risk_score = 0
        risk_points = []
        
        # 敏感词检测
        sensitive_words = await self.check_sensitive_words(content)
        if sensitive_words:
            risk_score += len(sensitive_words) * 10
            risk_points.extend(sensitive_words)
        
        # 违禁内容检测
        violations = await self.check_violations(content)
        if violations:
            risk_score += len(violations) * 20
            risk_points.extend(violations)
        
        # 版权检测
        copyright_issues = await self.check_copyright(content)
        if copyright_issues:
            risk_score += len(copyright_issues) * 15
            risk_points.extend(copyright_issues)
        
        return AuditResult(
            risk_score=risk_score,
            risk_points=risk_points,
            can_pass=risk_score < 80
        )
```

## 八、自动化ROI计算方法

### 8.1 ROI计算公式

```
┌─────────────────────────────────────────────────────────────┐
│                   自动化ROI计算公式                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ROI = (收益 - 成本) / 成本 × 100%                         │
│                                                             │
│  其中：                                                     │
│  收益 = 效率提升收益 + 质量提升收益 + 规模扩大收益           │
│  成本 = 工具成本 + 实施成本 + 维护成本 + 机会成本           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 8.2 收益计算

```yaml
# 自动化收益计算表

效率提升收益:
  公式: 时间节省 × 时薪价值
  
  示例场景:
    - 日均节省运营时间: 3小时
    - 时薪价值: 100元/小时
    - 年工作日: 250天
    - 年效率收益: 3 × 100 × 250 = 75,000元

质量提升收益:
  公式: (自动化后数据 - 自动化前数据) × 单位价值
  
  示例场景:
    - 违规率: 5% → 1%（下降4%）
    - 单次违规损失: 1,000元
    - 年发布次数: 500次
    - 年质量收益: 4% × 500 × 1,000 = 20,000元

规模扩大收益:
  公式: 新增产出 × 单位产出价值 - 新增成本
  
  示例场景:
    - 自动化后多管理账号: 5个
    - 单账号月产出: 3,000元
    - 年规模收益: 5 × 3,000 × 12 = 180,000元

总收益:
  效率收益 + 质量收益 + 规模收益
  = 75,000 + 20,000 + 180,000
  = 275,000元/年
```

### 8.3 成本计算

```yaml
# 自动化成本计算表

工具成本:
  订阅费用:
    - 内容创作AI: 500元/月 × 12 = 6,000元/年
    - 社群运营工具: 300元/月 × 12 = 3,600元/年
    - 数据监控工具: 800元/月 × 12 = 9,600元/年
    - 其他工具: 200元/月 × 12 = 2,400元/年
  合计: 21,600元/年

实施成本:
  - 初始配置: 5,000元（一次性）
  - 培训学习: 3,000元
  - 调试优化: 2,000元
  合计: 10,000元

维护成本:
  - 日常维护: 2小时/周 × 50元/小时 × 52周 = 5,200元/年
  - 问题修复: 1,000元/年（预估）
  - 版本更新: 1,500元/年
  合计: 7,700元/年

  - 实施期间无法做其他工作: 5,000元（预估）
  - 学习成本: 3,000元（预估）
  合计: 8,000元

```
