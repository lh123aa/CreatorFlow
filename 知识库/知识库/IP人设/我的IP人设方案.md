# IP人设方案：35岁转型者的英雄之路

> 基于荣格原型理论，为「35岁转型者+AI创业者」打造强共鸣人设

---

## 一、原型选择分析

### 1.1 六大原型匹配度对比

| 原型 | 匹配度 | 理由 | 风险 |
|------|--------|------|------|
| **英雄** | ★★★★★ | 35岁转型是天然的"英雄叙事"：起点困境→抗争→突破。"挑战100天，月入10万"本身就是英雄之旅的核心框架 | 可能显得太"鸡汤"，需要真实细节支撑 |
| **魔法师** | ★★★★☆ | Forge项目是"创造工具、改变规则"的典型魔法师行为；AI创业者身份天然契合"点石成金"的隐喻 | 魔法师原型单独使用缺乏情感温度 |
| **智者** | ★★★☆☆ | 有技术积累，但35岁转型期还不够"权威"，强行走智者路线容易显得空洞 | 可能被用户质疑"你自己都没转型成功，教什么" |
| **反叛者** | ★★★☆☆ | 35岁转型本身就是对"稳定是福"观念的挑战，有反叛基因 | 反叛者容易"得罪人"，不利于推广Forge商业产品 |
| **恋人** | ★★☆☆☆ | 共情陪伴不是用户的天然特质，强装会显得违和 | 性别和性格契合度低 |
| **照料者** | ★★☆☆☆ | 利他属性可借鉴（帮助开发者提效），但照料者过于"温柔"，不符合转型者的"战斗状态" | 定位模糊，缺乏攻击性 |

### 1.2 原型组合决策

**主原型：英雄** + **次原型：魔法师**

- **英雄**是叙事骨架：解决"为什么用户要关注你"的问题——因为你在做他们想做但不敢做的事
- **魔法师**是差异化锚点：解决"为什么是你而不是别人"的问题——因为你有Forge这个"魔法道具"

两者融合逻辑：英雄用 Forge 这个"魔法工具"完成自我突破，工具是英雄的武器，而非单纯展示技术能力。

## 二、人设定位

### 2.1 原型核心特质

**英雄原型核心特征：**
- 起点：平凡（或陷入困境）
- 动力：内心的召唤 + 外部的压力
- 过程：对抗恐惧、跨越障碍
- 结局：实现突破、获得成长
- 情感共鸣：让用户感到"我也可以"

**魔法师原型辅助特征：**
- 创造工具解决问题
- 带来惊喜和新可能
- 展示"不可思议"但可信的结果

### 2.2 身份标签（外在载体）

```
核心身份：「35岁，裸辞转型，正在证明自己」
辅助身份：「Forge智能代码插件开发者」
专业标签：「AI工具×创业实战」
状态标签：「Day X/100 · 月入10万挑战进行中」
```

### 2.3 目标人群

| 维度 | 描述 |
|------|------|
| **核心人群** | 28-40岁职场人，有转型/创业想法但缺乏行动力或方向 |
| **次要人群** | AI工具爱好者、技术创业者 |
| **共同特征** | 焦虑但渴望突破、关注真实成长故事、愿意为"效率工具"付费 |

### 2.4 核心情感诉求

| 用户痛点 | 英雄原型满足 | 解决方案 |
|----------|--------------|----------|
| "我都30多了，还能转型吗？" | 展示真实转型过程，证明年龄不是障碍 | 定期记录转型进度，不回避困难 |
| "看别人的成功故事，但自己做不到" | 用真实、不完美的过程建立代入感 | 展示失败、焦虑、反复，而不是只晒成果 |
| "想创业但不知道怎么开始" | 分享实战经验，提供可操作的路径 | Forge项目从0到1的全过程复盘 |
| "AI工具那么多，到底哪个有用" | 开发者亲自验证，用实际效果说话 | Forge的使用场景、效果数据 |

## 三、符号系统设计

### 3.1 视觉符号

#### 形象定位
- **穿搭风格**：商务休闲 + 技术感细节
  - 日常：简约高领毛衣/针织衫 + 深色直筒裤 + 手表
  - 出镜：白衬衫（挽袖子）+ 智能眼镜/耳机（技术感道具）
  - 禁止：西装领带（太正式）、大logo（像微商）
- **形象关键词**：成熟、真实、有战斗气息

#### 场景设计
- **主场景**：家庭书桌/工作室（真实、不装）
  - 元素：多屏工作台、Forge界面、咖啡杯、笔记本
  - 氛围：深夜/清晨的台灯光线（有叙事感）
- **副场景**：咖啡馆（偶尔外出工作）、技术分享场合

#### 道具/元素
- **核心道具**：Forge插件界面截图、项目进度看板
- **辅助道具**：
  - 倒计时日历（100天挑战可视化）
  - 写满计划的笔记本
  - 咖啡杯（稳定出镜，建立记忆点）

#### 色彩偏好
| 用途 | 主色 | 辅助色 | 点缀色 |
|------|------|--------|--------|
| 图片主调 | 深蓝/藏青（沉稳） | 暖白/米白（真实） | 橙/金色（突破、希望） |
| 数据/进度 | 科技蓝 | 渐变紫 | 红色（警示/紧急） |

#### 图片风格
- **整体风格**：水彩治愈风 + 叙事氛围感
  - 参考图片：`./用户上传/封面_1777388758469_0_x3n3.jpg`
  - 特点：柔和治愈、朦胧温柔、有情绪故事感
- **色调**：暖粉、浅橙、灰蓝为主色
- **质感**：水彩晕染效果、不追求写实
- **氛围**：静谧、舒缓、有电影感
- **构图**：平视偏侧中景视角，人物/场景为中心
- **元素**：雨滴、城市剪影、光影变化
- **禁止**：过度精修（失真）、纯产品截图（冷冰冰）、高饱和度浓烈色彩

### 3.2 语言符号

#### 口头禅/标志性表达
```
核心口头禅：
1. "35岁转型，我在证明这事儿能成"
2. "Day X/100，目标没变，方法在变"
3. "Forge不是炫技，是我踩过的坑"

辅助表达：
- "这坑我替你踩过了" （分享经验时）
- "说实话..." （建立真诚感）
- "从0到1，咱们一起" （号召行动）
```

#### 语言风格
| 维度 | 描述 |
|------|------|
| **语气** | 真诚、不装、有点倔但愿意认错 |
| **句式** | 短句为主，一句话说清楚一件事 |
| **态度** | 不跪舔用户、不高高在上，像个"已经出发、还在路上的同路人" |
| **敏感词** | 避免"暴富""躺赚""轻松"等字眼；用"实战""验证""一步一步" |

#### 互动方式
- **回复风格**：认真、有信息量、不敷衍
- **引导互动**：每篇结尾抛出问题，引导评论（如"你35岁敢转型吗？评论区聊聊"）
- **不做的互动**：不刷好评、不删负面评论（真实英雄不怕批评）

## 四、故事线设计

### 4.1 英雄之旅框架（主叙事线）

```
起点（平凡世界）：35岁，职场遇到天花板，想转型但不知道路在哪
    ↓
召唤（踏上旅程）：决定离开舒适区，押注AI创业
    ↓
第一道坎（遭遇困境）：转型初期的焦虑、怀疑、涨粉为0的打击
    ↓
Forge诞生（获得武器）：用技术积累打造工具，找到差异化方向
    ↓
100天挑战（跨越障碍）：用公开挑战倒逼自己，用透明进度建立信任
    ↓
进行中（待续...）：故事未完结，用户是见证者也是同行者
```

### 4.2 分支故事线

| 故事线 | 内容方向 | 作用 |
|--------|----------|------|
| **Forge进化史** | v1.0→v1.4.0的迭代过程、用户反馈、功能决策 | 展示产品力，建立技术信任 |
| **转型日记** | 100天挑战的真实记录，焦虑、失眠、反复 | 情感共鸣，让用户感到"不孤单" |
| **踩坑复盘** | 踩过的坑、犯过的错、得到的教训 | 实用价值，建立"过来人"权威 |
| **认知升级** | 转型过程中的思考、认知迭代 | 深度价值，吸引同频人 |

### 4.3 故事讲述原则

- **真实优先**：不编造故事，不粉饰失败
- **进度透明**：Day X公开打卡，用户是见证者
- **情绪起伏**：有焦虑有突破，不要全程"打鸡血"
- **留有悬念**：故事未完结，吸引持续关注

### 5.1 内容主题矩阵

| 主题类型 | 占比 | 内容方向 | 对应故事线 |

| **认知思考** | 15% | 转型方法论、AI工具趋势、个人成长 | 认知升级 |
| **互动话题** | 5% | 每周一次互动话题，引导评论 | 维持活跃 |

### 5.2 场景设计

#### 场景1：转型日记（Hero's Journey）
```
封面：Day X/100 + 一句话状态（如"失眠的第3天"）
正文结构：
- 今天的状态（真实情绪）
- 今天的进展（可量化）
- 今天的收获/踩坑（一个具体点）
- 明天计划（一个具体行动）
结尾：问用户一个问题
```

#### 场景2：Forge实战案例
```
封面：Before/After对比 或 效果数据
正文结构：
- 场景描述（什么情况下用了Forge）
- 具体操作（步骤可复制）
- 效果对比（数据说话）
- 对创业/转型的启发（升华）
结尾：引导试用/评论"你想用Forge解决什么问题"
```

#### 场景3：踩坑复盘
```
封面：踩坑标题 + 关键词（如"#产品定位坑"）
正文结构：
- 踩坑背景（什么时候、什么情况）
- 踩坑过程（具体发生了什么）
- 踩坑后果（损失了什么）
- 复盘结论（以后怎么做）
结尾：留一个问题（"你有没有踩过类似的坑？"）
```

### 5.4 与Forge项目的结合方式

| 结合方式 | 操作方法 | 注意事项 |
|----------|----------|----------|
| **故事融合** | 每个Forge内容都讲"为什么做这个功能"，不孤立展示产品 | 不要变成硬广 |
| **数据透明** | 公开Forge带来的效果（节省时间、效率提升等），用数据说话 | 不夸大，用真实用户反馈 |
| **场景还原** | 用真实工作场景展示Forge的使用，不摆拍 | 真实>精致 |
| **时机选择** | 重大进展时（里程碑用户、重大更新）才发Forge内容，平时保持人设 | 克制发布频率 |
| **CTA设计** | 结尾引导试用，但换着说法："想少踩我踩过的坑？→用Forge" | 不重复同一句话 |

## 六、人设一致性检查清单

### 6.1 符合英雄原型的事

| 行为 | 说明 |
|------|------|
| ✅ 公开100天挑战进度 | 英雄需要公开的考验，用户是见证者 |
| ✅ 展示不完美的过程 | 焦虑、失眠、反复都是英雄之旅的必要元素 |
| ✅ 面对批评和质疑 | 英雄不逃避，用行动回应 |
| ✅ 承担转型失败的风险 | 真实承诺，不是"试试看" |
| ✅ 帮助同行者 | 分享踩坑经验，扶持同路人 |
| ✅ 用Forge解决实际问题 | 工具是英雄的武器，不是炫技道具 |

### 6.2 破坏英雄原型的事

| 行为 | 风险 | 替代方案 |
|------|------|----------|
| ❌ 只晒成果，不展示过程 | 显得假，用户无法代入 | 每个成果都配上"怎么来的" |
| ❌ 用"暴富""躺赚"等字眼 | 英雄是奋斗者，不是收割者 | 用"实战""一步一步""验证中" |
| ❌ 删除负面评论 | 英雄不怕批评，删除显得心虚 | 认真回复，转化为信任机会 |
| ❌ 过度包装人设（摆拍、精修） | 英雄不需要滤镜，真实才有力量 | 用接近真人状态的图片风格 |
| ❌ 突然切换到不相关领域 | 原型漂移会让用户困惑 | 坚守"35岁转型"主线 |
| ❌ 强蹭热点、跟风话题 | 英雄有自己的节奏 | 选择与转型相关的热点才跟进 |
| ❌ 长时间断更 | 英雄之旅需要持续前进 | 哪怕一句话也保持更新节奏 |
| ❌ 与用户对立、嘲讽 | 英雄是同行者，不是高高在上的导师 | 平等交流，尊重用户 |

### 6.3 符合魔法师原型的事

| 行为 | 说明 |
|------|------|
| ✅ 展示Forge带来的"不可思议"效果 | 魔法师用魔法改变现实 |
| ✅ 解决别人解决不了的问题 | Forge的核心价值 |
| ✅ 不断迭代、创造新可能 | 魔法师的进化能力 |
| ✅ 用技术降低门槛 | 好的工具让人人都能"施魔法" |

### 6.4 破坏魔法师原型的事

| 行为 | 风险 | 替代方案 |
|------|------|----------|
| ❌ 只展示技术原理，不展示效果 | 魔法师的价值是改变，不是解释 | 每个技术内容都配效果展示 |
| ❌ 夸大功能、过度承诺 | 魔法要可信，不是玄学 | 实事求是，用数据支撑 |
| ❌ 把Forge当成唯一身份 | 魔法师是人，不是工具 | 人设在前，产品在后 |

## 七、执行原则

### 7.1 核心原则

1. **真实 > 完美**：宁可展示真实的焦虑，也不发完美但假的内容
2. **过程 > 结果**：每个结果都讲过程，用户关注的是"你怎么做到的"
3. **人设 > 产品**：先让人记住你是谁，再让人知道你在做什么
4. **克制 > 刷屏**：宁可少发一篇，也要保证质量

### 7.2 每日检查清单（发布前）

```
□ 内容是否围绕"35岁转型"主线？
□ 是否有真实细节（情绪、场景、数字）？
□ 语言是否用了口头禅/标志性表达？
□ 图片风格是否统一（色调、场景）？
□ 是否避免了敏感词（暴富、躺赚等）？
□ 结尾是否引导互动（问题/CTA）？
□ 是否符合英雄/魔法师原型人设？
□ 内容是否直接或间接关联Forge？
□ 是否有信息量（对用户有用）？
```

### 7.3 长期维护

| 维度 | 建议 |
|------|------|
| **人设深化** | 从"个人逆袭"延伸到"帮助更多人转型"，英雄升级为"引路人" |
| **原型进化** | 魔法师从"展示工具"进化到"展示用工具改变的可能性" |
| **内容沉淀** | 定期整理精华内容，形成"转型手册"等系列 |
| **数据复盘** | 每30天复盘：哪些内容涨粉？哪些互动高？人设是否稳定？ |
