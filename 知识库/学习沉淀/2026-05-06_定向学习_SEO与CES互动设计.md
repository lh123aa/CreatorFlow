## 一、SEO×小红书搜索流量方法论

### 核心认知
- **70%用户**在小红书有主动搜索行为
- **搜索流量转化率**是推荐流量的**3倍**
- 2026年算法更新：搜索权重向"关键词密度+互动增速"双指标倾斜

### KFS模型（KOL/KOC/KOS + Feeds + Search）
| 组成部分 | 说明 |
|---------|------|
| KOL/KOC/KOS | 关键意见领袖/消费者/销售者 |
| Feeds | 信息流广告，放大内容覆盖 |
| Search | 搜索广告，拦截高意向用户 |

### 关键词布局策略
```
标题前8字 = 地域词/痛点词 + 核心关键词
正文前100字 = 出现2次主关键词
全文 = 共出现7次主关键词（标题1次+前100字2次+段首2次+结尾2次）
```

### 长尾词矩阵
| 类型 | 示例 | 作用 |
|------|------|------|
| 产品词 | AI副业、副业工具 | 核心定位 |
| 场景词 | 中年转型、职场危机 | 精准人群 |
| 痛点词 | 时间不够、35岁焦虑 | 触发搜索 |

### 搜索优化执行清单
- [ ] 标题必须包含1-2个长尾关键词
- [ ] 正文前100字重复主关键词

- [ ] 搜索流量占比目标：从自然流量的15%提升到40%+

## 二、2026年CES社区互动评分体系

### CES公式（2026年更新）
```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

> ⚠️ 2026年更新：评论和关注的算法价值远超点赞和收藏

### 流量池晋级阈值
| 层级 | CES阈值 | 曝光量 | 考核周期 |
|------|---------|--------|----------|
| 种子池(L1) | 无门槛 | 200-500 | 发布即得 |
| 二级池(L2) | ≥50分 | 1000-3000 | 4-6小时 |
| 三级池(L3) | ≥200分 | 1万-3万 | 12-24小时 |
| 四级池(L4) | ≥1000分 | 10万-30万 | 24-72小时 |
| 五级池(L5) | ≥5000分 | 100万+ | 72小时+ |

### 2026年算法新重点
1. **用户停留时长** > 纯数据堆砌
2. **评论热度** > 点赞数量
3. **原创声明红利**：声明后初始流量池提升50%
4. **新粉互动率**：关注带来的质量比数量更重要

### 互动引导话术设计
```
评论区引导：
- "你遇到过类似情况吗？评论区聊聊"
- "有疑问的评论区见~"

收藏引导：
- "建议收藏备用，实践出真知"
- "先收藏，总会用到的"

关注引导：
- "关注我，持续更新XX干货"
- "下期分享XX技巧，点关注不迷路"
```

## 三、标题字数新标准

### 硬性限制（2025年确认）
| 字符类型 | 计法 | 最大数量 |
|----------|------|---------|
| 中文/日文/韩文 | 2单位/字 | **20字** |
| 英文/数字/ASCII | 1单位/字 | 40字符 |

> ⚠️ 小红书API限制：40单位（硬限制），超长会被拒绝

### 黄金字数区间
- **最优**：10-18字（用户读完不疲劳）
- **硬限制**：≤20字（必须遵守）
- **危险区**：19-20字（已接近极限）

### 标题结构公式
```
情绪词(1-3字) + 痛点/场景(4-6字) + 悬念/数字(4-6字) + 行动指令(可选)
```

### 标题避坑清单
- [ ] 不用感叹号超过2个
- [ ] 不用"震惊"、"必看"等标题党词汇
- [ ] **不超过20字**（小红书硬限制）
- [ ] 不使用【标题】等结构标签
- [ ] 不使用与内容不符的标题

## 四、AI内容合规规范（2025年强制）

### 强制要求
| 要求 | 违规后果 |
|------|---------|
| 必须标注"AI辅助创作" | 限流50% |
| 人工修改比例≥30% | 触发原创度检测 |
| 原创度≥60% | 进入优质创作者池 |

### 声明位置与格式
```markdown
建议位置1（开头）：
"【AI辅助创作】本文分享XX经验..."

建议位置2（结尾）：
"本内容由AI辅助整理，原创观点欢迎讨论~"
```

### 原创度提升方法
1. 加入个人真实经历和感受
2. 修改AI生成的套话和过渡语
3. 添加只有你知道的细节/案例
4. 重新组织语言表达方式
