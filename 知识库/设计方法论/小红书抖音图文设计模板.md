## 1. 研究背景与目标

### 1.1 研究背景

在社交媒体时代，图文内容是吸引用户注意力的第一道门槛。小红书和抖音作为两大核心内容平台，其图文设计有共性也有差异：

| 维度 | 小红书 | 抖音 |
|------|--------|------|
| 核心形态 | 图文 + 短视频 | 短视频为主，图文为辅 |
| 用户决策时间 | 1-3秒 | 0.5-1秒 |
| 内容调性 | 种草、攻略、真实感 | 娱乐、冲击、情绪化 |
| 图文比例 | 6-9张图/笔记 | 3-9张图/图文内容 |

### 1.2 研究目标

1. **提炼设计规律**：从高赞案例中归纳排版、配色、字体的通用法则
2. **建立模板体系**：设计3-5套可复用的图文模板
3. **优化AI工作流**：建立提示词模板库，提升生成效率
4. **统一视觉风格**：制定设计规范，确保内容系列化

## 2. 平台特性分析

### 2.1 小红书图文生态

**用户行为特征：**
- 平均停留时间：3秒决定是否点击
- 强视觉导向：封面决定点击率
- 注重实用价值与审美统一性
- 排斥硬广感过强的设计

**算法偏好：**
- 完读率高的笔记获得更多推荐
- 搜索流量占总曝光41%
- 首图必须真人实拍或高质量素材

### 2.2 抖音图文生态

**用户行为特征：**
- 竖屏沉浸式浏览
- 决策时间更短（0.5秒）
- 强娱乐性、情绪化内容更受欢迎

**图文内容定位：**
- 主要用于视频封面引导
- 纯图文内容偏资讯、知识类
- 需要更强的视觉冲击力

## 3. 优秀案例分析

### 3.1 小红书高赞封面类型

通过对小红书高赞图文的分析，归纳出以下8种主流封面类型：

| 类型 | 特征 | 适用场景 | 点击率 |
|------|------|----------|--------|
| **数字封面** | 大数字+痛点+结果 | 干货教程、合集 | 高 |
| **对比封面** | Before/After分屏 | 测评、蜕变记录 | 最高 |
| **钩子封面** | 强情绪问句或断言 | 痛点共鸣类 | 高 |
| **留白封面** | 极简构图、信息精炼 | 高端、文艺内容 | 中高 |
| **深色封面** | 深色背景+荧光字 | 科技、时尚内容 | 中高 |
| **人像封面** | 真人出镜+表情 | 美妆、穿搭、生活 | 高 |
| **拼图封面** | 多图组合展示 | 合集、攻略 | 中 |
| **文字封面** | 纯文字为主 | 观点、语录类 | 中 |

### 3.2 典型案例描述

#### 案例1：知识干货类
- **特征**：白底/浅灰底 + 大号黑体标题 + 副标题说明 + 截图/数据图
- **布局**：上方1/3放标题，主体区放内容图，底部留白
- **配色**：主色白/灰，辅助深灰，强调色科技蓝或橙色
- **字体**：标题80-120px，副标题40-60px，正文24-36px

#### 案例2：生活种草类
- **特征**：真人/产品实拍 + 暖色调 + 生活场景
- **布局**：人物居中偏下，面部朝向留白区；或产品居中配文字标签
- **配色**：莫兰迪色系或暖橙/粉色系
- **字体**：手写体或圆润字体，点击率更高

#### 案例3：科技数码类
- **特征**：深色背景 + 荧光色文字 + 科技纹理
- **布局**：信息图式排版，数字突出
- **配色**：深蓝/深紫背景 + 蓝紫渐变 + 荧光绿/青色高光
- **字体**：黑体为主，数字加粗加大

### 3.3 视觉元素使用规律

| 元素类型 | 使用频率 | 注意事项 |
|----------|----------|----------|
| emoji | 高频 | 每段1-2个，风格统一，避免堆砌 |
| 色块 | 高频 | 用于强调和分区，尺寸适中 |
| 分割线 | 中频 | 区分内容板块，常用emoji串或符号线 |
| 装饰图标 | 中频 | 风格统一，与内容主题相关 |
| 数字标注 | 高频 | 数字加粗放大，制造记忆点 |

## 4. 设计规律总结

### 4.1 排版核心原则

#### 原则一：视觉层级清晰
- 主标题：最大字号，视觉焦点
- 副标题/说明：中等字号，辅助信息
- 正文：较小字号，详细内容
- 标注/标签：最小字号，补充说明

#### 原则二：三段式呼吸排版
```
首段：痛点钩子 + emoji + 短句
中段：核心内容 + 对比图/步骤图
尾段：总结 + 互动引导
```
段落间留白1行，避免文字堆砌。

#### 原则三：留白适度
- 文案与图片间留1-2行空白
- 标题与正文间留1行空白
- 视觉呼吸感强，用户停留时间提升40%

#### 原则四：图文比例协调
- 3-4张图配适量文案
- 图文比例控制在1:1或2:3
- 避免图片太多或文案太少

### 4.2 配色系统

#### 主色调选择
| 内容类型 | 推荐主色 | 强调色 |
|----------|----------|--------|
| 知识干货 | 白色/浅灰 #FFFFFF/#F5F5F5 | 科技蓝 #4A90D9 |
| 生活种草 | 暖粉/米白 #FFF5F0/#FAF7F2 | 珊瑚橘 #FF6B6B |
| 科技数码 | 深灰/深蓝 #2D2D2D/#1A1A2E | 荧光绿 #00D4AA |
| 美食探店 | 暖黄/奶油白 #FFF8E7/#FFFEF0 | 橙红 #FF7043 |
| 时尚穿搭 | 黑白灰为主 | 品牌色点缀 |
| 旅行攻略 | 天空蓝/自然绿 #87CEEB/#90EE90 | 暖橙 #FFB347 |

#### 配色禁忌
- 同一画面不超过3种主色
- 避免高饱和度对比色直接碰撞（红+绿、蓝+橙）
- 文字与背景必须保证高对比度

### 4.3 字体规范

#### 推荐字体
| 用途 | 推荐字体 | 版权状态 |
|------|----------|----------|
| 标题 | 阿里巴巴普惠体 Bold | 免费商用 |
| 副标题 | 思源黑体 Medium | 免费商用 |
| 正文 | 思源黑体 Regular | 免费商用 |
| 手写/文艺 | 站酷快乐体/手写体 | 免费商用 |
| 装饰 | 霞鹜文楷 | 开源免费 |

#### 字号层级
| 层级 | 用途 | 字号范围 | 占图片宽度 |
|------|------|----------|------------|
| 主标题 | 核心信息 | 80-120px | 40-50% |
| 副标题 | 补充说明 | 40-60px | 20-30% |
| 正文 | 详细内容 | 24-36px | - |
| 标注 | 备注来源 | 16-20px | - |

#### 字体使用原则
- 单张图最多使用2-3种字体（含不同字重）
- 手写体点击率高38%，但科技内容适合黑体
- **必须确认字体免费商用授权**

### 4.4 构图法则

#### 黄金构图
- 主体置于画面黄金分割线（右侧1/3处）
- 面部朝向左侧留白区，制造视觉引导

#### 常用构图方式
| 构图 | 适用场景 | 特点 |
|------|----------|------|
| 中心构图 | 产品展示、人物特写 | 聚焦精准 |
| 对角线构图 | 动态场景、引导视线 | 有动感 |
| 上下分割 | 对比展示 | 信息丰富 |
| 左右对称 | 前后对比 | 直观清晰 |
| Z字型构图 | 文字较多内容 | 符合阅读习惯 |

### 4.5 安全区域

- **顶部安全区**：预留100px，避免被平台UI遮挡
- **底部安全区**：预留150px，留给标题文字
- **中心区域**：放置核心信息，避免边缘
- **人物面部**：头部上方预留15%空间

### 模板一：极简信息图（知识干货类）

**适用场景**：学习笔记、考研干货、时间管理、技能教程

│  │      内容主体区域        │    │
│  │    （截图/数据图/步骤图）│    │
│  │                         │    │
│  └─────────────────────────┘    │
│                                 │
│     ┌──┐  ┌──┐  ┌──┐  ┌──┐     │
│     │01│  │02│  │03│  │04│     │
│     └──┘  └──┘  └──┘  └──┘     │
│                                 │
│  ┌─────────────────────────┐    │
│  │     互动引导文案        │    │

└─────────────────────────────────┘
```

**配色方案**：
- 背景：#FFFFFF 或 #F8F8F8
- 主文字：#2D2D2D
- 强调色：#4A90D9（科技蓝）
- 点缀色：#FF6B35（橙色）

**字体规范**：
- 标题：阿里巴巴普惠体 Bold 80-100px
- 正文：思源黑体 Regular 28-32px

**提示词模板**：
```

右侧对应的图标和简短说明。顶部粗体标题"核心技能清单"。

## 7. 提示词模板库

### 7.1 通用提示词结构

**万能公式**：
```
主体 + 场景/环境 + 光线/氛围 + 风格 + 构图 + 画质参数
```

**避坑指南**：
- ❌ 避免抽象词："高级感"、"唯美"、"好看"
- ✅ 使用具象词："暖光"、"木桌"、"清晰可见"
- ✅ 控制在20-50词

## 8. 设计规范速查表

### 8.1 小红书图文规范

| 项目 | 规范值 |
|------|--------|
| 封面尺寸 | 1242×1660 px（3:4竖版） |
| 内容图尺寸 | 1080×1440 px |
| 主标题字数 | 3-7字 |
| 主标题字号 | ≥80px |
| 封面总字数 | ≤15字 |
| 配图数量 | 6-9张（含封面） |
| 字体 | 阿里巴巴普惠体 Bold（标题）+ 思源黑体（正文） |
| 安全留白 | 顶部100px、底部150px |

### 8.2 抖音图文规范

| 项目 | 规范值 |
|------|--------|
| 封面尺寸 | 1080×1920 px（9:16） |
| 图文内容尺寸 | 1080×1080 px（1:1） |
| 文字位置 | 底部1/3区域 |
| 文字字号 | ≥25px可读性最佳 |
| 强调方式 | 高对比度或描边 |

### 8.3 通用设计原则

```
1. 简洁：每张图只传达1个核心信息
2. 对比：深色背景配浅色字 / 浅色背景配深色字
3. 层级：3-4种字号创造视觉层次
4. 留白：适当呼吸感，避免拥挤
5. 一致：全篇同比例、同色调、同字体
```
