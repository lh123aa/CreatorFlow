# 法式复古甜酷风拼贴

## 适用内容
- 派对邀请、婚礼请柬
- 浪漫主题、女生节内容
- 复古美学分享
- 甜蜜活动推广

```
French vintage sweet-cool collage style, low saturation dusty pink background, torn paper edge texture revealing blue-gray grid paper underneath, layered visual effect, retro journal aesthetic, asymmetric vertical collage composition, lace decorative frames, vintage brass key with pink-white gingham ribbon, wax seal envelope, vintage royal carriage illustration with gold floral decorations, warm yellow vintage architecture scene, pearl decorations, hand-lettered typography, romantic yet playful atmosphere, detailed collage elements with handcrafted warmth
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 主标题 | 深灰棕 | #4A4238 |
| 副标题 | 玫瑰红 | #B87878 |
| 装饰文字 | 金色 | #C9A86C |
| 背景 | 豆沙粉 | #E8D4C4 |
| 网格纸层 | 浅蓝灰 | #D4DCDC |

## 装饰元素建议
- 撕纸边缘肌理
- 蕾丝镂空装饰框
- 复古黄铜钥匙 + 格纹丝带
- 火漆印信封
- 金色椭圆浮雕画框
- 珍珠缠绕装饰
- 复古马车插画
- 心形吊牌

## 注意事项
- 采用纵向分割的不对称拼贴构图
- 保持手作拼贴的温度感
- 复古元素与俏皮酷感结合
- 撕纸边缘要有毛糙质感
- 文字用手写衬线体更有味道
