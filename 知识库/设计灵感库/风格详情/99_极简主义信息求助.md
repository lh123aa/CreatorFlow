# 极简主义信息求助

## 适用内容
- 求助信息、问题咨询
- 务实理性、信息传达
- 社交求助、付费服务
- 简洁清晰、功能导向

## 背景提示词
```
Minimalist information help poster, cream-white matte paper texture with fine grain, soft light gray diagonal shadows creating subtle layers, centered black Song typeface text, blue underline under key phrases for emphasis, small date text at top corners, clean functional design, practical rational atmosphere, information as absolute visual focus
```

## 文字配色方案
| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 米白肌理 | #FFFBEB |
| 主文字 | 黑色宋体 | #111827 |
| 强调下划线 | 蓝色 | #3B82F6 |
| 日期 | 小号黑字 | #374151 |

## 装饰元素建议
- 柔和斜向光影
- 蓝色细下划线强调
- 日期角标

## 注意事项
- 居中对称构图
- 信息为绝对视觉焦点
- 蓝色下划线突出关键词
- 务实理性的求助氛围
- 适合求助信息、付费服务
