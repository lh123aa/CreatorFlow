## 二、新增学习任务：自媒体运营

### 2.1 任务设计

**任务名称**：每日自媒体运营学习
**学习时长**：5-10分钟/天
**学习内容**：

| 模块 | 学习重点 | 预计周期 |
|------|----------|----------|
| 发布计划 | 发布时间、频率、节奏 | 持续积累 |
| 数据分析 | 各平台指标含义、判断标准 | 持续积累 |
| 账号运营 | 账号定位、人设、互动技巧 | 持续积累 |
| 热点追踪 | 如何借势、热点发现 | 持续积累 |
| 竞品分析 | 同行账号、爆款拆解 | 持续积累 |

### 2.2 学习流程

```
1. 搜索当日运营相关内容（小红书运营、抖音运营等）
2. 找1-2个有价值案例或知识点
3. 提取可复用的方法/模板
4. 更新到知识库
```

### 2.3 产出存储

- 文件路径：`./知识库/运营规范/运营知识库.md`
- 每天积累1个知识点或案例

**文件路径**：`./知识库/运营规范/数据记录.md`

**单篇数据记录**：

```markdown

- 收藏数：

- 点赞率：点赞/阅读
- 收藏率：收藏/阅读

### 数据解读
- 表现：优秀/良好/一般/较差
- 原因分析：
- 可复用经验：

### 评论亮点

```

### 5.2 数据判断标准（待运营学习后补充）

| 指标 | 优秀 | 良好 | 一般 | 较差 |

| 点赞率 | >5% | 3-5% | 1-3% | <1% |
| 收藏率 | >8% | 5-8% | 2-5% | <2% |
| 互动率 | >10% | 6-10% | 3-6% | <3% |

## 九、闭环验证

完整闭环：

```
学习（创作+运营）→ 知识库 → 创作流程 → 内容库存 → 内容日历 → 发布 → 数据记录 → 复盘 → 调整发布策略
      ↑                                                                                    |
      └──────────────────────────────── 知识体系补充 ←─────────────────────────────────────┘
```

两条线清晰：
- **数据反馈 → 调整发布策略**（运营闭环）
- **知识缺口 → 调整学习方向**（学习闭环）
