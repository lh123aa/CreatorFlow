# 主题分析模板

> 在创作之前，先对主题进行分析，确定应该应用哪些知识模块。

---

## 一、主题分析框架

### 步骤1：主题核心解析

```
主题：________________________

核心内容是什么？（用1-2句话概括）
→ ________________________

目标受众是谁？
→ ________________________

受众痛点是什么？
→ ________________________

希望达到什么效果？
→ 种草 / 干货 / 情感共鸣 / 认知刷新 / 行动转化
```

### 步骤2：内容调性判断

| 维度 | 选项 | 本次选择 |
|------|------|---------|
| **内容类型** | 干货分享 / 产品种草 / 情感故事 / 认知刷新 / 案例分析 | |
| **情绪基调** | 专业权威 / 亲切分享 / 震撼颠覆 / 温暖治愈 / 犀利吐槽 | |
| **表达风格** | 逻辑推导 / 故事叙述 / 清单罗列 / 对话问答 | |
| **内容深度** | 入门科普 / 进阶技巧 / 深度分析 / 行业洞察 | |

### 步骤3：知识模块匹配

□ 情绪共鸣型 → 能触发情感共鸣

## 三、主题分析示例

### 示例主题：AI Agent的自我进化能力

**步骤1：主题核心解析**
```
核心内容：AI Agent如何通过记忆、技能、迭代实现自我进化
目标受众：对AI感兴趣的开发者/创业者/效率工具使用者
受众痛点：AI用完就忘，每次都从零开始，没有积累
希望达到的效果：认知刷新 + 实用价值
```

**步骤2：内容调性判断**
```
内容类型：干货分享 + 认知刷新
情绪基调：专业权威 + 震撼颠覆
表达风格：逻辑推导
内容深度：进阶技巧
```

**步骤3：知识模块匹配**
```
选题类型：信息差型 + 认知刷新型
理由：反常识观点"AI不是一次性的"，刷新"用完就忘"的认知

标题类型：反常识型 + 数字型
理由："90%的人用AI都是一次性的"有颠覆性，可加数字增强可信度

正文结构：爆款万能结构
理由：痛点明确（AI没记忆）→ 价值输出（四层架构）→ 细节拆解

钩子类型：痛点暴击 + 颠覆认知
理由：开头直接点痛点，再用反常识抓住注意力
```

**步骤4：知识加载清单**
```
需要加载：
✓ 选题模板库 → 确认信息差型公式
✓ 标题模板库 → 确认反常识型公式
✓ 正文模板库 → 确认爆款万能结构
✓ 钩子文案规范 → 确认痛点暴击公式
```

## 五、与现有系统的连接

```
                    ┌──────────────┐
                    │   确定主题    │
                    └──────┬───────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│                  主题分析（本模板）                         │
│  - 输入：主题内容                                         │
│  - 处理：分析框架判断                                      │
│  - 输出：知识加载清单                                      │
└──────────────────────────────────────────────────────────┘
                           ↓
                    ┌──────────────┐
                    │  知识索引.md  │ ← 确认模块路径
                    └──────┬───────┘
                           ↓
                    ┌──────────────┐
                    │ 精确加载知识  │ ← 只加载分析结果指定的模块
                    └──────┬───────┘
                           ↓
                    ┌──────────────┐
                    │   套用创作    │
                    └──────────────┘
```

**关键连接点**：
1. 主题分析 → 输出知识加载清单
2. 知识加载清单 → 指引读取知识索引
3. 知识索引 → 提供模块路径
4. 精确加载 → 只读取需要的模块
