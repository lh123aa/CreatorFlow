## 二、标签选择方法

### 2.1 小红书标签规则

#### 基础规则（2025年9月更新）
- **单篇笔记最多添加8个标签**
- 标签是连接内容与用户的核心纽带，直接影响算法推荐

#### 标签选择策略

**【70-30法则】**
- 70%精准长尾词 + 30%热门流量词

**标签组合公式**：
```
1个核心流量词 + 2-3个精准长尾词 + 1-2个场景词 + 1-2个人群词 + 1个品牌/IP词
```

#### 各类型标签选择

| 标签类型 | 示例 | 作用 |
|----------|------|------|
| 核心流量词 | #穿搭 #护肤 | 吸引泛流量 |
| 精准长尾词 | #黄皮显白口红 #小个子显高穿搭 | 精准触达目标用户 |
| 场景词 | #通勤穿搭 #约会妆容 #露营必备 | 场景化获流 |
| 人群词 | #职场新人 #学生党 #宝妈 | 定向人群覆盖 |
| 品牌词 | #优衣库 #完美日记 | 品牌关联流量 |

#### 标签选择步骤

1. **竞品分析**：搜索同类型爆款笔记，记录高频标签
2. **关键词库建立**：核心词+长尾词各50个以上
3. **每篇标题包含2-3个关键词**
4. **结合热度与精准度选择**：
   - 高热度+高相关 = 必选
   - 低热度+高相关 = 优先选（竞争小）
   - 高热度+低相关 = 慎选

#### 常见错误
- ❌ 标签与内容毫不相关
- ❌ 全部使用热门大词（竞争激烈，难以突围）
- ❌ 标签数量过多或过少

### 2.2 抖音标签规则

#### 标签类型与选择

| 标签类型 | 说明 | 示例 |
|----------|------|------|
| 行业标签 | 垂直领域核心标签 | #美妆 #穿搭 #健身 |
| 产品标签 | 具体产品/品牌 | #某品牌气垫 #某型号手机 |
| 人群标签 | 目标受众定位 | #职场女性 #学生党 |
| 场景标签 | 使用场景 | #办公室穿搭 #宿舍好物 |
| 热点标签 | 平台热门话题 | #挑战赛 #节日热点 |
| 地域标签 | 区域定向 | #北京美食 #上海探店 |

#### 标签选择原则

**【三层标签法】**
```
第一层（1个）：核心行业大词
第二层（2-3个）：细分领域词
第三层（1-2个）：场景/人群词
```

#### 流量标签获取方法

1. **抖音搜索框下拉词**：输入核心词获取联想词
2. **创作者服务中心**：查看热点词排行榜
3. **竞品视频标签**：分析同类爆款视频使用标签
4. **趋势榜单**：关注抖音热榜、挑战榜

#### 实操步骤

1. 标题前10字嵌入行业通用搜索词（如"减脂食谱"优于"我的晚餐"）
2. 描述第一行嵌入2-3个精准长尾词
3. 添加3-5个精准话题标签
4. 利用POI地址增加本地流量

## 三、互动引导话术

### 3.1 小红书评论引导话术

#### 【置顶说明体】（发布后立即自评）

**目的**：主动补充信息、预判问题、设置话题

**模板**：
```
【置顶】统一回复大家最关心的3个问题：
1.链接在橱窗
2.身高165/体重50kg
3.拍摄设备是iPhone
也想知道，你们觉得图3和图6哪套搭配更适合通勤？
```

#### 【引导提问体】（文末/评论区）

**开放式问题**：
- "你们最想看哪款测评？评论区告诉我！"
- "大家在生活中有遇到过类似情况吗？"
- "这款产品你们用过吗？来聊聊使用感受~"

**选择题式**：
- "你更喜欢A款还是B款？"
- "这套适合通勤还是约会？黄皮能驾驭这个色号吗？"
- "早餐选哪个？A.豆浆油条 B.牛奶麦片"

**福利诱导**：
- "评论区抽3位粉丝送同款！"
- "点赞+收藏+评论，抽取5位送小样"

#### 【精准夸夸体】（回复用户评论）

**目的**：让用户感到被看见、被理解

**句式**：
- "姐妹你好懂！当时我也……（简短分享细节），感觉找到组织了！"
- "完全说出了我的心声！"
- "Hi~你晒的对比图太有说服力啦！"

#### 【趣味接梗体】（回复常见问题）

**目的**：把枯燥问答趣味化

**句式**：
- 用户问"链接呢？"→ "链接在飞奔来的路上，快接住！"
- 用户问"求教程"→ "教程已安排，关注不迷路~"
- 用户说"太实用了"→ "收藏起来用的时候就不怕找不到啦！"

#### 【共情承接体】（回复情绪类评论）

**句式**：
- "真的懂这种疲惫感…其实第12天才转折点，坚持住！"
- "谢谢你分享！这个问题困扰很多人呢"
- "感谢反馈，这款确实偏油皮友好，干皮建议做好打底"

#### 【延展引导体】（回复后抛新话题）

**句式**：
- "下期专门讲修复节奏，关注不迷路~"
- "已记入下期隐藏款合集，蹲到更新记得来看！"
- "评论区揪出真相！这句话错在哪？"

### 3.2 抖音评论引导话术

#### 视频内口播引导

**点赞引导**：
- "看到这里的你，能给我点个小红心吗？"
- "觉得这期有用的点个赞，让我知道！"

**评论引导**：
- "你们用过哪些好用的？评论区说说"
- "你们最想看哪期？评论最多的安排"
- "你选A还是B？评论区告诉我"

**关注引导**：
- "关注我，每天分享______"
- "想看后续的，点个关注不迷路"

#### 评论区置顶引导

**互动问题型**：
- "你们觉得这个方法靠谱吗？"
- "你们还有哪些好用的？评论区补充"

**争议话题型**：
- "有人说_______，你同意吗？"
- "我觉得_______，但有人不认同，你觉得呢？"

**资料引流型**：
- "想要【资料名称】的，评论区扣'想要'，私信发给你"

#### 回复技巧

1. **前5条评论务必回复**：影响算法二次推荐
2. **用问题回复问题**：引导用户继续互动
3. **及时回复**：2小时内响应最佳
4. **避免万能回复**：不用"谢谢"、"嗯嗯"等敷衍

## 五、数据验证方法

### 小红书
1. 创作者中心 → 数据中心 → 粉丝 → 活跃时间
2. 提取近30天粉丝在线高峰曲线
3. 重点关注重合度>70%的时间段

### 抖音
1. 创作者服务中心 → 数据中心 → 粉丝数据 → 活跃时间段
2. 观察三线交汇：粉丝在线人数、内容互动率、直播观看率

### A/B测试方法
1. 同类型内容，在早8:30、午12:45、晚21:00三个时段测试
2. 间隔3-5天，记录每篇发布后2小时内互动率
3. 连续测试2-3周，确定专属峰值
