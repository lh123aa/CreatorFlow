## 一、直播前准备SOP

### 1.1 选品策略

#### 选品维度评估表

| 维度 | 权重 | 评估标准 | 数据来源 |
|------|------|----------|----------|
| 佣金率 | 20% | >30%为优质 | 平台后台/联盟计划 |
| 产品力 | 25% | 差异化卖点明确 | 用户调研/竞品分析 |
| 供应链 | 20% | 库存稳定/发货快 | 供应商评估 |
| 市场需求 | 20% | 搜索量增长趋势 | 百度指数/平台热词 |
| 客单价适配 | 15% | 与粉丝消费力匹配 | 历史订单数据 |

#### 引流款/利润款/形象款配置

```
直播选品金字塔：
         【形象款】
        客单价最高
        树立品牌调性
        占比5-10%
       
      【利润款】      【引流款】
    贡献主要利润      吸引流量
    占比60-70%      占比20-30%
    品质稳定/复购高   高性价比/限时
```

#### 选品节奏规划

| 阶段 | 时长 | 选品数量 | 策略重点 |
|------|------|----------|----------|
| 引流期 | 前30分钟 | 2-3款 | 高性价比/强需求 |
| 爆款期 | 30-90分钟 | 3-5款 | 主推利润款 |
| 平滑期 | 90分钟后 | 穿插进行 | 维持热度 |
| 收尾期 | 最后30分钟 | 1-2款 | 限时/限量 |

## 二、直播中运营SOP

### 2.1 开场标准流程

#### 开场黄金5分钟

| 时间点 | 动作 | 话术要点 |
|--------|------|----------|
| 0-1分钟 | 欢迎语+互动 | "欢迎XXX进入直播间，新进来的扣个1" |
| 1-2分钟 | 本场预告 | "今天给大家准备了XX福利，错过等一周" |
| 2-3分钟 | 建立信任 | "我是XX，专注XX领域X年" |
| 3-4分钟 | 互动拉停留 | "刷666的宝宝等下有福袋" |
| 4-5分钟 | 引出第一款 | "好，我们先上第一款..." |

#### 提升留存率的技巧

1. **前30秒定生死**
   - 禁止长时间感谢进入
   - 立即抛出本期最大亮点
   
2. **3分钟留人大法**
   - "进来的宝宝等下整点抽免单"
   - "先别走，5分钟后上王炸福利"

3. **评论区互动**
   - 念出用户名+感谢
   - 回应弹幕问题
   - 设置互动话题

### 2.2 直播节奏把控

#### 节奏黄金法则

```
开场 (0-10分钟): 低客单价 → 引流款
           ↓
中期 (10-60分钟): 主推款循环 → 利润款
           ↓
后期 (60-90分钟): 组合套餐 → 逼单
           ↓
收尾 (最后10分钟): 限量秒杀 → 下场预告
```

#### 憋单与放单技巧

**憋单流程**:
```
引出产品 → 讲解价值 → 揭示价格 → 制造稀缺 → 倒计时放单
   ↓          ↓          ↓          ↓           ↓
 吸引注意    建立认知   冲击认知    紧迫感      成交
```

**憋单话术模板**:
> "这款产品官方价299，今天直播间给你们砍到99！"
> "但是今天库存只有500单，抢完恢复原价"
> "想要的直接扣1，我看看有多少人想要！"
> "好，3、2、1，上链接！"

### 2.3 互动技巧大全

#### 弹幕互动话术

| 场景 | 话术模板 |
|------|----------|
| 欢迎入场 | "欢迎XX（昵称）来到直播间，新朋友点个关注" |
| 引导评论 | "觉得主播讲得好的扣666" |
| 回应问题 | "XX问的这个XXX问题特别好，我给大家解释一下" |
| 催单互动 | "想要这款的扣想要，不要犹豫！" |
| 感谢打赏 | "感谢XX的火箭/嘉年华，爱你哟" |

#### 福袋设置策略

| 福袋类型 | 设置时间 | 时长 | 目的 |
|----------|----------|------|------|
| 开场福袋 | 开播前5分钟 | 5-10分钟 | 拉留存 |
| 整点福袋 | 每小时整点 | 3-5分钟 | 维持热度 |
| 促单福袋 | 上链接前 | 1-3分钟 | 提高转化 |
| 收尾福袋 | 下播前 | 10分钟 | 引流下期 |

### 2.4 数据实时监控

#### 关键数据监控表

| 指标 | 监控频率 | 预警阈值 | 应对措施 |
|------|----------|----------|----------|
| 在线人数 | 每分钟 | 下降20%/5分钟 | 调整话术/发福袋 |
| 互动率 | 每10分钟 | <5% | 加强互动话术 |
| 商品点击率 | 每5分钟 | <15% | 调整产品讲解 |
| 转化率 | 每10分钟 | <3% | 优化促单话术 |
| GPM | 每30分钟 | 低于目标20% | 调整货品组合 |

#### 数据预警应对

| 场景 | 表现 | 应对策略 |
|------|------|----------|
| 在线下降 | 人数持续下滑 | 发福袋+憋单+调整讲解节奏 |
| 互动低迷 | 评论减少 | 提问互动+抽奖+调整话术 |
| 转化低 | 点击高但成交少 | 强化价值/增加赠品/限时逼单 |
| 退货激增 | 售后问题增多 | 调整选品/优化讲解话术 |

## 四、各平台直播规则差异

### 4.1 抖音直播

#### 平台特性

| 特性 | 说明 |
|------|------|
| 算法核心 | 实时流量池赛马，5分钟数据决定推流 |
| 流量来源 | 推荐页为主(60-70%)，关注页为辅 |
| 特色功能 | 小店/橱窗/购物车全链路 |
| 变现方式 | 带货佣金/打赏/星图广告 |

#### 2026年最新规则

| 规则类型 | 具体要求 | 违规处罚 |
|----------|----------|----------|
| 带货权限 | 粉丝≥1000或完成实名认证 | 无权限不能带货 |
| 虚假宣传 | 不得夸大功效/虚构原价 | 扣分/限流/封号 |
| 最低价承诺 | 全网最低价声明需有依据 | 违规下架 |
| 极限词禁用 | 第一/顶级/最佳等禁用 | 警告/扣分 |
| 婴幼儿用品 | 需提供资质证明 | 下架/封号 |

#### 抖音直播技巧

1. **黄金30秒**: 前30秒决定80%流量走向
2. **憋单技巧**: 制造稀缺感，3秒内放单
3. **付费联动**: 千川投放+自然流量协同
4. **粉丝维护**: 关注页曝光为主

### 4.2 快手直播

#### 平台特性

| 特性 | 说明 |
|------|------|
| 算法核心 | 老铁关系链，私域流量权重高(70%+) |
| 流量来源 | 关注页为主(70%+)，同城/发现辅助 |
| 特色功能 | 磁力引擎/聚星/快手小店 |
| 变现方式 | 直播带货/打赏/磁力金牛 |

#### 快手直播技巧

1. **关系运营**: 强化主播与粉丝的情感连接
2. **家族文化**: 可加入家族获取流量扶持
3. **老铁经济**: 强调真实/接地气/信任感
4. **磁力引擎**: 粉条加热提升直播间人气
5. **内容节奏**: 慢热型，粉丝粘性>流量

### 4.3 视频号直播

#### 平台特性

| 特性 | 说明 |
|------|------|
| 算法核心 | 社交推荐55%+算法推荐45% |
| 流量来源 | 朋友圈/社群/公众号联动 |
| 特色功能 | 私域撬动公域，微信生态闭环 |
| 变现方式 | 小程序/商品分销/广告 |

#### 视频号直播技巧

1. **私域激活**: 直播前社群/公众号预热预约
2. **朋友圈裂变**: 分享至朋友圈获取社交推荐
3. **连麦互动**: 增加直播间活跃度
4. **公众号联动**: 直播预告/回顾文章
5. **微信小店**: 无需资质，支持分销

### 4.4 小红书直播

#### 平台特性

| 特性 | 说明 |
|------|------|
| 算法核心 | 笔记内容质量+互动数据 |
| 流量来源 | 发现页为主，搜索辅助 |
| 特色功能 | 买手电商/品牌合作/探店 |
| 变现方式 | 带货佣金/品牌合作/知识付费 |

#### 小红书直播技巧

1. **笔记预热**: 直播前发布预告笔记
2. **颜值经济**: 画面精美，场景精致
3. **买手属性**: 种草属性强，真实分享
4. **客单价**: 相对较高，注重品质
5. **互动氛围**: 营造闺蜜分享感

### 4.5 B站直播

#### 平台特性

| 特性 | 说明 |
|------|------|
| 算法核心 | 内容质量+用户兴趣匹配 |
| 流量来源 | 推荐页+关注页+搜索 |
| 特色功能 | 充电/醒目留言/弹幕文化 |
| 变现方式 | 充电/直播签约/广告/带货 |

#### B站直播技巧

1. **社区氛围**: 重视弹幕互动和社区文化
2. **内容垂直**: 强内容属性，垂直深耕


## 八、直播数据指标体系

### 8.1 核心指标定义

#### 流量指标

| 指标 | 定义 | 计算公式 | 行业均值 |
|------|------|----------|----------|
| 场观 | 累计观看人数 | 去重UV | 品类差异大 |
| 人均观看 | 平均观看时长 | 总时长/场观 | 1-3分钟 |
| 峰值在线 | 同时在线最高 | 实时统计 | 平均在线5-10倍 |
| 新增关注 | 直播新增粉丝 | 直播关注数 | 场观1-3% |
| 互动率 | 互动用户占比 | (评论+点赞)/场观 | 5-15% |

#### 转化指标

| 指标 | 定义 | 计算公式 | 优秀值 |
|------|------|----------|--------|
| 曝光-点击率 | 商品曝光点击率 | 点击/曝光 | >20% |
| 点击-成交率 | GPV转化率 | 成交数/点击 | >10% |
| 成交转化率 | 整体成交转化 | 成交人数/场观 | >3% |
| GPM | 千次观看成交额 | GMV/场观×1000 | 品类基准 |
| 客单价 | 单笔订单金额 | GMV/订单数 | 品类均值1.5倍 |

#### 效率指标

| 指标 | 定义 | 计算公式 | 优化方向 |
|------|------|----------|----------|
| 时均GMV | 每小时成交额 | GMV/直播时长 | 稳定高效 |
| 人效 | 每UV贡献GMV | GMV/场观 | 提升客单/转化 |
| 退货率 | 退款订单占比 | 退款数/订单数 | <品类均值 |
| 好评率 | 售后好评占比 | 好评数/评价数 | >95% |

### 8.3 数据分析维度

#### 横向对比分析

| 对比维度 | 分析内容 | 目的 |
|----------|----------|------|
| 历史对比 | 本场vs上一场 | 趋势判断 |
| 同行对比 | vs同类账号均值 | 竞争力评估 |
| 目标对比 | vs设定KPI | 完成度评估 |

#### 纵向拆解分析

```yaml
GMV拆解:
  GMV = 流量 × 转化率 × 客单价
  
流量拆解:
  流量 = 直播场观 × 人均观看时长
  
转化拆解:
  转化 = 商品曝光 × 点击率 × 成交率
  
客单拆解:
  客单 = 单品购买 × 组合购买 × 加购
```

#### 归因分析

| 问题类型 | 表现 | 归因方向 | 优化策略 |
|----------|------|----------|----------|
| 流量低 | 场观不足 | 预热不足/权重下降 | 优化预热/付费投放 |
| 留存差 | 在线下降快 | 内容不够吸引 | 优化话术/增加互动 |
| 转化低 | 点击多成交少 | 价格/价值不匹配 | 强化价值/调整价格 |
| 客单低 | 转化高GMV低 | 产品结构问题 | 调整选品/组合销售 |
