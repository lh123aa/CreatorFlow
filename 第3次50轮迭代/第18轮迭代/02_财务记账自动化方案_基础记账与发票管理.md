## 五、多币种管理

### 5.1 汇率处理

**多币种收入**：
```yaml
常见币种:
  • USD (美元) - 主要结算货币
  • CNY (人民币) - 部分中国品牌
  • EUR (欧元) - 欧洲品牌
  • QAR (卡塔尔里亚尔) - 本地业务
  
汇率来源:
  • Google搜索"USD to CNY"
  • XE.com实时汇率
  • 银行结汇汇率
```

**汇率记录表**：
```markdown
## 汇率记录表

| 日期 | 货币对 | 汇率 | 来源 |
|------|--------|------|------|
| 01/15 | USD/CNY | 7.25 | Google |
| 01/15 | USD/EUR | 0.92 | Google |
| 01/15 | USD/QAR | 3.64 | Google |
```

### 5.2 换算规则

**统一折算原则**：
```
记账货币: USD

收入折算:
  USD收入 → 直接记录
  CNY收入 → 按当日汇率折算
  EUR收入 → 按当日汇率折算
  
支出折算:
  同上
  
月末调整:
  汇率波动超过2% → 重新评估
  大额应收应付 → 按期末汇率调整
```

## 六、实战配置

### 6.1 记账系统起步

**工具选择**：
```yaml
方案A: 轻量级（免费）
  • Google Sheets 记账表
  • Notion 发票管理
  • 每月手工汇总

方案B: 中级（$0-50/月）
  • Wave (免费记账软件)
  • Notion 发票管理
  • 部分自动化

方案C: 专业级（$50+/月）
  • QuickBooks
  • 发票自动化
  • 税务报表
```

### 6.2 月度记账流程

```
每月1日:
□ 导出上月银行账单
□ 整理PayPal/Wise账单
□ 记录所有订阅支出
□ 核对品牌合作收款
□ 更新汇率

每月5日:
□ 完成上月记账
□ 生成月度报表
□ 分析收支情况
□ 备份数据

每月末:
□ 规划下月支出预算
□ 检查发票完整性
□ 准备季度报表（如需要）
```
