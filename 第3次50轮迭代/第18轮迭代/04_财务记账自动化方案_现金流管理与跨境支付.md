## 一、现金流管理

### 1.1 现金流的重要性

**为什么关注现金流**：
```
┌─────────────────────────────────────────────────────────┐
│              现金流vs利润                                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  利润: 收入 - 支出 = 账面盈利                           │
│                                                         │
│  现金流: 实际到账的钱 ≠ 利润                            │
│                                                         │
│  常见情况:                                              │
│  • 利润$5000，但$3000还未到账                          │
│  • 实际可支配现金不足                                    │
│                                                         │
│  风险:                                                  │
│  • 收入延迟导致无法支付账单                             │
│  • 大量应收账款无法回收                                 │
│  • 税务到期却发现没钱                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 三、跨境支付管理

### 3.1 跨境支付渠道

**常用支付工具对比**：
```yaml
PayPal:
  优点: 普及率高、即时到账
  缺点: 手续费较高(4%+)
  适用: 欧美品牌合作

Wise (原TransferWise):
  优点: 手续费低、汇率好
  缺点: 到账稍慢
  适用: 多币种收付

Gumroad:
  优点: 专为创作者设计
  缺点: 主要美元结算
  适用: 数字产品销售

Stripe:
  优点: 支付体验好
  缺点: 注册复杂
  适用: 独立站销售

本地银行:
  优点: 安全
  缺点: 手续费高、限制多
  适用: 大额结算
```

### 3.2 费用优化策略

**手续费节省技巧**：
```yaml
PayPal优化:
  • 大额支付协商低费率
  • 及时提现避免累积
  • 选择合适提现方式

Wise优化:
  • 开通多币种账户
  • 汇率高时换汇
  • 使用Wise卡消费

综合策略:
  • 小额用PayPal（方便）
  • 大额用Wise（省钱）
  • 长期持有用Wise换汇
```

## 五、风险管理

### 5.1 财务风险识别

**常见财务风险**：
```yaml
收款风险:
  • 品牌方拖延付款
  • 汇率波动损失
  • 账户被冻结

支出风险:
  • 订阅自动续费未注意
  • 汇率损失
  • 超预算消费

系统风险:
  • 支付平台故障
  • 账户被盗
  • 记录丢失
```

### 5.2 风险应对策略

**预防措施**：
```
□ 预收款: 大额项目要求预付款
□ 合同: 明确付款条款和期限
□ 记录: 完整保存所有交易记录
□ 分散: 不要只用单一支付方式
□ 备份: 财务数据多重备份
□ 保险: 考虑商业保险（如有）
```
