## 二、报表自动化生成

### 2.1 Google Sheets公式

**自动汇总公式**：
```excel
=SUMIF('每日记录'!B:B,"流量变现",'每日记录'!F:F)
' 按类型汇总收入

=SUMIFS('支出记录'!F:F,'支出记录'!A:A,">=2024-01-01",'支出记录'!A:A,"<=2024-01-31")
' 按日期范围汇总支出

=AVERAGEIF('每日记录'!B:B,"流量变现",'每日记录'!H:H)
' 计算平均单价
```

### 2.2 月报自动生成

**自动化工作流**：
```
触发: 每月1日 08:00
     ↓
Step 1: 汇总上月收入数据
Step 2: 汇总上月支出数据
Step 3: 计算利润指标
Step 4: 对比上月数据
Step 5: 生成环比变化
Step 6: 创建Notion月报记录
Step 7: 发送邮件报告
```

## 三、税务管理（卡塔尔）

### 3.1 卡塔尔税务概览

**税务环境**：
```yaml
卡塔尔税务优势:
  ✅ 无个人所得税
  ✅ 无企业所得税
  ✅ 无增值税（VAT）
  
需注意:
  ⚠️ 跨境业务可能涉及他国税务
  ⚠️ 居住地申报要求
  ⚠️ 跨境支付合规
```

### 3.2 跨境税务考虑

**常见情况**：
```yaml
美国来源收入:
  - 如果是美国税务居民 → 需申报美国税
  - 非美国税务居民 → 通常预扣税后无需额外申报

中国来源收入:
  - 中国税务居民（183天规则）→ 需申报
  - 非中国税务居民 → 通常无需申报

其他国家:
  - 根据当地法规判断
  - 建议咨询专业税务顾问
```

### 3.3 记录保存要求

**财务记录保存**：
```yaml
建议保存年限:
  • 收入记录: 7年
  • 支出发票: 7年
  • 合同协议: 永久
  • 银行对账单: 5年
  • 税务申报: 7年

备份要求:
  • 本地备份 + 云端备份
  • 定期（比如每月）备份
  • 纸质原件 + 电子扫描件
```

## 四、预算管理

### 4.1 收入预算

**收入预算制定**：
```yaml
预算制定方法:
  1. 历史数据分析
     - 近3-6个月平均收入
     - 增长趋势预测
     
  2. 目标倒推
     - 年收入目标 ÷ 12 = 月目标
     - 考虑季节性波动
     
  3. 保守估计
     - 预期收入的80%作为基准
     - 预留缓冲空间

示例:
  上半年月均: $2000
  增长预期: 每月+10%
  保守系数: 0.8
  
  7月预算: $2000 × 1.1 × 0.8 = $1760
  8月预算: $2000 × 1.1² × 0.8 = $1936
```

## 五、财务分析

### 5.1 盈利能力分析

**关键盈利指标**：
```yaml
利润率:
  利润率 = 净利润 / 收入 × 100%
  优秀: >60%
  良好: 40-60%
  一般: 20-40%
  需改进: <20%

人均产出:
  月产出 = 月收入
  年产出 = 月收入 × 12
  
时间价值:
  时薪价值 = 月收入 / 月工作小时
  目标: >$50/小时
```
