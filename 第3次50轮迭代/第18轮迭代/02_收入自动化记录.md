# 收入自动化记录

## 前言

自动化收入记录可以减少人工操作，提高准确性。本指南提供收入自动化记录方案。

---

## 第一部分：收入来源识别

### 1.1 主要来源

**YouTube/Google AdSense**

- 月度结算
- 自动打款
- 需要手动记录

**TikTok Creator Fund**

- 定期结算
- 需手动记录

**联盟营销平台**

- Amazon Associates
- ShareASale
- 各联盟平台

### 1.2 品牌合作收入

- 一次性收款
- 分期收款
- 里程碑收款

---

## 第二部分：自动化记录方案

### 2.1 Payoneer收入自动记录

**Zapier模板**

```
触发：Payoneer新收款
执行：
1. 获取收款详情
2. 写入Google Sheets
3. 计算QAR金额
4. 发送通知
```

### 2.2 PayPal收入自动记录

```
触发：PayPal新收款
执行：
1. 获取收款信息
2. 写入财务表
3. 发送确认
```

## 第四部分：对账流程

### 4.1 定期对账

**每周对账**

- 核对收款记录
- 确认账户余额
- 识别差异

### 4.2 差异处理

- 汇率差异
- 手续费扣除
- 平台抽成

---

## 总结

建立自动化的收入记录系统，减少手动操作，提高准确性。
