│                                                         │

## 二、内容存档自动化模板

### 2.1 YouTube视频存档工作流

**模板名称**：YouTube视频自动备份

**工作流逻辑**：
```
触发条件：YouTube新视频发布
         ↓
Step 1: 获取视频详情（标题、描述、标签、缩略图URL）
         ↓
Step 2: 在Notion数据库创建记录
         ↓
Step 3: 下载缩略图到Google Drive
         ↓
Step 4: 发送通知到Slack/邮件
         ↓
Step 5: 更新内容日历
```

**Zapier配置详情**：
```
App: YouTube
Trigger: New Video In Channel

App: Notion
Action: Create Database Item
  - Title: {{Title}}
  - URL: {{Video URL}}
  - Published Date: {{Published Date}}
  - Thumbnail: {{Thumbnail URL}}
  - Duration: {{Duration}}
  - Status: "待整理"

App: Google Drive
Action: Download File
  - URL: {{Thumbnail URL}}
  - Folder: /YouTube Thumbnails/YYYY-MM/

App: Email (Gmail)
Action: Send Email
  - To: 自己邮箱
  - Subject: 新视频发布 - {{Title}}
  - Body: {{Video URL}}
```

### 2.2 社交媒体内容存档工作流

## 三、内容创作辅助工作流

### 3.1 选题灵感收集工作流

**模板名称**：热点话题自动追踪

**工作流逻辑**：
```
触发条件：每天早上8:00 GMT+3
         ↓
Step 1: 搜索Twitter/Reddit热门话题
         ↓
Step 2: 筛选与创作领域相关的热点
         ↓
Step 3: 创建Notion灵感记录
         ↓
Step 4: 发送今日热点摘要邮件
         ↓
Step 5: 在Slack/群组分享
```

**提示词模板**：
```markdown
## 每日热点分析提示词

你是一位专注于[你的领域]的内容创作者。
请分析以下热点话题，找出与我的领域相关的切入点：

热点话题：[粘贴热点]
我的创作领域：[你的定位]

请输出：
1. 关联分析：为什么这个热点与我的领域相关
2. 内容角度：3个可能的创作角度
3. 差异化点：如何从独特视角切入
4. 快速响应：24小时内可以发布的内容形式
```

### 3.2 视频脚本辅助工作流

**模板名称**：AI辅助脚本生成

**工作流配置**：
```
Step 1: Notion中创建脚本需求记录
        ↓
Step 2: 触发ChatGPT API生成初稿
        ↓
Step 3: 保存脚本到Notion
        ↓
Step 4: 发送通知
```

**ChatGPT提示词模板**：
```markdown
角色：你是一位专业的内容创作者，擅长制作[你的内容类型]视频。

任务：为我的下一个视频撰写脚本

主题：[粘贴你的视频主题]
时长：约[分钟]分钟
风格：[幽默/专业/亲切/严肃]

要求：
1. 开头：5秒黄金钩子，吸引观众
2. 中间：逻辑清晰，信息丰富
3. 结尾：Call to Action

格式：
- 时间戳标注
- 镜头说明
- 台词内容
- B-roll建议
```

## 四、内容发布自动化模板

### 4.1 多平台同步发布工作流

**模板名称**：一键多平台分发

**支持的平台组合**：
```
方案A: YouTube → TikTok + Instagram Reels
方案B: 主平台 → 5个平台同步
方案C: 定制化多平台组合
```

**工作流配置（YouTube优先）**：
```
触发：YouTube新视频发布
     ↓
等待：视频处理完成（30分钟）
     ↓
Step 1: 下载视频到本地
Step 2: 使用CapCut处理成竖屏版本
Step 3: 发布到TikTok
Step 4: 发布到Instagram Reels
Step 5: 创建YouTube Shorts
Step 6: 更新Notion发布记录
Step 7: 发送完成通知
```

### 4.2 定时发布管理工作流

**模板名称**：智能定时发布

**策略配置**：
```yaml
发布策略:
  多哈时间 → 目标受众时间映射:
    09:00 GST → 东亚晚间 21:00 CST
    12:00 GST → 中东下午
    15:00 GST → 欧洲上午
    21:00 GST → 美洲下午

  平台适配:
    TikTok: 多哈09:00, 15:00, 21:00
    Instagram: 多哈10:00, 16:00
    YouTube: 多哈08:00 (优先)
```

## 六、实战案例：多哈华人博主工作流

### 案例：科技评测博主自动化实践

**背景**：
- 定位：科技产品评测（主要面向中东）
- 频率：每周3条视频
- 痛点：多平台管理太耗时

**自动化工作流配置**：
```
内容创作流程：
├── 选题：Notion灵感库 → ChatGPT辅助分析
├── 脚本：Notion → ChatGPT生成 → 手动优化
├── 视频：本地剪辑 → 自动存档Google Drive
└── 发布：Buffer排队 → Zapier同步到各平台

数据追踪流程：
├── 日报：RescueTime自动记录
├── 周报：Zapier自动生成
└── 月报：手动深度分析
```

**效率提升数据**：
| 环节 | 优化前 | 优化后 | 节省 |
|------|--------|--------|------|
| 存档整理 | 2h/周 | 0 | 2h |
| 数据收集 | 1.5h/周 | 10min | 1.3h |
| 多平台发布 | 3h/周 | 0 | 3h |
| 灵感收集 | 2h/周 | 30min | 1.5h |
| **总计** | **8.5h/周** | **40min/周** | **7.7h** |

## 八、模板使用指南

### 8.1 模板导入步骤

```
Step 1: 注册/登录Zapier
Step 2: 点击"Create Zap"
Step 3: 搜索并选择触发应用
Step 4: 配置触发条件
Step 5: 添加第一个Action
Step 6: 配置Action参数
Step 7: 测试工作流
Step 8: 开启并监控
```

### 8.2 常见问题解决

| 问题 | 解决方案 |
|------|----------|
| API权限不足 | 检查应用授权设置 |
| 数据格式错误 | 添加Formatter步骤处理 |
| 触发延迟 | 调整轮询频率或使用Webhook |
| 步骤失败 | 添加Filter条件过滤 |
