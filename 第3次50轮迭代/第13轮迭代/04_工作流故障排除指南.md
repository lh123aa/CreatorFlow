# 工作流故障排除指南

## 前言

自动化工作流可能遇到各种问题。本指南提供常见故障的诊断和解决方案。

---

## 第一部分：常见错误类型

### 1.1 触发器问题

**问题：Trigger不触发**

可能原因：
- API权限不足
- 连接过期
- 触发条件不满足

解决方案：
- 重新授权API
- 刷新连接
- 检查触发条件

### 1.2 执行动作问题

**问题：Action执行失败**

可能原因：
- 数据格式不匹配
- 必填字段缺失
- API限流

解决方案：
- 转换数据格式
- 补全必填字段
- 添加延时或重试

### 1.3 数据映射问题

**问题：数据为空或错误**

可能原因：
- 字段名不匹配
- 数据结构变化
- 路径错误

解决方案：
- 检查字段映射
- 重新获取数据
- 使用Parse JSON

---

## 第二部分：Zapier故障排除

### 2.1 常见Zapier问题

**Task失败**

| 错误类型 | 原因 | 解决方案 |
|---------|------|---------|
| Connection Error | API连接问题 | 重新连接 |
| Validation Error | 数据格式错误 | 检查输入 |
| Rate Limit | API限流 | 添加Delay |
| Auth Error | 认证过期 | 重新授权 |

**Zap关闭原因**

- 连续失败超过阈值
- 数据格式变化
- 连接断开

### 2.2 Zapier调试技巧

1. 查看Task History了解失败原因
2. 使用"Replay"测试修复
3. 添加Filter减少失败
4. 使用Webhooks测试API

---

## 第三部分：Make故障排除

### 3.1 常见Make问题

**Scenario不运行**

可能原因：
- 调度设置错误
- Scenario暂停
- 账户余额不足

解决方案：
- 检查Schedule设置
- 恢复Scenario
- 检查操作数

**Module执行失败**

可能原因：
- 数据格式错误
- API变更
- 权限不足

解决方案：
- 添加Error Handler
- 检查数据格式
- 更新权限

### 3.2 Make调试技巧

1. 使用实时运行测试
2. 添加Router分析数据
3. 使用Array Aggregator调试
4. 查看Execution History

---

## 第四部分：API相关问题

### 4.1 API认证问题

**OAuth token过期**

解决步骤：
1. 刷新token
2. 更新连接
3. 设置自动刷新

**API Key无效**

解决步骤：
1. 重新生成Key
2. 更新Zapier/Make连接
3. 验证权限

### 4.2 API限流问题

**Rate Limit错误**

解决方案：
1. 添加Delay模块
2. 减少请求频率
3. 使用批量API

---

## 第五部分：数据问题

### 5.1 数据格式问题

**JSON解析失败**

解决方案：
1. 使用Parse JSON模块
2. 检查JSON格式
3. 添加Error Handler

**日期格式错误**

解决方案：
1. 使用Date/Time Formatter
2. 统一日期格式
3. 处理时区转换

### 5.2 数据丢失问题

**字段映射丢失**

解决方案：
1. 重新获取样本数据
2. 检查字段是否存在
3. 添加默认值

---

## 第六部分：性能问题

### 6.1 运行缓慢

**原因分析**

- 复杂的数据处理
- 大量API调用
- 网络延迟

**优化方案**

1. 减少不必要的数据获取
2. 使用批量API
3. 添加缓存
4. 优化数据结构

### 6.2 超时问题

**解决方案**

1. 减少数据量
2. 分批处理
3. 增加超时设置
4. 使用异步处理

---

## 总结

故障排除需要系统性思维：识别问题→分析原因→应用解决方案→验证修复。建立错误日志，持续优化工作流。
