# Zapier工作流模板库（上）

## 前言

Zapier是最受欢迎的自动化工具之一。本指南提供30+可直接使用的Zapier工作流模板，帮助创作者实现日常任务自动化。

---

## 第一部分：社媒发布自动化（10+模板）

### 模板1：YouTube新视频通知

```
触发：YouTube新视频上传
动作：
1. 发送Gmail邮件通知
2. 在Slack频道通知
3. 记录到Google Sheets

适用场景：第一时间获知内容发布
```

### 模板2：Instagram新帖子同步到Twitter

```
触发：Instagram新帖子
动作：
1. 提取图片和caption
2. 格式化为Twitter格式
3. 发布到Twitter（添加图片）

适用场景：多平台内容同步
```

### 模板3：TikTok新视频通知Discord

```
触发：TikTok新视频
```
