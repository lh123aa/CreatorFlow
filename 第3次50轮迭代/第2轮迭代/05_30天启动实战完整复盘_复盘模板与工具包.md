```markdown
## 3. 我给谁看？（受众定位）
- 目标用户：__________
- 用户痛点：__________

## 4. 我和别人有什么不同？（差异化）
```

```markdown
# 定位公式

[身份标签] + [地域标签] + [内容形式] = 我的定位

- 形式：短视频分享
```
