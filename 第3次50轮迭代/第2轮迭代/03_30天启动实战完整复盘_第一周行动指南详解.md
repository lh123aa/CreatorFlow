## Day 2: 准备日

### 🌅 上午（9:00-12:00）- 设备调试

#### 设备检查清单
```
📱 手机设置：
   □ 分辨率：1080P或4K
   □ 帧率：30fps或60fps
   □ 画质：最高
   □ 防抖：开启

🎤 麦克风测试：
   □ 测试录音清晰度
   □ 调整收音距离
   □ 检查电池电量

💡 灯光测试：
   □ 测试补光效果
   □ 调整光源位置
   □ 确认色温

📐 背景布置：
   □ 背景整洁不杂乱
   □ 统一视觉风格
   □ 无干扰元素
```

#### 拍摄环境标准
```
光线标准：
   • 主光：45度角，亮度足够
   • 补光：消除阴影
   • 避免：背光、眩光、阴阳脸

声音标准：
   • 环境安静无噪音
   • 麦克风收音清晰
   • 无回声混响

画面标准：
   • 稳定不抖动
   • 焦点清晰
   • 构图舒适
```
