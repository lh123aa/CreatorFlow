## 二、内容创作方法

### 2.1 化妆教程

**教程结构**：
```
1. 妆前准备（护肤、隔离）
2. 底妆（粉底、遮瑕）
3. 眼妆（眼影、眼线、睫毛）
4. 眉妆（眉形、填充）
5. 腮红高光（提亮）
6. 唇妆（口红）
7. 定妆（完成）
```

**拍摄技巧**：
- 正面+侧面双机位
- 特写展示细节
- 操作过程完整
- 前后对比

### 2.2 产品测评

**测评框架**：
```
1. 产品简介
2. 价格和购买渠道
3. 外观设计
4. 使用感
5. 效果展示（前后对比）
6. 适用肤质/人群
7. 总结推荐
```

**客观性原则**：
- 真实使用体验
- 优缺点都说
- 注明是否为合作
- 适合人群要明确

### 2.3 护肤分享

**内容方向**：
- 护肤步骤分享
- 肤质改善记录
- 产品搭配推荐
- 护肤知识科普
