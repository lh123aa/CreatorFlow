## 一、线下活动类型

### 1.1 活动类型
```yaml
分享型:
  • 公开演讲
  • 分享会
  • 读书会

工作坊型:
  • 技能培训
  • 实战演练
  • 小组指导

社交型:
  • Meetup
  • 茶话会
  • 会员聚会

混合型:
  • 上午分享+下午工作坊
  • 线上+线下结合
```

```yaml
门票收入:

```

### 2.2 场地选择
```yaml
场地类型:
  • 咖啡厅/餐厅 (轻松氛围)
  • 联合办公空间 (专业感)
  • 酒店会议室 (高端)
  • 大学教室 (教育感)
  • 自有场地 (成本控制)

选择因素:
  • 容纳人数
  • 交通便利性
  • 设备设施
  • 费用预算
  • 场地氛围
```
