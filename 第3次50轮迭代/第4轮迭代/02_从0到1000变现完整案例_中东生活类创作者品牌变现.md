## 五、踩坑与教训

### 坑1: 合作条件不明确

```
问题：
- 首个合作口头约定
- 商家要求改了很多次
- 耗时耗力

教训：
- 所有约定要书面确认
- 明确交付内容
- 设定修改次数
```

### 坑2: 不敢报价

```
问题：
- 商家问价格，紧张
- 报了个低价
- 付出回报不成正比

教训：
- 报价要有底气
- 明确自己价值
- 不要低价内卷
```

### 坑3: 忽视合同

```
问题：
- 没签合同就拍摄
- 商家临时变卦
- 没有保障

教训：
- 必须签合同
- 保护自己权益
- 合同是合作基础
```

## 六、可复制的经验

### 报价公式

```
报价 = 成本 + 利润 + 溢价

成本：
- 时间成本（制作小时 × 时薪）
- 交通成本
- 设备折旧
- 其他支出

利润：
- 期望收入
- 风险溢价

溢价：
- 品牌溢价（知名客户可加价）
- 时效溢价（加急可加价）
- 独家溢价（独家可加价）
```

### 商家BD话术

```
主动联系模板：

"您好，我是多哈小绿洲的博主，
在TikTok有2万粉丝，主要分享多哈本地生活。

我注意到您的餐厅/店铺，很感兴趣，
想和您合作一次探店内容。

合作形式可以是：
1. 我免费探店，帮您拍摄内容
2. 如果需要付费推广，我可以提供付费方案

这对您的店铺会有以下价值：
- 本地华人曝光
- 品牌口碑传播
- 真实内容种草

您有兴趣了解一下吗？"
```
