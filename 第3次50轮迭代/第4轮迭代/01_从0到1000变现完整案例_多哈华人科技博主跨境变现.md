## 五、踩坑与教训

### 坑1: 首次报价过低

```
问题：
- 为了首单，报价$300
- 实际成本$160，几乎不赚钱
- 后续涨价困难

教训：
- 报价要有底线
- 首单也要保证基本利润
- 积累案例固然重要，但不能亏本

改进：
- 建立报价成本模型
- 设定最低报价标准
- 即使优惠也要有原则
```

### 坑2: 合同意识薄弱

```
问题：
- 首个合作是口头协议
- 后续交付有争议
- 尾款结算拖延

教训：
- 所有合作必须有书面合同
- 明确交付标准和付款方式
- 保护自己权益

改进：
- 准备标准合同模板
- 所有合作书面确认
- 定金+尾款模式
```

### 坑3: 时间管理混乱

```
问题：
- 接到合作后，创作时间被挤压
- 内容质量下降
- 粉丝反馈变差

教训：
- 商业内容和创作内容要平衡
- 预留足够创作时间
- 不能因为商业影响主业

改进：
- 设定商业内容比例上限（30%）
- 固定商业合作处理时间
- 保持创作质量
```
