# 自动化报告生成

## 前言

自动化报告可以大大提升复盘效率。本指南提供自动化报告生成方案。

---

## 第一部分：报告类型

### 1.1 日报

**核心内容**

- 当日数据概览
- 重要事件记录
- 次日计划

### 1.2 周报

**核心内容**

- 本周数据汇总
- 内容表现分析
- 问题与改进
- 下周计划

### 1.3 月报

**核心内容**

- 本月数据总览
- 增长分析
- 变现分析
- 重点内容回顾
- 下月策略

---

## 第二部分：自动化模板

### 2.1 Google Sheets报告模板

**周报模板**

```
📊 本周数据周报

【数据概览】
- 总播放量：X (+X%)
- 新增粉丝：X (+X%)
- 总互动：X (+X%)
- 收入：$X

【最佳内容】
1. [内容标题] - 播放量X
2. [内容标题] - 播放量X

【问题分析】
1.
2.

【下周计划】
1.
2.
```

### 2.2 自动填充公式

**数据汇总公式**

```
=SUM(YouTube!播放量)
=SUM(TikTok!播放量)
=TOTAL
```

---

## 第三部分：自动发送设置

### 3.1 Zapier自动化

**周报自动发送**

```
触发：每周一 9:00
执行：
1. 汇总数据到Sheets
2. 生成报告文本
3. 发送Gmail
```

### 3.2 Make自动化

**月报自动生成**

```
触发：每月1日
执行：
1. 汇总上月数据
2. AI生成分析
3. 生成报告
4. 发送邮件
```

---

## 第四部分：AI辅助报告

### 4.1 ChatGPT报告生成

**Prompt模板**

```
请基于以下数据生成周报：

数据：
- 播放量：X (+X%)
- 粉丝：X (+X%)
- 互动：X (+X%)
- 收入：$X

请生成包含分析和建议的周报。
```

### 4.2 趋势分析

**AI分析要点**

- 增长/下降原因
- 内容优化建议
- 市场趋势洞察
- 行动建议

---

## 总结

自动化报告让复盘更高效。设置好模板和自动化，让数据报告自动生成。
