## 二、核心指标体系

### 2.1 增长指标

**粉丝增长指标**：
```yaml
基础指标:
  - 总粉丝数（各平台）
  - 日/周/月净增长
  - 增长率（百分比）
  - 增长趋势（上升/平稳/下降）

深度指标:
  - 粉丝留存率（新粉丝30天后留存）
  - 粉丝来源分布（推荐/搜索/分享/其他）
  - 互粉率（互动用户/总粉丝）
  - 流失率（取关/掉粉）
```

**指标定义与计算**：
```
粉丝增长率 = (本期粉丝 - 上期粉丝) / 上期粉丝 × 100%

例如:
  上周粉丝: 10000
  本周粉丝: 10500
  增长率 = (10500 - 10000) / 10000 × 100% = 5%
```

### 2.2 互动指标

**互动率计算**：
```yaml
核心互动指标:
  - 点赞率 = 点赞数 / 播放量 × 100%
  - 评论率 = 评论数 / 播放量 × 100%
  - 分享率 = 分享数 / 播放量 × 100%
  - 保存率 = 保存数 / 播放量 × 100%
  - 综合互动率 = (点赞+评论+分享+保存) / 播放量 × 100%

各平台参考值:
  TikTok: 互动率 > 5% 为优秀
  YouTube: 互动率 > 3% 为优秀
  Instagram: 互动率 > 3% 为优秀
  小红书: 互动率 > 5% 为优秀
```

### 2.3 内容指标

**内容效果评估**：
```yaml
视频内容指标:
  - 播放量/观看量
  - 平均观看时长
  - 完播率 = 完成观看 / 点击播放 × 100%
  - 5秒留存率
  - 流量来源分布

图文内容指标:
  - 曝光量
  - 点击率
  - 阅读完成率
  - 互动率

爆款标准（参考）:
  - TikTok: 播放 > 10万
  - YouTube: 播放 > 5万
  - Instagram: 曝光 > 5万
  - 小红书: 点赞 > 1000
```

## 三、Google Sheets看板搭建

**数据表结构**：
```
📊 创作者数据看板
├── 📄 每日数据
│   ├── 各平台每日数据
│   └── 自动汇总
│
├── 📄 周报数据
│   ├── 周度汇总
│   └── 趋势分析
│
├── 📄 月报数据
│   ├── 月度汇总
│   └── 环比分析
│
├── 📄 财务数据
│   ├── 收入记录
│   └── 支出记录
│
└── 📄 看板仪表盘
    ├── 核心指标卡
    ├── 趋势图表
    └── 对比分析
```

### 3.2 每日数据录入表

**模板结构**：
```markdown
## 每日数据记录表

| 日期 | 平台 | 粉丝数 | 净增长 | 播放量 | 点赞 | 评论 | 分享 | 互动率 |
|------|------|--------|--------|--------|------|------|------|--------|
| 01/01 | TikTok | 10000 | +50 | 5000 | 250 | 20 | 15 | 5.7% |
| 01/01 | Instagram | 5000 | +30 | 3000 | 150 | 15 | 10 | 5.8% |
```

**自动计算公式**：
```excel
净增长 = 今日粉丝 - 昨日粉丝
互动率 = (点赞+评论+分享)/播放量
周增长率 = (周末粉丝-周初粉丝)/周初粉丝
```

## 四、数据采集自动化

### 4.1 手动录入配置

**标准化录入流程**：
```
每日固定时间（如21:00 GST）：
1. 登录各平台后台
2. 记录当日数据
3. 粘贴到Google Sheets
4. 检查数据合理性
5. 更新看板视图
```

### 4.2 半自动化采集

**Browser Automation**：
```javascript
// 使用Browserless或其他服务

// 提取关键数据
```

```yaml

Instagram:
  路径: 专业账户 > Insights
  可导出: 限制，需第三方工具
```

### 6.1 时区处理

**GMT+3时区数据处理**：
```yaml
数据记录原则:
  - 使用多哈时间(GMT+3)记录
  - 标注数据截止时间
  - 考虑目标受众时区

发布时间建议:
  多哈上午9点 → 东亚晚间21点
```
