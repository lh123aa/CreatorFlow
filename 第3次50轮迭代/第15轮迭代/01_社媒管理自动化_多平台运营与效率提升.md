## 二、多平台内容适配

### 2.1 一稿多发策略

```
┌─────────────────────────────────────────┐
│        内容适配矩阵                       │
├─────────────────────────────────────────┤
│                                         │
│  原始素材（拍摄）                        │
│       │                                 │
│       ▼                                 │
│  ┌────┴────┬────────┬────────┐         │
│  │         │        │        │         │
│  ▼         ▼        ▼        ▼         │
│ TikTok   Instagram  YouTube  Snapchat   │
│ 60秒内   Reels     长视频   本地内容    │
│          静态      Shorts   故事        │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 平台适配清单

| 平台 | 时长 | 比例 | 字幕 | 音乐 | 特殊要求 |
|------|------|------|------|------|----------|
| TikTok | 15-60秒 | 9:16 | 必须 | 热门 | 阿拉伯语 |
| Instagram | 30-90秒 | 4:5/9:16 | 推荐 | 热门 | Reels优先 |
| YouTube | 1-10分钟 | 16:9 | 必须 | 版权 | Shorts同步 |
| Snapchat | 10-60秒 | 9:16 | 必须 | 本地 | 故事格式 |

### 2.3 内容改发模板

```markdown
# 一稿多发适配指南

## TikTok版
- 时长：裁剪至60秒内
- 开头：3秒钩子前置
- 字幕：阿拉伯语+英语双语
- 标签：#Qatar #Doha #[话题]

## Instagram版
- 时长：30-90秒
- 比例：4:5（Feed）或9:16（Reels）
- 封面：单独设计
- 描述：添加长文案+话题

## YouTube版
- 时长：完整版本
- 比例：16:9
- 封面：YouTube专属封面
- 描述：SEO优化描述

## Snapchat版
- 时长：10-60秒
- 风格：更本地化
- 格式：故事分镜
```

## 三、定时发布自动化

### 3.1 Buffer发布设置

**平台连接**：
```
Step 1: 登录Buffer
Step 2: 点击"Add new channel"
Step 3: 选择平台（TikTok, Instagram等）
Step 4: 授权连接
Step 5: 确认账号
```

**内容排期**：
```
┌─────────────────────────────────────────┐
│        周内容排期表                      │
├─────────────────────────────────────────┤
│                                         │
│  周一 21:00 - TikTok (知识干货)         │
│  周二 21:00 - Instagram (生活分享)      │
│  周三 20:00 - Snapchat (本地日常)        │
│  周四 19:00 - YouTube (深度内容)        │
│  周五 20:00 - 全平台 (周末特辑)         │
```

### 3.2 发布模板

**标题模板库**：
| 类型 | 模板 | 示例 |
|------|------|------|
| 悬念型 | 你不知道的... | 多哈人不知道的5个秘密 |
| 数字型 | X个...的... | 3个多哈生活的真相 |
| 对比型 | ...vs... | 中国vs卡塔尔教育 |
| 利益型 | ...必看的... | 在多哈必吃的餐厅 |
| 情绪型 | [情绪词]... | 太离谱了！多哈物价 |

**描述模板**：
```markdown
[一句话概括内容价值]

📍 地点：[相关地点]

👤 我是[名字]，在多哈[X]年的华人

🔔 关注我，获取更多中东生活干货！

```

## 九、核心要点总结

1. **内容一次制作多平台分发**，最大化内容价值
2. **定时发布是效率关键**，批量准备+定时发布
3. **评论互动不能自动化**，这是建立粉丝关系的关键
4. **数据统一追踪**，了解各平台表现差异
5. **中东市场TikTok优先**，但Instagram和Snapchat不可忽视
