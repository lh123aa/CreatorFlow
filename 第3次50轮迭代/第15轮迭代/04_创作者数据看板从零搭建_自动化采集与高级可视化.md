## 二、Zapier自动化配置

### 2.1 YouTube数据同步

**Zap配置模板**：
```
Trigger: Schedule (Every Day at 9:00 AM GST)
  ↓
Action 1: HTTP Request
  Method: GET
  URL: https://www.googleapis.com/youtube/v3/channels
  Query Params:
    - part: statistics
    - id: YOUR_CHANNEL_ID
    - key: YOUR_API_KEY
  ↓
Action 2: Google Sheets
  Spreadsheet: 创作者数据看板
  Worksheet: 每日数据
  Values: 
    - Date: {{TODAY}}
    - Subscribers: {{response.items.0.statistics.subscriberCount}}
    - TotalViews: {{response.items.0.statistics.viewCount}}
```

### 2.2 TikTok数据同步

**Zap配置思路**：
```
挑战: TikTok API限制较多

解决方案:
1. 使用第三方数据工具（如Nindo）
2. 或手动+半自动化
3. 或使用Make的高级模块

备选方案:
- 每2-3天手动更新
- 重点关注趋势而非精确数字
```

### 2.3 数据整合工作流

**完整数据流**：
```
早上9:00 GST
     ↓
Step 1: YouTube数据 → Google Sheets
Step 2: Instagram数据 → Google Sheets
Step 3: TikTok数据 → Google Sheets（手动）
     ↓
Step 4: Google Sheets计算汇总
     ↓
Step 5: 检查异常数据
     ↓
Step 6: 发送日报到Slack/微信（如有异常）
```

## 三、Google Sheets高级公式

### 3.1 数据汇总公式

**多表汇总**：
```excel
=SUM('01'!B2,'02'!B2,'03'!B2,...) 
' 汇总多个sheet的数据

=SUMIF('每日数据'!A:A,"TikTok",'每日数据'!D:D)
' 条件求和

=QUERY('每日数据'!A:H,"SELECT A, SUM(D) GROUP BY A")
' SQL风格查询
```

### 3.2 趋势计算公式

**增长率计算**：
```excel
' 日增长率
=(今日粉丝-昨日粉丝)/昨日粉丝

' 7日移动平均
=AVERAGE(B2:B8)

' 30日趋势线斜率
=SLOPE(D2:D31,SEQUENCE(30))
```

### 3.3 条件格式

**数据高亮设置**：
```
应用场景:
- 增长率>10% → 绿色背景
- 增长率<-5% → 红色背景
- 互动率>5% → 加粗显示
- 目标达成→100% → 特殊标记

设置路径:
格式 → 条件格式 → 添加规则
```

### 4.1 动态图表

**迷你图使用**：
```excel
=SPARKLINE(B2:M2,{"chartType","line";"color","blue"})
' 在单元格内显示小趋势图

=SPARKLINE(B2:M2,{"chartType","bar";"max",MAX(B2:M2)})
```

### 5.2 月度报表模板

**自动生成月报**：
```excel
='每日数据'!A1

本月数据汇总:
- 总曝光: =SUMIFS('每日数据'!F:F,'每日数据'!A:A,">="&DATE(2024,1,1),'每日数据'!A:A,"<="&DATE(2024,1,31))
- 总互动: =SUMIFS('每日数据'!G:G,...)
- 平均互动率: =总互动/总曝光
```

## 六、告警系统

### 6.1 异常检测规则

**告警触发条件**：
```yaml
粉丝异常:
  - 日增长 < -100 → 紧急告警
  - 日增长 > 1000 → 检查是否刷量
  
互动率异常:
  - 互动率 < 1% → 内容质量问题
  - 互动率 > 15% → 检查数据真实性

收入异常:
  - 收入为0超过7天 → 检查收款账户
  - 收入突增 > 50% → 确认来源
```

### 6.2 告警通知配置

**Zapier告警工作流**：
```
Trigger: Google Sheets公式检测到异常
  ↓
Filter: 只处理异常情况
  ↓
Action: 发送通知
  - Slack: #创作者数据告警
  - 邮件: 紧急告警
  - 微信: 重要提醒（如可用）
```
