## 二、AI文字创作工具

### 2.1 ChatGPT创作应用

**内容创作提示词模板**：
```markdown
# 短视频脚本模板

角色：你是一位专业的短视频创作者，擅长创作吸引人的内容
任务：为一个关于[主题]的TikTok视频创作脚本
要求：
- 时长：30-60秒
- 结构：开头3秒钩子+中间内容+结尾引导
- 风格：适合多哈/中东观众
- 语言：[阿拉伯语/英语/双语]

输出格式：
1. 视频标题
2. 开头文案（3秒）
3. 主体内容（按时间轴）
4. 结尾引导语
5. 标签建议
```

**多哈内容创作示例**：
```
主题：多哈生活小技巧

标题：多哈生活必须知道的5个小技巧！

开头（3秒）："在多哈生活，这5件事你一定要知道！"

主体：
- 0-15秒：交通出行（地铁使用技巧）
- 15-30秒：购物省钱（商场打折季）
- 30-45秒：美食推荐（本地隐藏美食）
- 45-60秒：文化体验（本地习俗）

结尾："还想知道什么？评论区告诉我！"
```

## 九、AI创作避坑指南

### 9.1 常见问题

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 内容同质化 | AI味道明显 | 人工深度改写 |
