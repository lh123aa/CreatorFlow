## 一、提示词工程基础

### 1.1 提示词核心要素

```
┌─────────────────────────────────────────┐
│         提示词核心结构（COSTAR）          │
├─────────────────────────────────────────┤
│                                         │
│  C - Context（背景）                    │
│  └─ 提供任务的背景信息                  │
│                                         │
│  O - Objective（目标）                  │
│  └─ 明确希望AI完成什么                  │
│                                         │
│  S - Style（风格）                      │
│  └─ 设定输出风格                        │
│                                         │
│  T - Tone（语气）                       │
│  └─ 设定表达语气                        │
│                                         │
│  A - Audience（受众）                   │
│  └─ 明确目标读者                        │
│                                         │
│  R - Response（响应格式）               │
│  └─ 设定输出格式                        │
│                                         │
└─────────────────────────────────────────┘
```

### 1.2 基础提示词模板

**短视频脚本提示词**：
```markdown
# 模板：短视频脚本生成

## 背景
我是一位在多哈生活的华人内容创作者，
主要制作关于中东生活、文化、旅游的内容。

## 目标
为TikTok/Instagram Reels创作一个60秒内的短视频脚本。

## 风格
- 轻松自然，像朋友聊天
- 有信息价值，让人觉得有用
- 有情绪共鸣，让人想点赞

## 受众
- 生活在中东的华人
- 对中东感兴趣的其他国家用户
- 年龄18-35岁

## 主题
[在此填入主题]

## 输出格式
1. 标题（吸引人）
2. 开头文案（3秒钩子）
3. 脚本正文（按时间轴）
4. 结尾引导语
5. 推荐标签（3-5个）
```

## 三、高级提示词技巧

### 3.1 链式思考（Chain of Thought）

```markdown
请按以下步骤分析并生成内容：

Step 1: 分析目标受众
- 他们的痛点是什么？
- 他们关心什么？
- 他们想得到什么？

Step 2: 确定核心信息
- 最想传达的1-2个信息是什么？
- 如何让观众记住？

Step 3: 设计结构
- 开头如何吸引注意力？
- 中间如何展开？
- 结尾如何引导行动？

Step 4: 生成内容
基于以上分析，生成完整的视频脚本。

[填入你的主题]
```

### 3.2 迭代优化技巧

**第一轮：生成**
```
生成5个关于[主题]的短视频标题
每个标题要求：
- 吸引眼球
- 有悬念或价值
- 适合TikTok风格
```

**第二轮：评估**
```
评估以下标题，并指出优缺点：

[粘贴第一轮生成的标题]

评估维度：
- 吸引力
- 清晰度
- 创新性
- SEO友好度
```

**第三轮：优化**
```
基于评估结果，优化以下标题：

[选择最好的标题]

优化方向：
- 更吸引人
- 更具体
- 更有悬念
```

### 3.3 角色扮演技巧

```markdown
你是一位在多哈生活了5年的华人创作者，
```

## 四、批量内容生成

### 4.1 批量选题生成

```markdown
一次性生成一周的选题计划

主题方向：[在此填入，如"多哈美食探店"]
数量：7个选题
格式：标题+一句话描述+预计时长

要求：
- 多样化，覆盖不同角度
- 有爆款潜力
- 适合多哈/中东受众
```

### 4.2 批量脚本生成

```markdown
生成一周内容的批量脚本

周一：[主题类型]
周二：[主题类型]
...

每个脚本包含：
1. 标题
2. 开头3秒
3. 主体内容（简洁版）
4. 结尾引导

注意保持：
- 内容多样性
- 风格一致性
- 制作可行性
```

### 4.3 批量标题生成

```markdown
为一个视频生成20个标题选项

视频主题：[粘贴视频核心内容]

标题类型覆盖：
- 悬念型（5个）
- 数字型（5个）
- 情感型（5个）
- 利益型（5个）

每个标题标注：
- 类型
- 预计点击率（高/中/低）
- 适合平台
```

### 8.2 优化建议

| 检查项 | 问题 | 优化方向 |
|--------|------|----------|
| 开头不够抓人 | 流失率高 | 强化3秒钩子 |
| 内容太干 | 完播率低 | 增加故事性 |
| 没有记忆点 | 记不住 | 加金句/反转 |
| CTA不明确 | 互动低 | 强化行动引导 |

## 九、核心要点总结

1. **好的提示词=好结果**，COSTAR框架是基础
2. **迭代优化是关键**，不要一次生成就完事
3. **本地化提示词**，需要针对中东文化调整
4. **批量生成提效**，一次性生成多个版本
5. **人工审核必须**，AI只是助手不是替代
