## 一、AI工具评测定位

### 1.1 领域选择策略

**为什么做AI工具评测**：
- 市场需求大：AI工具层出不穷
- 变现路径清晰：联盟、付费内容
- 差异化机会：华人视角稀缺
- 内容生命周期长：工具迭代慢

**评测领域细分**：
| 细分领域 | 市场需求 | 竞争程度 | 适合切入 |
|----------|----------|----------|----------|
| AI写作工具 | 高 | 高 | 中 |
| AI图像生成 | 高 | 中高 | 高 |
| AI视频制作 | 中高 | 中 | 高 |
| AI办公效率 | 高 | 中 | 高 |
| AI编程工具 | 中 | 低 | 中 |

### 1.2 差异化定位

**华人创作者优势**：
- 中文AI工具评测稀缺
- 多哈用户的使用场景
- 跨境使用经验分享
- 中英文切换教程

**内容差异化策略**：
```
定位 = AI工具 + 使用场景 + 目标用户

示例：
"专为跨境电商创业者打造的AI工具指南"
"多哈华人如何使用AI提升工作效率"
```

## 二、评测内容制作

### 2.1 评测框架

**标准评测维度**：

| 维度 | 评估内容 | 评分标准 |
|------|----------|----------|
| 功能性 | 核心功能是否完善 | 1-10 |
| 易用性 | 上手难度 | 1-10 |
| 性价比 | 价格vs功能 | 1-10 |
| 输出质量 | 结果满意度 | 1-10 |
| 稳定性 | 运行是否流畅 | 1-10 |

**评测模板**：
```
1. 工具简介（1分钟）
   - 是什么
   - 解决什么问题

2. 核心功能演示（3-5分钟）
   - 功能1演示
   - 功能2演示
   - 特色功能

3. 优缺点分析（2分钟）
   - 优点123
   - 缺点123

4. 适用场景（1分钟）
   - 适合人群
   - 不适合人群

5. 总结推荐（1分钟）
   - 评分
   - 推荐指数
```

### 2.2 评测制作流程

**前期准备**：
- 注册账号实际使用
- 准备测试素材（文案、图片等）
- 设计测试任务
- 整理使用感受

**拍摄要点**：
| 环节 | 内容 | 时长 |
|------|------|------|
| 开场 | 引入+简介 | 30秒 |
| 演示 | 实际操作演示 | 3-5分钟 |
| 讲解 | 优缺点分析 | 2分钟 |
| 总结 | 推荐建议 | 1分钟 |

### 2.3 深度对比

**横评制作**：
```
对比维度：
1. 核心功能对比
2. 输出质量对比
3. 价格对比
4. 适用场景对比
5. 优劣势总结
```

**对比表设计**：
| 工具 | 功能 | 价格 | 质量 | 易用 | 综合 |
|------|------|------|------|------|------|
| 工具A | ★★★★ | ★★★★ | ★★★★ | ★★★★★ | 推荐 |
| 工具B | ★★★★ | ★★★ | ★★★★★ | ★★★ | 备选 |
