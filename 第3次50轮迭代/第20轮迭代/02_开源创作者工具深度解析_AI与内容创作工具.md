## 二、开源AI工具

### 2.1 本地大语言模型

**Ollama - 本地LLM运行**：
```yaml
工具简介:
  • 在本地运行大语言模型
  • 支持多种模型 (Llama, Mistral, etc.)
  • 无需云端，保护隐私
  
安装:
  • macOS: brew install ollama
  • Windows: 下载安装包
  • Linux: curl命令安装

使用方法:
  ollama run llama2
  ollama run mistral
  ollama pull codellama  # 编程模型

适用场景:
  • 写作助手
  • 内容润色
  • 脚本生成
  • 多语言翻译
```

**LocalAI**：
```yaml
工具简介:
  • 自托管AI API服务
  • 兼容OpenAI API
  • 支持多种模型

适用场景:
  • 有服务器资源的创作者
  • 需要API集成的开发者
  • 高隐私要求场景
```

### 2.2 图像生成工具

**Stable Diffusion**：
```yaml
工具简介:
  • 开源图像生成模型
  • 本地运行
  • 高度可定制

安装选项:
  • Automatic1111 WebUI (最流行)
  • ComfyUI (工作流导向)
  • Fooocus (简单易用)

必备模型:
  • SD 1.5 / SDXL
  • LoRA 模型 (风格定制)
  • VAE (细节优化)

推荐插件:
  • ControlNet (精确控制)
  • img2img (图生图)
  • Inpainting (局部重绘)
```

**ComfyUI工作流**：
```
ComfyUI优势:
  • 可视化工作流
  • 高度可定制
  • 节省显存
  • 适合进阶用户

基础工作流:
  加载模型 → 文本提示 → 采样生成 → 输出图像
  
进阶工作流:
  加载模型 → ControlNet → 文本提示 → 采样生成 → 图像增强 → 输出
```

### 3.2 字幕工具

**Whisper**：
```yaml
工具简介:
  • OpenAI开源语音识别
  • 高准确率
  • 多语言支持

使用方式:
  • 命令行: whisper audio.mp3
  • GUI工具: WhisperDesktop
  • 在线工具: 在线Whisper

输出格式:
  • TXT (纯文本)
  • SRT (字幕文件)
  • VTT (网页字幕)
  • JSON (详细时间戳)
```

**autocaptions**：
```yaml
工具简介:
  • 基于Whisper的字幕工具
  • 自动生成SRT/VTT
  • 支持批量处理

功能:
  • 语音识别
  • 翻译字幕
  • 格式转换
```

### 3.3 视频处理

**FFmpeg**：
```yaml
工具简介:
  • 强大的视频处理命令行工具
  • 几乎支持所有格式
  • 批量处理

常用命令:
  # 格式转换
  ffmpeg -i input.mp4 output.avi
  
  # 压缩视频
  ffmpeg -i input.mp4 -crf 23 output.mp4
  
  # 提取音频
  ffmpeg -i input.mp4 -vn output.mp3
  
  # 剪辑片段
  ffmpeg -i input.mp4 -ss 00:00:10 -t 00:00:30 output.mp4

GUI工具:
  • HandBrake (视频压缩)
  • Shotcut (剪辑)
  • lossless-cut (快速剪辑)
```
