# 开发与自动化开源工具

## 前言

开发工具和自动化工具提升创作效率。本指南介绍相关开源工具。

---

## 第一部分：代码编辑器

### 1.1 VS Code

**定位**：代码编辑器

**特点**

- 免费开源
- 丰富的扩展
- 智能提示
- Git集成
- 跨平台

**创作者适用场景**

- 编写自动化脚本
- 网站开发
- 数据分析

**推荐扩展**

- GitHub Copilot（AI辅助）
- Prettier（代码格式化）
- Live Server（网页预览）

### 1.2 VSCodium

**定位**：VS Code开源版本

**特点**

- 完全开源
- 无遥测数据
- 与VS Code功能相同

---

## 第二部分：版本控制

### 2.1 Git

**定位**：版本控制系统

**核心命令**

```bash
# 初始化仓库
git init

# 克隆仓库
git clone url

# 添加文件
git add .

# 提交
git commit -m "message"

# 推送
git push

# 拉取
git pull
```

### 2.2 GitHub/GitLab

**定位**：Git仓库托管

**功能**

- 代码仓库
- 协作开发
- Issue追踪
- CI/CD
