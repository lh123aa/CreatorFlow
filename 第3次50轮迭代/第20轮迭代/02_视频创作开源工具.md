# 视频创作开源工具

## 前言

视频创作是创作者的核心工作。本指南详细介绍视频创作相关的开源工具。

---

## 第一部分：视频编辑

### 1.1 DaVinci Resolve

**定位**：专业级视频编辑

**特点**

- 免费版功能强大
- 专业调色
- 音频处理
- 特效合成

**适用场景**

- 长视频编辑
- 调色需求
- 特效制作

**学习资源**

- Blackmagic Design官方教程
- YouTube教程
- DaVinci Resolve官方社区

### 1.2 OBS Studio

**定位**：屏幕录制和直播

**特点**

- 完全免费
- 支持多场景
- 实时滤镜
- 直播推流

**适用场景**

- 屏幕录制
- 游戏直播
- 在线课程录制

---

## 第二部分：视频转换

### 2.1 HandBrake

**定位**：视频格式转换

**特点**

- 免费开源
- 支持多种格式
- 可预设配置
- 批量转换

**适用场景**

- 格式转换
- 压缩优化
- 批量处理

### 2.2 FFmpeg

**定位**：命令行视频处理

**特点**

- 功能强大
- 脚本自动化
- 高效处理
- 跨平台

**使用示例**

```bash
# 视频压缩
ffmpeg -i input.mp4 -crf 23 output.mp4

# 格式转换
ffmpeg -i input.avi output.mp4

# 提取音频
ffmpeg -i input.mp4 -vn -acodec copy output.aac
```

## 第三部分：字幕工具

### 3.1 Whisper

**定位**：AI语音转文字

**特点**

- OpenAI开源
- 多语言支持
- 高准确率
- 离线运行

**安装使用**

```bash
pip install openai-whisper
whisper audio.mp3 --language zh
```

### 3.2 Subtitle Edit

**定位**：字幕编辑

**特点**

- 免费开源
- 多种格式支持
- 批量处理
- 时间轴调整
