│  └─ 📁 图标素材

   ├─ 📁 模板素材

### 3.2 素材命名规范

```
命名格式：[类型]_[主题]_[描述]_[日期]_[版本]

示例：

视频素材：
视频_多哈风景_海边日落_20240115_001

图片素材：
图片_餐厅_探店封面_20240115_001

音乐素材：
音乐_背景_轻快_无版权_001
```

### 3.3 素材标签系统

| 标签类型 | 示例 | 用途 |
|----------|------|------|
| 内容标签 | #探店, #vlog, #教程 | 内容分类 |
| 风格标签 | #暖色调, #现代感 | 视觉风格 |
| 用途标签 | #封面, #背景, #转场 | 使用场景 |
| 格式标签 | #16:9, #9:16, #1:1 | 比例格式 |
| 版权标签 | #原创, #免费商用, #付费 | 版权状态 |

## 七、核心要点总结

1. **知识管理防止经验流失**，好记性不如烂笔头
2. **素材库提升创作效率**，快速找到需要的素材
3. **模板库减少重复劳动**，一次制作多次使用
4. **本地化知识是差异化**，中东特色知识库是竞争优势
5. **持续运营才能发挥价值**，知识库需要日常维护
