## 二、邮箱与身份管理

### 2.1 邮箱策略

**创作者邮箱配置**：
```yaml
主邮箱:
  • 用途: 账号注册、找回、安全通知
  • 选择: Gmail/Outlook
  • 安全: 必须开启2FA
  
工作邮箱:
  • 用途: 商务沟通、合作联系
  • 选择: 主邮箱或专门工作邮箱
  • 安全: 必须开启2FA

备用邮箱:
  • 用途: 账号恢复
  • 选择: 不同服务商
  • 安全: 必须开启2FA
```

### 2.2 身份管理

**个人身份信息保护**：
```yaml
需要保护的信息:
  • 真实姓名
  • 身份证/护照号
  • 银行账户信息
  • 家庭地址
  • 电话号码
  
公开可用的信息:
  • 艺名/网名
  • 公开的社交账号
  • 公开的邮箱（如用于商务）

建议:
  • 使用艺名而非真名
  • 工作邮箱与私人邮箱分开
  • 不在公开平台暴露完整个人信息
```

## 四、第三方权限管理

### 4.1 已授权应用检查

**定期审查权限**：
```markdown
## 已授权应用检查

需要定期检查:
  • Google账号已授权的应用
  • Facebook已授权的应用
  • 邮箱已授权的应用

清理原则:
  • 不再使用的应用 → 移除
  • 权限过大的应用 → 限制
  • 可疑应用 → 立即移除

建议检查频率:
  • 每季度检查一次
  • 更换密码后重新审查
  • 发现异常立即清理
```

### 4.2 API与集成安全

**API密钥管理**：
```yaml
需要保管好的密钥:
  • YouTube API密钥
  • OpenAI API密钥
  • Zapier/Make API密钥
  • 各种平台开发者密钥

保护措施:
  • 不在代码中硬编码
  • 使用环境变量
  • 定期更换密钥
  • 限制密钥使用范围
```

## 五、域名与网站安全

### 5.1 域名管理

**域名安全要点**：
```yaml
域名注册信息:
  • 使用真实信息（合规要求）
  • 开启隐私保护
  • 设置紧急联系人

域名安全:
  • 自动续费必须开启
  • Registrar Lock开启
  • 转移锁定开启

安全检查:
  • 定期登录检查
  • 检查DNS设置
  • 确认续费日期
```

### 5.2 网站安全

**网站安全措施**：
```yaml
基础安全:
  • HTTPS加密（必须）
  • 强密码策略
  • 定期更新插件/主题
  
安全插件:
  • 防火墙插件
  • 恶意扫描插件
  • 登录保护插件
  
备份:
  • 定期备份网站
  • 测试恢复流程
```
