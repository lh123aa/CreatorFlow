### 3.1 设备安全策略

**设备安全原则**：
```yaml
设备安全4大原则:

1. 全磁盘加密
   - BitLocker (Windows)
   - FileVault (Mac)
   - 设备丢失时保护数据

2. 屏幕锁定
   - 设置强密码
   - 自动锁定 (1-5分钟)
   - 生物识别 (指纹/面部)

3. 系统更新
   - 自动更新系统
   - 及时安装补丁
   - 停止使用停止支持的版本

4. 最小权限
```

## 五、网络行为安全

### 5.1 安全上网习惯

**安全上网准则**：
```yaml
安全上网习惯:

链接点击:
  ✓ 确认发送者身份
  ✓ 检查URL是否正确
  ✓ Hover查看真实链接
  ✗ 不要点击可疑链接
  ✗ 不要打开未知附件

密码使用:
  ✓ 每个账户使用独立密码
  ✓ 使用密码管理器
  ✓ 启用双因素认证
  ✗ 不要使用简单密码
  ✗ 不要在多个网站重复使用同一密码

公共网络:
  ✓ 始终使用VPN
  ✓ 避免访问敏感账户
  ✓ 完成后退出登录
  ✗ 不要进行金融交易
  ✗ 不要传输敏感信息

邮件安全:
  ✓ 验证发件人地址
  ✓ 检查链接目的地
  ✓ 警惕紧急/威胁语气
  ✗ 不要提供登录凭据
  ✗ 不要打开可疑附件
```

### 5.2 钓鱼识别技巧

**钓鱼识别清单**：
```markdown
钓鱼识别检查:

发件人检查:
├── 地址是否正确 (注意细微差别)
├── 是否来自官方域名
├── 是否有拼写错误
└── 是否突然发送

内容检查:
├── 是否要求紧急操作
├── 是否威胁账号将被封
├── 是否承诺奖励
├── 是否语法奇怪
└── 是否索要敏感信息

链接检查:
├── Hover查看真实URL
├── 检查域名是否正确
├── 避免短链接直接点击
└── 在浏览器手动输入网址

附件检查:
├── 是否是exe/msi/vbs
├── 是否是Office宏文件
├── 来源是否可信
└── 打开前先杀毒扫描
```

### 5.3 密码管理策略

**密码安全实践**：
```yaml
密码管理:

密码原则:
  - 长度至少12位
  - 包含大小写字母
  - 包含数字
  - 包含特殊字符
  - 避免个人信息
  - 避免常见词汇

密码管理器推荐:
  免费:
  - Bitwarden: 开源免费
  - KeePassXC: 本地存储
  
  付费:
  - 1Password: $2.99/月
  - LastPass: $3/月
  - Dashlane: $4.99/月

密码使用策略:
  - 主密码: 最强、最独特
  - 社交媒体: 独立密码
  - 财务账户: 最强密码+2FA
  - 工作账户: 公司密码策略
```
