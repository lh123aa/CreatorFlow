## 第三部分：Zapier/Make自动化

### 3.1 自动备份模板

**Google Drive备份**

```
触发：每日定时
执行：
1. 查找新文件
2. 移动到备份文件夹
3. 记录备份日志
```

### 3.2 Notion数据导出

```
触发：每周定时
执行：
1. 导出Notion数据
2. 保存到Google Drive
3. 发送备份通知
```
