## 二、备份内容清单

### 2.1 内容素材备份

**必须备份的内容**：
```yaml
视频素材:
  • 原始拍摄素材（最珍贵）
  • 剪辑工程文件
  • 渲染输出成品
  • 历史发布版本
  
图片素材:
  • 原始照片
  • PSD/AI源文件
  • 封面设计源文件
  • 产品图片
  
音频素材:
  • 原创配音
  • 原创音乐
  • 音效素材
  
文档资料:
  • 脚本/文案
  • 合同协议
  • 财务记录
  • 客户资料
```

### 2.2 备份优先级

**按重要性排序**：
```markdown
P0 - 绝对不能丢:
  • 原创视频素材（拍完即备份）
  • 合同协议（法律文件）
  • 财务数据（多年积累）

P1 - 丢失影响大:
  • 剪辑成品
  • 脚本文案
  • 客户资料

P2 - 可重新获取:
  • 通用素材
  • 模板文件
  • 参考资料

P3 - 不备份也无所谓:
  • 临时文件
  • 缓存文件
  • 下载的测试文件
```

### 3.2 本地备份

**移动硬盘配置**：
```yaml
推荐配置:
  • 容量: 2TB-4TB
  • 类型: SSD（速度快）或 HDD（便宜）
  • 数量: 2块（一份常用，一份存档）

备份策略:
  • 每周同步一次
  • 每月完整备份一次
  • 每季度轮换存档

品牌推荐:
  • Samsung T7 (SSD)
  • WD My Passport (HDD)
  • LaCie (专业级)
```

### 3.3 自动化备份设置

**Backup and Sync**：
```
Google Backup & Sync:
  1. 下载安装 Backup & Sync
  2. 选择要备份的文件夹
  3. 设置同步频率
  4. 开启后台自动同步
```

**Time Machine (Mac)**：
```
Mac备份配置:
  1. 连接外置硬盘
  2. 打开系统偏好设置 → Time Machine
  3. 选择备份硬盘
  4. 开启自动备份
  5. 设置保留策略（保留所有版本）
```

**完整备份流程**：
```

  1. 复制素材到电脑
  2. 命名规范化（日期_项目_序号）
```

## 六、备份检查与测试

### 6.1 定期检查清单

**每周检查**：
```
□ 云端同步正常
□ 移动硬盘连接正常
□ 重要文件已备份
□ 无异常错误提示
```

**每月检查**：
```
□ 备份完整性验证
□ 恢复测试（抽检）
□ 清理过期备份
□ 更新备份记录
```

### 6.2 恢复测试

**恢复测试流程**：
```
每季度进行一次恢复测试:

1. 选择一个不太重要的文件
2. 故意删除本地文件
3. 从云端恢复
4. 验证文件完整性
5. 如有问题及时修复

注意:
• 不要测试最重要的文件
• 记录测试结果
• 及时修复发现的问题
```
