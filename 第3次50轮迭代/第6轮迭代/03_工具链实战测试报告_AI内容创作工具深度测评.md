## 六、AI工具组合使用

### 内容创作工作流

```
AI辅助创作流程：

Step 1: 选题/策划
- 工具：ChatGPT
- 使用：头脑风暴、选题灵感
- 提示："我想做XX选题，给我10个角度"

Step 2: 文案撰写
- 工具：ChatGPT/Claude
- 使用：脚本大纲、完整文案
- 提示："帮我写一个XX视频的脚本"

Step 3: 图片制作
- 工具：Midjourney/DALL-E
- 使用：封面图、配图
- 提示："生成一个XX风格的封面图"

Step 4: 视频配音
- 工具：剪映AI/11Labs
- 使用：配音生成
- 操作：文字转语音

Step 5: 字幕/翻译
- 工具：讯飞听见/剪映
- 使用：字幕生成、多语言
- 操作：录音转文字

Step 6: 剪辑优化
- 工具：剪映/CapCut
- 使用：智能剪辑、字幕
- 操作：AI辅助剪辑

## 七、AI工具使用技巧

### 提示词工程

```
基本技巧：

1. 明确指令
✗ "帮我写"
✓ "帮我写一个60秒的TikTok脚本，主题是XX，结构是：开头3秒钩子+中间内容+结尾CTA"

2. 提供上下文
✗ "写标题"
✓ "为我的多哈生活账号写10个标题，目标用户是想了解中东的华人"

3. 分步提问
✗ "写完整视频脚本"
✓ 先："这个选题的核心观点是什么？"
   然后："针对这些观点，举例说明"
   最后："整合成完整脚本"

4. 迭代优化
- 初稿 → 提出修改意见 → 优化 → 再优化
```

```
人工审核要点：
