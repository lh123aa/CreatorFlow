## 二、内容本地化策略


## 六、避坑清单

### 6.1 本地化常见错误

**本地化避坑**：
```
┌─────────────────────────────────────────────────────────┐
│               本地化避坑清单                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ❌ 错误1: 直接翻译                                   │
│  ─────────────────────                                 │
│  简单翻译英文内容，缺乏本地化                          │
│  → 深度本地化，本地案例                             │
│                                                         │
│  ❌ 错误2: 忽视文化差异                               │
│  ─────────────────────                                 │
│  触碰文化禁忌，内容被投诉                              │
│  → 了解文化底线，尊重当地                            │
│                                                         │
│  ❌ 错误3: 目标人群模糊                               │
│  ─────────────────────                                 │
│  什么人都想要，什么人都不精准                          │
│  → 明确目标人群，深耕细分                            │
│                                                         │
│  ❌ 错误4: 忽视阿拉伯语市场                           │
│  ─────────────────────                                 │
│  只做英语，错过阿拉伯语受众                            │
│  → 阿拉伯语内容是重要增量                            │
│                                                         │
│  ❌ 错误5: 合规意识不足                               │
│  ─────────────────────                                 │
│  不了解当地法规，内容违规                              │
│  → 了解法规，合规运营                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
