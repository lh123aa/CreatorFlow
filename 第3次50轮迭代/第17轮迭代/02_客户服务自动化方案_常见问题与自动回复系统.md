## 二、自动回复系统配置

### 2.1 平台原生自动回复

**Instagram自动回复**：
```yaml
快速回复设置:
  路径: Instagram专业账户 → 设置 → 快速回复
  
  可设置:
  • 常见问题快捷回复
  • 欢迎语
  • 离开回复
  
  示例:
  "你好！感谢留言~ 
   我会在24小时内回复你！
   如果是紧急合作，请邮件: xxx@email.com"
```

**TikTok自动回复**：
```yaml
自动回复设置:
  路径: TikTok Creator Tools → 自动回复
  
  可设置:
  • 关键词自动回复
  • 首次互动欢迎语
  • 常见问题解答
  
  示例关键词:
  • "价格" → 触发价格回复
  • "合作" → 触发合作信息
  • "在哪" → 触发地址回复
```

### 2.2 多平台关键词回复

**关键词回复矩阵**：
```yaml
关键词 → 回复映射:

"价格"/"price"/"how much":
  回复: 感谢咨询！我的服务/产品价格为：_
  请访问 _ 了解更多

"合作"/"collaboration"/"business":
  回复: 感谢合作意向！
  请发邮件至：xxx@email.com
  附上你的品牌介绍和合作方案~

"在哪"/"where"/"地址":
  回复: 店铺/位置信息：_
  地图链接：_

"时间"/"营业"/"open":
  回复: 营业时间：_
  斋月期间可能有调整，请关注最新公告
```

### 2.3 智能回复配置

**AI辅助回复思路**：
```
工作流:
1. 用户发送消息
2. 关键词检测/AI分析
3. 生成回复建议
4. 自动发送或人工确认
5. 学习优化

工具选择:
• ChatGPT API集成
• Manychat（Instagram）
• MobileMonkey（多平台）
```

## 三、常见问题分类

### 3.1 问题分类体系

**创作者常见问题分类**：
```yaml
咨询类:
  • 产品/服务价格
  • 购买/下单方式
  • 发货/交付时间
  • 使用/安装指导
  
合作类:
  • 品牌合作意向
  • 广告植入报价
  • 长期合作可能
  • 媒体采访邀请
  
技术类:
  • 视频无法播放
  • 链接打不开
  • 账号问题反馈
  • 功能建议反馈
  
售后类:
  • 退款/售后
  • 更换/补发
  • 使用问题
  • 效果反馈
```

### 3.2 标准回复模板

**价格咨询回复**：
```markdown
## 价格咨询回复模板

Hi [名字]！感谢你的咨询~ 👋

关于[产品/服务]：

📦 产品/服务介绍：
[简要描述]

💰 价格：
[具体价格]

📦 包含内容：
• [内容1]
• [内容2]
• [内容3]

🛒 购买方式：
[购买链接/下单流程]

❓ 如有其他问题，随时问我！

[你的名字]
```

**合作咨询回复**：
```markdown
## 合作咨询回复模板

你好！感谢对合作的兴趣！✨

我是[你的名字]，[账号定位]

关于合作：
我们主要提供以下合作形式：
• [形式1]：价格 $X 起
• [形式2]：价格 $X 起
• [形式3]：价格 $X 起

合作流程：
1. 发送品牌/产品介绍
2. 沟通合作细节
3. 确认方案并签约
4. 内容制作与发布

感兴趣的话，请发邮件至：[邮箱]
主题注明：品牌合作 + 品牌名称

期待合作！🤝
```

## 四、私信管理策略

### 4.1 私信分类处理

**优先级分类**：
```yaml
高优先级（24小时内回复）:
  • 潜在合作方
  • 大额订单客户
  • 媒体/采访邀请
  • 负面反馈/投诉

中优先级（48小时内回复）:
  • 购买意向客户
  • 普通合作咨询
  • 使用问题咨询

低优先级（可稍后回复）:
  • 简单问题
  • 闲聊消息
  • 无关内容
```

### 4.2 私信时间管理

**固定时间回复策略**：
```
时间分配:
┌─────────────────────────────────────────────────────────┐
│ 09:00-10:00  早上快速处理（紧急问题）                   │
│ 12:00-13:00  中午集中处理                              │
│ 17:00-18:00  下午集中处理                              │
│ 21:00-22:00  晚间快速浏览                              │
└─────────────────────────────────────────────────────────┘

批量处理技巧:
• 设定固定回复时间
• 开启消息提醒
• 使用快捷回复
• 标记待回复消息
```
