## 一、咨询流程设计

### 1.1 完整咨询流程

**标准化咨询流程**：
```
┌─────────────────────────────────────────────────────────┐
│                    咨询流程图                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  用户发起咨询                                            │
│       ↓                                                │
│  ┌─────────────────────────────────────┐               │
│  │         自动分流                    │               │
│  ├─────────────────────────────────────┤               │
│  │ 关键词识别 → 类型判断 → 优先级排序  │               │
│  └─────────────────────────────────────┘               │
│       ↓                                                │
│  ┌─────────────────────────────────────┐               │
│  │         自动回复                    │               │
│  ├─────────────────────────────────────┤               │
│  │ 标准回复模板 → 发送 → 等待反馈     │               │
│  └─────────────────────────────────────┘               │
│       ↓                                                │
│  ┌─────────────────────────────────────┐               │
│  │         人工跟进                    │               │
│  ├─────────────────────────────────────┤               │
│  │ 复杂问题 → 标记 → 人工处理 → 反馈  │               │
│  └─────────────────────────────────────┘               │
│       ↓                                                │
│  问题解决 → 记录归档 → 满意度回访                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 分流规则配置

**智能分流逻辑**：
```yaml
分流维度:
  1. 关键词识别
     • "合作"/"商务" → 合作部门
     • "购买"/"价格" → 销售部门
     • "技术"/"问题" → 技术支持
     
  2. 客户价值
     • 已有购买记录 → 优先处理
     • 潜在高价值 → 重点跟进
     • 普通咨询 → 标准流程
     
  3. 紧急程度
     • 明确紧急 → 即时响应
     • 普通咨询 → 标准流程
```

## 三、销售漏斗管理

### 3.1 销售漏斗设计

**创作者销售漏斗**：
```
曝光 (10000)
    ↓ (1%)
咨询 (100)
    ↓ (30%)
意向 (30)
    ↓ (50%)
报价 (15)
    ↓ (60%)
成交 (9)
    ↓ (40%)
复购 (4)
```

### 3.2 漏斗指标追踪

**关键指标**：
```yaml
漏斗指标:
  曝光→咨询: 咨询转化率
  咨询→意向: 意向转化率
  意向→成交: 成交转化率
  成交→复购: 复购率

计算公式:
  咨询转化率 = 咨询数 / 曝光数 × 100%
  成交转化率 = 成交数 / 意向数 × 100%
  客户终身价值 = 平均订单 × 平均购买次数
```

## 四、跟进自动化

### 4.1 跟进规则配置

**自动跟进触发**：
```yaml
触发条件:
  • 新咨询 → 立即自动回复
  • 咨询后24h无回复 → 提醒
  • 报价后48h无回复 → 跟进
  • 成交后7天 → 回访
  • 成交后30天 → 推荐复购
  • 成交后60天 → 推荐新产品
```

### 4.2 跟进模板

**首次跟进模板**：
```markdown
## 首次跟进（24小时后）

Hi [名字]！

想确认一下你是否看到我之前的回复~ 😊

有任何问题可以随时问我！

[你的名字]
```

**报价跟进模板**：
```markdown
## 报价跟进（48小时后）

Hi [名字]！

想跟进一下之前发送的方案 😊

有什么需要调整的吗？

如果有任何疑问，欢迎随时告诉我！

期待合作~ 🤝
```

**成交回访模板**：
```markdown
## 成交回访（7天后）

Hi [名字]！

感谢你的支持！🙏

产品/服务使用得怎么样？

如果有任何问题或建议，请告诉我~

祝好！
```

## 六、实战案例

**配置详情**：
```yaml
客户分类:
  A类: 高净值客户（月消费$500+）
  B类: 意向客户（有明确需求）
  C类: 普通咨询（价格敏感）
```
