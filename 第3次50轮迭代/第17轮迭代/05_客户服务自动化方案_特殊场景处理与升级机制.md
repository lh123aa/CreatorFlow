## 二、投诉处理机制

### 2.1 投诉分级标准

**投诉等级定义**：
```yaml
一级投诉 (轻微):
  - 普通不满表达
  - 期望未达成的失望
  - 语气友好可沟通
  → 处理: 标准回复+适当补偿

二级投诉 (中等):
  - 明确表达不满
  - 提出具体问题
  - 可能影响评价
  → 处理: 道歉+解决方案+跟进

三级投诉 (严重):
  - 强烈负面情绪
  - 公开表达不满
  - 要求赔偿或退款
  → 处理: 升级处理+专项解决方案

四级投诉 (危机):
  - 威胁投诉平台
  - 发布负面内容
  - 涉及法律风险
  → 处理: 立即升级+危机公关
```

### 2.2 投诉处理流程

**投诉处理SOP**：
```
┌─────────────────────────────────────────────────────────┐
│               投诉处理标准流程                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Step 1: 快速响应 (0-1小时)                             │
│  ─────────────────────                                 │
│  • 确认收到投诉                                         │
│  • 表示重视和歉意                                       │
│  • 承诺处理时间                                         │
│                                                         │
│  Step 2: 问题了解 (1-4小时)                            │
│  ─────────────────────                                 │
│  • 详细了解情况                                         │
│  • 收集相关证据                                         │
│  • 确认核心诉求                                         │
│                                                         │
│  Step 3: 方案制定 (4-24小时)                           │
│  ─────────────────────                                 │
│  • 分析问题原因                                         │
│  • 制定解决方案                                         │
│  • 准备补偿措施                                         │
│                                                         │
│  Step 4: 沟通解决 (24-48小时)                         │
│  ─────────────────────                                 │
│  • 诚恳道歉                                             │
│  • 提出解决方案                                         │
│  • 协商达成一致                                         │
│                                                         │
│  Step 5: 跟进确认 (48-72小时)                         │
│  ─────────────────────                                 │
│  • 确认问题解决                                         │
│  • 收集反馈                                             │
│  • 记录处理经验                                         │
│                                                         │
```

## 三、危机公关处理

### 3.1 危机识别与分级

**危机预警信号**：
```yaml
危机等级:

🚨 红色预警:
  - 多人在同一问题集中投诉
  - 负面内容在社交媒体传播
  - 涉及平台违规警告
  - 可能引发媒体报道

🟠 橙色预警:
  - 知名博主/大V公开批评
  - 投诉升级至平台官方
  - 问题持续发酵
  - 品牌声誉受损

🟡 黄色预警:
  - 负面评价增加
  - 问题讨论引起关注
  - 需要预防性处理
```

### 3.2 危机处理流程

**危机公关SOP**：
```
危机处理时间线:

T+0: 发现危机
├── 立即评估严重程度
├── 通知相关人员
└── 启动危机响应

T+1: 初步应对
├── 官方回应
├── 表明态度
└── 承诺处理

T+4: 调查原因
├── 全面了解情况
├── 收集证据
└── 制定解决方案

T+24: 正式回应
├── 发布处理公告
├── 公布解决方案
└── 展示改进措施

T+48: 持续跟进
├── 执行解决方案
├── 持续沟通
└── 收集反馈

T+1周: 复盘总结
├── 问题根因分析
├── 流程改进
└── 预防措施制定
```

### 3.3 危机回复原则

**危机公关沟通原则**：
```markdown
危机沟通黄金原则:

1. 快速响应
   - 第一时间回应
   - 不要沉默或拖延
   - 表明重视态度

2. 诚实透明
   - 承认问题存在
   - 不推卸责任
   - 及时更新进展

3. 承担责任
   - 道歉要诚恳
   - 赔偿要到位
   - 承诺要可行

4. 持续沟通
   - 定期更新进展
   - 保持渠道畅通
   - 主动反馈结果

5. 后续跟进
   - 彻底解决问题
   - 展示改进成果
   - 预防再次发生
```

### 4.1 升级触发条件

**自动升级规则**：
```yaml
自动升级触发:

  - 连续3次负面表达
```

## 五、恶意行为识别与处理

### 5.1 恶意行为类型

**常见恶意行为**：
```yaml
骚扰行为:
  - 重复发送相同内容
  - 辱骂性语言
  - 人身攻击
  - 垃圾信息

欺诈行为:
  - 虚假投诉威胁
  - 恶意退款
  - 钓鱼诈骗
  - 冒充身份

恶意竞争:
  - 虚假差评
  - 水军攻击
  - 恶意举报
  - 剽窃内容
```

### 5.2 识别与处理

**识别和处理策略**：
```markdown
识别标准:
├── 消息频率异常 (>10条/小时)
├── 内容重复率 (>80%)
├── 情绪极端化 (持续负面)
├── IP/设备异常
└── 历史行为记录

处理方式:
├── 轻度: 警告+限制
├── 中度: 禁言+记录
├── 重度: 拉黑+法律
└── 欺诈: 报警处理
```
