# 自动回复系统搭建

## 前言

自动化回复可以大幅提升客户服务效率。本指南提供自动回复系统搭建方案。

---

## 第一部分：邮件自动回复

### 1.1 规则设置

**Gmail规则**

- 关键词过滤
- 自动标签
- 自动转发
- 自动回复

### 1.2 模板配置

**合作咨询回复**

```
感谢您的合作咨询！

我是[姓名]，[账号]的创作者。

关于合作：
- 我们主要合作类型：[类型]
- 合作邮箱：[邮箱]
- 报价参考：[链接]

期待合作！
```

## 第三部分：WhatsApp自动回复

### 3.1 Business自动回复

**离线回复**

```
感谢您的消息！

我现在不方便回复，将在[时间]内给您回复。

如需紧急帮助，请发送邮件至：[邮箱]
```

**快速回复**

- 常见问题快捷回复
- 菜单式回复

### 3.2 Business Hours

- 设置营业时间
- 非营业时间回复
- 紧急联系指引

## 第四部分：智能回复AI

### 4.1 ChatGPT辅助

**配置方法**

```
使用ChatGPT作为助手：
1. 提供常见问题库
2. 配置回复风格
3. 设置人工介入规则
```

### 4.2 注意事项

- 保持人性化
- 关键问题人工介入
- 持续优化模板
- 保护隐私信息
