## 二、套餐组合策略

### 2.1 套餐设计原则

**套餐设计核心原则**：
```yaml
套餐设计原则:

1. 价值叠加
   - 套餐价值 > 各部分之和
   - 创造"划算"感知
   - 给用户占便宜的感觉

2. 层次分明
   - 基础套餐: 满足基本需求
   - 进阶套餐: 主流选择
   - 高端套餐: 满足高端需求

3. 差异化定位
   - 不同套餐针对不同用户
   - 避免内部竞争
   - 引导用户选择目标套餐

4. 清晰明了
   - 一眼看懂区别
   - 不要过于复杂
   - 3-4个套餐最佳
```

## 六、避坑清单

### 6.1 定价常见错误

**定价避坑**：
```
┌─────────────────────────────────────────────────────────┐
│               定价避坑清单                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ❌ 错误1: 价格过低                                   │
│  ─────────────────────                                 │
│  ¥9.9的课程 → 显得廉价，用户不珍惜                    │
│  → 价格要体现价值                                      │
│                                                         │
│  ❌ 错误2: 价格过高                                   │
│  ─────────────────────                                 │
│  一上来就定高价 → 吓跑用户                              │
│  → 建立价格阶梯，引导升级                              │
│                                                         │
│  ❌ 错误3: 定价混乱                                   │
│  ─────────────────────                                 │
│  各种折扣、优惠、套餐 → 用户算不清                      │
│  → 简化定价，清晰明了                                  │
│                                                         │
│  ❌ 错误4: 不敢涨价                                   │
│  ─────────────────────                                 │
│  成本涨了但价格不敢动                                   │
│  → 定期小幅涨价，逐年提升                              │
│                                                         │
│  ❌ 错误5: 忽视渠道价格                               │
│  ─────────────────────                                 │
│  不同渠道不同价 → 造成用户困惑                          │
│  → 渠道价格要有明确规则                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 6.2 交付常见错误

**交付避坑**：
```markdown
交付避坑清单:

❌ 交付太复杂
   → 简化流程，降低学习成本

❌ 反馈太慢
   → 设置SLA，及时反馈

❌ 内容不更新
   → 建立更新机制，保持活力

❌ 忽略新手引导
   → 完善入门引导，快速上手

❌ 售后缺失
   → 建立退费政策，解除顾虑
```
