## 一、课程平台选择

### 1.1 平台对比分析

**主流课程平台对比**：
```
┌─────────────────────────────────────────────────────────┐
│               课程平台对比                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  平台选择考量因素:                                       │
│  ───────────────────────────────────────────            │
│  • 支付支持 (多币种/本地支付)                           │
│  • 受众覆盖 (全球/区域)                                 │
│  • 功能完善度                                           │
│  • 费用成本                                             │
│  • SEO流量                                              │
│  • 数据控制                                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

```yaml
国际平台:

Teachable:
  - 费用: $29-119/月 + 交易费
  - 优势: 功能强大、定制灵活
  - 支付: 信用卡、PayPal
  - 适合: 有技术背景

Thinkific:
  - 费用: 免费版 + Pro $36/月
  - 优势: 免费版可用、功能丰富
  - 支付: 信用卡、PayPal
  - 适合: 预算有限

Kajabi:
  - 费用: $149-399/月
  - 优势: 全套解决方案
  - 支付: 信用卡、PayPal
  - 适合: 规模化运营

Podia:
  - 费用: 免费版 + $39/月
  - 优势: 无交易费
  - 支付: 信用卡、PayPal
  - 适合: 小规模起步

Gumroad:
  - 费用: 8.5% + 手续费
  - 优势: 极简、粉丝友好
  - 支付: 多种支付
  - 适合: 单课销售
```

## 五、避坑清单

### 5.1 平台选择避坑

**平台避坑**：
```
┌─────────────────────────────────────────────────────────┐
│               平台选择避坑清单                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ❌ 避坑1: 被平台绑定                                   │
│  ─────────────────────                                 │
│  全部课程放一个平台                                     │
│  → 保留自己的用户数据，多平台分发                       │
│                                                         │
│  ❌ 避坑2: 忽视隐性成本                                │
│  ─────────────────────                                 │
│  只看月费，忽视交易费                                   │
│  → 计算实际成本，包括交易手续费                         │
│                                                         │
│  ❌ 避坑3: 功能过度                                    │
│  ─────────────────────                                 │
│  买了企业版但只用基础功能                               │
│  → 从基础版开始，按需升级                              │
│                                                         │
│  ❌ 避坑4: 忽视用户体验                                │
│  ─────────────────────                                 │
│  平台界面复杂，购买流程长                               │
│  → 亲自体验购买流程，不断优化                           │
│                                                         │
│  ❌ 避坑5: 不测试支付                                  │
│  ─────────────────────                                 │
│  上线后发现支付失败                                     │
│  → 上线前完整测试所有支付流程                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 5.2 交付避坑

**交付避坑**：
```markdown
交付避坑清单:

❌ 自动化过头
   → 保留人工介入点，复杂问题人性化处理

❌ 内容不更新
   → 建立更新机制，保持课程活力

❌ 忽视售后
   → 设置明确的售后政策，解除用户顾虑

❌ 不收集反馈
   → 主动收集反馈，持续改进课程

❌ 过度承诺
   → 承诺要可兑现，避免差评
```
