## 二、平台数据分析工具

### 2.1 TikTok分析

**Creator Analytics核心指标**：
| 指标 | 查看位置 | 分析价值 |
|------|----------|----------|
| 视频浏览量 | 视频详情 | 基础流量 |
| 观看时长 | 视频详情 | 完播分析 |
| 互动数据 | 视频详情 | 内容质量 |
| 观众来源 | 受众分析 | 流量来源 |
| 粉丝增长 | 账号总览 | 增长趋势 |

**关键分析维度**：
```
┌─────────────────────────────────────────┐
│        TikTok数据诊断框架                │
├─────────────────────────────────────────┤
│                                         │
│  流量诊断：                              │
│  - 播放量低 → 标题/封面/话题问题        │
│  - 播放量高但涨粉低 → 内容转化差        │
│                                         │
│  互动诊断：                              │
│  - 点赞高评论低 → 引导不足              │
│  - 评论负面 → 内容争议或质量问题        │
│                                         │
│  留存诊断：                              │
│  - 完播率低 → 开头不够吸引             │
│  - 跳出率高 → 内容与预期不符            │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 Instagram分析

**Insights核心指标**：
| 指标 | 说明 | 达标值 |
|------|------|--------|
| 覆盖率 | 触达用户数 | 粉丝数×3+ |
| 互动率 | (点赞+评论)/粉丝 | >3% |
| 静态保存率 | 保存到收藏 | >2% |
| 分享率 | 转发分享 | >1% |
| 粉丝增长 | 净增粉丝 | 持续正增长 |

### 2.3 YouTube分析

**YouTube Studio核心指标**：
| 指标 | 说明 | 优化方向 |
|------|------|----------|
| 点击率(CTR) | 缩略图+标题效果 | >10% |
| 平均观看时长 | 内容吸引力 | 越高越好 |
| 观众留存 | 完播情况 | >50% |
| 订阅来源 | 涨粉渠道 | 分析来源 |

```

  └─ 500-2000：选题/话题问题

□ 完播率分析
  ├─ <30%：开头不够吸引
  └─ 30-50%：内容节奏问题

  ├─ <1%：内容价值不足
  └─ 1-3%：引导互动不足

□ 转化率分析
  └─ 涨粉率<3%：缺乏关注理由
```

### 6.2 选题决策模型

```javascript
// 选题评分模型（简化版）
function scoreTopic(topic) {
  const trending = checkTrend(topic);  // 热度
  const competition = checkCompetition(topic);  // 竞争度
  const fit = checkFit(topic);  // 账号匹配度
  
  const score = trending * 0.4 + (1-competition) * 0.3 + fit * 0.3;
  
  return score > 0.6 ? "推荐" : "不推荐";
}
```

### 6.3 内容优化优先级

| 问题 | 数据表现 | 优化优先级 |
|------|----------|------------|

| 互动不足 | 互动率<1% | P1 |

## 九、核心要点总结

1. **数据是决策基础**，不做"拍脑袋"创作者
2. **核心指标要每天盯**，发现异常及时调整
3. **爆款分析是金矿**，每次爆款都要深挖规律
4. **竞品监测不可少**，知己知彼百战不殆
5. **自动化数据收集**，减少人工记录的时间成本
