# 财务与变现管理系统

## 前言

财务管理系统是创作者长期发展的基础。本指南提供财务与变现管理系统的完整方案。

---

## 第一部分：收入管理

### 1.1 收入分类

**收入类型**

| 类型 | 来源 | 频率 |
|-----|------|------|
| 广告分成 | YouTube/TikTok | 月 |
| 品牌合作 | 企业合作 | 不定期 |
| 联盟营销 | 产品推广 | 不定期 |
| 知识产品 | 课程/电子书 | 不定期 |
| 会员订阅 | 付费会员 | 月 |
| 其他 | 活动等 | 不定期 |

### 1.2 收入追踪数据库

| 属性 | 类型 |
|-----|------|
| 收入来源 | Title |
| 类型 | Select |
| 金额 | Currency |
| 币种 | Select |
| 日期 | Date |
| 平台 | Select |
| 状态 | Select |
| 备注 | Text |
