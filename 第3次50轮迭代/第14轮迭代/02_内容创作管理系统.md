# 内容创作管理系统

## 前言

建立系统化的内容创作管理流程是持续输出的保障。本指南提供内容创作管理系统的完整搭建方案。

---

## 第一部分：内容创作流程

### 1.1 创作阶段划分

**阶段定义**

| 阶段 | 说明 | 状态 |
|-----|------|------|
| 灵感 | 选题灵感收集 | 💡 |
| 规划 | 选题确认和规划 | 📋 |
| 准备 | 资料收集和准备 | 📚 |
| 创作 | 脚本撰写/拍摄 | ✍️ |
| 制作 | 剪辑和后期 | 🎬 |
| 审核 | 内容审核 | ✅ |
| 发布 | 定时发布 | 🚀 |
| 复盘 | 数据复盘 | 📊 |

### 1.2 工作流模板

```
灵感库 → 选题队列 → 制作清单 → 发布日历 → 数据复盘
```

---

## 第二部分：选题管理

### 2.1 选题来源

**灵感收集**

- 热点追踪
- 受众反馈
- 竞品分析
- 自我思考

### 2.2 选题评估

| 维度 | 权重 | 评分标准 |
|-----|------|---------|
| 受众需求 | 30% | 高/中/低 |
| 差异化 | 25% | 独特/一般/雷同 |
| 可执行性 | 20% | 简单/中等/复杂 |
| 时效性 | 15% | 热点/短期/长期 |
| 变现价值 | 10% | 高/中/低 |

---

## 第三部分：脚本管理

### 3.1 脚本模板

**标准结构**

```
标题：[标题]
时长：[时长]
平台：[平台]
类型：[类型]

【开场】
[钩子]

【正文】
[要点1]
[要点2]
[要点3]

【结尾】
[总结]
[行动号召]
```

### 3.2 脚本数据库

**属性**

| 属性 | 类型 |
|-----|------|
| 标题 | Title |
| 视频标题 | Text |
| 时长 | Number |
| 字数 | Number |
| 状态 | Select |
| 关联选题 | Relation |
