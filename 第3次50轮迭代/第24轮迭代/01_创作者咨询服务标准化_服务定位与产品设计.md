### 2.2 服务内容设计

**单次咨询标准包**：
```markdown
## 单次咨询内容

### 咨询前
- 填写咨询表（了解背景和问题）
- 预约时间
- 准备相关资料

### 咨询中 (60-90分钟)
- 问题诊断 (15分钟)
- 原因分析 (15分钟)
- 解决方案 (30分钟)
- 执行计划 (15分钟)

### 咨询后
- 发送咨询纪要
- 赠送相关资料
- 7天内邮件答疑
```

## 三、定价策略

### 3.1 定价原则

**定价考虑因素**：
```yaml
成本计算:
  • 时间成本
  • 机会成本
  • 准备时间
  • 后续服务

价值定价:
  • 为客户创造的价值
  • 替代方案成本
  • 市场参考价格

竞争定价:
  • 竞品定价调研
  • 差异化定价
  • 品牌溢价
```

### 3.2 定价参考

**不同领域定价参考**：
```markdown
| 领域 | 单次咨询 | 套餐(3次) | 陪跑(4周) |
|------|----------|-----------|------------|
| 内容创作 | $99-199 | $299-499 | $1999-3999 |
| 平台运营 | $149-299 | $499-999 | $2999-5999 |
| 变现策略 | $199-399 | $699-1499 | $3999-7999 |
| 跨境出海 | $249-499 | $999-1999 | $4999-9999 |
| 品牌咨询 | $299-599 | $1499-2999 | $5999-9999 |
```

### 3.3 定价技巧

**定价心理学**：
```yaml
锚定效应:
  • 设置高价选项
  • "最受欢迎"选项居中
  • 引导选择中间价位

套餐设计:
  • 3次套餐最划算
  • 年付折扣
  • 早鸟价

价值包装:
  • 原价 vs 现价
  • 包含具体权益
  • 限时优惠
```

## 四、服务流程设计

### 4.1 标准服务流程

**完整服务流程**：
```
Step 1: 潜在客户了解
  ├── 官网/社交媒体
  ├── 案例/评价
  └── 服务介绍
  
Step 2: 需求沟通
  ├── 填写咨询表
  ├── 初步评估
  └── 确认需求匹配

Step 3: 预约与付款
  ├── 选择服务产品
  ├── 完成付款
  └── 确认时间

Step 4: 咨询准备
  ├── 发送准备材料
  ├── 收集相关信息
  └── 准备方案框架

Step 5: 正式咨询
  ├── 视频/语音咨询
  ├── 问题诊断
  ├── 方案讨论
  └── 行动计划

Step 6: 后续跟进
  ├── 发送纪要
  ├── 执行指导
  └── 效果追踪
```

### 4.2 咨询准备清单

**咨询前准备**：
```markdown
□ 回顾客户填写的咨询表
□ 研究客户的账号/作品
□ 准备相关案例
□ 准备工具/模板
□ 列出问题清单
□ 准备PPT/文档
□ 测试通话设备
□ 准备笔记本
```

## 六、客户开发

### 6.1 获客渠道

**咨询客户来源**：
```yaml

  • 分享咨询相关干货
  • 在内容中提及咨询服务
  • 案例分享展示专业度

私域转化:
  • 粉丝群推广
  • 邮件列表
  • 微信私聊

口碑推荐:
  • 满意的客户推荐
  • 转介绍奖励
  • 案例推荐

付费推广:
  • 小红书/抖音广告
  • 搜索引擎广告
  • 精准投放
```

### 6.2 转化策略

**潜在客户转化路径**：
```

    ↓ (对咨询感兴趣)
```
