## 一、咨询流程标准化

### 1.1 标准流程框架
```
需求了解 → 评估匹配 → 预约付款 → 咨询准备 → 正式咨询 → 后续跟进
```

## 二、咨询交付技巧

### 2.1 咨询技巧
```yaml
倾听技巧:
  • 让客户充分表达
  • 记录关键信息
  • 适时提问确认

提问技巧:
  • 开放式问题
  • 追问细节
  • 引导思考

反馈技巧:
  • 先肯定再建议
  • 具体可操作
  • 提供案例
```

### 2.2 常见问题应对
```yaml
问题: 客户期望过高
应对: 理性分析，调整预期

问题: 超出能力范围
应对: 诚实说明，推荐其他资源

问题: 客户犹豫不决
应对: 提供试用/小目标

问题: 需要长期指导
应对: 推荐套餐/陪跑服务
```
