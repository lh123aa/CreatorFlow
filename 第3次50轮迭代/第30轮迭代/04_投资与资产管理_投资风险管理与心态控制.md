## 一、风险管理基础

### 1.1 风险的定义与分类

**风险本质**：
- 风险是收益的不确定性
- 风险不等于损失
- 合理的风险是投资的一部分

**风险类型**：
| 类型 | 描述 | 影响 |
|------|------|------|
| 市场风险 | 系统性风险，不可分散 | 全市场 |
| 非市场风险 | 个别资产特有 | 可分散 |
| 流动性风险 | 变现困难 | 资金需求 |
| 信用风险 | 违约风险 | 债券/理财 |
| 通胀风险 | 购买力下降 | 长期持有 |
| 汇率风险 | 外汇波动 | 跨境投资 |

### 1.2 风险承受能力评估

**评估维度**：
1. **财务状况**：收入稳定性、资产规模、负债水平
2. **投资经验**：投资年限、知识水平、亏损经历
3. **时间跨度**：投资期限、流动性需求
4. **心理素质**：对波动的容忍度、情绪稳定性

**风险测评问卷**：
| 问题 | 选项 | 风险等级 |
|------|------|----------|
| 投资目标 | 保本/稳健/增值/高收益 | 低→高 |
| 可承受亏损 | <5%/5-15%/15-30%/>30% | 低→高 |
| 投资期限 | <1年/1-3年/3-5年/>5年 | 低→高 |
| 波动反应 | 焦虑/不安/接受/加仓 | 低→高 |

### 1.3 风险管理原则

**核心原则**：
1. **不亏损原则**：保住本金是首要任务
2. **适度分散**：不要把鸡蛋放在一个篮子里
3. **止损纪律**：设置止损线并严格执行
4. **仓位控制**：避免过度集中
5. **风险预算**：控制整体风险敞口

## 二、风险控制方法

### 2.1 仓位管理

**仓位管理原则**：
| 方法 | 说明 | 适用场景 |
|------|------|----------|
| 固定仓位 | 每次投入固定金额 | 定投策略 |
| 金字塔 | 越涨越买少，越跌越买多 | 价值投资 |
| 金字塔倒 | 越涨越买多，越跌越买少 | 趋势投资 |
| 凯利公式 | 最优下注比例 | 高手 |

**仓位控制规则**：
- 单只股票不超过总仓位20%
- 单个行业不超过总仓位30%
- 高风险资产不超过总仓位40%
- 保留10-20%现金仓位

### 2.2 止损策略

**止损设置方法**：
| 方法 | 设置方式 | 优点 | 缺点 |
|------|----------|------|------|
| 固定止损 | 亏损X%止损 | 简单 | 不灵活 |
| 移动止损 | 随价格上涨调整 | 保护利润 | 可能被洗出 |
| 逻辑止损 | 逻辑破环止损 | 理性 | 需要判断 |

**止损执行要点**：
- 入市前设定止损位
- 写入交易计划
- 触发时严格执行
- 不要随意撤销

### 2.3 分散投资

**分散维度**：
| 维度 | 方法 |
|------|------|
| 资产类别 | 股票、债券、现金、商品 |
| 地域 | 美股、欧股、亚太、新兴 |
| 行业 | 科技、消费、金融、医疗 |
| 时间 | 分批买入 |
| 风格 | 价值、成长、平衡 |

**分散误区**：
- 分散≠随机买多只
- 分散≠买了10只同类股票
- 真正的分散需要低相关性

## 三、心理风险控制

### 3.1 常见心理偏差

**行为金融学发现**：
| 偏差 | 表现 | 对投资的影响 |
|------|------|--------------|
| 损失厌恶 | 对损失比收益更敏感 | 过早卖出盈利 |
| 从众心理 | 跟随大众行为 | 高买低卖 |
| 过度自信 | 高估自己的判断 | 过度交易 |
| 确认偏差 | 只听认同的观点 | 信息茧房 |
| 锚定效应 | 过度依赖第一个信息 | 错误估值 |
| 近期偏好 | 高估近期事件 | 判断失误 |

### 3.2 心理偏差应对

**具体策略**：

**损失厌恶应对**：
- 设定明确的止损规则
- 不要每天查看账户
- 关注长期收益而非短期波动
- 分散投资降低心理压力

**从众心理应对**：
- 建立独立思考的习惯
- 逆向思考：大众错的时候
- 控制信息来源多元化
- 坚持自己的投资原则

**过度自信应对**：
- 记录投资决策和分析
- 定期回顾和复盘
- 降低交易频率
- 接受不确定性

### 3.3 情绪管理技巧

**投资前准备**：
- 制定详细的投资计划
- 设定明确的买卖规则
- 预估各种情况应对
- 控制投入金额

**投资中执行**：
- 按计划执行，不要临时决策
- 记录情绪和想法
- 与计划不符时暂停
- 避免在情绪激动时操作

**投资后复盘**：
- 分析决策是否理性
- 总结情绪管理得失
- 改进投资系统
- 学习提升

## 四、风险事件应对

### 4.1 市场大跌应对

**大跌应对流程**：
```
大跌发生 → 冷静分析 → 评估原因 → 检查仓位 → 决策执行
     ↓
是否触及止损？ → 是 → 止损
     ↓ 否
是否在能力圈内？ → 否 → 减仓观察
     ↓ 是
是否有更好机会？ → 是 → 调仓
     ↓ 否
继续持有，定期检视
```

**大跌时的常见错误**：
- 恐慌性抛售
- 盲目抄底
- 加杠杆死扛
- 完全不理会

**正确做法**：
- 保持冷静
- 检查持仓质量
- 是否需要止损
- 是否是机会

### 4.2 黑天鹅事件应对

**黑天鹅特点**：
- 不可预测
- 影响巨大
- 事后可解释

**应对策略**：
- 始终保持现金仓位
- 避免过度杠杆
- 配置低相关性资产
- 分散投资
- 设定尾部风险止损

### 4.3 长期持有风险管理

**长期投资风险**：
| 风险 | 描述 | 应对 |
|------|------|------|
| 通胀风险 | 购买力下降 | 配置权益资产 |
| 集中风险 | 单吊个股 | 分散投资 |
| 机会成本 | 错失其他机会 | 定期检视 |
| 心理疲劳 | 长期无回报 | 合理预期 |

**定期检视清单**：
- 资产配置是否偏离
- 持仓基本面是否变化
- 是否需要再平衡
- 投资逻辑是否仍然有效

| Portfolio Visualizer | 组合分析 |
| K线工具 | 技术分析 |

### 5.2 账户风险控制

**账户管理原则**：
- 不要把资金放在一个账户
- 设置账户安全措施
- 定期检查账户
- 分离投资账户和消费账户

**密码和权限**：
- 强密码
- 双因素认证
- 不在公共设备登录
- 定期更换密码

### 5.3 应急计划

**应急情况准备**：
| 情况 | 预案 |
|------|------|
| 市场暴跌 | 止损规则执行 |
| 急需用钱 | 流动性资产准备 |
| 系统故障 | 备用联系方式 |
| 欺诈风险 | 安全验证流程 |

## 六、创作者特别风险

### 6.1 收入波动风险

**创作者收入特点**：
- 收入不稳定
- 有爆发期和淡季
- 平台政策变化影响大

**财务应对策略**：
- 建立3-6个月生活储备
- 收入高时多储蓄
- 配置稳定的被动收入
- 发展多元化收入

### 6.2 投资与创作平衡

**时间分配**：
- 投资不宜占用太多时间
- 选择简单有效的策略
- 定期检视而非频繁操作
- 必要时寻求专业帮助

**精力管理**：
- 投资是副业，创作是主业
- 不要因为投资影响创作
- 专注提升创作能力
- 财务自由是辅助目标

### 6.3 风险承受能力评估

**创作者特殊考虑**：
| 因素 | 影响 | 建议 |
|------|------|------|
| 收入不稳定 | 风险承受力降低 | 配置偏保守 |
| 职业风险 | 平台/粉丝变化 | 多元化收入 |
| 年龄因素 | 长期投资受限 | 中短期配置 |
| 家庭情况 | 责任和负担 | 保守配置 |

**适合创作者的投资**：
- 指数基金定投
- 分散的全球配置
- 低成本的被动管理
- 长期持有策略
