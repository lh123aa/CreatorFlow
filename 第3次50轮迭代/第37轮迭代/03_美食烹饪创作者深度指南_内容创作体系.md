## 二、内容创作方法

### 2.1 烹饪教程

**教程结构**：
```
1. 菜品介绍（是什么）
2. 食材准备（需要什么）
3. 烹饪步骤（怎么做）
4. 技巧要点（小窍门）
5. 成菜展示（完成图）
6. 品尝评价（好吃吗）
```

**拍摄要点**：
| 环节 | 拍摄重点 | 时长 |
|------|----------|------|
| 食材展示 | 清晰、整齐 | 20秒 |
| 处理过程 | 刀工、准备 | 1分钟 |
| 烹饪过程 | 火候、技巧 | 3-5分钟 |
| 成菜展示 | 摆盘、成品 | 30秒 |
| 品尝 | 吃播、口感 | 30秒 |

### 2.2 食谱内容

**食谱模板**：
```
【菜名】
⏱️ 时间：XX分钟
🍽️ 难度：简单/中等/困难
👥 份量：X人份

【食材】
- 食材1：XX克
- 食材2：XX克

【步骤】
1. 第一步
2. 第二步
...

【小贴士】
技巧或注意事项
```

### 2.3 拍摄技巧

**设备推荐**：
- 手机（主要）
- 手机云台（稳定）
- 收音麦克风
- 补光灯（室内）

**光线运用**：
- 自然光是最好的
- 靠窗拍摄
- 避免顶光
- 侧光更有质感
