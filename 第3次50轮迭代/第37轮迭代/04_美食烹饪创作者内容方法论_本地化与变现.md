## 三、本地化策略

### 3.1 清真食品

**清真要求**：
```markdown
清真要点:

食材:
  - 不含猪肉
  - 使用清真肉类
  - 食材来源可追溯
  - 清真认证

制作:
  - 避免混合
  - 独立器具
  - 清洁卫生
  - 符合规范

标注:
  - 明确标注清真
  - 解释清真概念
  - 尊重宗教习俗
  - 提供替代方案
```

## 五、拍摄与制作

### 5.1 美食拍摄技巧

**拍摄要点**：
```yaml
拍摄技巧:

光线:
  - 自然光最佳
  - 侧光突出质感
  - 逆光制造氛围
  - 补光必不可少

构图:
  - 三分法则
  - 低角度拍摄
  - 细节特写
  - 场景布置

色彩:
  - 色彩搭配
  - 暖色调为主
  - 食物本色
  - 背景协调

动态:
  - 倒菜瞬间
  - 热气腾腾
  - 切割过程
  - 拌匀动作
```

### 5.2 视频剪辑技巧

**剪辑要点**：
```markdown
剪辑技巧:

节奏:
  - 节奏明快
  - 3-5秒切换
  - 音乐配合

视觉:
  - 多角度

  - 字幕清晰
```
