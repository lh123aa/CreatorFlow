## 一、仓库结构

### 1.1 目录结构
```yaml
/
├── README.md          # 项目介绍
├── SUMMARY.md          # 内容索引
├── CONTRIBUTING.md     # 贡献指南
├── LICENSE             # 开源协议
│
├── 第1轮-第10轮/       # 入门基础
├── 第11轮-第20轮/      # 工具链
├── 第21轮-第30轮/      # 变现进阶
├── 第31轮-第40轮/      # 垂直深化
├── 第41轮-第50轮/      # 系统整合
│
├── 模板/               # 模板资源
├── 工具/               # 工具配置
└── 资料/               # 附录资料
```

### 1.2 文件命名规范
```yaml
格式: XX_文件名_副标题.md

示例:
  01_创作者踩坑记录_基础篇.md
  02_平台算法分析_TikTok详解.md

规范:
  • 使用中文
  • 下划线分隔
  • 无特殊字符
  • 简洁明了
```
