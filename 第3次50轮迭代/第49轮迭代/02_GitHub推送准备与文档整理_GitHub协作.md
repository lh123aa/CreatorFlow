## 一、GitHub协作

### 1.1 协作流程

**团队协作流程**：
```
Fork → Clone → Branch → Commit → Push → Pull Request → Review → Merge
```

### 1.2 分支管理

**分支策略**：
| 分支 | 用途 | 说明 |
|------|------|------|
| main | 主分支 | 稳定版本 |
| develop | 开发分支 | 开发中内容 |
| feature | 功能分支 | 新功能开发 |
| fix | 修复分支 | 错误修复 |

---

## 二、代码审查

### 2.1 审查流程

**PR审查步骤**：
1. 提交Pull Request
2. 团队成员审查
3. 提出修改意见
4. 提交者修改
5. 审查通过
6. 合并到主分支

### 2.2 审查标准

**审查要点**：
- 内容准确性
- 格式规范性
- 逻辑完整性
- 可读性
