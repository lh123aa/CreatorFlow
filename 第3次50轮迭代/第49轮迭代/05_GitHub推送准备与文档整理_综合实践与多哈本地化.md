## 五、发布流程

### 5.1 发布检查清单

**发布前检查**：
```markdown
发布检查:

□ 所有文件已整理
□ 文件名规范
□ 格式统一
□ 无错误链接

代码检查:
□ gitignore正确
□ 许可证完整
□ README完整
□ 贡献指南完整

□ 权限设置正确
□ CI/CD正常
```

### 5.2 发布流程

**发布流程**：
```
Step 1: 本地准备
├── 整理文档
├── 本地测试
├── 提交到main
└── 创建tag

Step 2: GitHub操作
├── 创建Release
├── 发布说明
├── 添加发布文件
└── 通知用户

Step 3: 后续维护
├── 监控Issues
├── 合并PR
├── 持续更新
└── 社区运营
```

## 七、避坑清单

### 7.1 常见错误

**发布避坑**：
```
┌─────────────────────────────────────────────────────────┐
│               发布避坑清单                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ❌ 不测试就发布                                       │
│  → 发布前本地完整测试                                  │
│                                                         │
│  ❌ 许可证选择错误                                     │
│  → 选择合适的开源许可证                               │
│                                                         │
│  ❌ 忽略安全敏感信息                                   │
│  → 确保无敏感信息泄露                                 │
│                                                         │
│  ❌ 文档不完整                                         │
│  → 确保README和贡献指南完整                           │
│                                                         │
│  ❌ 不设置分支保护                                     │
│  → main分支设置保护规则                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
