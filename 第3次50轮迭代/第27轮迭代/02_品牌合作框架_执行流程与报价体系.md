## 一、合作执行流程

### 1.1 标准合作流程

**完整合作周期**：
```
需求对接 → 方案提案 → 合同签署 → 内容制作 → 审核确认 → 发布执行 → 效果评估 → 款项结算
```

**各阶段时间参考**：
| 阶段 | 建议时长 | 注意事项 |
|------|----------|----------|
| 需求对接 | 3-7天 | 充分了解需求 |
| 方案提案 | 3-5天 | 提供多个方案 |
| 合同签署 | 3-7天 | 审核条款 |
| 内容制作 | 7-30天 | 按复杂度 |
| 审核确认 | 2-5天 | 及时响应 |
| 发布执行 | 按计划 | 准时发布 |
| 效果评估 | 7-14天 | 数据收集 |
| 款项结算 | 7-30天 | 跟进回款 |

### 1.2 需求对接

**关键信息收集**：
| 信息类型 | 具体内容 | 重要性 |
|----------|----------|--------|
| 品牌信息 | 品牌背景、调性、受众 | 必须 |
| 产品信息 | 产品特点、卖点、卖点 | 必须 |
| 合作目标 | 曝光、转化、品牌 | 必须 |
| 目标受众 | 年龄、兴趣、地域 | 必须 |
| 预算范围 | 合作预算 | 必须 |
| 时间要求 | 发布时间、周期 | 必须 |
| 交付要求 | 内容形式、审核 | 必须 |

**需求确认清单**：
- [ ] 品牌及产品介绍
- [ ] 合作目标和KPI
- [ ] 内容形式和要求
- [ ] 预算和报价
- [ ] 时间安排
- [ ] 审核流程
- [ ] 独家要求
- [ ] 版权归属

### 1.3 方案提案

**提案内容框架**：
```
1. 品牌理解
   - 品牌调性分析
   - 目标受众匹配
   - 合作价值判断

2. 内容策略
   - 内容创意概念
   - 创意呈现方式
   - 差异化亮点

3. 执行计划
   - 制作时间表
   - 发布排期
   - 配合事项

4. 报价方案
   - 服务内容明细
   - 费用构成
   - 支付方式

5. 案例参考
   - 相关成功案例
   - 效果数据展示
```

## 二、报价体系

### 2.1 报价维度

**影响报价的因素**：
| 因素 | 说明 | 对报价影响 |
|------|------|------------|
| 粉丝量 | 账号影响力 | 正相关 |
| 互动率 | 粉丝活跃度 | 高互动高报价 |
| 内容质量 | 内容专业度 | 正相关 |
| 品牌契合度 | 与品牌匹配度 | 影响合作成功率 |
| 交付形式 | 内容复杂度 | 视频>图文 |
| 独家程度 | 是否独家合作 | 独家加价 |
| 使用权限 | 使用范围和期限 | 扩大加价 |

### 2.2 报价标准参考

**图文合作报价**：
| 粉丝量 | 参考报价 | 说明 |
|--------|----------|------|
| 1万以下 | 200-500元 | 起步阶段 |
| 1-5万 | 500-2000元 | 成长期 |
| 5-10万 | 2000-5000元 | 成熟期 |
| 10-50万 | 5000-20000元 | 影响力期 |
| 50万+ | 20000+ | 头部账号 |

**视频合作报价**：
| 粉丝量 | 参考报价 | 说明 |
|--------|----------|------|
| 1万以下 | 500-1500元 | 起步阶段 |
| 1-5万 | 1500-5000元 | 成长期 |
| 5-10万 | 5000-15000元 | 成熟期 |
| 10-50万 | 15000-50000元 | 影响力期 |
| 50万+ | 50000+ | 头部账号 |

**报价调整系数**：
| 因素 | 调整系数 | 说明 |
|------|----------|------|
| 高互动率 | 1.2-1.5 | 互动率>5% |
| 独家合作 | 1.5-2.0 | 独家加价 |
| 长期合作 | 0.8-0.9 | 优惠折扣 |
| 批量合作 | 0.7-0.9 | 打包优惠 |
| 复杂制作 | 1.2-1.5 | 定制内容 |

### 2.3 报价策略

**报价技巧**：
1. **锚定策略**：先报高价，留出谈判空间
2. **套餐报价**：多内容打包，捆绑销售
3. **阶梯报价**：按量定价，鼓励加量
4. **价值报价**：强调效果，按效果定价

**报价沟通原则**：
- 明确报价包含内容
- 说明报价有效期
- 保持专业态度
- 不轻易降价

## 三、内容制作规范

### 3.1 制作流程

**标准制作流程**：
```
创意策划 → 脚本撰写 → 素材准备 → 内容制作 → 内部审核 → 提交品牌 → 修改确认 → 最终交付
```

**各阶段要点**：
| 阶段 | 时间 | 要点 |
|------|------|------|
| 创意策划 | 1-2天 | 创意方向、形式选择 |
| 脚本撰写 | 1-3天 | 结构、话术、产品信息 |
| 素材准备 | 2-5天 | 产品、场景、道具 |
| 内容制作 | 3-7天 | 拍摄/设计/剪辑 |
| 内部审核 | 1天 | 质量检查 |
| 品牌审核 | 1-3天 | 按品牌反馈修改 |
| 最终交付 | 1天 | 格式、命名规范 |

### 3.2 内容审核

**审核标准**：
| 维度 | 标准 | 注意事项 |
|------|------|----------|
| 产品呈现 | 清晰展示产品 | 不得丑化、贬低 |
| 信息准确 | 数据/声明准确 | 避免虚假宣传 |
| 品牌调性 | 符合品牌形象 | 不得有损品牌 |
| 合规要求 | 符合广告法 | 避免绝对化用语 |
| 原创性 | 内容原创 | 不得抄袭 |

**审核沟通**：
- 提前了解品牌审核标准
- 主动沟通避免偏差
- 预留修改时间
- 保留沟通记录

### 3.3 交付规范

**交付内容清单**：
- [ ] 主内容文件（图片/视频）
- [ ] 封面图
- [ ] 文案/脚本
- [ ] 发布时间截图
- [ ] 效果数据（如有）

**交付格式要求**：
| 内容类型 | 格式要求 |
|----------|----------|
| 图片 | JPG/PNG，3000px以上 |
| 视频 | MP4，1080P以上 |
| 文案 | Word/PDF，标注品牌信息 |
| 封面 | 单独一个文件 |

## 四、合同与法律

### 4.1 合同核心条款

**必备条款**：
| 条款 | 内容要求 |
|------|----------|
| 合作内容 | 具体形式和数量 |
| 交付时间 | 各阶段时间节点 |
| 验收标准 | 内容审核标准 |
| 费用及支付 | 金额、节点、方式 |
| 知识产权 | 内容版权归属 |
| 保密条款 | 商业信息保密 |
| 违约责任 | 双方违约处理 |
| 争议解决 | 纠纷处理方式 |

### 4.2 知识产权约定

**版权归属类型**：
| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 创作者保留 | 创作者保留版权 | 品牌仅使用一次 |
| 共同拥有 | 双方共同拥有 | 深度合作 |
| 品牌买断 | 品牌获得版权 | 高价一次性买断 |
| 授权使用 | 品牌获得授权 | 限定范围使用 |

**使用权限约定**：
- 使用期限
- 使用平台
- 使用地域
- 是否可二次编辑

### 4.3 风险防控

**风险识别**：
| 风险类型 | 描述 | 防范措施 |
|----------|------|----------|
| 品牌毁约 | 品牌方取消合作 | 预付款 |
| 内容争议 | 内容引起法律问题 | 免责条款 |
| 款项拖欠 | 品牌方拖延付款 | 付款节点 |
| 品牌负面 | 品牌出现负面新闻 | 声誉评估 |
| 超范围使用 | 品牌超范围使用 | 明确范围 |

## 五、执行管理

### 5.1 项目管理

**项目管理要素**：
| 要素 | 内容 |
|------|------|
| 目标 | 合作目标和KPI |
| 范围 | 具体交付内容 |
| 时间 | 时间表和里程碑 |
| 成本 | 预算和报价 |
| 质量 | 审核标准 |
| 沟通 | 对接方式和频率 |

**时间管理工具**：
- Notion：项目看板
- Asana：任务管理
- Trello：简单协作
- Excel：进度追踪

### 5.2 沟通管理

**沟通机制**：
| 沟通类型 | 频率 | 内容 |
|----------|------|------|
| 进度同步 | 每周 | 工作进展 |
| 问题升级 | 随时 | 需要协调的问题 |
| 审核反馈 | 按需 | 内容审核 |
| 效果复盘 | 完成后 | 数据反馈 |

**沟通记录**：
- 重要沟通邮件留档
- 关键决策记录
- 修改记录保存

### 5.3 风险管理

**风险监控**：
| 风险 | 预警信号 | 应对措施 |
|------|----------|----------|
| 进度延期 | 接近deadline未完成 | 加班/缩减范围 |
| 审核不通过 | 多次修改仍有问题 | 沟通明确标准 |
| 款项逾期 | 超过约定时间未付 | 催款+暂停合作 |
| 品牌负面 | 品牌出现负面 | 评估是否继续 |
