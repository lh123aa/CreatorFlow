## 二、选题策划方法

### 2.1 选题来源

| 来源类型 | 具体渠道 | 价值 |
|----------|----------|------|
| 用户需求 | 评论、私信、搜索 | 高 |

| 自身经历 | 个人经验分享 | 中 |
| 专业知识 | 领域知识输出 | 高 |

### 2.2 选题评估矩阵

| 维度 | 评估标准 | 权重 |
|------|----------|------|
| 粉丝需求 | 是否满足粉丝期待 | 30% |
| 差异化 | 是否与竞品不同 | 25% |
| 可执行性 | 能否高质量完成 | 25% |

## 三、脚本撰写方法

### 3.1 脚本结构模板

**短视频脚本**：
```
┌─────────────────────────────────────────┐
│ 时间      │ 内容        │ 备注          │
├─────────────────────────────────────────┤
│ 0-3秒    │ 开头钩子    │ 抓注意力       │
│ 3-15秒   │ 核心内容    │ 价值输出       │
│ 15-30秒  │ 高潮/反转   │ 情绪峰值       │
│ 30-60秒  │ 结尾引导    │ 互动引导       │
└─────────────────────────────────────────┘
```

### 3.2 开头写法

**黄金3秒法则**：
| 写法 | 示例 |
|------|------|
| 疑问式 | "你知道多哈人最讨厌什么吗？" |
| 惊叹式 | "天哪！这家餐厅居然..." |
| 冲突式 | "我被多哈本地人嘲笑了..." |
| 数字式 | "3个多哈生活的秘密..." |

### 3.3 内容展开技巧

**内容节奏**：
```
开头（3秒）→ 铺垫（10秒）→ 高潮（15秒）→ 结尾（5秒）
```

**内容技巧**：
- 善用对比
- 制造悬念
- 情绪调动
- 故事化表达

|------|------|------|
| 推拉 | 突出重点 | 低 |
| 摇移 | 展示环境 | 中 |

```
素材整理 → 初剪 → 精剪 → 调色 → 字幕 → 音效 → 输出
```

## 五、标题封面方法

### 5.1 标题写法

**高点击标题公式**：
```
标题 = 数字 + 关键词 + 情绪词 + 悬念
```

**标题模板**：
| 类型 | 模板 | 示例 |
|------|------|------|
| 数字型 | X个...的... | "5个多哈生活的真相" |
| 疑问型 | 你知道...吗？ | "你知道多哈人怎么过节吗？" |
| 对比型 | ...vs... | "多哈 vs 迪拜，区别是..." |
| 悬念型 | 原来... | "原来多哈人这样待客" |

### 5.2 封面设计

**封面要素**：
```
┌─────────────────────────────────────────┐
│           高点击封面要素                 │
├─────────────────────────────────────────┤
│ 人物：出镜、有表情                       │
│ 文字：大字、关键词                      │
│ 色彩：对比强、鲜明                      │
│ 画面：有张力、抓眼球                    │
└─────────────────────────────────────────┘
```

**封面模板**：
| 类型 | 特点 | 适用 |
|------|------|------|
| 人物+文字 | 直接有效 | 知识类 |
| 产品展示 | 突出主体 | 带货类 |
| 场景+文字 | 氛围感 | 生活类 |

## 九、核心要点总结

1. **选题决定内容方向**：好选题是成功的一半
2. **开头决定留存**：黄金3秒必须抓住注意力
3. **脚本决定质量**：好的脚本是好内容的基础
4. **封面决定点击**：封面是内容的门面
5. **本地化决定传播**：符合本地审美才能走得更远
