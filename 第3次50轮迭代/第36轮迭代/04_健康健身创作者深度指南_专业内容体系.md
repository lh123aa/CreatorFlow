## 二、内容创作方法

### 2.1 健身教程

**内容结构**：
```
1. 目标说明（练什么）
2. 动作示范（怎么做）
3. 要点讲解（注意点）
4. 组数次数（练多少）
5. 常见错误（别踩坑）
6. 进阶退阶（可调整）
```

**动作演示**：
- 多角度展示
- 关键肌肉标注
- 正确vs错误对比
- 适合人群说明

### 2.2 减脂内容

**热门选题**：
| 选题 | 吸引力 | 示例 |
|------|--------|------|
| 居家燃脂 | 高 | "每天15分钟，一个月后..." |
| 饮食建议 | 高 | "减脂期这样吃" |
| 习惯养成 | 中高 | "减脂成功的习惯" |
| 经验分享 | 高 | "我减了20斤的方法" |

### 2.3 健身Vlog

**内容形式**：
- 训练记录
- 健身房探店
- 减脂日记
- 健身前后对比
