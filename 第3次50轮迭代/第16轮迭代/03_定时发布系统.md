# 定时发布系统

## 前言

定时发布确保内容在最佳时间触达受众。本指南提供完整的定时发布系统搭建方案。

---

## 第一部分：Buffer定时发布

### 1.1 Buffer设置

**账号连接**

- YouTube
- TikTok
- Instagram
- LinkedIn
- Twitter

### 1.2 发布排期

**示例排期**

| 平台 | 发布时间 |
|-----|---------|
| YouTube | 周五 15:00 |
| TikTok | 周一 12:00 |
| Instagram | 周二 13:00 |
| LinkedIn | 周三 10:00 |

---

## 第二部分：Hootsuite定时发布

### 2.1 功能特点

- 多账号管理
- 团队协作
- 分析报告

### 2.2 发布流程

1. 内容创建
2. 平台选择
3. 时间设置
4. 预览确认
5. 确认发布

## 第三部分：各平台原生定时

### 3.1 YouTube定时

**Studio设置**

1. 上传视频
2. 设置缩略图
3. 填写标题描述
4. 选择发布时间
5. 公开/定时

### 3.2 TikTok定时

**定时发布**

1. 创建视频
2. 编辑内容
3. 设置发布时间
4. 保存草稿/发布

### 3.3 Instagram定时

**Creator Studio**

- 网页版定时
- 移动版定时

## 第四部分：自动化发布

### 4.1 Zapier发布自动化

**模板**

```
触发：Google Sheets新行
执行：
1. 提取内容信息
2. 上传到YouTube
3. 设置定时发布
4. 记录到日志
```

### 4.2 Make发布自动化

**多平台同步**

```
Trigger：YouTube新视频
执行：
1. 下载视频
2. 格式转换
3. 上传到TikTok
4. 上传到Instagram
5. 记录状态
```
