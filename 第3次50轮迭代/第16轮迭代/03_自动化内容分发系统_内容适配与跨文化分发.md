## 二、内容本地化策略

### 2.1 本地化层级

**内容本地化四层级**：
```
Level 1: 字幕本地化
┌─────────────────────────────────────────┐
│ 原内容 + 多语言字幕                     │
│ • 仅翻译字幕                            │
│ • 保留原音                              │
│ • 最快最简单                            │
└─────────────────────────────────────────┘

Level 2: 界面本地化
┌─────────────────────────────────────────┐
│ 字幕 + 封面文字 + 标题                   │
│ • 翻译所有文字                          │
│ • 适配平台风格                          │
│ • 保持内容一致                          │
└─────────────────────────────────────────┘

Level 3: 文化本地化
┌─────────────────────────────────────────┐
│ 文化适配 + 本地案例 + 热点结合           │
│ • 调整文化元素                          │
│ • 加入本地相关案例                      │
│ • 结合当地热点                          │
└─────────────────────────────────────────┘

Level 4: 深度本地化
┌─────────────────────────────────────────┐
│ 完全本土化 + 本地制作 + 当地合作        │
│ • 完全针对当地受众                      │
│ • 可能需要本地团队                      │
│ • 最高投入最高回报                      │
└─────────────────────────────────────────┘
```

### 2.2 多语言字幕方案

**字幕制作流程**：
```yaml
工具选择:
  DeepL/Google Translate: 初稿翻译
  人工校对: 确保准确
  CapCut/剪映: 添加字幕

字幕格式:
  中文 → 英文
  中文 → 阿拉伯语（可选）
  
翻译原则:
  • 保持原意
  • 符合目标语言习惯
  • 适当本地化表达
```

**翻译提示词**：
```markdown
翻译任务:
请将以下中文内容翻译为英文，保持简洁易懂：

[粘贴中文内容]

要求:
1. 简洁，适合字幕显示
2. 保持口语化
3. 避免直译，选择意译
4. 保留关键词和亮点
```

## 四、文化敏感性指南

### 4.1 伊斯兰文化注意事项

**必须避免的内容**：
```yaml
宗教相关:
  ❌ 任何宗教的负面内容
  ❌ 先知/宗教人物相关
  ❌ 宗教比较内容
  
着装规范:
  ❌ 过于暴露的穿着
  ❌ 泳装/内衣展示
  ❌ 暗示性内容

饮食禁忌:
  ❌ 猪肉相关内容
  ❌ 酒精正面展示
  ❌ 斋月白天进食画面

节日注意:
  ❌ 斋月敏感内容
  ❌ 开斋节/宰牲节不当庆祝
  ✅ 尊重当地节日
```

### 4.2 正面展示指南

**推荐展示内容**：
```yaml
文化展示:
  ✅ 阿拉伯建筑之美
  ✅ 本地美食（非猪肉/酒精）
  ✅ 传统服饰（abaya等）
  ✅ 文化体验活动

生活方式:
  ✅ 高端生活方式（符合当地审美）
  ✅ 家庭温馨场景
  ✅ 朋友聚会（男女分开或家庭场景）
  ✅ 运动健身

商业内容:
  ✅ 奢侈品（当地流行）
  ✅ 高端餐饮
  ✅ 旅行体验
  ✅ 科技产品
```

## 五、实战案例

**内容制作策略**：
```markdown
原始内容: 多哈高端餐厅探店视频（5分钟）

适配版本:

版本1 - 小红书（华人受众）:
```
