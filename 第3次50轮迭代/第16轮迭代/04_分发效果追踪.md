# 分发效果追踪

## 前言

追踪分发效果是优化策略的基础。本指南提供分发效果追踪方案。

---

## 第一部分：追踪指标

### 1.1 核心指标

| 指标 | 说明 | 计算 |
|-----|------|------|
| 播放量 | 内容曝光 | 直接统计 |
| 互动率 | 互动程度 | (赞+评+分)/播 |
| 完播率 | 观看完成 | 看完/总播 |
| 转化率 | 到主平台 | 跳转数/播 |

### 1.2 跨平台追踪

**追踪方法**

- UTM参数追踪
- 专属链接
- 二维码追踪
