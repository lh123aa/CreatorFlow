## 一、项目管理基础

### 1.1 创作者项目类型

| 类型 | 说明 | 周期 |
|------|------|------|
| 内容项目 | 单条内容制作 | 1-7天 |
| 活动项目 | 线下活动 | 30-60天 |
| 产品项目 | 产品开发 | 60-180天 |
| 品牌项目 | 品牌合作 | 按项目 |

### 1.2 项目管理框架

```
立项 → 计划 → 执行 → 监控 → 收尾
```

---

## 二、内容项目管理

### 2.1 内容制作流程

| 阶段 | 内容 | 时长 |
|------|------|------|
| 选题 | 确定主题 | 1天 |
| 策划 | 设计内容 | 1天 |
| 制作 | 拍摄/录制 | 1-3天 |
| 后期 | 剪辑制作 | 1-2天 |
| 发布 | 上传运营 | 1天 |

### 2.2 进度管理

**甘特图示例**：
```
周一：选题+策划
周二：拍摄
周三：后期制作
周四：发布
```
