## 三、AI Prompt模板库（50+精选）

### 3.1 选题策划类 Prompt

#### Prompt 1：爆款选题挖掘
```markdown
我想做一个关于[主题]的账号，目标受众是[受众描述]。

请帮我找出：
1. 这个领域的10个高互动选题（附分析）
2. 每个选题的爆款元素拆解
3. 差异化切入角度建议

请用表格输出，标注每个选题的潜力指数。
```

#### Prompt 2：用户痛点挖掘
```markdown
我是一个[你的身份]创作者，专注于[领域]。

请帮我分析目标用户[受众描述]的：
1. Top 10 核心痛点
2. 每个痛点背后的心理需求
3. 针对每个痛点的内容切入点

请用结构化方式输出。
```

#### Prompt 3：热点内容转化
```markdown
最近[行业]有一个热点：[热点描述]

请帮我分析：
1. 这个热点为什么火？（底层逻辑）
2. 作为[领域]创作者，如何蹭热点而不翻车？
3. 给出3个不同角度的内容创意

要求：接地气、可操作、有个人特色。
```

### 3.2 脚本撰写类 Prompt

#### Prompt 4：短视频脚本生成
```markdown
帮我写一个[时长]秒的短视频脚本。

主题：[你的主题]
目标受众：[受众描述]
风格：[幽默/专业/温暖/犀利等]

脚本结构：
- 开场钩子（前3秒）：制造悬念/痛点/冲突
- 核心内容：3个要点/步骤
- 结尾CTA：引导关注/评论/行动

要求：
1. 语言口语化，适合念出来
2. 标注每个部分的时长
3. 包含具体文案和金句
```

#### Prompt 5：长视频深度脚本
```markdown
帮我写一个[时长]分钟的视频脚本，主题是[主题]。

目标：
- 让观众看完后能[具体收获]
- 看完后想[行动]

脚本结构：
1. 开头（10%）：痛点共鸣 + 承诺
2. 主体（75%）：
   - Part 1：[核心观点1] + 案例/数据
   - Part 2：[核心观点2] + 案例/数据
   - Part 3：[核心观点3] + 案例/数据
3. 结尾（15%）：总结 + 资源 + CTA

要求：
- 每个观点有具体案例支撑
- 标注语气、节奏、情绪
- 预留插图/素材位置
```

#### Prompt 6：教程类脚本
```markdown
写一个"[教程主题]"的教程脚本。

目标用户：[用户画像]
难度：初学者/进阶/高级
预计时长：[X]分钟

要求：
1. 步骤清晰，每步有明确动作
2. 预判常见错误和卡点
3. 提供快速成功的小技巧
4. 包含练习/实操环节

格式：步骤编号 + 动作 + 讲解
```

## 五、AI合规使用指南

### 5.1 平台规则红线

#### 各平台AI内容政策
| 平台 | AI内容政策 | 披露要求 | 限流风险 |
|------|-----------|----------|----------|
| YouTube | 允许但不鼓励 | 推荐标注 | 原创度下降可能 |
| TikTok | 允许 | 推荐标注 | 高频发布可能 |
| Instagram | 允许 | 推荐标注 | 原创判定严格 |
| 小红书 | 允许 | 推荐标注 | 识别度较高 |
| 公众号 | 允许 | 无明确要求 | 相对宽松 |

#### 风险等级划分
```
🟢 低风险：AI辅助 + 大量人工修改 + 原创素材
🟡 中风险：AI生成 + 基础修改
🔴 高风险：纯AI生成 + 最小修改 + 无个人风格

建议：保持🟢或🟡风险等级
```

### 5.2 合规使用建议

#### 最低合规标准
```markdown
## AI内容最低合规要求

1. **实质性修改**
   - AI初稿必须经过人工修改≥50%
   - 加入个人经历、独特观点、原创素材
   - 调整语言风格符合个人品牌

2. **来源披露**
   - 建议在简介/描述中标注"AI辅助"
   - 不强制但推荐，建立信任
   - 参考写法："本文由AI辅助创作，个人经验整理"

3. **质量把关**
   - AI可能产生事实错误，必须核实
   - AI可能产生偏见，注意甄别
   - 涉及专业领域需专业人士审核

4. **原创度保护**
   - 不要直接发布AI输出
   - 加入个人素材、独特案例
   - 保持内容的差异化价值
```

#### 版权合规检查清单
```markdown
## AI生成内容版权自检

### 图片类
- [ ] 确认AI图片版权归属（各平台政策不同）
- [ ] 不要直接使用含品牌logo的设计
- [ ] 人物AI生成需谨慎（可能有肖像权问题）
- [ ] 建议添加个人元素（文字、水印、混合）

### 视频类
- [ ] AI生成视频的音乐需确认版权
- [ ] 混用AI素材和原创素材
- [ ] 视频模板注意授权范围

### 文字类
- [ ] AI生成内容禁止抄袭/洗稿
- [ ] 数据、事实需核实
- [ ] 引用来源必须标注
```

### 5.3 AI使用避坑指南

#### 常见翻车案例
| 场景 | 翻车类型 | 后果 | 解决方案 |
|------|----------|------|----------|
| AI生成数据 | 虚构数据 | 公信力崩塌 | 标注"AI估算"+核实 |
| AI生成人物 | 肖像问题 | 法律风险 | 避免写实人物/用虚拟形象 |
| AI翻译 | 语义错误 | 误导受众 | 人工审核关键信息 |
| AI生成新闻 | 虚假信息 | 封号风险 | 官方信息源优先 |
| AI写代码 | 安全漏洞 | 用户损失 | 测试后再发布 |
