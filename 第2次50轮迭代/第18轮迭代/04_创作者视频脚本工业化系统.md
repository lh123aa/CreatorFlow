## 一、视频脚本的5种基本结构

### 结构1：总分总结构

**最经典的内容结构**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                        总（开头）                           │
│                    提出核心观点                             │
│                         ↓                                   │
│                                                             │
│                        分（主体）                           │
│                 观点1 → 观点2 → 观点3                       │
│                         ↓                                   │
│                                                             │
│                        总（结尾）                           │
│                    总结+行动号召                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**适用场景**：知识分享、观点阐述、教程讲解

**脚本示例（总分总）**：

```
【开场 - 10%】
"今天我要告诉你一个关于YouTube算法的真相，
这个真相可能和你想的完全不一样。"

【主体 - 80%】
观点1："第一个秘密是完播率不是最重要的"
  - 解释完播率的局限性
  - 举例说明
  
观点2："第二个秘密是点击率决定推荐量"
  - 解释CTR的重要性
  - 提供提高CTR的方法
  
观点3："第三个秘密是互动率影响长期排名"
  - 解释互动率的作用
  - 提供增加互动的方法

【结尾 - 10%】
"所以，如果你想让视频被更多人看到，
记住这三件事：..."
```

### 结构2：问题-解决方案结构

**直击痛点的内容结构**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                   问题（Pain Point）                        │
│                 "你是不是也遇到..."                         │
│                         ↓                                   │
│                                                             │
│                 共情（Empathy）                            │
│              "我完全理解你的感受"                           │
│                         ↓                                   │
│                                                             │
│                方案（Solution）                            │
│              "其实解决方案很简单..."                        │
│                         ↓                                   │
│                                                             │
│                 行动（Action）                            │
│              "现在就跟我一起做..."                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**适用场景**：教程类、问题解决类、痛点导向类内容

### 结构3：故事弧线结构

**利用叙事吸引力的结构**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                    设定（Setup）                            │
│               介绍背景和主角                                 │
│                   ↘                                         │
│                    冲突（Conflict）                        │
│               遇到挑战/问题                                 │
│                    ↘                                        │
│                     高潮（Climax）                         │
│               关键时刻/转折点                               │
│                    ↘                                        │
│                     解决（Resolution）                     │
│               问题解决/学到什么                             │
│                    ↘                                        │
│                     主题升华（Theme）                       │
│              超越故事的普世意义                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**适用场景**：Vlog、个人故事、案例分享

### 结构4：对比结构

**通过对比制造张力**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                 错误方式 vs 正确方式                        │
│                                                             │
│   ┌─────────────────┐          ┌─────────────────┐         │
│   │    错误方式      │          │    正确方式      │         │
│   │   做法1          │          │   做法1'         │         │
│   │   做法2          │          │   做法2'         │         │
│   │   做法3          │          │   做法3'         │         │
│   └─────────────────┘          └─────────────────┘         │
│                                                             │
│                         ↓                                   │
│                                                             │
│                    总结对比                                 │
│                  "差距就是..."                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**适用场景**：评测、避坑指南、方法论讲解

### 结构5：清单结构

**清晰有序的结构**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│               "做XXX你需要知道N件事"                        │
│                                                             │
│                    1. 第一件事                              │
│                         ↓                                   │
│                    2. 第二件事                              │
│                         ↓                                   │
│                    3. 第三件事                              │
│                         ↓                                   │
│                       ...                                   │
│                         ↓                                   │
│                    N. 第N件事                               │
│                         ↓                                   │
│                      总结                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**适用场景**：Top榜单、清单类、步骤类内容

## 五、AI辅助脚本生成工作流

### 工作流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│     ┌──────────┐    ┌──────────┐    ┌──────────┐              │
│     │  选题    │ →  │  脚本    │ →  │  修改    │              │
│     │  策划    │    │  生成    │    │  优化    │              │
│     └──────────┘    └──────────┘    └──────────┘              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Step 1：选题策划

**给AI的指令模板**：

```
我是一个专注于[领域]的创作者，目标受众是[描述]。
请根据以下关键词，帮我策划5个视频选题：

关键词：[列出核心关键词]

每个选题需要包含：
1. 标题（吸引人，包含数字/情绪词）
2. 核心观点（1句话）
3. 适合的视频时长
4. 适合的平台
5. 预计难点
```

### Step 2：脚本生成

**给AI的指令模板**：

```
请帮我写一个[时长]分钟的视频脚本。

【基本信息】
主题：[具体主题]
风格：[幽默/严肃/温暖/专业]
目标受众：[描述]

【结构要求】
使用[总分总/问题-解决/故事弧线]结构

【必须包含的元素】
- 开场Hook
- 至少3个要点/故事
- 结尾CTA

【注意事项】
- 语言口语化，适合视频表达
- 每个要点有具体例子
- 控制节奏，不要太拖沓

【字数】
总字数约[具体数字]字
```

### Step 3：脚本优化

**给AI的优化指令**：

```
请优化以下脚本，使其更适合视频表达：

[粘贴原脚本]

优化方向：
1. 增加口语化表达
2. 添加过渡语
3. 增加互动引导（如"你们觉得呢"）
4. 缩短冗余部分
5. 强化开头和结尾
```

## 七、从脚本到成片的转化SOP

### 标准化流程

```
Step 1: 脚本定稿
├─ 完成脚本撰写
├─ 自检清单检查
├─ 确认发布计划（平台/时间）
└─ 导出最终版本

Step 2: 拍摄准备
├─ 确认拍摄场地
├─ 准备设备（相机/灯光/麦克风）
├─ 打印脚本/提词器准备
├─ 准备道具/素材
└─ B-roll拍摄计划

Step 3: 拍摄执行
├─ 正式录制
├─ 多条备选
├─ 检查素材完整性
└─ 备份原始文件

Step 4: 后期剪辑
├─ 导入素材
├─ 初剪（按脚本顺序）
├─ 添加B-roll/字幕
├─ 调色/调音
├─ 添加封面/片头片尾
└─ 预览并修改

Step 5: 导出发布
├─ 按平台要求导出
├─ 上传视频
├─ 填写标题/描述/标签
├─ 选择封面图
└─ 设置发布时间

Step 6: 发布后
├─ 检查视频状态
├─ 第一时间互动（评论回复）
├─ 数据监控（前24小时）
└─ 记录表现数据
```

| 发布 | 使用定时发布功能 | 10% |
