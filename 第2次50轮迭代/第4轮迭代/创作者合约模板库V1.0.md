## 一、合约概述与使用指南

### 1.1 合约的重要性

```
┌─────────────────────────────────────────────────────────┐
│                 合约的重要性                              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ⚠️ 没有合约的风险：                                    │
│  ├── 对方不付款 → 无法追责                             │
│  ├── 对方拖欠作品 → 无法要求交付                      │
│  ├── 内容被滥用 → 无法维权                            │
│  ├── 出现争议 → 无据可查                             │
│  └── 合作范围不清 → 被无限加量                         │
│                                                         │
│  ✅ 有合约的好处：                                      │
│  ├── 明确双方权利义务                                 │
│  ├── 防止纠纷                                         │
│  ├── 保护知识产权                                     │
│  ├── 便于维权                                         │
│  └── 专业形象加分                                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 简易版vs正式版选择

```
┌─────────────────────────────────────────────────────────┐
│              合约版本选择指南                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  【简易版】- 邮件/聊天确认                              │
│  适用场景：                                             │
│  ├── 金额 < $500                                       │
│  ├── 简单单次合作                                     │
│  ├── 对方是熟人/信任度高                              │
│  └── 对方不愿签正式合同                               │
│                                                         │
│  示例：                                                 │
│  "确认：$300，1条TikTok视频，3天内交付，商业授权30天"  │
│                                                         │
│  ═══════════════════════════════════════════════════   │
│                                                         │
│  【正式版】- 完整合同                                  │
│  适用场景：                                             │
│  ├── 金额 > $500                                       │
│  ├── 复杂合作/长期合作                                │
│  ├── 首次合作的品牌                                   │
│  ├── 涉及版权/独家授权                               │
│  └── 任何你不确定的情况                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 合约常见陷阱与避坑

```
⚠️ 必须避免的陷阱：

1. 口头承诺不算数
   ❌ "先做，改天再签合同"
   ✅ 任何合作都应有书面确认

2. 模糊的交付物定义
   ❌ "帮忙做几条视频"
   ✅ "3条60秒视频，1080p，含字幕"

3. 没有明确的时间线
   ❌ "尽快做完"
   ✅ "2024年3月15日前交付初稿"

4. 无限修改次数
   ❌ "改到满意为止"
   ✅ "包含2次免费修改，第3次起$50/次"

5. 版权归属不清
   ❌ "内容发布后归品牌所有"
   ✅ "创作者保留版权，品牌获得X年授权"

6. 没有预付款
   ❌ "做完一起结账"
   ✅ "50%预付，50%交付后3天内结清"

7. 没有退款政策
   ❌ "概不退换"
   ✅ "交付前可全额退款，交付后按比例退款"

8. 排他条款没有补偿
   ❌ "合作期间不能接竞品"
   ✅ "排他期3个月，额外补偿$XXX"
```

### 8.2 修改请求应对

```
遇到不合理条款时的应对话术：

问题：对方要求永久版权
回应：「我们的政策是内容版权归创作者所有。
      授权可按你们需要的范围和时间来谈，
      这是对双方都公平的做法。」

问题：对方要求无限修改
回应：「我们通常包含X次免费修改，
      这是为了保证质量和效率。
      超出的修改我们可以按工时计费。」

问题：没有预付款
回应：「我们的标准流程是50%预付，
      这是对双方都有保障的安排。
      请理解我们需要保障基本投入。」

问题：要求签"独家永久授权"
回应：「永久授权对我们影响很大，
      我们可以讨论X年授权或独家使用权，
      但需要相应的补偿。」
```
