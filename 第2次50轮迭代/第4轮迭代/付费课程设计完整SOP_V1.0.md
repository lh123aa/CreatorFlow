### 1.2 市场调研方法

```
步骤1: 竞品分析
├── 找到3-5个同类课程
├── 分析他们的：课程名/价格/大纲/销量/评价
├── 工具： Udemy, Skillshare, Teachable, Gumroad
└── 产出：竞品分析表

步骤2: 用户需求验证
├── 在社交媒体发布相关内容测试反应
├── 创建等待列表（Waitlist）
├── 发起投票/问卷
└── 产出：需求验证报告

步骤3: 市场规模评估
├── 可触达目标用户数量
├── 付费意愿调研
├── 定价空间分析
└── 产出：市场容量估算

步骤4: 差异化定位
├── 我的独特优势是什么？
├── 与竞品有什么不同？
├── 为什么用户选我不选别人？
└── 产出：USP（独特销售主张）
```

### 2.2 学习路径设计原则

```
✅ 难度递进
├── 从简单到复杂
├── 从理论到实践
└── 每个模块都有"学完能做什么"的目标

✅ 即学即用
├── 每个知识点都有对应的练习
├── 提供模板/工具/检查清单
└── 让学生快速看到成果

✅ 成就感设计
├── 阶段性成果展示
├── 完成证书/徽章
└── 社区分享机会

✅ 闭环设计
├── 每模块：概念讲解 → 操作演示 → 练习 → 反馈
└── 整体：问题 → 方法 → 实践 → 成果
```

## 三、内容制作

### 3.1 录制方式对比

| 方式 | 设备要求 | 制作难度 | 适合类型 |
|------|----------|----------|----------|
| **屏幕录制** | 电脑+录屏软件 | ⭐ | 软件教程/操作演示 |
| **真人出镜** | 相机/手机+麦克风 | ⭐⭐⭐ | 个人品牌课程 |
| **画外音+PPT** | 麦克风+PPT | ⭐⭐ | 知识讲解类 |
| **混合模式** | 综合 | ⭐⭐⭐ | 综合性课程 |
| **AI生成** | AI工具 | ⭐ | 辅助/大纲 |

### 3.2 推荐工具栈

```
录制设备：
├── 相机：iPhone 14+ / 索尼A6400
├── 麦克风：Rode Wireless GO / Blue Yeti
├── 灯光：环形灯 / 柔光箱
└── 提词器：Teleprompter App

录屏软件：
├── Mac: OBS / QuickTime
├── Win: OBS / Camtasia
└── 跨平台: Loom / ScreenPal

视频编辑：
├── CapCut（推荐，免费）
├── Descript（AI加持）
├── Camtasia（专业版）
└── Premiere（高级）

AI辅助工具：
├── ChatGPT：脚本/大纲
├── ElevenLabs：配音
├── Runway：视频增强
└── Canva：PPT/封面
```

### 3.3 内容制作流程

```
Day 1-2: 准备
├── 完成课程大纲
├── 准备PPT/素材
├── 写好逐字稿
└── 测试设备

Day 3-4: 录制
├── 分段录制（每个模块单独录）
├── 一次不用录太长（10-15分钟一段）
├── 允许自己出错，可以重录
└── 保持精力充沛时录制

Day 5: 后期
├── 剪辑视频
├── 添加字幕
├── 添加过渡/动画
└── 导出高清版本

Day 6: 配套材料
├── 制作练习模板
├── 制作检查清单
├── 制作课程讲义/PDF
└── 整理课程资源包

Day 7: 审核与发布
├── 通看一遍检查错误
├── 测试所有链接
├── 上传到平台
└── 准备销售页
```

## 四、平台选择

### 4.1 平台对比表

| 平台 | 适合类型 | 费用 | 优缺点 |
|------|----------|------|--------|
| **Gumroad** | 数字产品/课程 | 免费/手续费10% | ✅简单易用 ❌功能有限 |
| **Teachable** | 在线课程 | $29-119/月 | ✅功能全 ❌费用较高 |
| **Thinkific** | 在线课程 | 免费/付费$49+ | ✅免费版好用 ❌复杂功能贵 |
| **Kajabi** | 会员站/课程 | $149-399/月 | ✅一体化 ❌贵 |
| **Podia** | 课程/社区 | $39-89/月 | ✅性价比高 ❌分析功能弱 |
| **Udemy** | 市场型课程 | 营收分成 | ✅大流量 ❌价格战激烈 |

### 4.2 平台推荐选择

```
多哈创作者推荐：

🎯 首选：Gumroad + 自建站
├── 费用低（无月费，只有销售手续费）
├── 直接收款，无平台限制
├── 配合 Shopify/独立站
└── 适合：起步阶段 / 单一课程

🎯 进阶：Thinkific + Gumroad
├── Thinkific 免费版托管课程
├── Gumroad 处理销售/订阅
└── 适合：有多门课程规划

🎯 高端：Teachable + 独立站
├── Teachable 专业功能
├── 配合 Stripe 收款
└── 适合：课程业务为主
```

## 十一、常见问题FAQ

### Q1: 我没有录课经验，设备要很专业吗？
**A**: 不需要。新手推荐：手机(iPhone 14+)+ 无线麦克风(Rode Wireless GO) + 自然光/环形灯。内容质量比设备重要。

### Q2: 课程应该多长？
**A**: 没有标准答案。完整课程建议3-8小时（分多个视频），每个视频10-20分钟。学习体验比总时长重要。

### Q3: 如何确保课程质量？
**A**: 先做免费内容测试市场反应；录完后自己完整看一遍；找2-3个测试学员试看并收集反馈；根据反馈修改后再正式发布。

### Q4: 课程没人买怎么办？
**A**: 检查：销售页是否转化？定价是否合理？目标用户是否准确？流量来源是否到位。先卖免费产品积累名单，用低價课验证市场，再推出高价课。

### Q5: 可以用AI生成课程内容吗？
**A**: 可以用AI辅助（写大纲/脚本/润色），但核心内容必须自己创作。纯AI内容缺乏个人经验和真实案例，价值感低。

### Q6: 如何防止盗版？
**A**: 无法完全防止，但可以：Watermark水印、平台限制观看次数、分批交付内容、提供独有价值（如社群/更新）让正版更有价值。
