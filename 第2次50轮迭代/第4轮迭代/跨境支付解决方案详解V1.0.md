## 二、Stripe 详解

### 2.1 注册与接入

```
Stripe 注册要求：
├── 个人：18岁以上 + 身份证/护照
├── 银行账户（支持美元/欧元等）
├── 邮箱 + 手机号
└── 业务描述（卖什么）

支持国家（部分）：
✅ 美国/加拿大/英国/欧盟
✅ 新加坡/香港/日本/澳大利亚
⚠️ 中国大陆：需要香港公司/美国公司
⚠️ 卡塔尔：需要美国/LLC
```

### 2.2 费率详解

```
标准费率：
├── 国内交易：2.9% + $0.30
├── 国际交易：额外 +1%（如果货币不同）
└── 货币转换：1% 如果非美元结算

特殊情况：
├── 动态3D安全卡：可能触发额外验证
├── 高风险行业：提高至 3.5-4%
└── 大额交易：可申请协商

实际案例：
├── $100 收款：实收 $96.80
├── $500 收款：实收 $485.80
└── $1000 收款：实收 $970.30
```

### 2.3 提现方式

```
Stripe 提现选项：

Bank Transfer（推荐）：
├── 美国ACH：免费，2-7工作日
├── 电汇：$15/笔，1-2工作日
└── 支持多币种账户

Stripe 账号结构：
├── 可以设置多币种余额
├── 自动转换需注意汇率损失
└── 建议用 Wise 接收美元再转换
```

### 2.4 税务表单

```
美国税务合规（W-9 / W-8BEN）：

W-9（美国人）：
├── 用途：报税用
├── 何时填：收入超过$600
└── 填写：SSN/ITIN

W-8BEN（外国人）：
├── 用途：证明非美国税务居民
├── 何时填：注册Stripe时
└── 更新：每3年

1099表格（美国收入）：
├── Stripe自动生成
├── 超过$600会发给你
└── 用于年度报税
```

## 三、Paddle 详解

### 3.1 MoR模式（Merchant of Record）

```
什么是 MoR？

传统模式：你 → 收款 → 你的账户 → 税务处理
      ↓
Paddle模式：你 → 收款 → Paddle → 税务处理 → 你的账户
      ↓
           ↑
     Paddle代缴增值税/Tax

MoR 优势：
✅ 自动处理增值税（EU VAT/US Sales Tax）
✅ 退款争议由Paddle处理
✅ 覆盖更多国家/地区
✅ 合规风险低
```

### 3.2 Paddle 费率结构

```
基础费率：
├── 标准：5% + $0.50/笔
└── 高频：4% + $0.50/笔（需要申请）

对比 Stripe：
├── Stripe：2.9% + $0.30
├── Paddle：5% + $0.50
└── 差值：约2%值得吗？

选择Paddle的理由：
├── 省去税务处理时间和成本
├── 覆盖150+国家
├── 退款和争议他们处理
└── 如果每月税务处理成本>2%选Paddle
```

### 3.3 VAT处理

```
Paddle 自动处理：
├── EU VAT（MOSS申报）
├── UK VAT
├── US Sales Tax（州级）
├── 加拿大 GST/HST
└── 日本消费税

你不需要：
❌ 注册各国VAT号
❌ 计算税额
❌ 申报VAT
❌ 维护税务记录

你收到的是：净销售额（税后金额）
```

## 四、PayPal 详解

### 4.1 跨境收款设置

```
PayPal 收款配置：

个人账户：
├── 适合：小额/偶发收款
├── 限额：$10,000/年（认证后可提升）
└── 费率：同商务账户

商务账户（推荐）：
├── 适合：定期收款
├── 无限额
└── 需企业认证

收款偏好设置：
├── 接受所有付款
├── 开启买家保护（会影响卖家）
└── 设置退款政策
```

### 4.2 费率详解

```
跨境交易费率：

美国国内：
├── 标准：2.99% + $0.30
└── 量大可申请降低

跨境收款：
├── 标准：4.99% + $0.30（货币转换）
├── 跨境交易：3.99% + $0.30
└── 实际跨境：约5-6%

货币转换损失：
├── PayPal自带汇率：通常比市场汇率低2-3%
├── 建议：收款后立即提现到银行
└── 或者用Wise转换更划算
```

### 4.3 争议处理

```
PayPal 争议流程：

Step 1: 买家开启争议（20天内）
├── 冻结资金
├── 卖家可回应
└── 提供证据

Step 2: 升级为索赔（20天后）
├── PayPal介入裁决
├── 通常45天内处理
└── 可能需要提供证据

避免争议技巧：
✅ 清晰的商品描述
✅ 及时发货有追踪
✅ 保留沟通记录
✅ 退款政策明确
✅ 商品描述与实物一致
```

## 五、Wise（多币种管理）

### 5.1 核心功能

```
Wise（以前叫TransferWise）：

✅ 核心优势：
├── 真实中间市场汇率（非加点汇率）
├── 低费用转账
├── 多币种账户
└── 支持50+货币

功能对比：
├── 个人账户：换汇/转账/收款
├── 商业账户：API集成/批量付款/多用户
└── 推荐：先用个人账户验证

多哈创作者适用场景：
├── 接收Stripe/PayPal美元
├── 转换为其他货币
├── 转账到本地银行
└── 持有多种货币余额
```

### 5.2 费率详解

```
Wise 费率结构：

换汇：
├── 汇率：真实中间市场汇率
├── 手续费：0.3-1%（货币不同）
└── 示例：换$1000 USD→EUR，约$3-10费用

转账：
├── 同行转账：低/免费
├── 银行转账：$1-5
└── 卡片支付：约1%

收款：
├── 本地账户：免费
├── SWIFT电汇：约$8-15
└── 美元ACH：可能免费

实际案例对比：
┌─────────────────┬──────────┬──────────┐
│ 转$1000 USD→EUR │ Wise      │ 传统银行  │
├─────────────────┼──────────┼──────────┤
│ 汇率            │ 0.92 EUR │ 0.89 EUR │
│ 费用            │ $5       │ $30+     │
│ 到账            │ €915     │ €863     │
│ 节省            │ -        │ $52      │
└─────────────────┴──────────┴──────────┘
```

### 5.3 多币种账户使用

```
Wise 多币种账户：

开通货币：
├── USD（美国账户）
├── EUR（欧元区）
├── GBP（英国）
├── AED（阿联酋）
└── 其他50+货币

使用方法：

场景1: Stripe美元收款
├── Stripe → Wise USD账户
├── 在Wise持有USD
├── 按需转换EUR/AED
└── 转出到本地银行

场景2: 支付海外服务
├── 直接用Wise余额支付
├── 支持AWS/Google Ads等
└── 避免PayPal高费率

场景3: 英镑收入（YouTube AdSense）
├── YouTube → Wise GBP账户
├── Wise自动转换或持有
└── 转到本地AED或USD
```

## 六、加密货币收款方案

### 6.1 适用场景

```
为什么考虑加密货币：

✅ 优点：
├── 无国界限制
├── 无审查/冻结风险
├── 到账快（分钟级）
└── 适合高风险行业

⚠️ 缺点：
├── 价格波动大
├── 合规风险（部分地区）
├── 用户认知门槛
└── 税务处理复杂

推荐场景：
├── 面向加密社区
├── 高风险内容（规避传统支付）
├── 全球化收款（无地域限制）
└── 作为备用收款方案
```

### 6.2 方案对比

```
加密收款平台：

BitPay：
├── 支持BTC/ETH/USDC等
├── 可转换为法币
├── 支持主流电商集成
└── 费率：1%+$15

Coinbase Commerce：
├── 支持多种加密货币
├── 自动转换为USD
├── Shopify/WooCommerce集成
└── 费率：免费（Coinbase收取）

NOWPayments：
├── 支持50+币种
├── 自动转换
├── 无KYC选项
└── 费率：0.5-1%

Paxful：
├── P2P交易
├── 支持多种支付方式
└── 适合个人用户
```

### 6.3 风险提示

```
⚠️ 重要风险提示：

税务风险：
├── 大多数国家对加密货币收税
├── 持有→增值 可能需要交税
├── 建议咨询专业税务顾问
└── 保留完整交易记录

合规风险：
├── 部分国家限制加密支付
├── 建议明确告知用户
├── 避免在受限地区推广
└── 考虑法律风险

价格风险：
├── 收到后立即转换
├── 或者接受波动作为策略
└── 建议设置自动转换
```

## 八、资金安全与合规

### 8.1 安全最佳实践

```
账户安全：
├── 开启双因素认证（2FA）
├── 使用强密码+密码管理器
├── 定期检查账号活动
└── 绑定手机号和邮箱验证

资金分散：
├── 不要把所有钱放在一个账户
├── 设置多个收款账户
├── 及时提现到安全账户
└── 保持一定现金流储备

欺诈防范：
├── 识别钓鱼邮件/短信
├── 不随意点击链接
├── 验证收款人信息
└── 保留完整交易记录
```

### 8.2 合规要点

```
美国税务（如果你有美国收入）：
├── 超过$600需申报1099
├── Stripe/PayPal会发1099
├── 使用W-9/W-8BEN正确申报
└── 建议找专业税务顾问

欧盟VAT（如果卖数字产品给欧洲）：
├── 销售到欧盟需处理VAT
├── MOSS简化申报
├── 或使用Paddle自动处理
└── 注意各国起征点

卡塔尔/中东：
├── 卡塔尔消费税5%（2024年起）
├── 海湾合作委员会一般免税
├── 建议保留收入记录
└── 咨询当地税务专家

通用建议：
✅ 保留所有交易记录（至少7年）
✅ 区分个人和业务账户
✅ 定期对账
✅ 年度审计（可选但推荐）
✅ 咨询跨境税务专家
```

### 10.2 常见问题FAQ

### Q1: 中国大陆用户能用Stripe吗？
**A**: 不能直接用中国大陆身份注册。需要：①注册香港公司；②注册美国LLC（如Wyoming）；③使用他人账户（不推荐）。建议用PayPal + Wise组合。

### Q2: PayPal争议太多怎么办？
**A**: 争议无法完全避免，但可以：①保留完整发货/交付记录；②及时回应争议；③设置明确的退款政策；④考虑Stripe替代（Stripe争议更少）。

### Q3: 哪种方式费率最低？
**A**: Wise换汇费率最低（真实汇率+0.3-1%）。Stripe收款费率较低（2.9%），但提现有费用。组合使用：Stripe收款 + Wise提现/换汇。

### Q4: 收入需要报税吗？
**A**: 需要。无论在哪里，你都需要为收入报税。了解：你居住地税务（卡塔尔）、收入来源国税务（美国/欧盟）、跨境税务协议。建议找专业的跨境税务顾问。

### Q5: 资金被冻结怎么办？
**A**: 冷静应对：①联系平台了解原因；②提供要求的材料；③保持沟通；④如果无法解决，考虑其他平台。预防：合规运营、避免高风险内容、保持账号活跃。

### Q6: 如何降低手续费？
**A**: ①用Wise接收Stripe提现而非直接银行；②避免PayPal货币转换；③大额交易可申请Stripe折扣；④考虑Paddle省去税务处理成本。
