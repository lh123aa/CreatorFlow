# 创作者平台政策速查指南

> **2026年最新政策** — 一句话总结+关键要点。来源：各平台官方公告（2026年1-4月更新）。

## 📺 YouTube

### 货币化政策要点 (2026)

| 要求 | 标准门槛 | 备注 |
|------|----------|------|
| 订阅者 | 1,000人 | 真实订阅者 |
| 有效观看时长 | 4,000小时 | 过去12个月 |
| 或 | 1,000人 + 1,000万Shorts播放 | 90天内 |
| 账户年龄 | 30天以上 | — |
| 2步验证 | 必须开启 | Google账号 |
| 政策合规 | 无重大违规 | 持续监控 |

**广告友好内容标准（Advertiser-Friendly）：**
- ✅ 允许：教育性/评论性内容、时事分析、健康生活
- ⚠️ 需谨慎：暴力事件报道（需教育价值）、政治话题（需平衡）
- ❌ 禁止：仇恨言论、暴力美化、危险活动指导

**2026年新变化：**
- 敏感话题审核更精细化，文脉判断替代一刀切
- 教育/评论类内容广告通过率提升
- Shorts与长视频广告政策逐步统一

### 版权政策

```
Content ID系统：
  → 自动检测版权内容
  → 权利方选择：追踪/封锁/盈利共享

手动版权 strikes：
  → 3次 = 频道终止
  → 1次 = 7天功能限制
  → strikes 90天后自动过期（除非诉讼中）

合理使用（Fair Use）：
  → 平台不裁定，需自行判断或法律解决
  → 因素：目的、性质、使用的数量/影响
```

### 社区准则要点

**严重违规（立即终止）：**
- 儿童安全相关内容
- 恐怖主义/暴力极端主义
- 恶意伪造文件
- 骚扰/威胁

**一般违规（警告+删除）：**
- 垃圾信息/误导性元数据
- 冒充他人
- 有害内容（暴力/自残）
- 隐私侵犯

### 变现政策红线

```
永久取消变现：
  ✗ 垃圾信息/欺骗性内容
  ✗ 误导性内容（点击诱饵/缩略图不符）
  ✗ 危险活动/违法行为
  ✗ 骚扰/仇恨内容

暂时限制：
  ○ 质量问题内容（低价值）
  ○ 重复上传/回收内容
  ○ 争议话题处理不当
```

## 🎵 TikTok

### 创作者基金/奖励计划 (2026)

| 项目 | 要求 | 报酬（估算） |
|------|------|--------------|
| **Creator Rewards Program** | 1万粉丝+10万播放/30天+18岁 | $0.50-$1.00/千qualified播放 |
| **TikTok Shop Affiliate** | Shop开通资格 | 佣金制（产品不同） |
| **Live Gifts** | 1000粉丝+满18岁 | 观众打赏分成 |
| **品牌合作** | 无门槛 | 自行协商 |

**重要更新（2026）：**
- 创作者基金已更名为"Creator Rewards Program"
- 视频需1分钟+才能计入奖励
- 合格播放（qualified views）才计算报酬
- 高价值类别（金融/教育）报酬更高

### 内容限制

```
绝对禁止：
  ✗ 仇恨言论/仇恨行为
  ✗ 暴力/血腥内容
  ✗ 色情/裸露
  ✗ 危险行为挑战
  ✗ 误导性医疗信息
  ✗ 非法商品/服务

限制内容：
  ⚠️ 枪支相关（特定地区）
  ⚠️ 政治内容（需透明）
  ⚠️ 酒精/烟草（年龄限制）
  ⚠️ 赌博（特定地区）

特殊限制：
  ○ Beauty Filter（美化滤镜）需标注
  ○ AI生成内容需标注
```

### AI内容政策（2026新规）

| 情况 | 要求 |
|------|------|
| AI生成的视频 | 必须标注"AI生成" |
| AI辅助编辑 | 建议标注（非强制） |
| AI虚拟人物/数字人 | 必须标注 |
| 战争/冲突AI内容 | 必须标注，否则90天封禁 |

### 电商政策

```
TikTok Shop资格：
  ○ 满足平台居住/经营要求
  ○ 完成身份验证
  ○ 良好社区准则记录

禁止销售：
  ✗ 假冒商品
  ✗ 违禁药品
  ✗ 武器/弹药
  ✗ 成人内容
  ✗ 野生动物制品
```

## 📸 Instagram (Meta)

### 商业账户政策

**账号类型：**
- 创作者账号：专为创作者设计
- 商业账号：企业/品牌使用
- 个人账号：普通用户

**变现功能门槛（2026）：**
| 功能 | 要求 |
|------|------|
| Reels Bonuses | 账号状态良好+地区资格 |
| Badges (直播) | 18岁+ |
| Subscriptions | 1万+粉丝（部分地区） |
| Brand Deals | 无门槛（自行BD） |

### 内容审查规则（2026年4月更新）

**2026年4月原创性新规：**
```
聚合/搬运账号限流：
  → 主要是别人内容的账号不再推荐
  → Repost功能可以保留但需原tag
  → 需"实质性改造"才算原创
  → 适用于：Reels+照片+轮播帖

原创性评判：
  ✓ 添加评论/解读
  ✓ 混剪/二创
  ✓ 原创视角/分析
  ✗ 简单搬运/水印去重
  ✗ 微调后发布
```

### 社区准则

**仇恨言论：**
- 基于种族、民族、国籍、宗教、性别、性取向、残疾的歧视
- 隐性仇恨内容（如黑色face、仇恨符号变体）

**暴力与危险：**
- 暴力/血腥内容
- 自残/自杀相关（即使是meme）
- 危险活动指导

**虚假信息：**
- 健康相关误导信息
- 选举相关虚假信息
- 暴力事件虚假报道

### 变现政策

```
允许的变现方式：
  ✓ 品牌合作（需#ad标签）
  ✓ 联盟营销
  ✓ 数字产品销售
  ✓ 直播打赏
  ✓ IG Shopping

违规行为：
  ✗ 虚假承诺（快速致富等）
  ✗ 误导性广告
  ✗ 购买虚假互动
  ✗ 垃圾信息行为
```

## 🔍 Google/SEO

### Helpful Content Update (2026)

```
核心原则：
  → "人们-first"内容优先
  → 专业知识/经验展示
  → 满足搜索意图
  → 完整/深度解答

AI内容政策：
  → 不禁止AI，但要求添加价值
  → 纯AI内容可能降权
  → AI辅助需E-E-A-T支撑

内容质量评估：
  ✓ 专业性（Expertise）
  ✓ 经验（Experience）
  ✓ 权威性（Authoritativeness）
  ✓ 信任（Trustworthiness）
```

### Core Update应对

```
更新期间（通常1-2周）：
  → 不要急于做重大改变
  → 持续发布高质量内容
  → 监控排名变化

更新后如排名下降：
  → 评估内容是否真正满足用户需求
  → 检查E-E-A-T信号
  → 与搜索意图匹配度
  → 竞争对手分析
  → 不要为了SEO做短期优化
```

## ⚠️ 政策违反申诉流程

### YouTube申诉
```
1. YouTube Studio → 设置 → 账号状态
2. 选择具体问题
3. 点击"申诉"或"请求审核"
4. 提交说明（事实+理由）
5. 等待1-7天
6. 如被拒，可再次申诉或等待90天
```

### TikTok申诉
```
1. 收到通知 → 查看违规详情
2. 点击"申诉"按钮
3. 选择申诉原因
4. 提交说明
5. 等待1-3天
```

### Instagram申诉
```
1. 收到通知 → 查看违规详情
2. 点击"申请复审"
3. 提交说明
4. 等待时间不定（通常1-7天）
```

### X申诉
```
1. 账号功能受限 → 查看原因
2. 点击"申请复审"
3. 提交身份验证（如需要）
4. 等待1-7天
```
