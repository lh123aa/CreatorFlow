## 🚨 账号被封/限流

### "我刚被封号了！"

**🚨 前5分钟该做什么：**
1. **截图所有证据** — 封号通知、违规原因截图
2. **停止所有操作** — 不要反复尝试登录，会加重标记
3. **确认封号类型** — 临时限制 vs 永久封禁

**📋 可能原因排查：**
- 违反社区准则（仇恨言论、暴力内容等）
- 版权 strikes（音乐/视频/图片）
- 垃圾信息和刷量行为
- 虚假信息传播
- 年龄/地区政策违规

**✅ 逐步解决方案：**
```
临时限制（1-30天）：
  1. 查看具体违规通知
  2. 删除违规内容
  3. 等待期限结束
  4. 申诉解除标记

永久封禁：
  1. 仔细阅读封号原因
  2. 准备申诉：说明情况+承诺改进
  3. 提交申诉（通常1-7天回复）
  4. 如果申诉失败，准备账号迁移

账号申诉模板：
"Dear [平台] Team,
I received a [ban/strike/limit] on [日期] for [原因].
I understand that my content may have violated [具体政策].
I want to clarify that [你的解释].
I am committed to complying with community guidelines and will [改进措施].
Please review my case and reconsider my account status.
Thank you."
```

**🔗 相关指南：** 平台政策速查 → 申诉流程

### "我的视频被限流了"

**🚨 前5分钟该做什么：**
1. 检查是否有违规通知/社区准则警告
2. 查看近期视频的推荐量变化
3. 确认是否使用了违规音乐/标签

**📋 可能原因排查：**
- [ ] 新账号权重低（养号期）
- [ ] 使用了版权音乐/内容
- [ ] 频繁使用限流标签
- [ ] 互动诱骗（"点赞获取..."）
- [ ] 内容质量下降
- [ ] 账号异常行为

**✅ 逐步解决方案：**
```
诊断步骤：
  1. YouTube → Studio → 账号状态
  2. TikTok → 个人主页 → 账号状态
  3. Instagram → 设置 → 账号状态

修复行动：
  ✓ 停止一切可疑行为
  ✓ 删除违规内容
  ✓ 保持正常发布频率（7-14天）
  ✓ 提高内容质量
  ✓ 避免使用已知的限流标签
  ✓ 逐步增加互动（自然增长）

如果14天后无改善 → 申诉
```

**🔗 相关指南：** 平台政策速查 → 内容审查规则

## ⚖️ 收到侵权通知

### "我收到了版权侵权通知"

**🚨 前5分钟该做什么：**
1. **不要删除视频** — 除非是恶意侵权指控
2. 记录侵权类型和来源
3. 查看是 Content ID 匹配还是手动举报

**📋 侵权类型与应对：**

| 类型 | 前5分钟 | 长期方案 |
|------|--------|----------|
| **Content ID** | 视频保留但广告归权利方 | 使用原创/授权音乐 |
| **手动举报** | 评估是否误判 | 准备反驳或删除 |
| **商标侵权** | 立即停止使用 | 替换品牌元素 |
| **DMCA** | 认真对待，准备反通知 | 建立内容审核流程 |

**✅ 逐步解决方案：**
```
收到 DMCA 后可选路径：

路径A - 认错删除：
  1. 删除视频
  2. 不再使用该内容
  3. 三次strike = 永久封号

路径B - 合理使用辩护：
  1. 确认你的使用属于合理使用：
     - 评论/批评/教育目的
     - 引用比例合理
     - 改变了作品性质
  2. 准备反驳声明
  3. 提交反通知（见急救包模板）

路径C - 直接和解：
  联系权利方，请求撤销
```

**🔗 相关指南：** 数字急救包 → 法律文件急救包 → DMCA模板

### "我被抄袭了"

**🚨 前5分钟该做什么：**
1. 截图/录屏抄袭证据
2. 记录抄袭者账号和内容链接
3. 确认对方是否进行了实质性复制

**📋 侵权程度判断：**
- 完全照搬 → 立即行动
- 洗稿/同义改写 → 证据收集
- 引用+原创评论 → 可接受范围
- 模仿风格 → 无法维权

**✅ 逐步解决方案：**
```
步骤1: 直接联系（最快速）
  发送友好通知：
  "Hi [名字], I noticed my content [链接] was shared on your channel [链接] without credit. Please add attribution or remove it within 48 hours. Thank you!"

步骤2: 平台投诉
  YouTube → 版权中心 → 提交版权声明
  TikTok → 举报 → 知识产权侵权
  Instagram → 举报 → 知识产权

步骤3: DMCA takedown
  准备材料：
  - 原创作品链接
  - 抄袭内容链接
  - 身份证明
  提交至: dmca@平台域名

步骤4: 法律途径（成本高）
  仅建议用于：
  - 重大经济损失
  - 恶意且持续的侵权
  - 有能力承担法律费用
```

**🔗 相关指南：** 数字急救包 → 法律文件急救包

```
       收入下降诊断树

     ┌───────┴───────┐
     ▼               ▼
  单一平台        多个平台
     │               │
  ┌──┴──┐        ┌──┴──┐
  ▼     ▼        ▼     ▼
  算法   内容    季节性  经济
  变化   问题    因素    因素

## 💬 舆论危机

### "我收到了仇恨评论/被网暴了"

**🚨 前5分钟该做什么：**
1. **不要回复** — 任何回复都会让事情升级
2. 截图所有证据
3. 确认是否涉及个人信息泄露

**📋 危机程度判断：**

| 级别 | 特征 | 响应策略 |
|------|------|----------|
| **轻度** | 零星负面评论 | 忽略/隐藏 |
| **中度** | 有组织的负面活动 | 隐藏+屏蔽 |
| **重度** | 人肉搜索/死亡威胁 | 报警+法律+平台举报 |
| **危机** | 涉及现实安全 | 立即报警 |

**✅ 逐步解决方案：**
```
轻度（零星评论）：
  1. 隐藏评论
  2. 拉黑用户
  3. 关闭私信陌生人
  4. 继续正常更新

中度（有组织攻击）：
  1. 开启评论审核
  2. 私信攻击者停止（仅一次）
  3. 联系平台客服
  4. 发布冷静的声明（如需要）
  5. 保持沉默，不火上浇油

重度（人肉/威胁）：
  1. 截图所有威胁证据
  2. 向平台举报
  3. 咨询律师
  4. 考虑暂时停更
  5. 如有人身威胁 → 立即报警
```

**🔗 相关指南：** 紧急决策树 → 网暴应对决策树

```

## 📄 法律/财务文件

### "我收到了法律文件"

**🚨 前5分钟该做什么：**
1. **不要忽视** — 这是严肃的法律问题
2. 确认文件类型（DMCA/传票/律师函/合同）
3. 不要自行回复对方

**📋 文件类型判断：**

| 文件类型 | 紧迫性 | 立即行动 |
|----------|--------|----------|
| **DMCA通知** | 🟡 中 | 评估是否侵权，准备反通知或删除 |
| **DMCA反通知** | 🟡 中 | 如果你合理使用，可提交 |
| **C&D (停止函)** | 🟡 中 | 停止相关行为，咨询律师 |
| **传票/诉讼** | 🔴 高 | 立即咨询律师 |
| **税表/IRS** | 🔴 高 | 立即处理，不可忽视 |

**✅ 应对步骤：**
```
第一步：识别文件
  - 阅读所有内容
  - 记录发送方、日期、要求

第二步：不要自行行动
  - 不回复对方
  - 不删除可能相关的证据
  - 不签任何文件

第三步：寻求专业帮助
  - 传票/诉讼 → 必须找律师
  - DMCA/C&D → 可咨询律师或按模板处理
  - 税务文件 → 立即联系会计师

第四步：时间敏感
  - 诉讼文件通常有时限
  - 错过期限可能导致默认败诉
```

**🔗 相关指南：** 数字急救包 → 法律文件急救包 → 税务速查

### "我收到1099-K/税表了"

**🚨 前5分钟该做什么：**
1. 确认是哪家平台寄来的
2. 记录金额和你实际收到的对比
3. 确认是否需要立即处理

**📋 税表类型判断：**

| 税表 | 来源 | 触发条件 | 你需要做什么 |
|------|------|----------|--------------|
| **1099-K** | PayPal/Stripe等 | 超阈值（美国：$600+） | 报为收入 |
| **1099-NEC** | 品牌/客户 | $600+ | 报为收入，可抵成本 |
| **1099-MISC** | 平台 | $600+ | 同上 |
| **1042-S** | 外国平台 | 非美国税务居民 | 取决于居住国 |

**✅ 应对步骤：**
```
情况1: 金额和你记录一致
  → 正常收入，报税即可
  → 保留所有记录

情况2: 金额高于你记录
  → 联系平台核实
  → 可能包含退款/其他调整

情况3: 你没报过这个收入
  → 联系平台，可能被盗用或错误
  → 即使错误也建议咨询会计师

情况4: 你在卡塔尔0税率地区
  → 仍需申报，但不需缴美国税
  → 填写W-8BEN声明
  → 咨询国际税务专家
```

**🔗 相关指南：** 税务速查指南 → 1099-K详解

## 🌐 技术急救

### "我的网站挂了"

**🚨 前5分钟该做什么：**
1. 确认是域名问题还是主机问题
2. 尝试访问测试（用手机/VPN）
3. 检查是否仅你一个人问题

**📋 诊断清单：**

```
第一步：确认问题范围
  □ 用不同设备访问
  □ 用手机数据（非WiFi）
  □ 用VPN从其他地区测试

第二步：检查组件状态
  □ 域名（WHOIS/DNS检查）
  □ 主机服务状态
  □ SSL证书
  □ CDN状态

第三步：常见错误（按频率）
  1. DNS传播延迟（新建/修改后）
  2. 主机流量超限
  3. SSL证书过期
  4. 网站代码错误
  5. 被攻击/恶意流量
```

**✅ 紧急修复步骤：**
```
立即行动（5分钟内）：
  1. 联系主机商紧急支持
  2. 如果有备份，启用备份
  3. 设置维护页面（安抚访客）

短期修复（1-24小时）：
  1. 确定问题根源
  2. 修复或恢复
  3. 全面测试
  4. 更新DNS缓存

长期预防：
  ✓ 使用可靠主机
  ✓ 设置监控告警
  ✓ 定期备份
  ✓ SSL证书自动续期
```

**🔗 相关指南：** 数字急救包 → 技术急救包
