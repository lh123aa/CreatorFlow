## 📦 内容备份急救包

### 3-2-1备份原则

```
3份内容副本
    ├── 本地原始文件（你的电脑/硬盘）
    ├── 本地备份（外接硬盘/NAS）
    └── 云端备份（云存储服务）

2种不同存储介质
    ├── 固态/机械硬盘
    └── 云存储（Google Drive/Dropbox/iCloud等）

1份异地备份
    └── 云端存储（防本地灾难）
```

### 备份清单

**视频素材与成片**
```
备份位置A（本地）：
  路径：_____________________
  最近更新时间：____年__月__日

备份位置B（云端）：
  服务：_____________________
  同步状态：_____________________

备份位置C（冷备）：
  存储介质：_____________________
  存放位置：_____________________
```

**重要文档**
```
□ 所有平台的服务条款/政策记录
□ 品牌合作合同（扫描件+原件）
□ 收入记录和税务文件
□ 密码和账号信息（加密）
□ 联系方式列表
□ 紧急联系人信息
```

### 内容备份时间表

| 频率 | 内容 | 执行 |
|------|------|------|
| 每天 | 完成后立即备份当天素材 | 手动/自动同步 |
| 每周 | 检查云端同步状态 | 手动检查 |
| 每月 | 验证备份完整性 | 测试恢复 |
| 每季度 | 全量备份检查 | 完整审计 |
| 每年 | 清理过期备份 | 整理归档 |

### 恢复测试流程

```
每季度执行一次恢复测试：

1. 选择一个随机备份文件
2. 按照你的恢复流程操作
3. 确认能够正常恢复
4. 记录测试结果和时间
5. 如果测试失败 → 立即修复备份系统

测试记录：
  Q1: 日期______ 结果______
  Q2: 日期______ 结果______
  Q3: 日期______ 结果______
  Q4: 日期______ 结果______
```

### 品牌合作合同检查清单

签署前必须确认：
- [ ] 双方权利和义务清晰
- [ ] 报酬金额和支付时间明确
- [ ] 内容审核流程和标准
- [ ] 排他性条款的范围和期限
- [ ] 违约责任和赔偿条款
- [ ] 终止条件提前通知期限
- [ ] 知识产权归属
- [ ] 保密条款
- [ ] 争议解决方式

### 常用法律联系方式

```
一般咨询（非紧急）：
  - 当地律师协会转介服务
  - 在线法律平台（LegalZoom等）

版权问题：
  - 美国版权局：www.copyright.gov
  - DMCA代理：各平台官网查找

税务问题：
  - 注册税务师（EA/CPA）
  - 国际税务律师

紧急（涉及传票/诉讼）：
  - 立即联系律师
  - 不要回复任何法律文件
```

## 🔄 急救包定期更新清单

### 季度检查（每3个月）

```
□ 密码管理器主密码未变更但仍安全
□ 所有2FA备用码有效
□ 备用邮箱可访问
□ 云端备份同步正常
□ 本地备份完整
□ 法律文件模板仍然适用
□ 紧急联系人信息更新
□ 保险仍在有效期内
□ 域名/主机续费已处理
```

### 年度检查（每年）

```
□ 完整审计所有账号
□ 清理不用的账号和权限
□ 更新所有密码
□ 生成新的2FA备用码
□ 检查并更新法律文件
□ 回顾收入记录和税务文件
□ 评估保险覆盖是否足够
□ 测试完整的恢复流程
□ 更新紧急联系人
□ 整理归档过期内容
```

### 紧急更新触发条件

立即更新急救包如果：
- [ ] 账号被盗或存在安全风险
- [ ] 密码泄露事件
- [ ] 更换主要设备
- [ ] 更换邮箱或手机号
- [ ] 重大搬家或联系方式变更
- [ ] 财务账号变更
- [ ] 开始新的业务合作关系

---

> **记住**：
> - 纸质备份保存在安全位置（防火防水保险箱）
> - 数字备份使用加密存储
> - 定期测试恢复流程
> - 不要把所有信息放在同一个地方
