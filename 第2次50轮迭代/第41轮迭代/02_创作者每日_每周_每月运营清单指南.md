| 周期 | 建议时间 | 核心任务 |
|------|----------|----------|

## 📅 每日清单

### 版本A：精简版（新手期/时间紧张时）

```
⏰ 建议时间：30分钟/天

□ 内容创作（15分钟）
  ├── 写1条社交媒体帖子 或
  ├── 录制1个短视频素材 或
  └── 回复1条热门内容

□ 社交互动（10分钟）
  ├── 回复评论/私信（5分钟）
  ├── 点赞/评论他人内容（3分钟）
  └── 搜索相关话题互动（2分钟）

□ 数据检查（5分钟）
  ├── 查看昨日数据（播放/点赞/关注）
  └── 记录关键指标
```

### 版本B：标准版（增长期/日常运营）

```
⏰ 建议时间：60分钟/天

□ 内容创作（25分钟）
  ├── 创作/发布内容（15分钟）
  ├── 标题/描述优化（5分钟）
  └── 话题标签研究（5分钟）

□ 社交互动（15分钟）
  ├── 回复所有评论（8分钟）
  ├── 回复私信/邮件（5分钟）
  └── 主动互动（2分钟）

□ 数据分析（10分钟）
  ├── 查看关键指标（播放/互动/关注）
  ├── 记录数据到表格
  └── 标记表现好的内容

□ 学习/灵感（10分钟）
  ├── 刷同领域内容找灵感（5分钟）
  └── 阅读1篇行业文章/看1个教程（5分钟）
```

### 版本C：完整版（变现期/全力运营）

```
⏰ 建议时间：90-120分钟/天

□ 内容创作（45分钟）
  ├── 批量创作内容（20分钟）
  ├── 剪辑/后期处理（15分钟）
  ├── SEO优化（5分钟）
  └── 封面/缩略图（5分钟）

□ 社交互动（20分钟）
  ├── 回复评论（10分钟）
  ├── 私信/邮件回复（5分钟）
  └── 主动拓展/合作（5分钟）

□ 数据分析（15分钟）
  ├── 详细数据分析（10分钟）
  ├── 竞品监测（3分钟）
  └── 记录和归档（2分钟）

□ 变现跟进（10分钟）
  ├── 检查订单/收入
  ├── 回复客户咨询
  └── 更新产品页面

□ 学习/灵感（10分钟）
  └── 持续学习和优化
```

## 📆 每周清单

### 周一：计划日

```
⏰ 建议时间：45-60分钟

□ 内容计划
  ├── 制定本周发布计划（1-7条内容）
  ├── 确认内容主题和形式
  ├── 准备素材和脚本
  └── 安排发布时间表

□ 本周目标
  ├── 设定本周关键指标目标
  │   ├── 关注增长目标：____
  │   ├── 播放/阅读目标：____
  │   └── 变现目标：____
  └── 确认本周优先事项（最多3件）

□ 待办事项
  ├── 品牌合作跟进
  ├── 产品/课程更新
  └── 其他待办
```

### 周二-周四：执行日（每日重复）

```
⏰ 每日30-60分钟

□ 保持每日清单执行
□ 记录问题和灵感
□ 必要时调整计划
```

### 周五：复盘日

```
⏰ 建议时间：60-90分钟

□ 周数据复盘
  ├── 收集本周数据
  │   ├── 总播放/阅读量：____
  │   ├── 新增关注：____
  │   ├── 互动率：____%
  │   ├── 变现收入：____$
  │   └── 对比上周：____%
  ├── 分析表现最好的内容（1-3条）
  │   ├── 为什么好？
  │   ├── 哪些因素可以复用？
  │   └── 记录到选题库
  └── 分析表现差的内容（1-3条）
      ├── 为什么差？
      ├── 下次如何改进？
      └── 是否继续尝试？

□ 本周成就
  └── 列出本周3个最大成就

□ 本周问题
  └── 列出本周3个最大问题

□ 解决方案
  └── 针对问题的解决方案
```

### 周六/周日：缓冲日

```
⏰ 建议时间：30分钟

□ 预处理下周内容
  ├── 头脑风暴选题
  ├── 收集素材
  └── 撰写部分内容框架

□ 休息与恢复
  └── 保持工作生活平衡
```

## 📆 每月清单

### 月初：规划与准备

```
⏰ 建议时间：60-90分钟

□ 上月数据汇总
  ├── 总播放/阅读量
  ├── 总新增关注
  ├── 平均互动率
  ├── 总收入
  └── 对比上月/去年同期

□ 本月目标设定
  ├── 关注增长目标：____（+__%）
  ├── 内容产出目标：__条
  ├── 变现收入目标：__$
  └── 重点项目里程碑

  ├── 确定本月4个核心主题
  ├── 安排每周重点
  └── 标记重要节点（节日/事件）

□ 工具和订阅审查
  ├── 检查订阅续费日期
  ├── 评估工具使用情况
  └── 考虑新工具需求
```

```
⏰ 建议时间：30-45分钟

□ 15日进度检查
  ├── 是否按计划完成50%目标？
  ├── 需要调整计划吗？
  ├── 有哪些障碍需要解决？
  └── 是否需要求助？

  ├── 课程/产品进度
  ├── 品牌合作进展
  └── 关键项目里程碑
```

⏰ 建议时间：90-120分钟

  │   └── 其他：__$
  ├── 汇总本月支出
  │   ├── 工具订阅：__$
  │   ├── 广告投放：__$
  │   └── 其他：__$
  ├── 计算净利润：__$
  └── 更新财务追踪表

□ 增长数据回顾
  ├── 总关注变化
  ├── 各平台增长对比
  ├── 流量来源分析
  └── 竞品对比

## 🛠️ 清单的定制化

### 根据阶段调整

```
新手期（0-3个月）：
├── 每日：精简版A
├── 每周：简化复盘
├── 每月：基础审计
└── 重点：建立习惯

增长期（3-12个月）：
├── 每日：标准版B
├── 每周：完整复盘
├── 每月：详细审计
└── 重点：增长和优化

变现期（6-18个月）：
├── 每日：完整版C
├── 每周：变现追踪
├── 每月：财务报告
└── 重点：收入增长

规模期（12个月+）：
├── 每日：按需调整
├── 每周：战略回顾
├── 每月：全面审计
└── 重点：系统化和规模化
```

### 根据精力调整

```
精力充沛时：
├── 完成完整清单
├── 处理复杂任务
└── 创作高质量内容

精力有限时：
├── 只做必须项（每日清单）
├── 推迟非紧急任务
└── 保持基本运营

休息日：
├── 预处理下周内容
├── 回复必要消息
└── 完全休息
```

### 工具化推荐

```
Notion模板：
├── 每日/每周/每月清单
├── 数据追踪仪表盘
├── OKR追踪系统
└── 内容日历

Todoist/任务管理：
├── 每日待办
├── 周期性任务
└── 习惯追踪

电子表格（Google Sheets/Excel）：
├── 数据追踪表
├── 财务记录表
└── 内容日历
```
