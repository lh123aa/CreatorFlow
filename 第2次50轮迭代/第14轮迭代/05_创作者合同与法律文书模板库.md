## 一、品牌合作合同模板

### 1.1 品牌合作合同

```
┌─────────────────────────────────────────────────────────────────┐
│                    创作者品牌合作协议                            │
│                  CREATOR BRAND AGREEMENT                         │
└─────────────────────────────────────────────────────────────────┘

合同编号：[编号]
签订日期：[日期]

【甲方 - 品牌方】
公司名称：[品牌公司名称]
注册地址：[地址]
联系人：[姓名]
邮箱：[邮箱]
电话：[电话]

【乙方 - 创作者】
姓名：[你的全名]
身份证号/护照号：[护照号]
地址：[你的地址]
邮箱：[邮箱]
电话：[电话]

─────────────────────────────────────────────────────────────────

第一条 合作概述

1.1 甲方委托乙方作为其[产品/品牌]的推广创作者，在乙方
    运营的[平台名称，如YouTube/Instagram/TikTok等]账号
    上发布推广内容。

1.2 本协议规定了双方的权利、义务和责任，以及合作的具体
    条款和条件。

第二条 合作内容

2.1 合作平台：[YouTube/Instagram/TikTok/等]

2.2 合作账号：
    • 账号名称：[账号名]
    • 账号链接：[链接]
    • 粉丝数量：约[数量]（截至签订日）

2.3 内容要求：
    • 内容类型：[视频/图文/Story等]
    • 内容时长：[如60秒/2分钟/等]
    • 内容主题：[产品/品牌推广]
    • 交付日期：[具体日期]
    • 审核日期：交付后[如3个工作日]

2.4 品牌元素要求：
    • 品牌露出方式：[详细描述]
    • 品牌信息呈现：[具体要求]
    • 禁止内容：[明确禁止的内容]

第三条 报酬与支付

3.1 合作报酬：
    • 总报酬金额：[金额] [货币，如USD]
    • 支付方式：[银行转账/PayPal/其他]
    • 收款账户：[账户信息]

3.2 支付条件：
    • 预付款：[金额]（合同签署后[X]日内支付）
    • 尾款：[金额]（内容发布并确认后[X]日内支付）

3.3 税费：
    乙方自行负责其所在国家/地区的税务申报。
    甲方不负责代扣代缴乙方个人所得税。

3.4 银行手续费：
    如涉及国际转账，银行手续费由甲方承担。

第四条 双方权利与义务

【甲方权利与义务】
4.1 甲方有权审核乙方提交的推广内容，但应尊重乙方的创作自由。
4.2 甲方应在收到内容后[X]个工作日内完成审核，超时视为通过。
4.3 甲方应按时支付约定的报酬。
4.4 甲方应提供必要的品牌资料、产品样品（若需要）。

【乙方权利与义务】
4.5 乙方应按照约定的时间和质量要求交付内容。
4.6 乙方应确保内容真实、合法，不含虚假宣传。
4.7 乙方发布内容后，未经甲方书面同意，不得删除。
4.8 乙方应如实披露合作关系（按相关法规要求）。

第五条 内容审核与修改

5.1 审核流程：
    乙方提交内容 → 甲方审核 → 修改意见（如有）→ 确认发布

5.2 修改次数：
    甲方有权要求不超过[X]次修改，超过次数的修改另议费用。

5.3 审核标准：
    内容应符合甲方品牌形象，不得包含：
    • 政治敏感内容
    • 色情暴力内容
    • 竞品信息
    • 虚假或夸大宣传
    • 违反平台政策的内容

第六条 发布与保留

6.1 发布平台：[具体平台]
6.2 发布时间：[具体日期/交付后X日内]
6.3 内容保留期：内容发布后至少保留[如6个月/12个月]。
6.4 提前删除：如需提前删除，应双方书面同意。

第七条 排他性条款

7.1 排他期限：合作期间及结束后[X]个月内
7.2 排他范围：[竞品种类/品类]
7.3 违反排他：违约方应赔偿[金额]

第八条 知识产权

8.1 甲方授权乙方使用其商标、品牌元素用于本协议约定的推广。
8.2 内容版权：双方共同拥有发布内容的版权。
    • 甲方可用于官方渠道宣传
    • 乙方可用于作品集展示
8.3 未经双方同意，不得将内容用于第三方。

第九条 保密条款

9.1 双方应对合作中涉及的敏感信息保密。
9.2 保密期限：协议终止后[如2年]。
9.3 保密内容包括但不限于：价格、策略、产品信息。

第十条 违约责任

10.1 任一方违反本协议，应承担违约责任。
10.2 甲方违约：应支付乙方已完成工作的合理报酬。
10.3 乙方违约：应退还预付款并赔偿甲方实际损失。

第十一条 协议终止

11.1 终止情形：
    • 双方协商一致
    • 一方严重违约，另一方书面通知后[X]日内未改正
    • 不可抗力
    • 法律规定的其他情形

11.2 终止后义务：
    • 支付已完成工作的报酬
    • 归还对方财产/资料
    • 继续履行保密义务

第十二条 不可抗力

12.1 因不可抗力导致无法履行协议，双方免责。
12.2 不可抗力包括：自然灾害、战争、瘟疫、政府行为等。
12.3 遭遇不可抗力一方应及时通知对方。

第十三条 争议解决

13.1 本协议适用[卡塔尔/阿联酋/英国]法律。
13.2 争议解决：首先友好协商；协商不成，提交[仲裁机构/法院]解决。
13.3 仲裁地点：[城市]

第十四条 其他条款

14.1 本协议自双方签字/盖章之日起生效。
14.2 本协议一式两份，双方各执一份，具有同等法律效力。
14.3 本协议附件与正文具有同等法律效力。
14.4 未经双方书面同意，不得转让本协议项下权利义务。
```

### 1.2 品牌合作关键条款解读

**必须包含的关键条款**：

| 条款 | 重要性 | 说明 |
|------|--------|------|
| **报酬与支付** | ⭐⭐⭐⭐⭐ | 金额、方式、时间节点 |
| **内容交付** | ⭐⭐⭐⭐⭐ | 数量、格式、审核流程 |
| **审核权** | ⭐⭐⭐⭐ | 审核次数、超时默认通过 |
| **发布与保留** | ⭐⭐⭐⭐ | 发布期限、保留时长 |
| **排他性** | ⭐⭐⭐⭐ | 排他范围、期限、违约 |
| **版权归属** | ⭐⭐⭐⭐ | 谁可以用内容做什么 |
| **违约责任** | ⭐⭐⭐⭐ | 违约后果 |
| **终止条款** | ⭐⭐⭐⭐ | 终止条件、后续义务 |

**创作者签约注意事项**：
```
✅ 必须：
• 明确交付时间和审核流程
• 限制修改次数
• 保留内容版权或使用权
• 明确排他范围
• 约定违约责任
• 约定内容删除规则

❌ 避免：
• "无限修改权"
• "永久排他"
• "无条件配合品牌"
• "无理由终止权"
• "内容版权归品牌"
```

## 二、联盟营销协议模板

### 2.1 联盟营销合作协议

```
┌─────────────────────────────────────────────────────────────────┐
│                    联盟营销合作协议                              │
│                AFFILIATE AGREEMENT                              │

合同编号：[编号]
签订日期：[日期]

【甲方 - 商家/品牌】

邮箱：[邮箱]

【乙方 - 联盟会员/创作者】
姓名：[你的姓名]
网站/社交媒体：[链接]
邮箱：[邮箱]
联盟代码：[你的专属代码]

─────────────────────────────────────────────────────────────────

第一条 合作概述

1.1 甲方授权乙方作为其联盟营销伙伴，通过乙方的渠道推广
    甲方产品/服务。

1.2 乙方将从其推广产生的销售/转化中获得佣金。

第二条 联盟链接与追踪

2.1 甲方将为乙方提供专属追踪链接。
    乙方的联盟链接：[URL]

2.2 追踪机制：
    • 通过Cookie追踪，Cookie有效期[X]天
    • 归因规则：唯一归因（归因给最后一次点击）
    • 延迟归因：如有退货，佣金可能在[X]天后确认

2.3 归因窗口：
    • 首次点击归因：X天
    • 最后点击归因：X天

第三条 佣金结构

3.1 佣金比例/金额：
    ┌────────────────────────────────────────┐
    │  产品/服务类型    │  佣金比例/金额      │
    ├────────────────────────────────────────┤
    │  [产品A]          │  [比例，如15%]      │
    │  [产品B]          │  [比例，如$10/单]    │
    │  其他产品          │  [按约定]           │
    └────────────────────────────────────────┘

3.2 佣金计算：
    • 佣金基于实际支付金额（扣除退款、退货、折扣）

3.3 最低佣金起付额：$[金额]（如$50）
    低于此金额，佣金将累积至下期。

3.4 佣金支付：
    • 支付周期：每月/每季度
    • 支付方式：[银行转账/PayPal]
    • 支付时间：结算周期结束后[X]日内

第四条 支付详情

4.1 账户信息：
    • 收款人：[姓名]
    • 收款方式：[PayPal/银行转账]
    • 账户信息：[详细]

4.2 税务信息：
    乙方自行负责税务申报。
    甲方可应要求提供收入证明文件。

第五条 推广规范

5.1 合规推广：
    乙方承诺以下推广行为：
    • 遵守所有适用法律法规
    • 遵守各平台推广政策
    • 不使用误导性宣传
    • 不冒用品牌官方身份
    • 明确披露联盟关系

5.2 禁止行为：
    • 垃圾邮件推广
    • 虚假宣传或夸大功效
    • 竞价品牌关键词（SEM）
    • 域名含甲方品牌名
    • 强制推销或骚扰用户
    • 使用品牌负面信息推广

5.3 披露要求：
    乙方应在所有推广内容中明确说明：
    "本链接为联盟链接，我可能从中获得佣金"
    或平台要求的其他标准披露语。

第六条 内容审核（如适用）

6.1 如甲方要求审核推广内容，乙方应配合。
6.2 审核应在[X]个工作日内完成。
6.3 未及时审核的内容，乙方可自行决定发布。

第七条 独家性

7.1 本协议不构成独家合作。
7.2 乙方可推广其他品牌，包括竞争对手。
7.3 如需独家合作，需另行协商。

第八条 知识产权

8.1 甲方授权乙方使用其商标、品牌元素用于推广。
8.2 此授权仅限本协议有效期内。
8.3 未经授权，乙方不得将甲方知识产权用于其他用途。

第九条 保密条款

9.1 双方对合作中获知的商业信息保密。
9.2 保密义务在本协议终止后继续有效[X]年。

第十条 联盟账户管理

10.1 甲方提供联盟后台供乙方查看：
    • 追踪链接数据
    • 销售/转化数据
    • 佣金数据

10.2 数据更新频率：[实时/每日/每周]

第十一条 欺诈防范

11.1 禁止欺诈行为：
    • 自我购买
    • 教唆他人购买
    • 篡改追踪链接
    • 虚假点击或转化

11.2 欺诈处理：
    发现欺诈行为，甲方有权：
    • 立即终止协议
    • 扣留未支付佣金
    • 追回已支付佣金
    • 追究法律责任

第十二条 协议终止

12.1 终止方式：
    • 双方书面协议
    • 一方提前[X]天书面通知
    • 一方严重违约

12.2 终止后：
    • 停止使用联盟链接
    • 停止推广行为
    • 支付已确认佣金
    • 返还品牌资料

第十三条 责任限制

13.1 甲方不对乙方的收入做任何保证。
13.2 甲方不对乙方的推广效果做任何保证。
13.3 任何情况下，甲方赔偿不超过本协议项下已支付佣金。

第十四条 争议解决

14.2 争议解决：友好协商，协商不成提交[仲裁/诉讼]

第十五条 其他

15.2 本协议取代双方之前所有口头/书面协议。
15.3 协议变更需双方书面同意。
```

### 2.2 联盟营销协议注意事项

| 条款 | 你应该关注 | 建议 |
|------|------------|------|

| **独家条款** | 尽量避免 | 争取非独家 |

```
• 每个人情况不同，适用方案不同

任何健康相关决定前，请咨询专业医疗人员。
```

## 九、NDA保密协议模板

```
┌─────────────────────────────────────────────────────────────────┐
│                        保密协议                                  │
│              NON-DISCLOSURE AGREEMENT (NDA)                      │
└─────────────────────────────────────────────────────────────────┘

协议编号：[编号]
签订日期：[日期]

【披露方】（"披露方"）：
姓名/公司：[名称]
地址：[地址]

【接收方】（"接收方"）：
姓名/公司：[名称]
地址：[地址]

─────────────────────────────────────────────────────────────────

第一条 保密信息定义

1.1 "保密信息"包括但不限于：
    • 商业计划、财务信息
    • 客户/供应商信息
    • 技术/产品信息
    • 营销策略
    • 任何标注"保密"的信息

1.2 以下信息不属于保密信息：
    • 公开可获得的信息
    • 接收方事先已知的信息
    • 接收方从第三方合法获得的信息
    • 法律要求披露的信息

第二条 保密义务

2.1 接收方应：
    • 对保密信息保密
    • 不向第三方披露
    • 仅用于约定目的
    • 采取合理措施保护

2.2 接收方不得：
    • 复制保密信息（除非必要）
    • 用于披露目的
    • 让未授权人员接触

第三条 允许披露

3.1 在以下情况下可披露：
    • 获得披露方书面同意
    • 法律/法院要求
    • 监管机构要求

3.2 如需依法披露：
    • 尽量提前通知披露方
    • 仅披露必要部分

第四条 保密期限

4.1 本协议有效期：[起始日期]至[结束日期]
4.2 或：自披露时起[X]年
4.3 某些信息可能要求永久保密。

第五条 返还/销毁

5.1 协议终止或要求时：
    接收方应：
    • 返还所有保密信息
    • 或销毁并提供证明

第六条 所有权

6.1 披露信息不转让任何权利。
6.2 接收方不因本协议获得任何权利。

第七条 无授权

7.1 本协议不授权任何许可或权利。

第八条 违约

8.1 违约可能导致：
    • 禁令救济
    • 损害赔偿
    • 其他法律救济

8.2 违约不影响其他法律救济。

第九条 适用法律

9.1 本协议受[国家/地区]法律管辖。
9.2 争议解决：友好协商或[仲裁/诉讼]。

第十条 其他

10.1 本协议构成双方完整协议。
10.2 修订需书面同意。
10.3 任何一方不得转让本协议。
```

## 十、合同关键条款解读

### 10.1 必须包含的条款

| 条款类型 | 必须包含内容 | 重要性 |
|----------|--------------|--------|
| **服务范围** | 具体工作内容、交付物 | ⭐⭐⭐⭐⭐ |
| **报酬与支付** | 金额、方式、时间 | ⭐⭐⭐⭐⭐ |
| **知识产权** | 内容版权归属、授权范围 | ⭐⭐⭐⭐⭐ |
| **保密条款** | 保密内容、期限、例外 | ⭐⭐⭐⭐ |
| **违约责任** | 违约后果、赔偿方式 | ⭐⭐⭐⭐ |
| **终止条款** | 终止条件、后续义务 | ⭐⭐⭐⭐ |
| **争议解决** | 法律适用、仲裁/诉讼 | ⭐⭐⭐ |
| **修改条款** | 变更程序 | ⭐⭐⭐ |

### 10.2 创作者必须争取的权益

```
✅ 必须争取：
• 明确的内容审核流程和次数限制
• 保留作品集展示权
• 合理的排他范围和时间
• 按时付款保障
• 终止后的合理处理
• 明确的违约责任

❌ 尽量避免：
• "完全按照品牌要求修改"
• "所有内容版权归品牌"
• "永久排他"
• "无条件终止权"
• "无限修改权"
• "无具体金额的'合理报酬'"
```

### 10.3 什么情况必须找律师

**强烈建议咨询律师的情况**：

| 情况 | 原因 |
|------|------|
| **首次签约大品牌** | 合同金额大/条款复杂 |
| **涉及独家协议** | 影响未来收入 |
| **跨司法管辖区** | 多哈/迪拜/欧美法律不同 |
| **合作金额超过$10,000** | 风险较高 |
| **涉及许可/转让** | 版权问题复杂 |
| **对方使用不标准合同** | 可能有不公平条款 |
| **发生纠纷** | 专业法律支持 |
| **涉及合伙/公司** | 法律责任重大 |

**可以自己处理的情况**：
- 小额/简单合作（<$1000）
- 标准格式合同
- 简单的数字产品销售
- 已有明确模板的合作
