## 一、非设计师的设计基础

### 1.1 四大设计原则

```
设计基础四元素：

1. 对比（Contrast）
   └── 深浅/大小/颜色对比让信息层级清晰

2. 对齐（Alignment）
   └── 元素有序排列，视觉连贯

3. 重复（Repetition）
   └── 统一风格，建立品牌识别

4. 亲密性（Proximity）
   └── 相关元素靠近，逻辑分组
```

### 1.2 色彩基础

```
色彩构成：
├── 色相：颜色的本质（红/蓝/黄）
├── 明度：明暗程度
└── 饱和度：鲜艳程度

色轮关系：
       黄色
      /    \
   橙色     绿色
   /          \
红色 ---- 紫色 ---- 蓝色

配色方案：

单色系：同一色相，不同明度饱和度
        → 和谐统一，适合品牌色

互补色：色轮对面（如红+绿）
        → 强烈对比，适合强调

类比色：相邻颜色（如蓝+紫+粉）
        → 柔和舒适，适合背景

三角色：等距三色（如红+黄+蓝）
        → 丰富活泼，适合插图

分割互补：互补色两旁的颜色
        → 既有对比又不过于强烈
```

### 1.3 品牌色系统

```
建立品牌色步骤：

1. 确定主色（1个）
   ├── 体现品牌性格
   ├── 使用场景最多
   └── 优先选择中性色背景上的颜色

2. 确定辅助色（2-3个）
   ├── 配合主色使用
   ├── 用于信息分类
   └── 与主色协调

3. 确定中性色（2个）
   ├── 文字色（深灰/黑色）
   ├── 背景色（白色/浅灰）
   └── 边框/分割线

4. 建立色值规范
   ├── HEX值（网页）
   ├── RGB值（屏幕）
   ├── CMYK值（印刷）
   └── Pantone色号（精准）

示例（知识博主配色）：
├── 主色：#2563EB（专业蓝）
├── 辅助：#10B981（成长绿）
├── 强调：#F59E0B（活力黄）
├── 文字：#1F2937（深灰）
└── 背景：#FFFFFF（白）
```

### 1.4 字体系统

```
字体分类：

衬线字体 Serif
├── 有装饰性笔画
├── 传统/权威感
├── 适合标题
└── 示例：Georgia, Times New Roman

无衬线字体 Sans Serif
├── 简洁现代
├── 清晰易读
├── 适合正文
└── 示例：Helvetica, Arial, Inter

手写字体 Script
├── 优雅/亲切
├── 适合装饰
└── 示例：Caveat, Pacifico

等宽字体 Monospace
├── 代码/数据展示
└── 示例：Courier, Roboto Mono

创作者字体搭配建议：
├── 标题：1种装饰性字体
├── 正文：1-2种无衬线字体
├── 强调：同一字体的不同粗细
└── 数量：整套视觉不超过3种字体
```

### 1.5 排版基础

```
字号层级：

移动端（手机）：
├── 标题1：32-40px
├── 标题2：24-28px
├── 正文：16-18px
├── 辅助文字：14px
└── 标签/角标：12px

桌面端：
├── 标题1：48-60px
├── 标题2：32-40px
├── 正文：16-18px
├── 辅助文字：14px
└── 标签/角标：12px

行间距建议：
├── 正文字体：行高1.5-1.8倍
├── 标题字体：行高1.0-1.2倍
└── 短文本：行高1.2-1.5倍

字间距建议：
├── 标题：0-2%字宽
├── 正文：0%或略微宽松
└── 紧凑感文字：-2%到0%
```

### 1.6 留白艺术

```
留白的作用：
├── 提升可读性
├── 增强呼吸感
├── 引导视觉焦点
└── 传递高级感

留白原则：
├── 内容不要撑满
├── 相关元素靠近
├── 不相关元素分离
├── 边缘留白均匀
└── 移动端留白更多

留白比例参考：
├── 安全边距：画面5-10%
├── 元素间距：内容高度10-20%
├── 段落间距：行高的50-100%
└── 卡片内边距：15-25px
```

### 6.4 常见问题解决

```
解决常见问题：

手指畸形 → 添加"realistic hands, correct fingers"

画面模糊 → 添加"sharp focus, high resolution"

风格不对 → 添加参考艺术家名或风格词

构图不好 → 指定视角：front view/side view/aerial view

文字乱码 → 避免在图中生成文字

颜色不准 → 指定配色方案或添加color palette

内容重复 → 使用不同的seed值或调整描述
```

```
黄金法则：

1. 人物面部特写（点击率+50%）
   └── 表情要夸张/有张力

2. 高对比度文字
   └── 白字黑边/亮色背景

3. 情绪表达强烈
   └── 笑/惊讶/疑问/震惊

4. 简洁明了
   └── 30%留白，信息不过载

5. 品牌一致性
   └── 统一色调/字体/风格
```

### 7.2 各平台缩略图规范

```
YouTube缩略图：
├── 尺寸：1280×720（16:9）
├── 文件大小：≤2MB
├── 格式：JPG/PNG
├── 关键：文字+人物+高对比

TikTok封面：
├── 尺寸：1080×1920（9:16）
├── 关键：竖版设计，中央主体

Instagram帖子封面：
├── 尺寸：1080×1080（1:1）或1080×1350
├── 关键：视觉冲击力

小红书封面：
├── 尺寸：1080×1440（3:4）
├── 关键：竖版文字大，笔记合集统一风格
```
