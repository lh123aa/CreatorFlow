## 一、视频制作全流程概览

### 1.1 单人创作的工作流

```
idea（创意）→ 脚本（30分钟）→ 拍摄（1-3小时）→ 粗剪（30分钟）→ 
精剪（1-2小时）→ 调色（15分钟）→ 字幕（15-30分钟）→ 导出上传
```

### 1.2 时间分配建议（多哈气候适配）

| 场景 | 最佳时间 | 时长 | 说明 |
|------|----------|------|------|
| 室内录制 | 上午9-11点/下午4-6点 | 2-3h | 避开正午强光 |
| 外景拍摄 | 10月-4月清晨/傍晚 | 1-2h | 多哈冬季黄金时段 |
| 室内讲座 | 任何时间 | 灵活 | 灯光可控 |

## 四、灯光设计方案

### 4.1 自然光运用（$0方案）

**多哈黄金时段**
```
拍摄位置选择：
├── 窗户正对面：柔和正面光（最佳）
├── 窗户45度侧：经典三分之二光
├── 窗户正侧面：戏剧性侧光
└── 背对窗户：需正面补光
```

**自然光优化技巧**
```
时间选择：
├── 室内：上午10点前/下午4点后
├── 户外：10月-4月清晨或傍晚
└── 避开：正午12点-3点（多哈阳光极强）

反光板DIY：
├── 白色泡沫板（超市$5可买）
├── 铝箔纸包裹纸板（更硬朗）
└── 白色床单/浴巾（柔光补充）
```

### 4.2 环形灯方案（$35-80）

**推荐产品**
```
入门级：18寸LED环形灯（约$35）
├── 淘宝/AliExpress直邮多哈
├── 三档亮度+三种色温
└── 包含手机支架

进阶级：优篮子环形灯（约$80）
├── 显色指数更高（Ra>95）
├── 可调色温3200K-5600K
└── 遥控器控制
```

**环形灯使用技巧**
```
人像拍摄：
├── 眼睛反光：环形灯在相机正上方
├── 柔和肤色：距离1-1.5米
└── 避免过曝：不超过面部最亮区域

产品展示：
├── 侧后方45度打光
├── 创建漂亮的产品轮廓光
└── 用白色纸板补阴影
```

### 4.3 三点布光系统（进阶）

```
标准三点布光：
              [主光]
                 ↓
    [轮廓光] → [主体] ← [补光]
                 ↑
            [反光板]

参数设置（入门级LED灯）：
├── 主光：100%亮度，5600K（模拟日光）
├── 补光：50-70%亮度，略暖5600K
└── 轮廓光：80%亮度，偏暖3200K（分离背景）
```

## 五、视频构图与拍摄技巧

### 5.1 基础构图法则

**三分法则（黄金分割）**
```
将画面用两条横线和两条竖线分成9格
                  
    ┌─────┬─────┬─────┐
    │     │     │     │
    │  ●  │     │     │  ● = 视觉焦点
    │     │     │     │    放在交叉点上
    ├─────┼─────┼─────┤
    │     │     │     │
    │     │     │  ●  │
    │     │     │     │
    └─────┴─────┴─────┘
```

**五种基础构图**
```
1. 中心构图：主体放中间（适合特写/产品）
2. 三分构图：人物在左/右1/3线（最常用）
3. 框架构图：利用门窗/树枝框住主体
4. 引导线构图：利用道路/栏杆引导视线
5. 留白构图：画面大量空白（高级感）
```

### 5.2 景别系统

| 景别 | 距离 | 用途 | 拍摄建议 |
|------|------|------|----------|
| 特写 | 面部 | 强调表情/产品细节 | 情感传达 |
| 近景 | 胸口以上 | 主播出镜 | 最常用景别 |
| 中景 | 膝盖以上 | 展示动作 | 访谈/对话 |
| 全景 | 全身 | 展示整体 | 环境交代 |
| 大远景 | 广阔背景 | 城市/风景 | B-roll素材 |

### 5.3 拍摄角度与高度

```
机位高度对照：
├── 俯拍（高15度）：展示桌面/教程（上帝视角）
├── 平视（0度）：对话感/亲近感（最常用）
├── 仰拍（低15度）：权威感/高大感（少用）
└── 45度角：综合视角（产品展示）
```

### 5.4 单人自拍技巧

**手机自拍参数**
```
横屏（YouTube/长视频）：
├── 分辨率：1920×1080（1080p）
├── 构图：下巴占画面1/3，眼睛在上1/3线
└── 角度：微微俯视（显脸小）

竖屏（TikTok/Reels）：
├── 分辨率：1080×1920
├── 留白：头顶留10-15%
└── 视线：看屏幕上1/3处（对应观众眼睛）
```

**固定机位自拍技巧**
```
设置步骤：
1. 放置手机，调试好构图
2. 锁定曝光和对焦（iPhone长按画面）
3. 用语音控制开始录制
   ├── Siri："嘿Siri，开始录制"
   ├── 三星：Bixby语音指令
   └── 或使用定时拍摄功能
4. 放置提词器（手机/电脑）
5. 备一杯水在旁边
```

## 六、免费剪辑软件实操

### 6.1 软件选择指南

```
软件选择决策树：

剪辑需求
├── 简单快速发布（手机为主）
│   ├── CapCut（免费，TikTok官方）

│
└── 苹果生态
    ├── iMovie（免费）
    └── 推荐理由：iPhone无缝衔接
```

### 6.2 CapCut电脑版教程

**界面认识**
```
┌────────────────────────────────────────────┐
│  媒体库 │     预览窗口      │   属性面板   │
│         │                   │              │
│ [素材]  │    [播放预览]     │ [滤镜/特效]  │
│         │                   │              │
├────────────────────────────────────────────┤
│                 时间轴                       │
│  [视频轨1] [视频轨2] [音频轨1] [字幕轨]     │
└────────────────────────────────────────────┘
```

**基础操作流程**
```
第一步：导入素材
├── 拖拽文件到媒体库
├── 支持格式：MP4/MOV/AVI
└── 建议创建项目文件夹

第二步：粗剪
├── 拖素材到时间轴
├── 用「剃刀」工具裁切（快捷键C）
├── 删除不要的片段
└── 预览整体节奏

第三步：添加转场
├── 溶解/交叉淡化（最常用）
├── 移动转场（短视频推荐）
└── 控制时长：0.3-0.5秒

第四步：添加字幕
├── 自动字幕（自动识别）
├── 调整时间轴对齐
└── 修改识别错误的字

第五步：导出
├── 分辨率：1080P（推荐）
├── 帧率：30fps（日常）/60fps（运动）
└── 格式：MP4(H.264)
```

### 6.3 DaVinci Resolve入门

**为什么选择DaVinci**
```
优势：
├── 免费版功能完整（无水印/无功能限制）
├── 专业级调色能力（好莱坞同款）
├── 多轨时间轴
└── 稳定性和专业性顶级

适用场景：
├── YouTube长视频（10分钟+）
├── 需要精细调色的内容
└── 批量处理多个视频
```

**基础调色流程**
```
调色工作流程：

1. 一级校准（基础调整）
   ├── 曝光：Lift/Gamma/Gain
   ├── 对比度：适当增加
   ├── 高光/阴影：恢复细节
   └── 白平衡：修正色偏

2. 风格化（创意调色）
   ├── 饱和度调整
   ├── 色调曲线
   ├── 色彩匹配
   └── 添加LUT（调色预设）

3. 局部调色
   ├── 限定器（选中特定颜色）
   ├── 窗口（形状遮罩）
   └── 跟踪（跟随移动主体）
```

**快速调色预设**
```
创作者常用LUT风格：
├── 电影感：Teal & Orange（青色+橙色）
├── 日系：Soft Fade（柔和褪色）
├── 高对比：Dark & Moody（暗调）
└── 干净明亮：Clean Bright（小白最爱）
```

快速上手指南：

导入 → 拖拽到时间轴 → 裁切 → 添加音乐 → 导出

## 七、视频剪辑SOP完整流程

### 7.1 粗剪阶段（30-60分钟）

```
粗剪检查清单：
□ 素材全部导入并备份
□ 按场景/类别整理素材
□ 按脚本顺序排列镜头
□ 剔除明显失误的片段
□ 确认视频时长符合目标
□ 视频节奏是否流畅
□ 音频是否同步
□ 关键信息是否完整保留
```

**快速粗剪技巧**
```
快捷键（DaVinci/CapCut通用）：
├── J/K/L：倒放/暂停/正放
├── I/O：设置入点/出点
├── C：剃刀（裁切）
├── Delete：删除选中片段
└── S：吸附开关

粗剪原则：
├── 先保留所有素材（备份）
├── 快速过一遍所有镜头
├── 只删明显不要的
└── 节奏宁快勿慢（短视频逻辑）
```

### 7.2 精剪阶段（1-2小时）

```
精剪核心要素：

1. 节奏控制
   ├── BGM节奏点卡点
   ├── 切换镜头时呼吸感
   └── 关键信息留足时间

2. 镜头衔接
   ├── 动接动/静接静（避免跳切）
   ├── 视线方向一致
   ├── 景别要有变化
   └── 考虑因果逻辑

3. 情绪节奏
   ├── 高潮点前置（短视频法则）
   ├── 留出情绪缓冲
   └── 结尾要有钩子
```

### 7.3 调色阶段（15-30分钟）

```
调色工作流：

轻度调色（日常vlog）：
├── 对比度+10~15
├── 高光-10~20
├── 阴影+5~10
├── 饱和度-5~10（莫兰迪感）
└── 完毕

中度调色（统一风格）：
├── 建立调色预设
├── 应用到所有片段
├── 微调不一致处
└── 导出参考帧对比

专业调色（内容要求高）：
├── 一级校准→二级校准→风格化
└── 使用LUT加速流程
```

### 7.4 字幕阶段（15-30分钟）

```
字幕制作流程：

自动生成（节省80%时间）：
├── CapCut：自动字幕功能
├── YouTube Studio：自动生成后下载
└── 准确性：英语85-95%，中文需人工校对

字幕样式选择：
├── 底部居中（最安全）
├── 顶部（说话人在下方时）
└── 左侧/右侧（对比画面时）

字幕设计要点：
├── 字体：简洁无衬线（Arial/Helvetica）
├── 大小：能看清即可，不要太大
├── 颜色：白色带黑色描边
├── 背景：半透明黑色条（可选）
└── 限制：每行不超过12字
```

### 7.5 导出设置

```
导出参数建议：

1080P 日常版：
├── 分辨率：1920×1080
├── 帧率：30fps
├── 码率：8-12 Mbps
└── 格式：MP4(H.264)

1080P 高质量：
├── 分辨率：1920×1080
├── 帧率：30fps
├── 码率：15-20 Mbps
└── 格式：MP4(H.264)

4K 专业版：
├── 分辨率：3840×2160
├── 帧率：30fps
├── 码率：35-50 Mbps
└── 格式：MP4(H.265)
```

## 八、缩略图制作

### 8.1 缩略图设计原则

```
黄金法则：
├── 高对比度色彩（3秒吸引注意力）
├── 大字体标题（一眼看清主题）
├── 人物面部特写（点击率+50%）
├── 情绪表达强烈（笑/惊/疑问）
└── 简洁明了（30%留白）

平台尺寸规范：
├── YouTube：1280×720（16:9）
├── TikTok：1080×1920（9:16）
├── Instagram Feed：1080×1080（1:1）
└── 建议：制作时用2倍像素
```

Figma（在线协作）

## 九、竖屏vs横屏制作差异

### 9.1 平台特性对比

```
平台 ════════════════════════════════

═══════════════════════════════════════

竖屏    ★★☆☆☆   ★★★★★   ★★★☆☆

时长    10-20min  15-60s   静态+Reels
═══════════════════════════════════════
```

### 9.2 竖屏内容策略

```
竖屏拍摄技巧：
├── 中央主体构图（不要担心裁切）
├── 头部留白15-20%
├── 眼睛看屏幕1/3处
├── 手势动作幅度要大
└── 背景简洁或虚化

竖屏内容类型：
├── 前三秒钩子必须强
├── 信息密度要高
├── 情绪要夸张
├── B-roll要用特写
└── 文字要大要醒目
```

### 9.3 横屏内容策略

```
横屏拍摄技巧：
├── 三分法构图
├── 留出剪辑安全边距
├── 说话时看镜头侧面（1/3线）
└── 背景交代环境

横屏内容类型：
├── 教程/知识讲解（最强）
├── 访谈/对话类
├── 演示/产品展示
├── 游戏/屏幕录制
└── vlog/旅行记录
```
