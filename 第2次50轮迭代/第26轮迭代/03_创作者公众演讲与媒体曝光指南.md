## 二、演讲类型与准备

### 2.1 演讲类型全览

**按场景分类**：

| 类型 | 时长 | 受众规模 | 准备周期 | 核心要点 |
|------|------|----------|----------|----------|
| 会议演讲 | 20-45min | 50-500+ | 2-4周 | 专业深度+互动 |
| Workshop | 1-3小时 | 10-50 | 2-4周 | 实操性强+交付物 |
| 播客嘉宾 | 30-90min | 不定 | 1-3天 | 对话深度+故事 |
| YouTube访谈 | 15-30min | 不定 | 1-2天 | 结构清晰+视觉 |
| 企业内训 | 2-8小时 | 10-100 | 1-2周 | 系统性+定制化 |
| TEDx | 8-18min | 不定 | 4-8周 | 思想深度+传播性 |

**按形式分类**：
- **纯演讲**：单向输出，PPT辅助
- **对话访谈**：Q&A形式，即兴成分多
- **工作坊**：互动为主，实践为主
- **直播**：实时互动，可录播复用

### 2.2 演讲准备SOP

**标准准备流程**：

```markdown
## 演讲准备7步法

### Step 1: 选题与目标确定（Day 1-2）
□ 明确演讲主题（不要超过1个核心观点）
□ 确定目标受众（他们关心什么？）
□ 设定演讲目标（知识传递/行动触发/情感共鸣）
□ 确定时长（严格控制内容容量）

### Step 2: 受众分析（Day 2-3）
□ 受众背景（专业度/年龄/行业）
□ 受众痛点（他们面临什么问题？）
□ 受众期望（他们想带走什么？）
□ 演讲约束（时间/场地/设备/敏感话题）

### Step 3: 内容结构设计（Day 3-5）
□ 设计开场钩子（3分钟抓住注意力）
□ 提炼3-5个核心要点
□ 设计每个要点的支撑材料
□ 设计结尾号召/总结
□ 预留Q&A时间（建议20%）

### Step 4: PPT/辅助材料制作（Day 5-10）
□ 选择PPT工具（见下方工具推荐）
□ 遵循10/20/30原则
□ 设计统一的视觉风格
□ 准备演讲稿/提词器

### Step 5: 排练与调整（Day 10-14）
□ 第一次完整排练（计时）
□ 优化内容节奏
□ 第二次排练（模拟真实场景）
□ 准备应对意外情况

### Step 6: 现场准备（演讲前一天/当天）
□ 提前踩点/测试设备
□ 准备备份材料
□ 准备自我介绍（1分钟版）
□ 心理调整

### Step 7: 交付与复盘
□ 精彩呈现
□ 收集反馈
□ 复盘总结
□ 内容复用（录播/文章/剪辑）
```

### 2.3 演讲结构设计

**经典结构模型**：

| 模型 | 结构 | 适用场景 |
|------|------|----------|
| 总分总 | 结论→分论点→总结 | 说服型演讲 |
| 问题解决 | 痛点→分析→方案→案例 | 培训型演讲 |
| 时间线 | 过去→现在→未来 | 分享型演讲 |
| 3P结构 | Problem-Promise-Proof | 提案型演讲 |
| 英雄之旅 | 背景→挑战→成长→分享 | 个人分享 |

**演讲内容容量参考**：
| 时长 | 核心要点 | 字数（约） | PPT页数建议 |
|------|----------|-----------|-------------|
| 5min | 1个 | 500-700 | 5-8页 |
| 15min | 2-3个 | 1500-2000 | 10-15页 |
| 30min | 3-5个 | 3000-4000 | 15-25页 |
| 45min | 4-6个 | 5000-6000 | 25-35页 |
| 60min+ | 5-8个 | 8000+ | 40+页 |

## 三、免费PPT制作方案

### 3.1 工具对比与选择

**免费PPT工具推荐**：

| 工具 | 优点 | 缺点 | 推荐场景 |
|------|------|------|----------|
| Google Slides | 免费/云端/协作 | 模板较少 | 日常/协作 |
| Canva | 模板丰富/设计感强 | 导出限制 | 设计感演讲 |
| Gamma | AI辅助/快速生成 | 功能有限 | 快速出稿 |
| WPS演示 | 本地+云端/中文友好 | 设计感一般 | 中文场景 |
| LibreOffice | 完全免费/本地 | 界面老旧 | 备份选择 |

### 3.2 Google Slides使用指南

**快速上手技巧**：
```
1. 从模板开始
   → slides.new 或 File → New from template
   
2. 快捷操作
   → Ctrl+D 复制页面
   → Ctrl+/ 插入元素
   → Ctrl+Alt+K 格式复制

3. 团队协作
   → 分享链接即可实时协作
   → 评论功能便于反馈

4. 演示模式
   → 激光笔工具（按住鼠标）
   → 放大镜（Alt+点击）
```

### 3.3 Canva演示功能

**Canva Pro免费试用**：
- 新用户7天免费
- 教育邮箱可申请免费
- 使用教育邮箱注册

**Canva演示技巧**：
```
1. 品牌套件设置
   → 提前设置好颜色/字体/Logo
   → 所有页面自动统一

2. 动画效果
   → 不宜过多，每页1-2个即可
   → 保持专业感

3. 导出设置
   → 选择PDF/PPT格式
   → 分辨率选最高

4. 演示模式
   → 可直接播放
   → 支持手势控制
```

### 3.4 Gamma AI演示

**Gamma特点**：
- 输入主题AI生成PPT
- 适合快速出原型
- 设计感强

**使用步骤**：
```
1. 输入主题/内容
2. 选择模板风格
3. AI生成初稿
4. 人工调整优化
5. 导出使用
```

### 3.5 PPT设计原则

**10/20/30原则**（Guy Kawasaki）：
- 10张幻灯片
- 20分钟演讲
- 30号以上字体

**视觉设计要点**：
```
┌─────────────────────────────────────────┐
│  好的PPT：                               │
│  • 每页1个核心信息                       │
│  • 图片>文字                            │
│  • 留白>拥挤                            │
│  • 一致性>花哨                           │
├─────────────────────────────────────────┤
│  避免：                                  │
│  • 大段文字                             │
│  • 超过3种颜色                          │
│  • 动画过多                             │
│  • 字体过小                             │
└─────────────────────────────────────────┘
```

## 四、获取演讲机会的策略

### 4.1 主动出击：如何联系活动方

**冷启动邮件模板**：

```markdown
主题：演讲提议：[主题] - [你的名字]

尊敬的[主办方姓名/职位]：

我是[名字]，[简短背景介绍，1-2句话]。

了解到[活动名称]正在筹备[主题方向]的演讲嘉宾，我想自荐分享[具体主题]。

我的演讲将覆盖：
• [要点1]
• [要点2]
• [要点3]

这个主题适合[目标受众]，因为[为什么你的内容对他们有价值]。

附件是我的演讲简介和个人介绍，供您参考。

期待您的回复，我们可以进一步沟通。

祝好，
[名字]
```

### 4.3 成为播客嘉宾

**播客嘉宾自荐**：

**Step 1: 找目标播客**
```
渠道：
• Apple Podcasts / Spotify 搜索你的领域
• Listen Notes (listennotes.com) 播客搜索
• 竞争对手的播客
• 行业推荐
```

**Step 2: 准备材料包**
```markdown
播客嘉宾资料包应包含：
□ 1张专业照片（高清）
□ 个人简介（50字版 + 150字版）
□ 话题建议列表（3-5个）
□ 过往播客经历（如有）
□ 社交媒体链接
□ 潜在受众规模数据
```

**Step 3: 投递邮件**
```
主题：播客嘉宾自荐 - [话题领域] + [你的名字]

正文模板：
[播客主持人名字]，我很喜欢你的节目，尤其是[具体一期]。

我是[名字]，[背景介绍]。我在[领域]有[X年经验]，专注于[细分方向]。

我想推荐以下几个话题：
1. [话题1] - [为什么适合你的听众]
2. [话题2] - [为什么适合你的听众]

我的独特视角是[你的差异化]，这与你的[受众特点]很匹配。

附上我的资料包，期待交流。
```

## 五、演讲变现路径

### 5.1 从免费到付费的演进

**演讲变现路线图**：

```
阶段1：积累期（0-1年）
→ 免费分享/低付费活动
→ 目标：建立案例和口碑
→ 收入：品牌曝光为主

阶段2：成长期（1-2年）
→ 开始收取小额演讲费
→ 目标：覆盖成本+小赚
→ 收入：$500-2000/场

阶段3：专业期（2-3年）
→ 稳定收费演讲
→ 目标：建立行业地位
→ 收入：$2000-5000/场

阶段4：专家期（3年+）
→ 高端演讲/企业培训
→ 目标：被动邀约+高单价
→ 收入：$5000-20000+/场
```

### 5.2 演讲定价策略

**定价参考表**：

| 演讲类型 | 新手参考价 | 有经验参考价 | 专家参考价 |
|----------|-----------|-------------|-----------|
| 本地Meetup | 免费 | $200-500 | $500-1000 |
| 行业会议 | $300-800 | $1000-3000 | $3000-8000 |
| 企业内训 | $500-1500/小时 | $1500-5000/小时 | $5000-15000/小时 |
| 跨国会议 | $1000-3000 | $3000-10000 | $10000-30000+ |
| 定制工作坊 | $1000-3000 | $3000-8000 | $8000-20000+ |

**影响定价的因素**：
- 演讲时长
- 受众规模
- 受众支付能力（企业>个人）
- 你的专业度和知名度
- 差旅需求
- 独家/排他要求

### 5.3 演讲合同要点

**演讲合同必备条款**：
```markdown
## 演讲服务合同核心内容

1. 基本信息
   • 日期/时间/时长
   • 地点（线上/线下）
   • 受众规模/类型

2. 服务内容
   • 演讲主题
   • 演讲形式（是否有互动/Q&A）
   • 是否有PPT/资料提供
   • 是否允许录制

3. 费用条款
   • 演讲费金额
   • 费用包含范围（差旅/住宿等）
   • 付款时间和方式
   • 取消/改期条款

4. 双方责任
   • 主办方提供（设备/场地/推广）
   • 演讲者提供（准时/内容质量）
   • 违约责任

5. 知识产权
   • 内容版权归属
   • 录制视频使用权限
   • 宣传使用肖像权
```

### 6.2 HARO/Connectively使用指南

**HARO（Help A Reporter Out）使用流程**：

```
注册流程：
1. 访问 helpareporter.com
2. 选择免费/付费计划
3. 设置领域偏好
4. 等待每日邮件

响应流程：
1. 收到记者需求邮件
2. 筛选匹配的问题
3. 撰写专业回复
4. 包含你的背景介绍
5. 等待记者联系

成功要点：
• 回复要简洁专业
• 突出你的专业背景
• 提供独特视角
• 回复要快（先到先得）
• 提供可引用的名言
```

**响应模板**：
```markdown
Subject: Expert Comment on [话题]

Hi [记者名字],

I saw your query about [具体问题] and would love to contribute.

[你的专业观点，2-3句话]

My background: [1-2句话背景介绍，包括你的权威性]

Happy to provide more detail or additional sources if needed.

Best,
[名字]
[Title/Company]
[联系方式]
[Headshot链接]
```

## 七、线上vs线下演讲技巧

### 7.1 线下演讲技巧

**现场控制要点**：

| 环节 | 技巧 | 注意事项 |
|------|------|----------|
| 开场 | 眼神交流/微笑/自信站姿 | 不要马上开始说 |
| 中场 | 移动/手势/声调变化 | 避免重复动作 |
| 互动 | 提问/投票/小游戏 | 控制时间 |
| 结束 | 明确总结/强有力收尾 | 不要说"我的演讲结束了" |

**应对意外情况**：
- 设备故障：准备PPT备份+纸质笔记
- 时间变化：准备好缩短/延长版本
- 冷场：准备更多互动问题
- 问题刁钻：承认+转移+承诺后续

### 7.2 线上演讲技巧

**线上演讲要点**：

| 维度 | 建议 |
|------|------|
| 环境 | 干净背景+良好光线 |
| 设备 | 至少HD摄像头+外接麦克风 |
| 网络 | 有线网络备份 |
| 软件 | Zoom/Teams+直播平台 |
| 录制 | 提前测试录制效果 |

**线上互动策略**：
```
┌─────────────────────────────────────┐
│  线上互动比线下更难，需要更多主动    │
├─────────────────────────────────────┤
│  • 开场互动：投票/问答/聊天          │
│  • 中场互动：定期提问确认理解        │
│  • 结尾互动：Q&A+下次预告            │
│  • 社媒互动：实时发推/评论区        │
└─────────────────────────────────────┘
```

### 7.3 混合演讲（Hybrid）

**混合模式挑战**：
- 线上线下体验不一致
- 技术要求更高
- 互动设计更复杂

**混合演讲建议**：
- 准备两套互动方案
- 安排专人负责线上观众
- 使用统一平台避免割裂
- 提前测试所有设备
