## 1. Prompt工程基础原则

### 核心结构

```
优秀Prompt = 角色 + 任务 + 约束 + 格式 + 示例
```

#### 1.1 角色设定 (Role)

**为什么重要**：角色设定让AI理解自己的身份和行为边界。

**正确示例**：
```
你是一位专注于[领域]的内容策划专家，
有10年帮助创作者规划内容的经验。
你擅长[具体技能]，风格是[风格描述]。
```

**常见错误**：
```
❌ "帮我写一个视频脚本"
✓ "作为YouTube知识类频道的内容策划专家..."
```

#### 1.2 任务描述 (Task)

**原则**：清晰、具体、可执行

**结构化描述**：
```
我需要你帮我完成：[具体任务]
背景：[为什么需要这个]
目标受众：[是谁]
期望输出：[什么形式]
```

**示例**：
```
我需要你帮我完成：为一个关于"如何在多哈找到远程工作"的视频
设计3个不同的开场hook

背景：这个视频是给想要在卡塔尔找远程工作的外籍人士看的，
     他们可能对本地情况不熟悉

目标受众：25-40岁，英语交流，有远程工作技能的外籍人士

期望输出：3个hook，分别适合不同风格（幽默/专业/情感）
```

#### 1.3 约束条件 (Constraints)

**常见约束类型**：

| 类型 | 示例 |
|------|------|
| 长度 | "不超过500字" |
| 格式 | "使用Markdown格式" |
| 风格 | "保持轻松幽默的语气" |
| 禁止 | "不要使用陈词滥调" |
| 必须 | "必须包含至少一个数据点" |

**示例**：
```
约束条件：
- 每个hook不超过50字
- 第一句话必须在3秒内抓住注意力
- 避免使用"大家好"、"今天我们来"等常见开场
- 目标受众是在多哈的外籍人士，需要考虑文化背景
```

#### 1.4 输出格式 (Format)

**指定格式的好处**：减少AI自由发挥的空间，获得更符合预期的输出。

**常见格式指定**：

```
格式要求：
1. 使用表格输出，包含列：Hook内容 | 类型 | 适用场景
2. 每个hook单独成段
3. 关键吸引力词用**加粗**
```

**结构化输出示例**：
```
输出格式：
## 开场Hook方案

### 方案1：[类型]
**Hook**: [文字]
**为什么有效**: [简短解释]
**适用场景**: [何时使用]

### 方案2：[类型]
...
```

#### 1.5 示例 (Examples)

**Few-shot Prompting**：通过示例让AI理解你想要的输出风格。

```
示例：

输入：我想要写一个关于"早起"话题的视频脚本开头
输出：
"你知道吗？每天早上5点起床的那个人，
可能不是比你更努力，而是比你更懂得'欺骗'自己的身体。
这个视频告诉你一个连科学家都在用的起床技巧..."

现在请为[你的话题]写一个类似风格的开头。
```

## 2. 创作者高频Prompt模板库

### 2.1 选题与研究类（20+模板）

#### 模板1：趋势分析
```
作为[领域]的内容策划专家，分析以下话题的当前趋势：

话题：[你的话题]
平台：[YouTube/TikTok/小红书等]
目标地区：[中东/全球等]

请提供：
1. 近3个月的趋势走向（上升/平稳/下降）
2. 热门相关话题
3. 潜在的利基角度
4. 搜索量和竞争程度评估
5. 建议的内容形式

格式：Markdown表格
```

#### 模板2：竞品内容分析
```
分析以下YouTube/TikTok频道最近20个视频的：
1. 平均播放量
2. 常见主题模式
3. 标题和缩略图风格
4. 内容时长分布
5. 观众互动特点

频道：[频道名或链接]

输出：
- 发现的机会点（他们没做但可以做的）
- 应该避免的重复内容
- 可以改进的地方
```

#### 模板3：受众痛点挖掘
```
我是一个专注于[领域]的创作者，目标受众是[描述]。

请帮我挖掘：
1. 这个群体最常见的3个痛点
2. 每个痛点背后的深层原因
3. 他们当前如何解决这些问题
4. 我的内容可以提供什么独特价值

注意：考虑多哈/中东地区的文化背景
```

#### 模板4：话题空白发现
```
在[平台]的[领域]板块，找出：
1. 被大量讨论但没有深度内容覆盖的话题
2. 有搜索需求但优质内容稀缺的领域
3. 新兴话题（近3个月刚出现）
4. 季节性/事件性话题（即将到来）

领域：[具体领域]
平台：[YouTube/TikTok/博客等]
地区：[中东/全球等]

格式：表格，包含话题、搜索需求、竞争程度、机会评分
```

#### 模板5：SEO关键词研究
```
为关于[主题]的内容进行关键词研究：

主题：[你的内容主题]
目标平台：[YouTube/Google/小红书]
目标语言：[中文/英文]

请提供：
1. 主关键词（高搜索量）
2. 长尾关键词（低竞争）
3. 问题型关键词（对话式）
4. 相关LSI关键词
5. 每个关键词的月搜索量估算和竞争程度

格式：表格，包含关键词、月搜索量、竞争度、建议使用位置
```

#### 模板6：内容日历规划
```
为[月份]的[平台]内容制定发布日历：

我的频道定位：[描述]
目标受众：[描述]
发布频率：[每周X个]
主要话题方向：[3-5个]

要求：
- 每周内容有主题关联性
- 包含不同内容类型（教育/娱乐/互动）
- 考虑平台算法偏好（如周二至周四表现更好）
- 留出灵活调整空间

格式：表格，包含日期、主题、类型、简短备注
```

#### 模板7：视频标题生成
```
为这个视频生成10个YouTube标题：

视频主题：[主题]
目标受众：[描述]
核心卖点：[1-2个]

要求：
- 包含数字（如果适用）
- 使用强力词汇（how/what/why/secret）
- 避免点击诱饵
- 每个标题不超过60字符
- 5个用疑问句，5个用陈述句

格式：编号列表
```

#### 模板8：缩略图文案设计
```
为这个视频的YouTube缩略图设计文案：

视频主题：[主题]
目标受众：[多哈外籍人士等]
竞争分析：[简要描述同类视频的缩略图风格]

请提供：
1. 主文案（不超过5个字）
2. 副文案（不超过10个字）
3. 强调词（1-2个字）

设计原则：
- 冲击力强，远处也能看清
- 使用对比色
- 避免文字过多
```

#### 模板9：内容差异化分析
```
分析我的频道与竞争对手的差异化机会：

我的频道：
- 定位：[描述]
- 风格：[描述]
- 特色：[描述]

竞争对手频道：
[列出3-5个主要竞争频道]

请分析：
1. 我的独特优势是什么
2. 竞争对手的薄弱环节
3. 可以采取的差异化策略
4. 内容角度建议

格式：Markdown表格对比
```

#### 模板10：观众问题挖掘
```
从以下来源挖掘目标受众最关心的问题：

来源：
1. YouTube/TikTok评论区（[频道名]）
2. Reddit [相关subreddit]
3. Quora [相关话题]
4. 论坛：[其他来源]

请整理：
1. 出现频率最高的10个问题
2. 每个问题的上下文（谁在问、为什么问）
3. 回答这些问题可以带来的价值
4. 建议的内容形式（长视频/短视频/图文）

格式：表格，包含问题、频率、背景、建议形式
```

### 2.2 内容创作类（30+模板）

#### 模板21：视频脚本开头
```
为一个关于[主题]的[时长]YouTube视频写开头：

视频核心信息：[1-2句话概括]
目标受众：[描述]
风格：[幽默/专业/亲切等]
独特角度：[你的个人见解]

要求：
- 0-10秒：强吸引力开场（hook）
- 10-30秒：价值预告（告诉观众会得到什么）
- 30-45秒：自我介绍（简短，如果是个人频道）
- 使用口语化表达
- 避免："大家好"、"今天我们来"等常见开场

格式：完整脚本，带时间戳
```

#### 模板22：视频脚本主体
```
继续视频脚本的主体部分：

视频主题：[主题]
目标受众：[描述]
核心论点：[3-5个]
时长：[X分钟]

对于每个论点，请提供：
1. 段落开头（承接上文）
2. 核心内容（包含数据/案例/故事）
3. 过渡语（引出下一个论点）

约束：
- 每个段落2-3分钟
- 每5分钟至少一个笑点或情感点
- 关键数据用视觉提示[*数据*]
- 口语化表达

格式：带时间戳的完整脚本
```

#### 模板23：视频脚本结尾
```
为一个关于[主题]的视频写结尾：

视频主要内容：[简要回顾]
核心要点：[3个]
行动号召目标：[订阅/评论/分享/点击链接等]

要求：
- 总结要点（30-45秒）
- 回顾价值（让观众确认学到了）
- CTA（明确但不过度推销）
- 引导评论（问一个问题）
- 关联下一个视频（如果适用）

格式：完整脚本
```

#### 模板24：TikTok脚本
```
为一个关于[主题]的TikTok视频写脚本：

时长：30-60秒
目标：钩子+价值+互动

结构：
- 0-3秒：强hook（必须让人停下滑动）
- 3-15秒：核心信息（一个主要观点）
- 15-25秒：证明/解释（简要说明为什么）
- 25-40秒：附加价值（可选的额外信息）
- 最后5秒：CTA（关注/评论/分享）

风格：[幽默/震撼/感人/实用等]

格式：时间戳+文字稿+画面提示
```

## 3. Prompt优化技巧

### 3.1 Chain-of-Thought（思维链）

**原理**：让AI展示推理过程，提高回答质量。

**应用方法**：
```
❌ 直接问结果
"什么是最好的时间发布YouTube视频？"

✓ 引导推理过程
"请分析YouTube视频发布时间的影响因素，
包括：
1. 受众活跃时间
2. 平台算法特点
3. 竞争环境
4. 时区因素
然后给出建议，并说明推理过程。
最后，针对多哈受众给出具体建议。"
```

### 3.2 Few-shot Learning（少样本学习）

**原理**：通过示例让AI理解你想要的输出模式。

**应用方法**：
```
现在你是一个[风格]的YouTube博主。
请按照以下示例的风格写视频开场：

示例输入：关于早起
示例输出：
"你们知道吗？每天叫醒我的不是闹钟，
而是对今天要做的事情的期待。
但问题是，大多数人早上醒来，
第一个念头是'不想上班'。
如果你也是这样，这个视频会改变你的早晨。"

现在请为[你的话题]写一个类似风格的开场。
```

### 3.3 自我批判与迭代

**方法**：让AI先生成，再让AI批评，再让AI改进。

```
第一步：请为[主题]写一个视频脚本。

第二步：请审查你刚才写的脚本，
找出3个最大的问题，并解释为什么。

第三步：请基于你的批评，
重新写一个改进版本的脚本。
```

### 3.4 角色扮演深度化

**基础版**：
```
你是一个有10年经验的内容策划专家。
```

**深度版**：
```
你是一个有10年经验的内容策划专家，
专注于[你的领域]的YouTube创作者。
你帮助过100+创作者从0到100万订阅，
特别擅长帮助个人创作者找到独特定位。
你风格直接，说话有洞察力，
经常用反直觉的观点让人印象深刻。
你讨厌泛泛而谈，只给可执行的建议。
```

## 4. 常见错误与修正

### 错误1：Prompt过于模糊

```
❌ "帮我写一个视频脚本"

✓ "为一个关于'如何在多哈找远程工作'的YouTube视频
写一个3-5分钟的开场hook。
目标受众是想要在卡塔尔工作的外籍人士。
风格要专业但亲切，避免过于说教。
第一句话要有冲击力，能让人停下来。
不超过50字。"
```

### 错误2：缺少上下文

```
❌ "这篇文章怎么样？"

✓ "请审核以下文章的内容质量：

文章主题：[主题]
目标受众：[描述]
预期目的：[教育/娱乐/销售]

[粘贴文章]

请从准确性、逻辑性、可读性、吸引力
四个维度打分，并给出改进建议。"
```

### 错误3：约束条件冲突

```
❌ "写一个100字以内的开场，
包含所有重要信息，
有详细的数据支撑，
风格幽默且专业，
适合所有年龄段观众"

→ 过于矛盾，几乎不可能实现

✓ "写一个100字以内的开场hook。
只包含一个核心卖点。
风格选择：幽默还是专业？（选择其一）
目标受众：25-40岁外籍人士"
```

### 错误4：期望一次性完美

```
❌ "一次性生成完美的视频脚本"

✓ 分步骤：
1. "先帮我设计视频的整体结构"
2. "现在帮我写每个部分的详细内容"
3. "帮我优化开场的hook"
4. "最后检查整个脚本的可读性"
```

### 5.1 Claude vs GPT风格差异

| 维度 | Claude | GPT-4 |
|------|--------|-------|
| 理解复杂度 | 更擅长复杂指令 | 擅长清晰指令 |
| 创意风格 | 更内敛、深刻 | 更直接、行动导向 |
| 角色扮演 | 更稳定 | 可能"出戏" |
| 长度控制 | 更精准 | 有时过于冗长 |
| 中文能力 | 良好 | 中等 |

你是一位深度的内容策略分析师。
你的特点是：

2. 经常质疑默认假设
3. 给出有洞察力的观点
4. 愿意指出问题而非一味迎合

请分析：[复杂问题]

- 每个不超过60字符

## 7. 从模板到自定义的进化

### 进化路径

```
阶段1：使用现成模板
↓
阶段2：修改模板适配自己需求
↓
阶段3：组合多个模板
↓
阶段4：创造专属模板
↓
阶段5：动态生成Prompt
```

### 自定义Prompt的开发流程

```
1. 明确需求
   - 我需要AI完成什么？
   - 当前有什么痛点？

2. 收集素材
   - 收集好的输出示例
   - 记录失败案例

3. 迭代开发
   - 从基础模板开始
   - 逐步添加约束
   - 测试不同变体

4. 固化归档
   - 确定最终版本
   - 记录适用场景
   - 持续优化
```

### 动态Prompt示例

```
# 基础模板
"为一个关于[主题]的YouTube视频写开场hook。"

# 加入变量
"为一个关于{{topic}}的{{platform}}内容写{{hook_type}}hook。
目标受众：{{audience_description}}
风格：{{tone}}
时长限制：{{max_duration}}
额外要求：{{additional_requirements}}"

# 配合配置表使用
```
