## 1. 核心理念：AI是搭档，不是替代者

### 核心原则

```
AI负责：80%的重复性、基础性工作
人类负责：20%的灵魂性、创意性、判断性工作
```

### 为什么不是替代？

| 维度 | AI优势 | 人类优势 |
|------|--------|----------|
| 效率 | 24/7不知疲倦 | 能感知情感细微差别 |
| 质量一致性 | 输出稳定 | 突破性创新 |
| 成本 | 边际成本趋零 | 真实生活经验 |
| 风险 | 可能产生幻觉 | 独立判断与责任 |

### 适合AI辅助的场景

- ✅ 大纲初稿生成
- ✅ 语法和拼写检查
- ✅ 多语言翻译初稿
- ✅ SEO关键词研究
- ✅ 数据整理与格式化
- ✅ 重复性格式转换

- ❌ 人生经历的真实性讲述
- ❌ 独家视角与判断
- ❌ 深度关系建立
- ❌ 最终价值判断
- ❌ 法律责任承担

## 2. AI内容生产的伦理底线

### 三大原则

#### 透明原则
- 在内容中适当披露AI使用情况
- 了解并遵守各平台AI标注要求
- 参考：[创作者AI创作伦理与合规指南](./05_创作者AI创作伦理与合规指南.md)

#### 真实原则
- 核实AI生成的事实性信息
- 不使用AI编造数据、引用、证言
- 对AI提供的信息保持合理怀疑

#### 质量原则
- AI输出必须经过人工审核
- 不发布"AI味"明显的低质量内容
- 保持内容的个人风格和独特价值

### 伦理决策树

```
遇到伦理困惑时问自己：

1. 这个内容会让观众误解事实吗？
   → 是：立即修改或删除
   → 否：继续

2. 我愿意对这个内容承担全部责任吗？
   → 否：重新考虑发布
   → 是：继续

3. 如果观众知道AI参与了我的创作，他们会感到被骗吗？
   → 是：需要增加透明度
   → 否：可以发布
```

## 3. 文字内容AI流水线

### 完整流水线概览

```
选题 → 大纲 → 初稿 → 编辑 → SEO → 多语言
  ↓       ↓       ↓       ↓       ↓       ↓
AI辅助  AI辅助  AI起草  AI辅助  AI辅助  AI翻译
人工审  人工调  人工重写 人工终审 人工验证 人工本地化
```

### 3.1 选题阶段

#### AI辅助方式

**趋势分析**
```
Prompt示例：
"分析[你的领域]在过去3个月的热门话题，
找出3个有潜力但尚未饱和的话题方向，
每个方向给出：
- 话题名称
- 为什么现在值得做
- 目标受众
- 简单的内容角度建议"
```

**需求验证**
```
Prompt示例：
"我考虑做[话题]的内容，
从SEO和社交媒体互动角度分析：
1. 这个话题的真实搜索量趋势
2. 竞争激烈程度
3. 受众的真实痛点
4. 我可以用什么独特角度切入"
```

#### 人工审核点
- ✅ AI是否理解了文化背景差异
- ✅ 话题是否符合个人定位
- ✅ 是否有足够的独特素材支撑

### 3.2 大纲阶段

#### AI辅助方式

**结构生成**
```
Prompt示例：
"为一篇关于[主题]的[平台]内容创建大纲：
- 目标受众：[描述]
- 目标长度：[字数/时长]
- 风格：[正式/轻松/专业等]
- 包含：开头hook、3-5个主要论点、结尾CTA

每个部分标注：
- 建议的具体内容方向
- 是否需要数据/案例支撑
- 预期的情感曲线"
```

#### 人工调整要点
- 调整逻辑流程，使其更符合个人叙事风格
- 增加/删除/合并某些部分
- 标记需要真实个人故事或案例的位置

### 3.3 初稿阶段

#### AI辅助方式

**分块起草法**（推荐）

不要让AI一次性生成整篇文章，而是分段生成：

```
阶段1：开头Hook生成
阶段2：每个主要论点段落单独生成
阶段3：过渡语生成
阶段4：结尾CTA生成
```

**示例Prompt（开头Hook）**：
```
为关于[主题]的文章写5个不同风格的开头Hook：
1. 惊人事实型
2. 场景代入型
3. 提问引发思考型
4. 故事引入型
5. 直接价值承诺型

每个Hook不超过3句话，
确保第一句就有强吸引力，
因为我需要在视频/文章开头抓住注意力。"
```

**关键段落人工重写**：

对于核心内容部分，AI生成后必须：
1. 用自己的语言和经历重写至少30%
2. 加入个人独到见解
3. 调整节奏和语气以匹配个人风格

### 3.4 编辑阶段

#### AI辅助方式

**语法和风格检查**

使用AI进行第一轮检查，但需要明确指令：

```
Prompt示例：
"请检查以下内容的语法、拼写、标点错误。
同时检查：
- 句子是否过于复杂难读
- 是否有重复表达
- 段落过渡是否流畅

不要修改我的个人风格和创意表达，
只标记需要修改的位置并说明原因。
最后给出修改建议，但最终决定权在我。"
```

**人工终审清单**

- [ ] 核心信息是否准确
- [ ] 个人声音是否保留
- [ ] 逻辑是否清晰
- [ ] 情感曲线是否满意
- [ ] 是否有任何AI幻觉

### 3.5 SEO阶段

#### AI辅助方式

**关键词研究**
```
Prompt示例：
"针对[你的内容主题]和[目标受众]，
提供：
1. 主关键词（高搜索量）
2. 长尾关键词（低竞争）
3. 问题型关键词（对话式搜索）
4. LSI关键词（同义词/相关词）

每个关键词给出：
- 月搜索量估算
- 竞争程度
- 建议的使用位置（标题/开头/小标题/结尾）"
```

**元描述生成**
```
Prompt示例：
"为一篇关于[主题]的文章生成3个元描述：
- 每个50-160字符
- 包含主关键词
- 有行动号召
- 每个风格不同（疑问型/价值承诺型/数字型）"
```

#### 人工验证点
- 关键词是否符合真实搜索意图
- 标题是否足够吸引点击
- 元描述是否准确反映内容

### 3.6 多语言阶段

#### AI辅助方式

**翻译初稿**
```
Prompt示例：
"将以下中文内容翻译成[目标语言]：

[粘贴内容]

要求：
- 保持原文的语气和风格
- 文化本地化（不是逐字翻译）
- 适合[目标平台]的风格
- 保留专业术语但提供解释"
```

#### 人工本地化校对

多语言内容必须经过人工校对：
- 语法和自然度检查
- 文化敏感性检查
- 平台特定格式调整
- 本地化表达替换

## 4. 视频内容AI流水线

### 完整流水线概览

```
脚本 → 分镜 → 录制/素材 → 剪辑 → 字幕 → 缩略图
  ↓       ↓       ↓         ↓      ↓       ↓
AI起草 AI建议 AI辅助   AI标记   AI生成 AI生成
人工改 AI调整 人工决策 人工剪辑 人工校 人工选
```

### 4.1 脚本阶段

#### AI辅助方式

**脚本起草**
```
Prompt示例：
"为一个[时长]的视频创建脚本：

主题：[具体主题]
目标受众：[描述]
风格：[幽默/专业/亲切等]
目的：[教育/娱乐/销售等]

提供：
1. 完整的脚本（口语化表达）
2. 每个部分的建议时长
3. B-roll建议（画面提示）
4. 关键转场词
5. 结尾互动问题建议"
```

### 4.2 分镜阶段

#### AI辅助方式

**分镜建议**
```
Prompt示例：
"为一个关于[主题]的[时长]视频创建分镜表：

包含：
- 镜头编号
- 镜头类型（特写/中景/全景等）
- 画面描述
- 建议时长
- 文案/台词
- B-roll建议
- 转场效果

格式用表格，方便打印参考"
```

### 4.3 字幕阶段

#### AI辅助方式

**自动字幕生成**

推荐工具（2026年）：
- **剪映**：免费，中文识别准确率高
- **CapCut**：多语言支持优秀
- **Descript**：可同时编辑文字和字幕

**AI字幕校对Prompt**：
```
Prompt示例：
"这是一段视频字幕，帮我：
1. 修正明显的识别错误
2. 调整时间轴使其与语速匹配
3. 添加必要的标点符号
4. 保留口语化表达的自然停顿
5. 标注需要强调的词（用*号）

原始字幕：
[粘贴字幕]"
```

#### 人工校对要点
- [ ] 人名、地名、专业术语准确性
- [ ] 是否符合口语习惯
- [ ] 关键词是否被正确识别
- [ ] 敏感词是否被错误识别

### 4.4 缩略图阶段

#### AI辅助方式

**缩略图生成候选**
```
工具推荐（2026年）：
- Leonardo.AI：高质量插画风格
- Midjourney：艺术感强
- DALL-E：快速生成
- Ideogram：文字渲染优秀

生成策略：
一次生成3-5个不同风格/构图的选项，
从中选择最合适的进行微调。
```

#### 人工选择标准
- [ ] 是否清晰传达视频主题
- [ ] 是否在缩略图中突出（文字/人脸/动作）
- [ ] 色彩是否足够醒目
- [ ] 是否符合个人/频道风格
- [ ] 平台尺寸适配性

### 4.5 剪辑辅助阶段

## 6. 质量控制检查点

### 每种内容类型的检查清单

#### 文字内容检查清单

- [ ] **准确性**：所有事实、数据、引用经过核实
- [ ] **原创性**：核心观点和故事属于自己
- [ ] **价值**：读者能从中获得明确价值
- [ ] **可读性**：句子长度合适，逻辑清晰
- [ ] **个人声音**：不像是AI写的
- [ ] **SEO**：关键词自然融入
- [ ] **格式**：标题、列表、段落结构合理

#### 视频内容检查清单

- [ ] **准确性**：视频中所有信息经过核实
- [ ] **节奏**：开头是否在3秒内抓住注意力
- [ ] **价值**：前30秒是否给出了继续观看的理由
- [ ] **字幕**：无明显错误
- [ ] **缩略图**：准确反映内容
- [ ] **合规**：AI使用已适当标注（如需要）
- [ ] **版权**：所有素材使用合规

#### 播客内容检查清单

- [ ] **音频质量**：降噪处理后是否清晰
- [ ] **节奏**：是否有过长或过短的部分
- [ ] **结构**：章节标记是否合理
- [ ] **摘要**：是否准确概括核心内容
- [ ] **可发现性**：标题和描述是否SEO友好

## 7. 避免"AI味"的策略

### AI味的典型特征

- 过度使用"首先、其次、最后"
- 陈词滥调的开头
- 过于完美/正式的语气
- 缺乏真实的犹豫和不确定
- 缺少个人细节和故事
- 过于整齐的逻辑结构

### 去AI味技巧

#### 1. 增加口语化表达

```diff
- "人工智能技术在当今社会发挥着重要作用。"
+ "说到AI，可能你会觉得这是个大话题，
+ 但今天咱们聊点实际的——"
```

#### 2. 保留适度的"不完美"

- 允许适度的口头禅（如果是你个人风格的一部分）
- 不要删除所有语气词
- 可以保留自然的思考停顿

#### 3. 注入个人元素

```diff
- "研究表明，学习新技能的最佳方法是..."
+ "我试过很多方法学新东西，
+ 后来发现[具体经历]才是真正有效的..."
```

#### 4. 打破AI的逻辑结构

- 故意跳步或类比
- 加入"顺便说一句"类的发散
- 使用反问句而非标准陈述

#### 5. 独特开场和结尾

```diff
# AI风格结尾
- "总之，本文讨论了...希望对你有帮助。"

# 个人风格结尾
- "行了，今天就聊到这儿。
- 有什么问题评论区见，
- 记得点个赞，咱们下期见！"
```

### 检测AI味的简单方法

1. **朗读测试**：大声朗读出来，是否像真人说话？
2. **朋友测试**：让朋友读一遍，是否能感受到"人"的存在？
3. **对比测试**：放在一堆真实人类写的内容中，是否明显突兀？
