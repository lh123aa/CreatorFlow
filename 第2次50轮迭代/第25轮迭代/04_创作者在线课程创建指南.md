## 1. 为什么创作者应该做课程

### 课程是最高杠杆的变现方式

**时间杠杆**：
```
1对1咨询：1小时 → 1份收入 → $100-500
写文章：10小时 → 多份收入 → $100-500
录课程：100小时 → N份收入 → $10000+

课程边际成本接近零
```

**收入潜力**：

| 变现方式 | 单价 | 边际成本 | 收入天花板 |
|---------|------|---------|-----------|
| 咨询服务 | $100/时 | $0 | $5000/月 |
| 文章创作 | $100/篇 | $0 | $3000/月 |
| 联盟营销 | $10/单 | $0 | $3000/月 |
| 在线课程 | $97/份 | $0 | $50000+/月 |

## 2. 课程类型选择

### 2.1 录播课程（自定进度）

**特点**：
- 预先录制，随到随学
- 学员自定学习节奏
- 可永久访问

**适合场景**：
- 技能教学
- 知识传授
- 工具使用
- 系统学习

**录制方式**：
- 屏幕录制（演示操作）
- 相机录制（真人出镜）
- 混合录制（画中画）

**课程结构**：
```
模块1：入门
├── 课时1.1：课程介绍
├── 课时1.2：基础概念
└── 课时1.3：准备工作

模块2：基础
├── 课时2.1：功能1
├── 课时2.2：功能2
└── 课时2.3：实战练习

模块3：进阶
├── 课时3.1：高级技巧
├── 课时3.2：案例分析
└── 课时3.3：项目实战
```

---

### 2.2 直播课程（群课/训练营）

**群课特点**：
- 固定时间上课
- 实时互动
- 学员共同学习

**训练营特点**：
- 封闭周期（7-30天）
- 高强度学习
- 社群+直播
- 作业+反馈

**适合场景**：
- 需要督学的学习
- 高互动内容
- 变现训练营
- 技能养成

**直播工具**：
- Zoom/Webinar
- Google Meet
- 飞书直播
- B站直播

---

### 2.3 微课程（Mini Course）

**特点**：
- 短小精悍（30-90分钟）
- 单点突破
- 低价或免费

**结构**：
```
微课程：《XXX三步入门》

课时1：第一步 - 10分钟
课时2：第二步 - 15分钟
课时3：第三步 - 15分钟
Bonus：快速检查清单

总时长：约40分钟
```

**定位**：
- 课程引流前端
- 建立信任
- 测试市场需求
- 升级转化

---

### 2.4 会员制持续课程

**特点**：
- 持续更新
- 会员免费/折扣
- 长期订阅

**结构**：
```
会员课程库：
├── 基础课（免费会员）
├── 进阶课（$15/月会员）
├── 高级课（$30/月会员）
└── 每月更新模块
```

**适合场景**：
- 持续学习需求
- 快速变化的领域
- 建立长期关系

---

## 4. 课程设计SOP

### Step 1：选题验证

**验证方法**：

```
方法1：问卷调查
├── 目标受众调研
├── 痛点确认
└── 付费意愿测试

方法2：竞品分析
├── 现有课程研究
├── 评分/评论分析
└── 差异化机会

方法3：内容测试
├── 免费内容发布
├── 流量/互动分析
└── 邮件列表意愿
```

**验证问题**：

| 问题 | 目的 |
|------|------|
| 你现在遇到的最大问题是什么？ | 确认痛点 |
| 你尝试过什么解决方法？ | 了解现有方案 |
| 你愿意为解决方案付多少钱？ | 定价参考 |
| 你希望多久学完？ | 课程长度 |
| 你现在在哪里？ | 起点确认 |

---

### Step 2：课程大纲设计

**大纲模板**：

```
课程名称：《XXX从入门到精通》

学员画像：
- 目标用户：
- 当前水平：
- 学习目标：

课程承诺：
学完这门课，你将能够___

模块1：基础（第1-2周）
学习目标：
课时：
- 1.1 介绍
- 1.2 核心概念
- 1.3 基础操作

模块2：进阶（第3-4周）
学习目标：
课时：
- 2.1 功能详解
- 2.2 实战应用
- 2.3 常见问题

模块3：精通（第5-6周）
学习目标：
课时：
- 3.1 高级技巧
- 3.2 案例分析
- 3.3 项目实战

Bonus内容：
- 资源包
- 清单模板
- 进阶学习路径
```

**模块设计原则**：
- 逻辑递进
- 每模块有明确目标
- 课时长度适中（5-20分钟）
- 有练习/作业

---

### Step 3：内容录制

**录制准备**：

```
设备清单：
├── 相机：手机/相机
├── 麦克风：领夹麦/USB麦（必买）
├── 灯光：环形灯/补光灯
├── 软件：OBS/Loom/Camtasia
└── 环境：安静/整洁背景

内容准备：
├── 讲稿/大纲
├── 演示素材
├── 屏幕录制内容
└── 视觉辅助
```

**录制设置**：

```
视频设置：
├── 分辨率：1080p
├── 帧率：30fps
├── 格式：MP4（H.264）
└── 布局：画中画/全屏

音频设置：
├── 采样率：48kHz
├── 格式：AAC
├── 音量：-3dB峰值
└── 降噪：启用
```

**录制技巧**：
- 提前练习讲稿
- 控制语速
- 停顿要自然
- 重复NG可重录
- 保持热情

## 6. 定价策略

### 定价心理学

| 价格点 | 心理锚定 | 适用场景 |
|--------|---------|---------|
| $27 | 低价入门 | 测试/引流 |
| $47 | 合理价值 | 基础课程 |
| $97 | 主流定价 | 核心课程 |
| $197 | 中高端 | 进阶课程 |
| $297-497 | 高端 | 深度课程/训练营 |
| $997+ | 企业级 | 系统课程/私教 |

---

### 定价因素

**影响定价的要素**：

| 要素 | 高价因素 | 低价因素 |
|------|---------|---------|
| 内容深度 | 系统完整 | 入门基础 |
| 学员价值 | 高ROI承诺 | 兴趣爱好 |
| 额外价值 | 社群/咨询/工具 | 纯内容 |
| 讲师权威 | 专家认证 | 新人 |
| 市场对比 | 独特稀缺 | 同质竞争 |

### 定价策略

#### 策略1：锚定定价

```
原课程：$297
锚定版：$497（添加1对1咨询）
结果：$297显得便宜
```
