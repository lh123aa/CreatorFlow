### 每一步详解

**Step 1：选题**

```
选题判断标准：

✓ 市场需求
- 有多少人需要这个？
- 他们的痛点是什么？
- 现有解决方案有哪些问题？

✓ 你能解决
- 这是你的专业领域吗？
- 你有独特视角或经验吗？
- 你能比现有方案更好吗？

✓ 商业价值
- 目标用户付费意愿如何？
- 定价空间有多大？
- 能否规模化销售？

选题来源：
- 社群/邮件中的高频问题
- 评论区反复出现的疑问
- 自己的亲身经历和教训
- 行业趋势和新机会
```

**Step 2：大纲**

```
大纲设计原则：

金字塔结构：
- 1个核心问题
- 3-5个主要模块
- 每个模块2-5个要点
- 每个要点1-2个案例/练习

用户视角：
- 从简单到复杂
- 从基础到进阶
- 符合学习规律
- 考虑用户时间

内容分配：
- 理论讲解：30%
- 案例分析：30%
- 实践练习：30%
- 总结回顾：10%
```

**Step 3：制作**

```
制作原则：

✓ 先完成，再完美
✓ 按照大纲逐步推进
✓ 每完成一个模块就保存
✓ 定期备份

制作节奏：
- 设定每日目标（如：完成1个模块）
- 避免长时间连续制作
- 穿插休息和运动
- 保持创作状态
```

**Step 4-7：定价、包装、测试、上线**

详见后续章节。

## 电子书制作SOP

### 为什么创作者应该出电子书

```
电子书优势：
- 制作门槛低（单人可完成）
- 边际成本几乎为零
- 可作为引流产品或变现产品
- 建立专业形象
- 积累长期资产
```

### 电子书制作工具（免费）

```
【文字处理】
├── Google Docs - 免费在线文档
├── Notion - 可直接导出PDF
└── Markdown + Pandoc - 极客方案

【排版设计】
├── Canva - 模板丰富，可导出PDF
├── Adobe InDesign - 专业排版（有免费试用）
└── Kindle Create - 亚马逊官方工具

【封面设计】
├── Canva - 免费模板
├── Fiverr - 找设计师（约$5-20）
└── Placeit - 快速生成封面
```

### 电子书制作流程

```
【阶段1：规划（1-2天）】

□ 确定电子书主题
□ 确定目标读者
□ 设定字数目标（5000-20000字）
□ 列出章节目录
□ 设定写作计划


【阶段2：写作（5-14天）】

□ 按照大纲逐章写作
□ 每天完成固定字数
□ 写完一章就保存
□ 不要追求完美，先完成


【阶段3：编辑（2-3天）】

□ 通读全文，检查逻辑
□ 修正语法和错别字
□ 优化表达和段落
□ 请他人帮忙校对（如有）


【阶段4：排版（1-2天）】

□ 选择排版模板
□ 设置字体和字号
□ 添加章节标题和分隔
□ 设计封面
□ 导出为PDF


【阶段5：发布（1天）】

□ 上传到Gumroad/亚马逊
□ 设置价格
□ 编写销售文案
□ 创建分享素材
```

**制作流程**：

```
【阶段1：准备（3-5天）】

□ 完善课程大纲

□ 每次录制1-3节课
□ 录完立即保存

□ 休息时做简短总结


【阶段3：后期（3-5天）】

□ 剪辑视频（删除停顿、错误）
□ 添加字幕

【阶段4：包装（2-3天）】

□ 录制销售视频（可选）
□ 设置价格


【阶段5：上线（1-2天）】

□ 上传到平台
□ 测试购买流程
□ 创建社群
□ 通知受众
```

```
标准课程结构：

┌─────────────────────────────────────────────────────────┐
│                    课程整体结构                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   【介绍】                                              │
│   欢迎视频 + 课程概览 + 学习指南                         │
│   ↓                                                    │
│   【模块1】                                             │
│   3-5节内容 + 练习/测验                                 │
│   ↓                                                    │
│   【模块2】                                             │
│   3-5节内容 + 练习/测验                                 │
│   ↓                                                    │
│   【模块3-5】（根据课程长度）                           │
│   ...                                                  │
│   ↓                                                    │

│   核心要点回顾 + 下一步行动 + 祝福                       │
│                                                         │

```

### 单节课结构

```
标准单节课（5-15分钟）：

1. 开头（30秒）
   - 本节课内容预告
   - 与上节课的连接
   - "今天我们将学习..."

2. 核心内容（5-12分钟）
   - 知识点讲解
   - 案例/例子
   - 实操演示（如有）

3. 总结（30秒）
   - 本节要点回顾
   - 下节课预告

4. 练习（可选）
   - 课后作业
   - 思考问题
```

## 产品定价策略与测试方法

### 定价心理学原理

```
【锚定效应】
先展示高价格，再展示优惠价
"原价$199，现在只要$99"

【尾数定价】
使用9结尾的价格
$19.99 > $20

【价值定价】
按解决的问题价值定价，而非成本
"帮用户每月多赚$1000，收费$99很便宜"
```

### 定价策略

```
【渗透定价】
- 低价进入市场（$9-29）
- 适合：第一款产品、新领域
- 优点：快速获得用户、建立口碑
- 风险：可能拉低品牌定位

【价值定价】
- 按解决方案的价值定价
- 适合：有明确ROI的产品
- 优点：更高的利润率
- 风险：需要强大的销售文案

【阶梯定价】
- 多个版本，不同价格
- 适合：有不同需求的用户
- 优点：覆盖更多用户
- 风险：版本设计复杂

【捆绑定价】
- 多个产品打包销售
- 适合：有系列产品
- 优点：提升客单价
- 风险：单个产品价值感知降低
```

### 价格测试方法

```
【A/B测试】

创建两个版本：
- 版本A：价格X
- 版本B：价格Y

测试方法：
1. 同时推广两个版本
2. 随机展示给用户
3. 统计转化率和总收入
4. 选择收益更高的

【分阶段提价】

测试步骤：
1. 当前价格销售2周
2. 提价20%，再销售2周
3. 比较总收入
4. 选择最优价格

【参考竞争对手】

调研同领域产品价格：
- 低价产品：$9-49
- 中价产品：$49-199
- 高价产品：$199+
```

```
【发布策略：软启动】

```

- 建立口碑
- 为下次销售做准备
