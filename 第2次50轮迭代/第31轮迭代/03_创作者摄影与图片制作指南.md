## 二、手机摄影进阶

### 2.1 光线运用

**自然光分类**：
| 时间段 | 光质 | 特点 | 适合场景 |
|--------|------|------|----------|
| 日出/日落 | 黄金时刻 | 暖色调，柔和，低角度 | 人像，风景 |
| 上午/下午 | 正常光 | 中性色调，稳定 | 大部分场景 |
| 正午 | 顶光 | 强光，硬阴影 | 需要特殊效果 |
| 阴天 | 散射光 | 柔和均匀 | 人像，细节 |
| 室内窗边 | 漫反射 | 自然柔和 | 产品，人像 |

**多哈光线下拍摄建议**：
```
多哈特点：
- 日照强烈，阴影明显
- 天空常蓝，但有时沙尘
- 室内依赖人工光

最佳拍摄时间：
- 冬季：上午9-11点，下午3-5点
- 夏季：清晨或傍晚（避免高温）

室内拍摄：
- 靠近窗户，利用自然光
- 避免正午强光直射
- 使用白色反光板补光
```

**人造光运用**：
```
补光灯使用：
- 45度角主光
- 对面补光消除阴影
- 背光轮廓光（可选）

色温选择：
- 暖光（3200K）：舒适氛围
- 中性光（4000K）：自然
- 白光（5600K）：专业标准

推荐：支持调节色温的LED补光灯
```

### 2.2 构图进阶

**构图法则详解**：

**1. 三分法则（最常用）**
```
核心：将画面横竖各分三等份
      ┌─────┬─────┬─────┐
      │     │     │     │
      │  A  │  B  │  C  │
      │     │     │     │
      ├─────┼─────┼─────┤
      │     │     │     │
      │  D  │  E  │  F  │
      │     │     │     │
      ├─────┼─────┼─────┤
      │     │     │     │
      │  G  │  H  │  I  │
      │     │     │     │
      └─────┴─────┴─────┘

技巧：
- 主体放在A/B/C/D/E/F/G/H/I交叉点
- 人物眼睛放在上1/3线
- 地平线放在上1/3或下1/3

手机设置：开启网格线辅助
```

**2. 引导线构图**
```
原理：利用线条引导视线到主体

常见引导线：
- 道路/铁轨
- 建筑线条
- 河流/海岸
- 楼梯/栏杆

技巧：
- 线条从画面边缘开始
- 指向主体或消失点
- 增强纵深感
```

**3. 框架构图**
```
原理：用前景元素形成框架

常见框架：
- 门框/窗户
- 树枝/拱门
- 镜子反射
- 手掌围成框

效果：
- 聚焦视线
- 增加层次
- 创造"偷窥"感
```

**4. 对称与平衡**
```
对称：
- 上下对称（水面倒影）
- 左右对称（建筑）
- 中心对称

平衡：
- 重量感平衡
- 色彩平衡
- 明暗平衡
```

**5. 留白构图**
```
原理：画面留出空白空间

作用：
- 突出主体
- 表达情绪
- 便于添加文字

建议：留白占画面30-50%
```

### 2.4 人像拍摄（自拍/半身/全身）

**自拍技巧**：
```
基础设置：
- 手机固定（使用三脚架或支架）
- 开启倒计时或蓝牙遥控
- 关闭美颜或调低美颜级别
- 开启网格线辅助

角度技巧：
- 微微俯视（显瘦）
- 侧脸45度（立体）
- 头发遮脸（显小）
- 避免俯拍（显胖）

光线技巧：
- 顺光：面部清晰
- 侧光：轮廓分明
- 逆光：发丝光/剪影
```

**半身照技巧**：
```
构图比例：
- 头顶留白：10-15%
- 腰部以下：10-15%
- 最佳比例：头部占画面1/3

手臂位置：
- 避免贴紧身体
- 自然垂放或轻触他物
- 交叉手时放松

眼神方向：
- 留出视线方向空间
- 看镜头或看远方
- 避免死盯某处
```

**全身照技巧**：
```
站立姿势：
- 重心放在一只脚
- 另一只脚稍向前或向后
- 膝盖微曲避免僵直

手臂位置：
- 一只手插腰
- 扶住包/帽子
- 自然垂放但微曲

与背景关系：
- 站在显眼位置
- 避免切割地平线
- 利用引导线
```

### 2.5 场景拍摄（旅行/美食/办公）

**旅行拍摄**：
```
多哈特色场景：
- 伊斯兰艺术博物馆
- 瓦齐夫市场
- 天际线景观
- 沙漠日出日落
- 滨海大道

拍摄技巧：
- 早起避开人群
- 利用倒影和对称
- 捕捉当地生活
- 注意文化禁忌

安全注意：
- 部分区域需许可
- 尊重当地习俗
- 避免拍摄当地人
```

**美食拍摄**：
```
基础设置：
- 自然光优先（窗边）
- 45度角或俯视
- 简洁背景
- 适当布景

美食角度：
- 45度角：最常用，展示立体
- 俯视：平面食物（披萨/沙拉）
- 侧视：层次丰富食物（汉堡/蛋糕）

增色技巧：
- 喷水增加新鲜感
- 用手抓取动作
- 添加餐具/配料
- 虚化背景
```

**办公/桌面拍摄**：
```
桌面布局：
- 整洁但有生活感
- 主角突出
- 道具辅助（咖啡/植物）

拍摄角度：
- 俯视（桌面全景）
- 45度角（桌面一角）
- 特写（单品展示）

布景技巧：
- 背景布/纸
- 装饰物点缀
- 光影效果
```

局部调整：
- 画笔工具（亮度/饱和/温度）
- 局部调整（点选区域）
```

**修图流程**：
```
步骤1：基础调整
- 亮度：+10至+20
- 对比度：+10至+20
- 氛围：+10至+20
- 高光：-10至-20（恢复细节）
- 阴影：+10（提亮暗部）

步骤2：细节增强
- 锐化：+20至+30
- 结构：+10至+20

步骤3：色调调整
- 暖色调：适合食物/暖色场景
- 冷色调：适合科技/天空
- 根据内容微调

步骤4：导出
- 导出为JPEG（最高质量）
- 可选：保存样式以便复用
```

**Snapseed双重曝光教程**：
```
效果：两张照片叠加
应用：
- 创意合成

- 艺术效果

步骤：
1. 打开第一张图片

```

- 追求最佳：WebP
```

## 八、版权合规

### 8.1 常见版权问题

**危险行为**：
```
❌ 直接使用Google图片
❌ 下载他人社交媒体照片
❌ 使用品牌Logo/商标
❌ 截图未标注来源
❌ 使用有版权的字体
❌ AI生成图片声称原创（部分有限制）
```

**安全做法**：
```
✅ 使用免费图库（注明来源更好）
✅ 使用自己拍摄的照片
✅ 使用CC0许可素材
✅ 使用已购买版权的素材
✅ 使用AI生成图片（确认平台许可）
✅ 使用原创字体/开源字体
```

### 8.2 许可证类型

| 许可证 | 商用 | 署名 | 修改 | 分发 |
|--------|------|------|------|------|
| **CC0** | ✅ | ❌ | ✅ | ✅ |
| **CC-BY** | ✅ | ✅ | ✅ | ✅ |
| **CC-BY-SA** | ✅ | ✅ | ✅ | ✅（相同许可） |
| **CC-BY-NC** | ❌ | ✅ | ✅ | ✅ |
| **All Rights Reserved** | ❌ | ❌ | ❌ | ❌ |

### 8.3 版权合规检查清单

**使用素材前**：
- [ ] 确认素材来源
- [ ] 查看许可证类型
- [ ] 确认使用场景允许
- [ ] 记录来源信息

**使用素材后**：
- [ ] 保留来源截图
- [ ] 按要求署名（如需要）
- [ ] 避免修改原始作品
- [ ] 商业用途需特别确认

**AI生成图片**：
- [ ] 确认平台服务条款
- [ ] 了解商业使用限制
- [ ] 避免生成仿制作品
- [ ] 标注AI生成（更规范）
