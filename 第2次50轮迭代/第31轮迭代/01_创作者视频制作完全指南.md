## 三、录制环境搭建

### 3.1 家庭工作室最小配置

**空间要求**：
- 最小2m×2m可用空间
- 背景整洁，避免杂乱
- 最好有自然窗户（非必须）

**环境布置原则**：
```
1. 背景：纯色墙面/书架/绿幕（三选一）
2. 光线：主光45度角照射，补光消除阴影
3. 声音：远离窗户/空调/路由器
4. 整洁：只保留拍摄相关的物品
```

### 3.2 多哈室内录制方案

**夏季（5月-10月）**：
- 空调房录制，注意：
  - 麦克风远离空调出风口
  - 录制前确认空调噪音不影响录音
  - 准备毛巾（出汗时擦拭）

**斋月期间**：
- 注意作息时间调整
- 避免在祈祷时间录制（大约日落后30分钟）
- 尊重当地文化，内容合规

### 3.3 背景方案推荐

**方案A：书架背景**（推荐，成本$0）
- 利用现有书架
- 摆放书籍+小物件
- 体现专业感和个性

**方案B：纯色墙面**（成本$20）
- 浅灰色/浅蓝色最佳
- 白色背景需要适当补光
- 用背景布或墙纸

**方案C：绿幕背景**（成本$30）
- 可随意更换虚拟背景
- 适合知识类创作者
- CapCut/OBS支持自动抠像

## 四、视频录制SOP

### 4.1 单人出镜录制技巧

**机位设置**：
```
1. 相机高度：与眼睛平齐或略低（3-5度俯角显瘦）
2. 距离：半身照时，头部占画面1/3
3. 构图：人物偏左或偏右，留出视线方向空间
4. 眼神：看镜头或看提示词，避免眼神飘移
```

**镜头前表达训练**：
- 每周录制3-5次，每次10-30分钟
- 第一次只录音频，不看画面
- 第二次开始看镜头，逐步适应
- 记录自己的"舒适区"话题和语速

**减少失误的技巧**：
- 使用提词器（手机/平板+提示App）
- 预录30秒自我介绍热身
- 允许自己停顿和重录
- 每次只录3-5分钟片段再拼接

### 4.2 屏幕录制教程

**电脑屏幕录制**（免费工具）：

**方案1：OBS Studio**（推荐，完全免费）
```
下载地址：obsproject.com
设置步骤：
1. 添加"显示捕获"或"窗口捕获"
2. 设置输出分辨率（1080p/720p）
3. 音频设置：桌面音频+麦克风
4. 开始录制
```

**方案2：ScreenPal**（免费版有水印）
- 在线录制，无需安装
- 免费版限制5分钟

**方案3：Mac自带QuickTime**
- 文件→新建屏幕录制
- 快捷键：Cmd+Shift+5

**手机屏幕录制**：
- iOS：控制中心→屏幕录制
- Android：下拉菜单→屏幕录制
- 推荐开启前置摄像头同时录制（画中画模式）

**屏幕录制最佳实践**：
- 分辨率：1080p minimum
- 帧率：30fps足够
- 光标效果：开启点击高亮
- 注释工具：提前准备标注软件

### 4.3 B-roll拍摄

**什么是B-roll**：
- 辅助镜头，增强视频观赏性
- 穿插在主镜头之间
- 补充说明内容、掩盖剪辑点

**常用B-roll类型**：
```
📹 环境镜头：城市风貌/工作环境/窗外景色
📹 物品特写：产品/书籍/工具/手部动作
📹 过程镜头：制作过程/操作演示/步骤展示
📹 情绪镜头：人物表情/自然风景/延时摄影
📹 数据镜头：图表/屏幕/文字动画
```

**B-roll拍摄清单**：
- [ ] 工作桌全景
- [ ] 键盘/鼠标特写
- [ ] 手写笔记/草稿
- [ ] 咖啡杯/办公用品
- [ ] 窗外城市景观（多哈天际线）
- [ ] 书本/资料
- [ ] 手机/电脑屏幕
- [ ] 产品包装/工具

**拍摄技巧**：
- 保持稳定，使用三脚架
- 多角度拍摄（平视/俯视/特写）
- 每个镜头至少10秒（方便剪辑）
- 预留足够过渡空间

### 4.4 直播录制

**录制方式**：
1. **平台录制**：YouTube/TikTok自动保存直播回放
2. **OBS录制**：同步录制本地高清版本
3. **手机录制**：作为备份方案

**OBS直播录制设置**：
```
输出设置：
- 分辨率：1920×1080
- 帧率：30fps
- 编码器：H.264
- 码率：4500-6000 kbps
- 音频： AAC 128kbps

文件输出：
- 格式：MKV（录制中不会丢失）
- 后期转换为MP4
```

**适用场景**：
- 需要专业调色

- 长期做视频，有学习意愿

- 下载免费版（Resolve）


### 6.2 剪辑节奏指南

**不同类型视频节奏**：
| 类型 | 镜头时长 | 节奏 | B-roll比例 |
|------|----------|------|------------|
| 教程/知识 | 5-15秒 | 稳定 | 40-60% |
| Vlog | 3-8秒 | 轻快 | 30-50% |
| 评测 | 8-20秒 | 中等 | 50-70% |
| 直播切片 | 30-60秒 | 保持原速 | 10-20% |

**避免的问题**：
- 镜头时长超过20秒（除非是特写/重要信息）
- 连续3个以上相同角度镜头
- 无意义的空白停顿
- 背景音乐与人声冲突

### 6.3 转场使用规范

**推荐转场**：
- **Cut（直接切换）**：最常用，90%的情况下使用
- **Dissolve（叠化）**：时间流逝/场景转换
- **Fade（淡入淡出）**：视频开头/结尾
- **Slide（滑入）**：强调对比/并列

**避免过度使用**：
- ❌ 旋转/缩放/3D效果（除非刻意为之）
- ❌ 过于花哨的转场
- ❌ 每隔几秒就换一个转场
- ❌ 转场时长超过1秒

## 七、字幕制作

### 7.1 自动字幕方案

**CapCut自动字幕**（推荐）：
```
操作步骤：
1. 导入视频到CapCut
2. 点击"文本"→"自动字幕"
3. 选择音频轨道
4. 等待生成（1分钟/5分钟视频）
5. 逐行检查修正
6. 导出时选择"硬字幕"
```

**YouTube自动字幕**：
```
操作步骤：
1. 上传视频到YouTube（私人/不公开）
2. 等待自动字幕生成（5-30分钟）
3. 下载字幕文件（SRT格式）
4. 导入到剪辑软件
5. 修正时间轴和内容
```

**语音转文字工具**：
- Whisper AI（免费开源，本地运行）
- 飞书妙记（免费，中文识别好）
- 讯飞听见（中文识别最佳，部分免费）

### 7.2 多语言字幕策略

**中东市场字幕方案**：
| 语言 | 字幕类型 | 工具推荐 |
|------|----------|----------|
| 中文 | 主字幕 | 飞书妙记/剪映 |
| 英文 | 第二字幕 | CapCut/YouTube |
| 阿拉伯语 | 可选字幕 | 人工翻译（重要视频） |

**字幕格式规范**：
- 每行不超过16个字符
- 字幕持续时间≥1秒
- 避免在快速对话时频繁换行
- 使用半透明黑色背景提高可读性

### 7.3 字幕样式设置

**推荐样式**：
```
字号：视频高度÷30（1080p约36px）
字体：系统默认或无衬线字体（如思源黑体）
颜色：白色（#FFFFFF）
描边：黑色描边 2px
背景：半透明黑色圆角矩形（80%不透明度）
位置：底部留10%边距
行间距：1.2-1.5倍
```

## 八、音频处理基础

### 8.1 音频基础调整

**音量标准化**：
```
目标音量：
- 人声：-10dB至-6dB RMS
- 背景音乐：-18dB至-15dB RMS
- 峰值不超过：-3dB（避免爆音）
```

**CapCut音频处理**：
```
1. 选中音频轨道
2. 点击"音频"→"音量"
3. 人声轨道：100-110%
4. 背景音乐：25-35%
5. 使用"音频标准化"一键优化
```

### 8.2 降噪处理

**CapCut降噪**：
```
步骤：
1. 选中音频
2. 点击"音频"→"降噪"
3. 选择降噪强度（默认30-50%）
4. 预览效果，避免过度降噪导致声音失真
```

**Audacity降噪**（进阶）：
```
步骤：
1. 录制一段环境噪音（5秒空白）
2. 选择噪音样本：效果→降噪→捕捉噪音轮廓
3. 选中整个音频
4. 应用降噪：效果→降噪→确定
5. 降噪量：6-12dB
```

**降噪注意事项**：
- 不要降噪过度（会导致声音不自然）
- 保留部分环境音更有真实感
- 严重噪音建议重录

### 8.3 均衡与压缩

**简单EQ调整**（CapCut）：
```
人声增强：
- 低频（80-200Hz）：-3dB（减少浑浊感）
- 中频（2-4kHz）：+2dB（增强清晰度）
- 高频（6-8kHz）：+1dB（增加明亮度）

音乐调整：
- 整体降低低频（减少与语音冲突）
- 切割特定频段避免与人声冲突
```

**压缩设置**（进阶）：
- 压缩比：3:1至6:1
- 阈值：-15dB至-10dB
- attack：10-30ms
- release：100-200ms

### 10.1 封面设计原则

**黄金法则**：
```
┌────────────────────────────────────────┐
│  封面=80%的点击率                        │
│  设计核心：一眼抓住注意力                 │
└────────────────────────────────────────┘
```

**关键要素**：
| 要素 | 要求 | 示例 |
|------|------|------|
| 人物表情 | 夸张/惊讶/开心 | 大笑/震惊/兴奋 |
| 文字 | 简短+大字体 | "这个秘密..."/"99%的人不知道" |
| 对比色 | 背景与前景高对比 | 深色背景+亮色文字 |
| 清晰度 | 高清无模糊 | 1080p以上 |

### 10.2 Canva封面模板

**免费模板获取**：
```
1. 访问 canva.com

3. 选择喜欢的模板
4. 替换图片和文字
5. 下载为PNG（1920×1080）
```

**封面元素布局**：
```
┌──────────────────────────────────────────┐
│                                          │
│  左上：频道Logo（小尺寸）                  │
│                                          │
│  中间：主体画面（人物/产品/场景）           │
│                                          │
│  下1/3：标题文字（白底黑字/深色底白字）     │
│                                          │
│  右侧：可选标签（如"NEW"/"FREE"）          │
│                                          │
└──────────────────────────────────────────┘
```
