# 标题模板库

从爆款案例反向提取的标题规律，用于自媒体内容创作。

---

## 核心原则

**真实 + 吸引 = 好标题**

- 标题党（夸大/编造）不可取
- 但要抓住用户注意力
- 真实内容也可以有吸引力的表达

---

## 标题类型模板

### 1. 数字型
**公式**：[具体数字] + [效果承诺/时间周期]

**爆款案例**：
- "10分钟搞定！宝宝辅食，8款营养搭配"（数字+结果）
- "0-3岁玩具怎么选|看这篇就够了"（年龄段数字+结果承诺）
- "月薪3000也能买！这5件辅食工具省下我半个LV"（人群数字+价格对比）

**标题模板**：
```
[时间/数量] + [核心结果] + [附加价值]
例：X分钟/X个/X天 + 动词结果 + 具体收益
```

---

### 2. 痛点型
**公式**：[问题场景] + [解决方案/暗示]

**爆款案例**：
- "新手妈妈看过来！选错连体衣竟让宝宝过敏了"（人群+痛点+后果）
- "宝宝一夜醒8次?你还在傻傻'喂奶哄睡'?"（数字痛点+反问）
- "夜醒5次变整觉！睡袋挑选血泪史"（痛点数字+结果+情绪词）

**标题模板**：
```
[精准人群] + [具体痛点] + [暗示解决方案]
例：新手妈妈必看！[痛点行为]竟然会导致[严重后果]
```

---

### 3. 结果型
**公式**：[诱人结果] + [数字支撑] + [行动引导]

**爆款案例**：
- "高敏感宝宝妈妈必看！这5个哄睡神器让我多活2年"（结果+数字+情感）
- "7天瘦5斤|跟着吃就会的减脂餐清单"（结果前置+数字+行动指令）
- "月嫂准备的月子餐 让我整个月子心情大好"（身份+结果+情绪）

**标题模板**：
```
[具体可感的结果] + [数字/证据] + [情感词]
例：[结果承诺]！[X个/XX天]，[情感收益词]
```

---

### 4. 悬念型/反常识型
**公式**：[反常识观点] + [悬念设置] + [价值钩子]

**爆款案例**：
- "别再夸孩子'真聪明'了!儿科医生说:这句话正在悄悄毁掉他的抗挫力"
- "别再敷面膜了|真正补水的3个方法|亲测有效"
- "不运动不节食！吃瘦18斤的食谱竟被健身教练偷学"

**标题模板**：
```
[禁止式引导] + [颠覆认知] + [权威背书/证据]
例：别再[常见行为]了！[权威身份]:[反常识结论]
```

---

### 5. 对比型
**公式**：[A vs B] + [结论/发现]

**爆款案例**：
- "你以为的穿搭博主在校穿搭 vs 现实中穿搭"
- "月薪5k买大牌|3个海淘技巧|省下一半钱"
- "每天陪娃3小时，不如高质量10分钟！'假陪伴'正在让孩子越来越孤僻"

**标题模板**：
```
[数字对比] + [反常识发现] + [问题揭示]
例：[长时间]不如[短时间]！[新概念/问题]
```

## 标题优化技巧

### 有效元素
- ✅ 具体数字（提高可信度）—— **90%母婴爆款标题带数字**
- ✅ 情绪词（必看、救命、神器）
- ✅ 时间/成本（降低心理门槛）
- ✅ 人群标签（精准定位）
- ✅ 权威背书（医生、专家、月嫂等身份）
- ✅ 反常识钩子（"别再..."、"竟然"）
- ✅ 禁止式引导（制造紧迫感）

### 禁用元素
- ❌ 震惊、99%的人不知道（标题党）
- ❌ 夸大效果（虚假承诺）
- ❌ 过度营销感
- ❌ 纯产品名/功能描述（无情绪钩子）

---

## 母婴/儿童类标题专项公式

**核心公式**：目标人群 + 痛点/问题 + 解决方案/结果

**黄金公式**：
```
[精准人群] + [具体痛点] + [解决方案/结果承诺]
例：新手妈妈必看！选错XX竟让宝宝XX了
```

**情绪词库**：
- 着急：急喊停、骂我、后悔太迟
- 共鸣：谁懂、救命、哭死、破防
- 信任：医生说、儿保、育儿师
- 利益：省下、多活X年、抄作业

### 8. 情绪化反转型（反常识+情绪词）
- **公式**：`[常见认知/矛盾体] + 反问 + [情绪词] + 悬念`
- **爆款案例**：
  - "手机越贵越好?别被'高价陷阱'骗惨了!真相竟然是……"
  - "拍照神器还是'照骗'?手机摄像头真能媲美单反吗?"
  - "充电越快越好吗?快充背后隐藏的'杀机'，你知道吗?"
- **特点**：
  - 用矛盾体制造认知冲突（神器vs照骗、越贵vs陷阱）
  - 反问句激发好奇心，促使用户寻找答案
  - 情绪词（坑爹、隐形坑、杀机）制造紧张感
  - 悬念收尾（真相竟然是……、你知道吗）引导点击
- **标题模板**：
  ```
  [矛盾体A]还是[矛盾体B]? + [情绪词/禁止式] + 悬念词
  [常见认知]?别被[负面词]!真相竟然是……
  ```
- **适用场景**：数码测评、好物对比、消费避坑

### 9. 成语流量型（2026新趋势）
- **公式**：`[热点成语] + [场景/人群] + [利益/结果]`
- **爆款案例**：
  - "万马奔腾吃垮自助!100元实现海鲜自由"（氛围+数字）
  - "马不停蹄搞副业，3个月存够旅游基金"（打工人+痛点+利益）
  - "一马当先get显白天花板，黄黑皮闭眼冲"（教程+人群+行动）
- **2026年5大流量成语**：
  - 跃马扬鞭（奋斗叙事）
  - 万马奔腾（热闹场景）
  - 马不停蹄（打工人共鸣）
  - 一马当先（教程专业背书）
  - 骐骥驰骋（高端格调）
- **特点**：
  - 成语自带文化底蕴，提升标题格调
  - 2026年热点梗，避免生僻成语
  - 搭配数字/利益点效果翻倍
- **标题模板**：
  ```
  [流量成语] + [具体场景/人群] + [数字/利益承诺]
  例：[成语]搞副业，[X个月]存够[目标]
  ```

### 7. 紧急号召型
- **公式**：`[感叹词] + [事件描述] + [紧迫感] + [数字/任务]`
- **爆款案例**：
  - "扩散周知!惊艳全国的柳州春天，正在紧急寻找100位记录者"
  - "正在紧急寻找" = 制造稀缺感和紧迫性
- **特点**：
  - 感叹词开场抓住注意力（扩散周知、紧急、必看）
  - 具体数字增强可信度（100位、3天、限时）
  - 任务型描述激发参与感（寻找、招募、需要你）
  - 适合：活动招募、城市营销、热点借势
- **标题模板**：
  ```
  [感叹词] + [事件/地点] + [紧迫感动词] + [数字/任务]
  例：扩散周知！[地点]正在紧急寻找[X位][角色]
  ```

### 8. 反差自嘲型
- **公式**：`[认知预期] vs [现实反差] + 自我调侃`
- **爆款案例（TikTok）**：
  - "me convincing myself I can do the viral yoga pose"（自嘲说服自己能做到）
  - "my nervous system thinking ___, when in reality ___"（神经系统以为vs现实）
- **特点**：
  - 用第一人称叙述制造真实感
  - 制造"以为vs现实"的反差笑点
  - 自我调侃降低防备，利于传播
  - 适合：生活记录、挑战内容、轻松娱乐
- **标题模板**：
  ```
  [第一人称] + [认知预期] + [when in reality / 没想到]
  例：me thinking I could... when in reality I can't
  例：我以为我能/我以为XXX，结果现实是YYY
  ```

### 10. 悬念揭秘型
- **公式**：`[数字钩子] + [悬念词] + [揭秘感]`

- **特点**：
  - 数字开头制造稀缺感和好奇心

- **标题模板**：
