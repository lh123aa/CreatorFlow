# 小红书爆款图文设计模板库

> 本库收集小红书爆款笔记的图文设计模板，包括配色方案、布局结构、视觉元素等，供快速参考和AI生成使用。

---

## 一、设计规范基础

### 1.1 封面尺寸规范
- **标准比例**: 3:4 竖版 (1080×1440px)
- **最小分辨率**: 720×960px
- **最佳显示**: 占满屏幕，视觉冲击力最强

### 1.2 封面四要素
| 要素 | 要求 | 说明 |
|------|------|------|
| 主题文字 | 清晰醒目 | 字号≥80px，占比画面70%以上 |
| 配色 | 高对比 | 与背景形成70%以上对比度 |
| 焦点 | 明确单一 | 一个核心信息，避免堆砌 |
| 风格 | 统一 | 形成账号辨识度 |

### 1.3 排版原则
- **黄金留白**: 内容占60-70%，留白占30-40%
- **呼吸感**: 段落间空行，行间距1.5-2倍
- **层级分明**: 标题40-50号 > 副标题30-35号 > 正文24-28号

#### 适用场景

- 强调"有感"而非"有用"，从"焦虑/开心"下钻到95种具体情绪

#### 核心公式
```
具体时间 + 感官细节（声音/触觉） + 生理反应 = 高共鸣开头
```

#### 视觉风格
```
风格：真实记录风 / 原生洞察风
配色：暖调（温馨场景）、冷调（严肃场景）
布局：留白充足、呼吸感强
元素：手机原相机噪点、手绘涂改痕迹、咖啡渍等生活元素
```

### 设计趋势总结（2026-04-14）

#### 封面设计三大新趋势
1. **高反差配色**：暗背景配亮字/亮背景配深字，0.8秒内抓住注意力
2. **整页1个核心信息**：删除多余装饰元素，封面信息只能有1个焦点
3. **反差元素提升好奇**：加一点与主题相关的反常识元素，跳出同质化

#### 配色选择新标准
- 色差拉到最大：暗背景→亮黄/亮白粗体字
- 亮度测试法：手机亮度调到最低，能看清大字=合格
- 反面案例：橘色美食图配橙色字，完全糊在一起

#### 布局新规则
- 封面核心信息=1个（要么最大标题，要么最有看点主体图）
- 所有无关元素全删：装饰贴纸、副标题、账号水印等
- 直接用模板：稿定设计/醒图的小红书封面模板，默认只留1个主标题+1个主体图

### 7.2 五图四律设计硬规则

| 规则 | 要求 | 操作要点 |

| 光影律 | 统一滤镜+光影 | VSCO A6滤镜+曝光+0.3、对比度+15 |
| 焦点律 | 中心区域保留15%空白 | 预留平台贴纸安全区 |
| 色彩律 | 多图色彩一致 | 统一色调，避免视觉割裂 |
