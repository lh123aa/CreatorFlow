# 正文模板库

> 适用平台：小红书 / 抖音  
> 适用场景：种草笔记、干货分享、教程指南、避坑攻略、情感共鸣

---

## 一、通用结构概述

### 核心公式

```
爆款正文 = 黄金开头（3秒钩子）+ 价值主体（痛点→方案）+ 互动结尾（引导行动）
```

### 排版规范

| 要素 | 规范 |
|------|------|
| 每段长度 | 2-3行，避免大段文字 |
| 段落分隔 | 用空行或符号（✨、———）隔开 |
| 关键信息 | 加粗标注，每段仅限1处加粗 |
| 数字编号 | 用中文数字（①②③）独立成段 |
| 关键词 | 添加 #标签# 增加搜索曝光 |

## 二、五大正文模板

### 模板1：AIDA种草结构（种草首选）

**适用场景**：产品推荐、好物分享、课程推广

#### 结构公式

```
Attention（吸睛开头）
    ↓
Interest（激发兴趣）
    ↓
Desire（唤起欲望）
    ↓
Action（引导行动）
```

#### 模板详解

| 段落 | 任务 | 写作要点 |
|------|------|----------|
| **开头** | 抛出痛点/反差 | 用感叹号/问号，1句话击中用户痛点 |
| **中间** | 讲核心亮点 | 具体化描述，1个成分/1个细节/1个动作 |
| **欲望** | 强调独特价值 | 用对比/数据增强说服力 |
| **结尾** | 引导互动 | "码住"、"评论区见"、"点击主页" |

#### 示例模板

```
你是不是也经常[痛点描述]？

直到我发现了[产品/方法]！

✨[核心亮点1]：具体描述
✨[核心亮点2]：具体描述  
✨[核心亮点3]：具体描述

用了之后[效果描述]，真的绝了！

你们还有什么问题？评论区问我～
```

#### 变体示例（场景开场）

```
作为一个[身份标签]的[人群]，我的[痛点]曾经...

直到遇见[产品/方法]！

[卖点1]：[具体效果]
[卖点2]：[具体效果]

[总结/推荐语]
需要的姐妹点击主页🔗
```

### 模板2：漏斗四段法（高转化）

**适用场景**：教程分享、技巧讲解、问题解决型内容

#### 结构公式

```
痛点陈述 → 场景代入 → 解决方案 → 行动指令
   3秒          5秒          10秒        2秒
```

#### 模板详解

| 步骤 | 核心任务 | 句式参考 |
|------|----------|----------|
| **① 痛点陈述** | 用短句+感叹号/问号开场 | "你是不是也..."、"XX问题真的绝了！" |
| **② 场景代入** | 描述具体画面 | "开会前补妆被同事盯着看..." |
| **③ 解决方案** | 产品名+1个成分+1个动作 | "[产品]含[成分]，用[动作]" |
| **④ 行动指令** | 明确告诉下一步 | "点击购物车第X个链接..." |

#### 示例模板

```
[痛点]一到下午就[问题描述]？

[场景]开会前补妆被同事盯着看，拍照前狂擦T区...

[方案][产品/方法]，只需[动作描述]

✅效果：[量化结果]

[行动指令]
```

#### 变体示例（清单式）

```
必须知道的[数字]个[主题]技巧：

① [要点1]：[具体说明+配图位置]

② [要点2]：[具体说明+配图位置]

③ [要点3]：[具体说明+配图位置]

✨收藏起来，需要时直接翻出来用！
```

### 模板3：SCQA情境结构（深度共鸣）

**适用场景**：职场成长、情感故事、生活感悟

#### 结构公式

```
S - Situation（情境）：设定背景
C - Conflict（冲突）：制造冲突/痛点
Q - Question（问题）：引出疑问
A - Answer（答案）：给出解决方案/观点
```

#### 模板详解

| 要素 | 写作任务 | 技巧 |
|------|----------|------|
| **S情境** | 快速切入场景 | 用"作为一个..."、"那天..."开场 |
| **C冲突** | 抛出问题/反差 | 用"但是..."、"没想到..."制造转折 |
| **Q问题** | 引出核心疑问 | "到底应该怎么办？" |
| **A答案** | 给出解决/感悟 | 分点阐述，加金句升华 |

#### 示例模板

```
【S-情境】
作为一个[身份]，我曾经[背景描述]...

【C-冲突】
但[转折事件]，我突然意识到[冲突点]...

【Q-问题】
[人群]到底应该怎么办？

【A-答案】
✅ [观点/方法1]
✅ [观点/方法2]  
✅ [观点/方法3]

[金句升华/价值总结]
你们觉得呢？评论区聊聊～
```

#### 情感共鸣变体

```
有没有一瞬间，你也觉得[情绪点]？

明明很努力，却[无奈]；
明明很在乎，却[失落]。

其实你已经很棒了，别为难自己。
[治愈句/金句]

懂的人自然会点赞 ❤️
```

### 模板4：清单盘点式（干货合集）

**适用场景**：知识分享、技巧总结、好物清单

#### 结构公式

```
数字+核心主题 → 分点干货（3-5条） → 总结升华
```

#### 模板详解

| 位置 | 写作要点 |
|------|----------|
| **标题区** | 数字开头，主题明确 |
| **分点** | 每条简洁具体，加✅或✨符号 |
| **配图** | 每条配实拍图+简短说明 |
| **结尾** | 收藏引导 |

#### 示例模板

```
[数字]个[主题]技巧，最后一个最关键！

✅ [技巧1]：[具体说明]

✅ [技巧2]：[具体说明]

✅ [技巧3]：[具体说明]

✨ 收藏起来，慢慢看！
```

#### 进阶版（有对比）

```
[数字]款[类别]测评｜拒绝踩坑！

▫️ 产品A：适合[人群]，但[缺点]
▫️ 产品B：适合[人群]，性价比高
▫️ 产品C：[特点]，但价格贵

👉 我的选择：[具体推荐]

你们用的是哪款？评论区告诉我！
```

### 模板5：避坑指南式（防踩雷）

**适用场景**：母婴育儿、护肤美妆、装修选购

#### 结构公式

```
避坑点（共性痛点）→ 错误做法 → 正确做法 → 总结建议
```

#### 模板详解

| 要素 | 写作要点 |
|------|----------|
| **开头** | 直击"为什么踩坑" |
| **避坑点** | 说明"为什么是坑" |
| **正确做法** | 给出"正确选择方法" |
| **配图** | 搭配对比图更直观 |
| **结尾** | 总结建议+收藏引导 |

#### 示例模板

```
新手妈妈最容易踩的[数字]个坑！

❌ 误区1：[错误做法]
✅ 正确做法：[正确方法]

❌ 误区2：[错误做法]
✅ 正确做法：[正确方法]

❌ 误区3：[错误做法]
✅ 正确做法：[正确方法]

别再花冤枉钱了！收藏转发给需要的姐妹～
```

### 模板6：情绪锚点式（高认同感）

**适用场景**：情感共鸣、生活感悟、职场吐槽、亲子日常

#### 结构公式

```
微场景唤醒 → 感官细节放大 → 未完成句式触发补全冲动
```

#### 核心原理

提取目标人群高频情绪痛点，用具象化生活细节唤醒记忆闪回，触发"这说的就是我"的认同感。

#### 句式技巧

| 技巧 | 示例 |
|------|------|
| **复刻微场景对话** | "甲方：要高级感。我：好的。甲方：太高级了，要接地气一点。我：……" |
| **放大感官体验** | "手机弹出17条未读，耳机里是ASMR雨声，而我的时间轴还卡在0:03:47" |
| **未完成句式** | "改到第5版方案时，老板发来一句'再想想'——我盯着屏幕，光标已经闪烁了1分23秒" |
| **时间+动作+结果** | "试错19次后，我把口播稿压缩到8秒，完播率从21%升至68%" |

#### 示例模板

```
[微场景复刻]
甲方：要高级感。
我：好的。
甲方：太高级了，要接地气一点。
我：……

[感官细节]
凌晨两点，改第8版PPT，
咖啡已经凉透，
肚子咕咕叫，
但屏幕的光还在闪。

[未完成句]
老板只说了三个字——
"再想想"
我盯着显示器，光标跳动了[时间]

[补全触发/共鸣句]
屏幕前的你，有过同样的经历吗？

评论区说出你的故事 👇
```

#### 情绪共鸣经典句式库

```
▎直击疲惫型
• 手机弹出17条未读，耳机里是ASMR雨声，而我的时间轴还卡在0:03:47
• 每天通勤2小时，挤地铁被踩了8脚，到公司已经精疲力尽
• 甲方说"大气"却给不出具体要求，改了12版回到第一版

▎扎心现实型
• 小时候，哭是解决问题的绝招。长大后，笑是面对生活的武器
• 没人扶你的时候，自己站直。路还长，背影要美
• 成年人的世界，沉默不是妥协，是慢慢看清，也慢慢放过

▎治愈共鸣型
• 你已经很棒了，别为难自己
• 遇见是福气，不遇见也是
• 愿你，天黑有灯，下雨有伞，一路有良人相伴
```

## 三、抖音/短视频正文公式

### 通用结构：3-15-5法则

```
爆款视频 = 黄金3秒开头 + 15秒价值主体 + 5秒互动结尾
```

### 开头钩子类型

| 类型 | 示例句式 |
|------|----------|
| **悬念提问** | "为什么同事摸鱼还比你升职快？" |
| **数字冲击** | "3个技巧，播放量从500涨到50万" |
| **反常识断言** | "熬夜反而效率高？年轻人正确作息" |
| **痛点直击** | "3小时通勤太崩溃？教你多睡1小时" |
| **情绪共鸣** | "漂在大城市的人，谁没在走廊吃过外卖？" |

### 主体内容类型

| 类型 | 结构 |
|------|------|
| **问题解决型** | 痛点→危害→解决方案 |
| **故事型** | 冲突→反转→升华 |
| **分析型** | 现象→原因→解决办法 |
| **知识型** | 观点→论证→金句 |

### 结尾互动引导

| 类型 | 示例 |
|------|------|
| **行动指令** | "转发给需要的朋友，一起省时间" |
| **情感共鸣** | "屏幕前的你，最想改变哪部分？" |
| **悬念预告** | "下期拆解百万播放秘密，关注不迷路" |
| **稀缺激励** | "前100名评论送资料包" |

## 六、使用注意事项

1. **模板是框架不是枷锁**  
   结合自身内容和赛道特点灵活调整

2. **数据具体化**  
   "从80分涨到95分" > "成绩提升"

3. **场景真实化**  
   用具体画面代替抽象描述

4. **行动明确化**  
   结尾必须有具体可执行的指令

5. **避免过度堆砌**  
   元素适量，避免视觉杂乱

## 模板7：情绪碎片式（抖音情感赛道爆款）

**适用场景**：情感共鸣、生活感悟、扎心语录、治愈文案

**数据来源**：2026年4月抖音情感文案刷屏案例

#### 核心公式

```
情绪碎片 = 微场景/情绪点 → 未完成句式 → 补全触发
```

#### 结构特点

| 要素 | 特点 | 示例 |
|------|------|------|
| **句式** | 短句（8-20字），高情绪浓度 | "旧人不知我近况，新人不知我过往" |
| **未完成句** | 留白引发用户补全冲动 | "我是你的半截诗，___" |
| **补全触发** | 引发"这就是我"的认同感 | "评论区说出你的故事" |

#### 四大情绪类型模板

##### ① 扎心遗憾型

```
[未完成句式]
大风刮倒梧桐树，曾经誓言生锈不作数。

[情绪点]
我可以什么都妥协，
唯独[某件事/某个人]不能将就。

[补全触发]
评论区说出你的故事 👇
```

**案例库**：
- "旧人不知我近况，新人不知我过往"
- "好多话想说，好多话没说，好多话不能说"
- "我们好像不该这样，不止这样，却只能这样"
- "有些关系，除了再见，好像别无选择"

##### ② 温柔治愈型

```
[松弛感开场]
允许一切发生，允许自己不完美。

[温暖句]
生活是旷野，不是轨道，
怎么走都可以。

[金句]
月亮慢慢变圆，事事慢慢如愿。
```

**案例库**：
- "允许一切发生，允许自己不完美"
- "生活是旷野，不是轨道，怎么走都可以"
- "每个人的花期不同，不必焦虑别人比你提前拥有"
- "风很温柔，花很浪漫，你很特别，我很喜欢"

##### ③ 人间清醒型

```
[洞察句]
爱别人适可而止，爱自己尽心尽力。

[观点强化]
心软不值钱，懂事没好处，
搞钱和爱自己才是终身课题。

[金句升华]
相处不累，久处不厌，就是最好的感情。
```

**案例库**：
- "爱别人适可而止，爱自己尽心尽力"
- "婚姻不是搭伙，是遇事有商量，难过有拥抱"
- "真正的安全感，从来不是别人给的，而是自己赚的底气"
- "不被爱的时候，安静退场也是一种体面"

##### ④ 暧昧心动型

```
[偏爱感开场]
在我这里，你是偏爱，是例外，是首选，是唯一。

[细节感]
你可以反复向我确认，这份爱不会过期。

[甜句]
山野万里，我只喜欢你，仅此而已。
```

**案例库**：
- "你可以反复向我确认，这份爱不会过期"
- "全世界教我长大，只有你让我做小孩"
- "不忙，你说，我在听"
- "你不是最好，却是我所有期待里的刚刚好"

#### 与情绪锚点式（模板6）的区别

| 维度 | 情绪锚点式（模板6） | 情绪碎片式（模板7） |
|------|-------------------|-------------------|
| **核心** | 微场景复刻+感官细节 | 短句+未完成句式 |
| **篇幅** | 中长（可读性段落） | 极短（15-25字/句） |
| **平台** | 小红书图文 | 抖音图文/口播 |
| **触发方式** | 场景共鸣 | 句式留白补全 |
| **适用场景** | 故事、职场、生活 | 情感语录、扎心文案 |

#### 使用技巧

1. **句式极简化**：每句不超过20字，情绪要精准
2. **未完成句是关键**：留白比完整句更能触发互动
3. **情绪分类清晰**：扎心/治愈/清醒/心动，四选一深挖
4. **结尾加互动**：通常用"评论区说出你的故事"收尾

## 六、模板6：观点轰炸式（高共鸣金句类）

**新增日期**：2026-04-14
**适用场景**：人生感悟、创业分享、情感共鸣、励志鸡汤

#### 爆款案例

**抖音4月爆款文案**：
> "最硬的后台是账户余额，最铁的关系是个人能力，最大的靠山是身体健康，最稳的安全感是凡事靠自己。一个人真正的厉害不是生来手握好牌，而是哪怕拿到一副烂牌也能打成王炸。"

#### 结构公式

```
核心观点排比（4-5个"最..."） → 逐条展开（生活化解释） → 金句升华 → 互动引导
   3秒钩子                    15秒主体              2秒收尾      1秒互动
```

#### 模板详解

| 位置 | 任务 | 技巧 |
|------|------|------|
| **开头** | 观点排比，制造冲击 | 4-5个"最..."句式，短促有力，用逗号连接 |
| **中间** | 逐条展开解释 | 每个观点1句话，用生活化例子佐证 |
| **升华** | 金句收尾 | 提炼核心观点，形成记忆点 |
| **互动** | 引导点赞评论 | "你们觉得呢？"、"同意的举手" |

#### 示例模板

```
[核心观点排比]
最[关键词1]是[内容1]，最[关键词2]是[内容2]，
最[关键词3]是[内容3]，最[关键词4]是[内容4]。

[逐条展开]
▫️ [关键词1]：[1句话解释]
▫️ [关键词2]：[1句话解释]
▫️ [关键词3]：[1句话解释]

[金句升华]
[核心感悟/总结]

[互动引导]
你们认同吗？评论区聊聊～
```

#### 变体示例（创业/商业版）

```
[排比句]
最可靠的收入是副业，最稳的投资是自己，
最大的底气是存款，最铁的后台是能力。

[展开]
▫️ 副业：不在于赚多少，在于多一条退路
▫️ 投资：自己才是最不会贬值的资产
▫️ 存款：让你在选择面前有底气说"不"
▫️ 能力：别人拿不走，随时能变现

[金句]
不是风口让你飞起来，而是你本来就是风筝。

#创业 #副业 #赚钱思维
```

#### 写作技巧

1. **排比句要精准**：每个"最"后面的词要具体、有画面感
2. **解释要接地气**：避免说教，用大白话讲道理
3. **金句要有反转**：最后一句最好有认知反转
4. **互动要自然**：不要硬引导，让用户自己想说

- 抖音：视频口播/字幕类
- 小红书：图文金句/感悟类

## 六、问题切片式正文（高停留率干货写法）

**适用场景**：知识分享、教程技巧、问题解答型内容

#### 核心原理

用户阅读耐受力趋近于零，长段落即流失。必须将知识压缩为可即时调用的"问题-答案"单元，每单元解决一个具体动作障碍。

#### 结构公式

```
疑问句开头 → 空行 → 加粗结论 → 简短原理
```

#### 模板详解

| 要素 | 写作要点 |
|------|----------|
| **疑问句** | 必须是真实评论区高频提问，如"刷酸后能用积雪草吗？" |
| **空行** | 制造视觉停顿，让眼睛"歇脚" |
| **结论** | 加粗+绿色字体，给出确定性答案 |
| **原理** | ≤2句话，引用权威来源，不说"我觉得" |

#### 示例模板

```
刷酸后能用积雪草吗？

可以，但需间隔20分钟且选无酒精配方。

积雪草苷与果酸会竞争皮肤吸收通道，建议先用果酸，等待20分钟皮肤pH值恢复后，再使用积雪草类产品。根据《中国药理学通报》研究，这样搭配反而能增强屏障修复效果。

防晒涂不够量会晒黑吗？

会，而且比不涂更危险。

防晒霜的防护指数是按照2mg/cm²标准用量测试的，实际用量不足时，防护效果呈指数下降而非线性下降。实验显示：用量减半，SPF值可能下降70%以上。

✨收藏起来，下次翻出来直接用！
```

#### 关键技巧

1. **问题来源**：从评论区、私信、搜索下拉词中挖掘真实疑问
2. **结论明确**：不给模糊答案，非A即B
3. **引用背书**：用"研究表明""数据显示""根据XX"增强可信度
4. **视觉节奏**：每100-150字一个"问题-答案"单元

## 八、收入对比式爆款标题（制造话题冲突）

**适用场景**：Vlog/成长/职场/副业/创业类内容

**爆款案例**：
> "月入五万在北京，下班做自媒体有多爽？"
> "在小县城月入3万，比大城市舒服太多了"
> "存款100万的我，终于不焦虑了"

#### 核心公式

```
收入对比式标题 = 收入数字 + 地域/身份标签 + 反差感/悬念
```

#### 公式拆解

| 要素 | 作用 | 示例 |
|------|------|------|
| **收入数字** | 制造话题感，吸引点击和评论 | "月入五万"、"存款100万" |
| **地域/身份** | 锚定人群，引发地域讨论 | "北京"、"小县城"、"95后" |
| **反差/悬念** | 制造认知冲突，提升完播率 | "有多爽？"、"比大城市舒服" |

#### 标题模板库

```
[收入+地域]
月入五万在北京，日子过得怎么样？
月入3万在小县城，存款速度有多快？

[收入+身份]
95后存款50万，比同龄人多还是少？
30岁前存款100万，我是这么做到的

[收入+反差]
月入五万，下班后我为什么还要做自媒体？
大城市月入两万，不如小县城五千幸福？

[收入+悬念]
存款多少才能不焦虑？我存到了
副业收入超过主业后，生活有什么变化？
```

#### 使用技巧

1. **数字要具体**：模糊的"很高"不如具体的"月入五万"
2. **地域/身份锚定**：让特定人群有代入感并参与讨论
3. **留悬念引发好奇**："有多爽？"比陈述句点击率高40%
4. **评论区引导**：主动引导讨论地域差异、收入对比等话题

#### 配套正文结构

```
[开头：收入展示]
月入五万在北京，说实话...

[中间：细节拆解]
工作方面：[具体描述]
生活方面：[具体描述]
心态变化：[具体描述]

[结尾：互动引导]
你们觉得这个收入在北京算什么水平？
评论区说说～

#月入五万 #北漂生活 #收入对比
```
