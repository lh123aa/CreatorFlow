# 专项指南01：ChatGPT与Claude提示词工程实战

## 一、AI工具在内容创作中的定位

### 1.1 AI是助手而非替代者

理解AI在创作中的定位至关重要。AI是提升效率的助手，不是取代创作的存在。

**AI擅长的**：

- 初稿生成和头脑风暴
- 信息搜集和整理
- 多语言翻译和改写
- 重复性工作的自动化

**AI不擅长的**：

- 真实的个人经历和情感
- 独特的人设和风格
- 对文化的深度理解
- 复杂的决策和判断

### 1.2 提示词工程的核心原则

**原则一：角色设定**。

告诉AI你希望它扮演的角色，越具体越好。

示例：
- ❌ "写一篇多哈探店文案"
- ✅ "你是一个专注于海外生活的美食博主，写一篇多哈阿拉伯餐厅探店文案，风格轻松自然，带有真实体验感"

**原则二：明确输出格式**。

指定输出的结构和格式要求。

示例：
- ❌ "写一个开头"
- ✅ "写一个30秒以内的视频开头，包含3个钩子选项，格式为：钩子1：[内容] 适用理由：[理由]"

**原则三：提供上下文**。

提供足够的背景信息让AI理解任务。

示例：
- ❌ "推荐一些选题"
- ✅ "我的账号是'多哈生活日记'，主要分享多哈华人生活，目前有5000粉丝，目标用户是想了解多哈生活的华人，推荐10个下周可以做的选题"

**原则四：迭代优化**。

通过反馈让AI不断改进输出。

示例：
- "这个标题不错，但太像标题党了，能不能再自然一点？"
- "内容不错，但能不能加入一些阿拉伯文化元素？"

## 二、ChatGPT在内容创作中的应用

### 2.1 文案创作提示词模板

**模板一：爆款标题生成**

提示词：
"你是一个资深的小红书博主，擅长写吸引人的标题。

我的内容主题是：[内容主题]
目标用户是：[目标用户]
内容调性：[调性，如轻松、专业、温暖等]

请生成10个标题，要求：
1. 包含数字或悬念
2. 符合小红书风格
3. 每个标题不超过20个字"

**模板二：种草文案撰写**

提示词：
"帮我写一篇小红书种草文案。

产品/服务：[产品名称]
核心卖点：[卖点1、2、3]
我的使用体验：[体验描述]
目标用户痛点：[用户痛点]

要求：
1. 开头有钩子，引发好奇
2. 中间包含使用场景和真实感受
3. 结尾有购买引导或互动
4. 总字数800-1000字"

**模板三：系列内容规划**

提示词：
"帮我规划一个[主题]系列内容。

系列名称：[系列名称]
系列定位：[系列定位]
预计做[数量]期

请列出：
1. 每期的主题和大纲
2. 系列的逻辑递进关系
3. 每期的差异化亮点"

### 2.2 多哈创作者专属提示词

**提示词一：多哈探店文案**

提示词：
"我是一个在多哈生活的华人博主，要去探访一家[餐厅类型]。

餐厅名称：[名称]
位置：[位置]
主打菜：[菜品]
特色：[特色]

请写一篇探店文案，要求：
1. 开头制造悬念或反差
2. 中间描写菜品和环境
3. 结尾给出评分和推荐理由
4. 加入一些阿拉伯文化元素
5. 适合小红书/抖音风格"

**提示词二：多哈生活选题**

提示词：
"为'多哈华人生活'账号推荐下周的7个选题。

背景：
- 账号主要分享多哈的真实生活
- 粉丝主要是想来多哈或在多哈的华人
- 最近多哈的热点：[近期热点]
- 斋月/节日期间：[节日背景]

请给出7个选题，包括：
1. 标题
2. 内容大纲
3. 适合的平台（小红书/抖音）
4. 预计效果"

### 2.3 内容改写与优化

**改写提示词**：

"将以下文案改写成更口语化、自然的风格，减少书面语感：

[原文]

同时：
1. 保持核心信息不变
2. 增加一些情感表达
3. 适合[平台]风格"

**优化提示词**：

"帮我优化以下小红书笔记：

[原文]

问题诊断：
1. 标题是否吸引人？
2. 开头是否有钩子？
3. 内容结构是否清晰？
4. 是否有互动引导？

请给出具体优化建议和修改后的版本。"

## 三、Claude在深度创作中的应用

### 3.1 Claude的优势

相比ChatGPT，Claude在以下场景有优势：

- 更长的上下文理解
- 更细腻的情感表达
- 更深入的分析能力
- 更安全的输出

### 3.2 深度分析类提示词

**模板一：竞品分析**

提示词：
"分析以下小红书账号的内容策略：

账号名称：[名称]
粉丝数：[数量]
主要领域：[领域]

分析维度：
1. 内容类型和比例
2. 标题风格特点
3. 封面设计风格
4. 互动策略
5. 变现方式

请给出详细的分析报告，以及我可以借鉴的3个点。"

**模板二：用户画像分析**

提示词：
"基于以下内容分析我的目标用户画像：

我的账号：[账号名]
内容主题：[主题]
目前粉丝：[数量]

请分析：
1. 我的目标用户是谁
2. 他们的核心需求是什么
3. 他们在小红书上的行为特点
4. 如何更好地吸引他们"

### 3.3 内容策划类提示词

**模板一：深度专题策划**

提示词：
"帮我策划一期深度内容专题。

主题：[主题]
目标受众：[受众]
预计时长/篇幅：[时长/篇幅]

请设计：
1. 专题的核心观点
2. 内容结构框架
3. 每个部分的关键信息点
4. 需要的数据/案例支撑
5. 可能的争议点和应对"

**模板二：跨平台内容改编**

提示词：
"将以下小红书图文内容改编为：

1. 抖音短视频脚本（60秒以内）
2. 微信公众号长文
3. 微博短帖

原文：[原文]

要求：
1. 保持核心信息不变
2. 适应各平台的内容风格
3. 抖音脚本需要包含拍摄建议"

## 四、提示词的迭代与优化

### 4.1 建立个人提示词库

**提示词分类**：

- 标题类：爆款标题生成、系列标题等
- 文案类：种草文案、探店文案等
- 策划类：选题规划、专题策划等
- 优化类：内容改写、标题优化等

**提示词迭代记录**：

记录每次使用的：
- 原始提示词
- 调整后的提示词
- 输出质量评估
- 改进方向

### 4.2 提示词优化技巧

**技巧一：Few-shot示例**。

给AI几个示例，让它理解你期望的输出风格。

示例：
"请按照以下风格写：

示例1：[案例1]
示例2：[案例2]

现在请写：[你的需求]"

**技巧二：分步引导**。

将复杂任务分解为多个简单步骤。

示例：
"帮我写一篇多哈美食攻略。
第一步：先列出攻略的核心要点
第二步：选择最吸引人的3个要点展开
第三步：设计开头和结尾
第四步：整合成完整文案"

**技巧三：约束条件**。

明确你不需要的内容。

示例：
"请写一篇探店文案，要求：
- 不要标题党
- 不要过度夸张
- 不要提到价格（因为可能不准确）
- 加入真实体验细节"

### 4.3 常见问题解决

**问题一：输出太泛化**

解决：增加更多具体细节和约束

**问题二：输出太机械**

解决：增加风格示例，调整措辞要求

**问题三：信息不准确**

解决：增加信息来源要求，要求AI标注不确定信息

## 五、本章核心要点总结

1. **AI定位**：助手而非替代者；擅长初稿、信息整理、翻译改写；不擅长真实经历、独特人设、深度文化理解。

2. **提示词四原则**：角色设定（明确AI身份）、明确输出格式（指定结构）、提供上下文（足够背景）、迭代优化（反馈改进）。

3. **ChatGPT应用**：爆款标题生成、种草文案撰写、系列内容规划；多哈创作者专属提示词（探店文案、生活选题）。

4. **Claude应用**：深度分析（竞品分析、用户画像）、内容策划（深度专题、跨平台改编）。

5. **提示词优化**：建立个人提示词库、Few-shot示例、分步引导、约束条件。
