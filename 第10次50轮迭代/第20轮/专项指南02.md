## 二、关键词布局

### 2.1 关键词类型

```
关键词类型：

品类词：
- 产品类别
- 行业通用词
- 如"化妆教程"

品牌词：
- 品牌名称
- 如"某某品牌推荐"

场景词：
- 使用场景
- 如"上班妆"

问题词：
- 疑问需求
- 如"怎么化妆不脱妆"

长尾词：
- 细分需求
- 如"干皮适合什么粉底液"
```

---

## 三、标题优化

### 3.1 标题公式

```
标题公式：

核心词+修饰词+情绪词+数字

示例：
- "新手化妆教程｜保姆级教学，3分钟出门"
- "这瓶精华液绝了！用了皮肤真的变好了"
- "5个化妆技巧，学会了你也能变美"
```

---

## 四、内容优化

### 4.1 关键词穿插

```
关键词穿插：

开头提及：
- 前3秒字幕包含关键词
- 视频开头提及

中间自然穿插：
- 内容中自然提到
- 不要刻意堆砌

结尾重复强调：
- 结尾再次提及
- 强化记忆

评论区引导：
- 评论区置顶
- 包含关键词
```

---

## 五、标签使用

### 5.1 标签策略

```
标签使用：

数量：3-8个
类型：
- 核心标签1-2个
- 行业标签2-3个
- 长尾标签1-2个
- 趋势标签1个

示例：
#化妆教程 #新手化妆 #日常妆 #保姆级教程 #化妆技巧
```
