# 合同风险防范指南

## 概述

合同是创作者商业合作的保护伞，但合同中的陷阱也很多。本指南将从合同常见陷阱、关键条款审核、维权处理三个方面，帮助创作者防范合同风险。

---

## 一、合同常见陷阱

### 1.1 费用相关陷阱

**陷阱一：费用支付模糊**

- 模糊表述：验收后支付
- 陷阱：无限期拖延
- 防范：明确具体日期

**陷阱二：附加条件**

- 模糊表述：效果满意后支付
- 陷阱：甲方随意定义"效果"
- 防范：明确验收标准

**陷阱三：扣押尾款**

- 模糊表述：保留10%尾款
- 陷阱：以各种理由不支付
- 防范：明确尾款支付条件

### 1.2 版权相关陷阱

**陷阱一：版权归属模糊**

- 模糊表述：版权归甲方所有
- 陷阱：包括创作者的肖像权等
- 防范：明确版权范围

**陷阱二：无限使用权**

- 模糊表述：永久使用
- 陷阱：创作者失去对内容的控制
- 防范：限制使用期限和范围

**陷阱三：改编权开放**

- 模糊表述：可以修改内容
- 陷阱：甲方随意修改损害形象
- 防范：明确修改权限

### 1.3 责任相关陷阱

**陷阱一：无限责任**

- 模糊表述：承担一切损失
- 陷阱：甲方损失都要赔
- 防范：限定责任范围

**陷阱二：效果保证**

- 模糊表述：保证效果
- 陷阱：无法保证的绝对效果
- 防范：明确可量化的效果指标

## 二、关键条款审核

### 2.1 审核清单

**基本信息**

- [ ] 双方信息是否准确
- [ ] 合作内容是否明确
- [ ] 合作期限是否清晰

**费用条款**

- [ ] 金额是否明确
- [ ] 支付时间是否明确
- [ ] 支付条件是否清晰
- [ ] 退款条款是否有

**交付条款**

- [ ] 交付内容是否明确
- [ ] 交付时间是否明确
- [ ] 验收标准是否清晰
- [ ] 修改次数是否限定

**版权条款**

- [ ] 版权归属是否明确
- [ ] 使用范围是否限定
- [ ] 使用期限是否明确
- [ ] 改编权限是否限定

**违约条款**

- [ ] 违约情形是否明确
- [ ] 违约责任是否合理
- [ ] 不可抗力条款是否有

### 2.2 重点条款示例

**合理条款示例**

```
【费用支付】
合同总金额为人民币XX元，分3期支付：
1. 合同签署后3个工作日内，支付30%预付款：XX元
2. 内容交付并验收通过后5个工作日内，支付50%：XX元
3. 合作结束且无异议后5个工作日内，支付20%尾款：XX元

【验收标准】
甲方收到内容后3个工作日内完成验收，逾期未提出异议视为验收通过。
```

**风险条款示例**

```
【风险条款】
甲方验收内容后3个工作日内提出修改意见，修改不超过2次。
如因甲方修改意见导致工作量增加，双方协商追加费用。
```

## 三、维权处理

### 3.1 常见纠纷

**纠纷一：拖欠款项**

- 表现：甲方拖延支付
- 处理：先协商，协商不成发律师函，最后起诉

**纠纷二：额外要求**

- 表现：甲方要求增加工作内容
- 处理：明确合同范围，拒绝免费加量

**纠纷三：版权纠纷**

- 表现：甲方超范围使用
- 处理：发送侵权通知，必要时起诉

### 3.2 维权步骤

**步骤一：保留证据**

- 保留所有沟通记录
- 保留交付证明
- 保留付款记录

**步骤二：友好协商**

- 先尝试协商解决
- 提出合理方案
- 保持专业态度

**步骤三：发函警告**

- 发送律师函
- 明确权利主张
- 设定回复期限

**步骤四：法律途径**

- 起诉到法院
- 申请财产保全
- 委托律师代理

---

## 总结

合同风险防范是创作者必备的技能。通过仔细审核合同条款，识别常见陷阱，明确关键条款，可以有效保护自己的权益。
