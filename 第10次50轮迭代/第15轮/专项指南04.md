# 供应链管理深度实操④：供应商谈判与合同管理

## 一、谈判准备

### 1.1 谈判目标设定

```
谈判目标矩阵：

最优目标（理想）：
- 最低价格
- 最优付款方式
- 最好服务
- 独家合作

可接受目标（现实）：
- 合理价格
- 可行付款方式
- 基本服务
- 稳定合作

底线目标（最低）：
- 成本可接受
- 按时交货
- 质量合格
- 基本配合

谈判策略：
□ 争取最优目标
□ 守住可接受目标
□ 绝不突破底线
```

## 二、谈判技巧

### 2.1 价格谈判

```
价格谈判技巧：

技巧一：多家比价
- 同时接触3-5家供应商
- 获取多个报价
- 创造竞争

技巧二：量价挂钩
- 承诺更大订单量
- 争取更低单价
- 阶梯报价

技巧三：组合谈判
- 多产品打包
- 争取整体折扣
- 综合成本降低

技巧四：付款换优惠
- 现金付款换折扣
- 预付款换低价
- 及时付款换优惠

技巧五：长期合作换优惠
- 承诺年度订单量
- 独家合作换低价
- 长期关系换支持
```

### 2.2 条款谈判

```
关键条款谈判：

交期条款：
- 标准交期
- 加急费用
- 延迟惩罚
- 提前奖励

付款条款：
- 预付款比例
- 尾款时机
- 账期支持
- 付款方式

质量条款：
- 质量标准
- 检验方式
- 不合格率
- 违约责任

退换条款：
- 质量问题退换
- 滞销品处理
- 退货成本
- 责任界定

MOQ条款：
- 最低起订量
- 试单支持
- 分批交货
```

### 2.3 心理战术

```
心理谈判技巧：

技巧一：不先亮底牌
- 让对方先报价
- 了解对方期望
- 掌握谈判主动

技巧二：制造稀缺
- 表示竞争激烈
- 强调名额有限
- 限时优惠

技巧三：欲擒故纵
- 表现出犹豫
- 准备离开姿态
- 争取更好条件

技巧四：合理施压
- 提供合理理由
- 强调双赢
- 维护关系

技巧五：适时让步
- 换取对方让步
- 小让步换大回报
- 维护尊严
```

```
采购合同模板：

甲方（采购方）：
地址：

电话：

地址：

根据《中华人民共和国民法典》及相关法律法规，甲乙双方经友好协商，就甲方向乙方采购产品事宜，达成如下协议：

一、产品信息
产品名称 | 规格 | 数量 | 单价 | 金额
---------|------|------|------|------

二、质量标准
[详细质量要求]

三、交货条款
1. 交货时间：[日期]
2. 交货地点：[地点]
3. 运输方式：[方式]

四、付款条款
1. 预付款：[金额]%
2. 尾款：[金额]%
3. 付款方式：[方式]

五、验收条款
1. 检验期限：[天数]
2. 异议期限：[天数]
3. 检验方式：[方式]

六、违约责任
1. 乙方延期交货，每延期一天支付合同金额[X%]的违约金。

七、其他约定
1. 本合同一式两份，甲乙双方各执一份。
2. 本合同自双方签字盖章之日起生效。
3. 本合同未尽事宜，双方另行协商。

甲方（签章）：       乙方（签章）：
```
