# 供应链管理深度实操③：物流与发货管理

## 一、物流模式选择

### 1.1 物流模式对比

```
物流模式选择矩阵：

模式一：直发模式
- 发货地：中国
- 时效：7-20天
- 成本：低
- 适合：低价产品/非急需

模式二：海外仓模式
- 发货地：海外仓
- 时效：3-7天
- 成本：中
- 适合：高价值/急需

模式三：虚拟海外仓
- 发货地：中国贴标
- 时效：声称3-7天
- 成本：低
- 风险：可能被认为是虚假发货

模式四：多哈本地仓
- 发货地：多哈
- 时效：3-7天
- 成本：中
- 适合：中东市场
```

### 1.2 物流服务商选择

```
物流服务商评估：

评估维度：
- 时效稳定性
- 价格竞争力
- 服务质量
- 清关能力
- 赔偿政策

推荐服务商：

国际快递：
- DHL：速度快，价格高
- FedEx：服务好，价格高
- UPS：美洲优势
- TNT：中东非洲优势

专线物流：
- 中东专线：性价比高
- 美国专线：稳定
- 欧洲专线：清关强

小包渠道：
- 中国小包：价格低
- 外国小包：速度快
```

### 1.3 物流成本计算

```
物流成本构成：

头程费用：
- 国内到仓库
- 仓储费用
- 处理费用

尾程费用：
- 海外配送
- 偏远附加
- 燃油附加

关税费用：
- 进口关税
- 增值税
- 清关费用

其他费用：
- 包装费用
- 保险费用
- 退件费用

总成本 = 头程 + 尾程 + 关税 + 其他
```

## 二、发货流程管理

### 2.1 标准发货流程

```
发货流程：

Step 1：订单获取
- 平台订单同步
- 订单信息确认
- 客户备注查看

Step 2：订单处理
- 库存确认
- 仓库拣货
- 包装准备

Step 3：发货操作
- 面单打印
- 包裹打包
- 称重记录

Step 4：出库扫描
- 扫描发货
- 物流追踪号
- 客户通知

Step 5：物流跟踪
- 物流状态
- 异常处理
- 到达通知

Step 6：签收确认
- 签收记录
- 问题处理
- 评价引导
```

### 2.2 打包标准

```
打包原则：

防护性：
- 防震防压
- 防潮防水
- 防盗防损

经济性：
- 合适尺寸
- 节约材料
- 降低运费

美观性：
- 品牌统一
- 整洁干净
- 专业形象

打包清单：

基础打包：
□ 产品主体
□ 说明书
□ 配件
□ 保修卡

包装材料：
□ 外包装盒
□ 内填充物
□ 封箱胶带
□ 快递单

品牌物料：
□ 品牌贴纸
□ 感谢卡
□ 售后卡
□ 店铺名片
```

### 2.3 异常处理

```
发货异常类型：

包装破损：
- 签收前发现：拒收/拍照留证
- 签收后发现：联系快递索赔

货物丢失：
- 联系快递查找
- 申请索赔
- 补发客户
- 追究责任

发错货物：
- 联系客户道歉
- 安排补发正确货物
- 收回错发货物
- 分析原因

物流延迟：
- 主动通知客户
- 解释原因
- 提供预计时间
- 必要时退款

签收问题：
- 未收到却被签收：调查
- 被代收：沟通确认
- 拒收：安排退回
```

## 三、海外仓管理

### 3.1 海外仓选择

```
海外仓选择标准：

仓库位置：
- 交通便利
- 靠近港口/机场
- 配送网络覆盖

仓库条件：
- 面积充足
- 温度/湿度控制
- 安全性高

服务能力：
- 处理速度
- 系统对接
- 质检服务

费用标准：
- 仓储费
- 操作费
- 配送费
- 附加费

推荐海外仓：

迪拜海外仓：
- 位置优越
- GCC配送快
- 清关便利
- 华人服务

美国海外仓：
- 西海岸仓（覆盖广）
- 东海岸仓（服务美东）
- 华人仓（语言好）
```

### 3.2 库存管理

```
海外仓库存管理：

备货策略：
- 安全库存 = 日均销量 × 备货天数 × 1.2
- 爆款备货：30-60天
- 常规款：15-30天
- 新品测试：少量多次

库存预警：
□ 库存<50%安全库存：预警
□ 库存<20%安全库存：告急
□ 滞销>60天：考虑清仓

调仓处理：
- 仓储费过高：调仓/清仓
- 滞销：清仓/转运
- 断货：紧急补货
```

### 3.3 退货处理

```
海外仓退货流程：

接收退货：
- 客户退货申请
- 仓库接收
- 录入系统

检验处理：
- 外观检验
- 功能检验
- 分类处理

处理方式：
- 良品：重新上架
- 残次：报废/折价
- 退货国内：成本高，不推荐

费用处理：
- 责任方承担
- 仓储费累积
- 及时止损
```

## 四、中东物流指南

### 4.1 中东物流特点

```
中东物流特点：

清关复杂：
- 沙特、阿联酋清关较规范
- 沙特需SASO认证
- 部分产品需要认证

配送特点：
- 本地最后一公里较慢
- 偏远地区覆盖差
- 斋月期间延误

成本特点：
- 关税较高
- 偏远附加费
- 末端配送费用高
```

### 4.2 中东专线选择

```
中东专线推荐：

阿联酋专线：
- 时效：7-15天
- 清关：较稳定
- 配送：Aramex/Noon

沙特专线：
- 时效：10-20天
- 清关：需认证
- 配送：SMSA/Aramex

GCC专线：
- 多国覆盖
- 一单到底
- 成本较高
```

### 4.3 多哈本地发货

```
多哈发货优势：

时效快：
- 境内：1-3天
- GCC：3-7天

服务好：
- 卡塔尔本地快递
- 支持COD（货到付款）

成本：
- 境内：较低
- 跨境：中等

推荐服务商：
- Qatar Post
- Aramex Qatar
- Barton Moving
```
