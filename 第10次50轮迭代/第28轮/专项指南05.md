## 二、评论话术模板

### 2.1 回复模板

**回复感谢**

```
"感谢支持！"
"谢谢你的认可"
"有你的支持真好"
```

**回复提问**

```
"好问题！[回答]"
"这个问题问得好，[详细回答]"
"你说的对，[补充内容]"
```

**回复建议**

```
"谢谢建议，我们会认真考虑"
"好主意！已经记录了"
"感谢反馈，我们会改进"
```

### 2.2 引导话术

**引导评论**

```
"你们觉得呢？评论区聊聊"
"有不同意见吗？"
"来，扣1让我看看有多少人"
```

**引导关注**

```
"喜欢的话点个关注吧"
"关注我，更多精彩内容"
"关注不迷路"
```

**引导互动**

```
"你们遇到过这种情况吗？"
"评论区告诉我"
"你们想要什么内容？"
```
