# 专项指南05：标准化模板体系

## 一、封面模板体系

### 1.1 封面设计原则

**简洁有力**：

- 信息清晰
- 一眼可读
- 避免杂乱

**风格统一**：

- 固定色调
- 固定字体
- 固定版式

**吸引点击**：

- 有视觉冲击
- 有信息钩子
- 有情感共鸣

### 1.2 封面模板类型

**模板类型一：信息型**

- 大标题+副标题
- 背景图+文字叠加
- 适用：知识类、干货类

**模板类型二：人物型**

- 人物居中
- 背景简洁
- 适用：生活类、vlog

**模板类型三：产品型**

- 产品为主
- 卖点突出
- 适用：种草类

**模板类型四：合集型**

- 多图拼贴
- 标题汇总
- 适用：盘点类

### 1.3 Canva模板制作

**模板设计**：

1. 确定尺寸（小绿书9:16/抖音9:16）
2. 设计版式
3. 保存为模板
4. 批量应用

**字体建议**：

- 中文：思源黑体/阿里巴巴普惠体
- 英文：Arial/Helvetica
- 装饰：手写体

## 二、剪辑模板体系

### 2.1 片头模板

**固定片头要素**：

- Logo/账号名
- 系列名称
- 日期/期数

**片头时长**：

- 1-3秒
- 简洁有力
- 可跳过设计

### 2.2 片尾模板

**固定片尾要素**：

- 关注引导
- 下期预告
- 互动话题

**片尾时长**：

- 3-5秒
- 留出互动时间

### 2.3 字幕样式

**字幕规范**：

- 字体统一
- 大小适中
- 颜色醒目
- 位置固定

**字幕模板**：

- 白色描边
- 居中底部
- 自动识别+手动调整

## 三、内容模板体系

### 3.1 文案结构模板

**探店文案结构**：

1. 开头钩子（引发好奇）
2. 场景引入（在哪里）
3. 核心体验（好吃/好玩）
4. 个人感受（真实评价）
5. 实用信息（地址/价格）
6. 结尾互动（引导评论）

**种草文案结构**：

1. 开头痛点（引发共鸣）
2. 产品引入（是什么）
3. 使用体验（好不好）
4. 核心卖点（为什么）
5. 购买引导（怎么买）

### 3.2 脚本模板

**口播脚本模板**：

```
[时长：X秒]
[画面描述：...]
[口播内容：...]
[备注：...]
```

**分镜脚本模板**：

```
镜头1：[时长] [画面描述] [台词] [音效]
镜头2：[时长] [画面描述] [台词] [音效]
```

## 四、模板管理

### 4.1 模板库建立

**模板分类**：

- 封面模板
- 剪辑模板
- 文案模板
- 脚本模板

**模板命名**：

- [类型]_[主题]_[版本]
- 封面_探店_v1.0

### 4.2 模板更新

**定期迭代**：

- 根据数据反馈调整
- 季度更新优化
- 保持新鲜感

**版本管理**：

- 保存历史版本
- 记录修改内容
- 便于回溯

## 五、本章核心要点

1. **封面模板**：设计原则（简洁有力/风格统一/吸引点击）；模板类型（信息型/人物型/产品型/合集型）；字体建议（思源黑体/Arial）

2. **剪辑模板**：片头（Logo/系列名/1-3秒）、片尾（关注引导/下期预告/3-5秒）、字幕样式（统一字体/大小/颜色）

3. **内容模板**：探店结构（开头钩子→场景→体验→感受→信息→互动）、种草结构（痛点→引入→体验→卖点→引导）

4. **模板管理**：建立模板库（分类/命名）、定期迭代更新、版本管理
