# 专项指南02：剪辑调色全流程SOP

## 一、剪辑基础流程

### 1.1 剪辑标准流程

**第一步：素材整理**

- 创建项目文件夹
- 按日期/内容分类素材
- 筛选可用片段
- 备份原始素材

**第二步：粗剪**

- 按顺序排列片段
- 删减冗余部分
- 确定基本结构
- 时长控制在目标范围内

**第三步：精剪**

- 调整片段顺序
- 添加转场效果
- 优化节奏
- 精确到帧

**第四步：调色**

- 基础调色（曝光/对比）
- 风格化调色
- 统一色调
- 肤色校正

**第五步：输出**

- 选择输出格式
- 设置分辨率
- 导出备份

### 1.2 剪辑节奏控制

**节奏原则**：

- 信息密度适中
- 跟随音乐节拍
- 留出呼吸空间

**节奏技巧**：

- 每5-8秒切换画面
- 高潮点使用特写
- 重要信息延长
- 过渡信息加速

### 1.3 转场选择

**常用转场**：

- 叠化（Cross Dissolve）：柔和过渡
- 闪白/闪黑：节奏转换
- 滑动：方向感强
- 缩放：强调重点

**使用原则**：

- 适度使用
- 服务内容
- 避免花哨

## 二、调色全流程

### 2.1 调色基础

**基础参数**：

- 曝光：调整整体明暗
- 对比度：调整明暗反差
- 高光：调整亮部细节
- 阴影：调整暗部细节
- 白色/黑色：调整白场和黑场

**白平衡**：

- 色温：冷暖色调
- 色调：绿-紫调整

### 2.2 风格化调色

**常用风格**：

- 暖色调：温馨、生活感
- 冷色调：专业、冷静
- 电影感：低饱和、高对比
- 小清新：高曝光、低对比

**多哈风格推荐**：

- 暖金色调：配合多哈阳光
- 青色点缀：呼应海洋元素
- 低饱和：高级感

### 2.3 统一色调

**多镜头统一**：

- 选择参考帧
- 复制调色参数
- 微调适配各镜头

**整体氛围**：

- 统一色温
- 统一对比度
- 统一饱和度

## 三、剪映调色教程

### 3.1 基础调色操作

**调整入口**：

剪映 → 调节 → 基本调节

**参数调整**：

- 亮度：+10~+20
- 对比度：+10~+15
- 饱和度：+5~+10
- 色温：+5~-5（根据风格）

### 3.2 风格化调色

**美食调色**：

- 亮度：+15
- 对比度：+15
- 饱和度：+20
- 锐化：+10

**风景调色**：

- 亮度：+10
- 对比度：+20
- 饱和度：+15
- 锐化：+15

### 3.3 滤镜使用

**剪映内置滤镜**：

- 美食：选"暖阳"或"美食"
- 风景：选"清新"或"风景"
- 人像：选"自然"或"人像"

**滤镜+手动调整**：

- 应用滤镜
- 降低滤镜强度（50-70%）
- 微调其他参数

## 四、本章核心要点

1. **剪辑流程**：素材整理（分类/筛选/备份）→粗剪（排列/删减/结构）→精剪（顺序/转场/节奏）→调色（基础/风格/统一）→输出

2. **节奏控制**：5-8秒切换、高潮特写、留出呼吸

3. **调色基础**：曝光/对比/高光/阴影；白平衡（色温/色调）

4. **风格化**：暖色调（温馨）、冷色调（专业）、电影感（低饱和高对比）

5. **剪映调色**：基础参数（亮度+10-20、对比+10-15）、滤镜使用（滤镜+手动调整）
