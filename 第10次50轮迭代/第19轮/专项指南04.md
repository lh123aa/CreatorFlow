# 视觉设计系统构建④：品牌视觉应用

## 一、应用场景

### 1.1 社交媒体应用

```
社交媒体视觉：

头像：
- 统一格式
- 清晰可辨
- 品牌元素

封面：
- 抖音封面
- 小红书封面
- 主页banner

帖子：
- 图片风格统一
- 视觉识别系统
- 品牌调性

视频：
- 片头统一
- 字幕风格
- 水印logo
```

---

## 二、电商素材

### 2.1 产品图规范

```
产品图规范：

白底图：
- 纯白背景
- 产品居中
- 光线均匀
- 多角度

场景图：
- 使用场景
- 生活化
- 有代入感

对比图：
- Before/After
- 效果展示
- 数据对比

细节图：
- 产品特写
- 质量展示
- 质感呈现
```

### 2.2 详情页设计

```
详情页设计：

开头：
- 吸引注意
- 产品亮点
- 痛点共鸣

中间：
- 详细展示
- 功能介绍
- 规格参数
- 买家评价

结尾：
- 行动号召
- 优惠信息
- 购买引导
```

---

## 三、直播素材

### 3.1 直播封面

```
直播封面设计：

设计要素：
- 主播图
- 产品图
- 标题大字
- 品牌logo

风格：
- 明亮干净
- 信息清晰
- 吸引点击
```

### 3.2 直播背景

```
直播背景设计：

背景要素：
- 品牌logo
- 产品展示
- 促销信息
- 品牌色

注意事项：
- 简洁不杂乱
- 文字不过多
- 产品突出
```
