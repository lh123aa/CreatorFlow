# 视觉设计系统构建①：品牌视觉基础

## 一、品牌视觉体系

### 1.1 视觉价值

```
视觉 = 品牌识别 + 用户记忆 + 专业感

视觉重要性：
- 第一印象决定一切
- 品牌识别的核心
- 专业形象的基础
- 用户信任的来源
```

---

## 二、品牌元素

### 2.1 品牌色

```
品牌色选择：

选择原则：
- 符合品牌调性
- 易于识别记忆
- 多场景适用
- 差异化明显

色彩比例：
- 主色（60%）：品牌核心色
- 辅助色（30%）：搭配使用
- 点缀色（10%）：强调使用

常见配色：
- 专业感：蓝色系
- 活力感：橙色/黄色
- 高端感：黑色/金色
- 清新感：绿色/白色
- 女性感：粉色/紫色
```

---

### 3.1 字体选择

```
字体选择：

标题字体：

正文字体：
- 清晰易读
```

## 四、品牌logo

### 4.1 Logo设计

```
Logo设计原则：

简洁独特：
- 简单明了
- 易于识别
- 过目不忘

多场景适用：
- 大小可变
- 颜色可变

版权保护：

- 版权登记
- 保留源文件

常见形式：
- 图形logo
- 文字logo
- 图文结合
```

## 五、视觉规范

### 5.1 色彩规范

```
色彩规范：

色值定义：
- HEX色值（网页）
- RGB色值（屏幕）
- Pantone色值（印刷）

使用比例：
- 主色：60%
- 辅助色：30%
- 点缀色：10%

禁忌搭配：
- 避免撞色
- 避免过杂
- 避免不清
```

### 5.2 字体规范

```
字体规范：

字号系统：
- 标题：24-48px
- 副标题：18-24px
- 正文：14-18px
- 辅助：12px

行间距：
- 正文：1.5-1.8倍
- 标题：1.2倍

字间距：
- 标题：正常
- 正文：正常
- 特殊：微调
```

### 5.3 排版规范

```
排版规范：

网格系统：
- 建立网格
- 对齐元素
- 保持一致

留白规范：
- 适当留白
- 呼吸感
- 不拥挤

对齐方式：
- 左对齐
- 居中
- 右对齐
- 两端对齐

视觉层次：
- 主次分明
- 重点突出
- 逻辑清晰
```
