## 二、设计四大原则

### 2.1 基础原则

```
设计四大原则：

对比（Contrast）：
- 色彩对比
- 尺寸对比
- 字体对比
- 空间对比

重复（Repetition）：
- 品牌元素重复
- 风格统一
- 视觉识别

对齐（Alignment）：
- 元素对齐
- 网格系统
- 整齐有序

亲密性（Proximity）：
- 相关元素靠近
- 无关元素分开
- 信息分组
```

## 三、爆款封面案例

### 3.1 案例分析

```
爆款封面特征：

视觉冲击：
- 大字醒目
- 色彩鲜明
- 有冲击力

信息明确：
- 一眼看出主题
- 关键信息突出
- 降低理解成本

留白适当：
- 不拥挤
- 有呼吸感
- 突出重点

品牌元素：
- 统一风格
- 品牌记忆
- 专业感
```
