# 主题分析示例集

## 示例1：干货分享类

**主题**：如何用AI提高工作效率10倍

```
核心解析：
- 内容核心：AI工具的高效使用方法
- 目标受众：上班族、创业者、效率追求者
- 受众痛点：工作效率低，不知道怎么用AI
- 内容调性：干货分享 + 专业权威

知识匹配：
- 选题类型：痛点型
  原因：效率低是明确痛点，需要解决方案
- 标题类型：数字型 + 利益承诺
  原因："10倍"数字震撼，承诺具体收益
- 正文结构：清单式
  原因：多个工具/方法适合罗列
- 钩子类型：结果前置
  原因：先展示"10倍效率"的结果

知识加载清单：
✓ topic-templates.md（痛点型）
✓ title-templates.md（数字型）
✓ content-templates.md（清单式）
✓ hook-formula.md（结果前置）
```
