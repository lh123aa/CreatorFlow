# CreatorFlow 完整工作流程

## 一、日常学习流程

每天定时学习爆款内容，持续积累知识：

```
搜索热门内容 → 分析案例 → 提取公式 → 更新知识模块 → 同步知识索引
```

### 学习重点
- **选题学习**：分析选题角度，归纳选题类型
- **标题学习**：拆解标题结构，总结标题公式
- **正文学习**：研究内容结构，提炼正文模板
- **设计学习**：分析视觉设计，总结设计规范

### 学习产出
每个学习任务产出：
- 1个新模板/公式
- 更新到对应知识模块
- 同步更新知识索引

---

## 二、创作执行流程

### 步骤1：确定主题

来源：
- 用户指定
- 自主选题（从学习积累中提取）
- 热点追踪

### 步骤2：主题分析

使用 `templates/topic-analysis.md`：

```
主题：________

核心解析：
- 内容核心：________
- 目标受众：________
- 受众痛点：________
- 内容调性：干货/种草/情感/认知刷新

知识匹配：
- 选题类型：________（原因：________）
- 标题类型：________（原因：________）
- 正文结构：________（原因：________）
- 钩子类型：________（原因：________）

知识加载清单：
□ topic-templates.md
□ title-templates.md
□ content-templates.md
□ hook-formula.md
```

### 步骤3：查知识索引

读取 `templates/knowledge-index.md`：
- 确认需要的模块路径
- 快速回顾核心公式

### 步骤4：精确加载知识

只读取主题分析确定的模块，不全量加载。

Token消耗预估：
- 快速创作：~1500 tokens（索引+1-2个模块）
- 完整创作：~3000 tokens（索引+全部模块）

### 步骤5：套用公式创作

按选定模板创作：
1. 用选题公式确定切入角度
2. 用标题公式写标题
3. 用钩子公式写开头
4. 用正文结构写内容
5. 设计封面（如需要）

### 步骤6：检查确认

用 `templates/checklist.md` 逐项确认：
- 选题公式是否应用？
- 标题公式是否应用？
- 钩子公式是否应用？
- 正文结构是否应用？
- 平台规则是否遵守？

---

## 三、复盘迭代流程

### 创作后复盘

```
发布 → 收集数据 → 分析效果 → 优化知识模块
```

复盘要点：
- 哪些公式效果好？
- 哪些公式效果差？
- 是否需要新增模板？
- 是否需要调整匹配逻辑？

### 知识库迭代

根据复盘结果：
1. 新增高效模板
2. 删除低效模板
3. 调整公式权重
4. 更新知识索引

---

## 四、自动化触发

### 定时学习

设置日程任务，每天自动学习：
- 每日选题学习
- 每日标题学习
- 每日正文学习
- 每日设计学习

### 创作触发

用户指令触发创作流程：
- "写一篇小红书笔记"
- "帮我写抖音脚本"
- "做个视频封面"

### 自动匹配

主题分析自动匹配知识模块：
- 识别关键词
- 判断内容类型
- 推荐模板组合

---

## 五、持续优化

### Token优化

- 索引精简：控制在500 tokens
- 模块独立：按需加载
- 公式速查：核心内容记忆化

### 匹配优化

- 记录匹配准确率
- 优化匹配逻辑
- 增加匹配维度

### 内容优化

- 追踪爆款趋势
- 更新过时模板
- 补充新平台规范
