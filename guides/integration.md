# 与AI Agent集成方案

## 一、集成架构

```
┌─────────────────────────────────────────────────────────┐
│                     AI Agent                             │
│  ┌─────────────────────────────────────────────────┐    │
│  │              长期记忆（MEMORY）                    │    │
│  │  - 知识索引精简版                                  │    │
│  │  - 核心公式速查                                    │    │
│  │  - 创作流程说明                                    │    │
│  └─────────────────────────────────────────────────┘    │
│                          ↓                              │
│  ┌─────────────────────────────────────────────────┐    │
│  │              文件系统（知识模块）                   │    │
│  │  - knowledge-base/*.md                           │    │
│  │  - templates/*.md                                │    │
│  └─────────────────────────────────────────────────┘    │
│                          ↓                              │
│  ┌─────────────────────────────────────────────────┐    │
│  │              执行流程                             │    │
│  │  主题分析 → 匹配模块 → 加载知识 → 创作 → 检查       │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

## 二、集成方式

### 方式A：记忆文件集成（推荐）

适用于：Coze、Claude、自建Agent

**步骤**：
1. 将 `templates/knowledge-index.md` 核心内容写入Agent的记忆文件
2. 将 `knowledge-base/` 目录放在Agent可访问的路径
3. Agent执行创作时，按流程读取对应模块

**优点**：
- 简单直接
- 兼容性好
- 易于维护

### 方式B：Skill封装

适用于：支持Skill的Agent平台

**目录结构**：
```
skill_content-creation/
├── SKILL.md              # 执行流程
├── references/
│   ├── knowledge-index.md
│   ├── topic-analysis.md
│   └── checklist.md
└── scripts/
    └── (可选辅助脚本)
```

**SKILL.md 示例**：
```markdown
# 内容创作技能

## 触发条件
用户要求创作内容（写笔记/写脚本/写文章）

## 执行流程
1. 确定主题
2. 读取 references/topic-analysis.md 进行主题分析
3. 根据分析结果读取 references/knowledge-index.md
4. 精确加载需要的知识模块
5. 套用公式创作
6. 用 references/checklist.md 检查

## 输出规范
- 标题：≤15字，有情绪词
- 正文：按选定结构，每句≤15字
- 检查：各环节确认通过
```

### 方式C：RAG检索增强

适用于：有向量数据库的Agent

**流程**：
1. 将知识模块向量化存储
2. 用户提出创作需求
3. 先做主题分析，提取关键词
4. 根据关键词检索相关知识模块
5. 注入上下文生成内容

**优点**：
- 更灵活的匹配
- 支持语义搜索
- 可扩展性强

## 三、定时学习集成

### 设置日程任务

```json
{
  "tasks": [
    {
      "name": "每日选题学习",
      "schedule": "0 7 * * *",
      "action": "学习选题并更新 knowledge-base/topic-templates.md"
    },
    {
      "name": "每日标题学习",
      "schedule": "0 7 * * *",
      "action": "学习标题并更新 knowledge-base/title-templates.md"
    },
    {
      "name": "每日正文学习",
      "schedule": "0 7 * * *",
      "action": "学习正文并更新 knowledge-base/content-templates.md"
    },
    {
      "name": "每日设计学习",
      "schedule": "0 7 * * *",
      "action": "学习设计并更新 knowledge-base/design-templates.md"
    }
  ]
}
```

### 学习任务执行流程

```
1. 搜索当日热门内容
2. 分析1-2个爆款案例
3. 提取公式/模板
4. 更新对应知识模块
5. 同步更新知识索引
```

## 四、自我迭代机制

### 迭代触发条件
- 发布后数据反馈
- 用户明确要求改进
- 发现新趋势/新公式

### 迭代流程
```
收集反馈 → 分析效果 → 优化知识模块 → 更新索引 → 测试验证
```

### 迭代记录
建议维护 `CHANGELOG.md` 记录每次迭代：
- 日期
- 迭代内容
- 效果变化
- 下一步计划

---

*持续迭代，让系统越来越好用*
