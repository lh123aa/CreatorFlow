## 平台规则整合

### 抖音5月算法要点
- 标签颗粒度细化：需标注更精准的细分标签
- 互动权重重分配：评论、转发、收藏权重提升
- 账号垂直度提升：内容一致性要求更高

### 小红书新规要点
- AI标注强制：AI生成内容必须标注
- 标签≤5个：单条笔记标签数量受限
- 标题≤20字：标题长度严格限制

### TikTok美区要点
- 0粉带货：无需粉丝基础即可带货
- 跨境变现：新机遇窗口期

## 关键洞察

### 核心认知
1. 全栈创作者 = 内容创作 + 运营 + 变现 + 技术 + 管理 五位一体
2. 多哈视角 = 跨境变现优先 + 小而美运营 + 中东本地化特色
3. 平台适应 = 抖音算法精细化 + 小红书AI规范 + TikTok0粉带货

### 差异化定位
- 地理优势：多哈——中东国际贸易枢纽
- 受众定位：华人expat + 本地阿拉伯人 + 跨境用户
- 内容特色：稀缺性本地内容 + 跨文化视角 + 实用信息整合
