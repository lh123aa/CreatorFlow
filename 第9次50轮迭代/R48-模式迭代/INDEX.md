## 核心方法论

### 变现模式生命周期

```
导入期（验证可行）→ 成长期（放大规模）→ 成熟期（优化效率）→ 衰退期（考虑转型）
```

### 迭代方向选择

| 类型 | 适用场景 | 风险程度 |
|------|----------|----------|
| 优化型 | 模式有效但效率有空间 | 低 |
| 扩展型 | 原有模式验证成功 | 中 |
| 转型型 | 原有模式失效 | 高 |

### 商业闭环四环节

```
流量闭环 → 转化闭环 → 交付闭环 → 服务闭环
```
