## 核心方法论提炼

### 一、内容模板体系

```
┌─────────────────────────────────────────────────────────┐
│                    内容模板体系                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   选题策划模板                                           │
│   ├── 选题评估模板                                       │
│   ├── 选题扩展模板                                       │
│   └── 选题日历模板                                       │
│                                                         │
│   视频脚本模板                                           │
│   ├── 标准视频模板                                       │
│   ├── 知识讲解模板                                       │
│   ├── 产品测评模板                                       │
│   └── 剧情演绎模板                                       │
│                                                         │
│   图文笔记模板                                           │
│   ├── 种草笔记模板                                       │
│   ├── 干货笔记模板                                       │
│   └── 日常分享模板                                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 二、质量控制三层面

| 层面 | 控制内容 | 关键措施 |
|------|----------|----------|
| 输入控制 | 选题质量、素材质量 | 准入审核、门槛设定 |
| 过程控制 | 制作流程、规范执行 | 节点检查、时间盒管理 |
| 输出控制 | 发布前最终审核 | 清单检查、敏感识别 |

### 三、AI与模板协同流程

```
模板拆分 → AI填充指令 → 人工审核 → 质量平衡
    │                           ↑
    └─── 效果追踪 → 指令优化 ────┘
```
