## 核心方法论提炼

### 一、AI选题系统四层级数据架构

```
┌─────────────────────────────────────────────────┐
│                  AI选题系统                       │
├─────────────────────────────────────────────────┤
│  Layer 1: 平台内生数据（真实可靠）                │
│  └─ 播放量、完播率、互动率、涨粉率                │
│  └─ 搜索趋势、热门话题、竞品数据                  │
│                                                  │
│  Layer 2: 社媒舆情数据（趋势预判）                │
│  └─ Twitter/X热门讨论                            │
│  └─ Reddit垂直社区                               │
│  └─ Instagram/Facebook热门标签                    │
│                                                  │
│  Layer 3: 电商搜索数据（变现连接）                │
│  └─ Google Trends搜索趋势                        │
│  └─ Amazon/Noon畅销榜单                          │
│  └─ 速卖通/Shein热销品类                         │
│                                                  │
│  Layer 4: 创作者生态数据（战略洞察）              │
│  └─ 竞品账号内容表现                             │
│  └─ MCN行业报告                                  │
│  └─ 平台政策变化                                 │
└─────────────────────────────────────────────────┘
```

### 二、热点分类与利用策略

| 热点类型 | 特征 | 生命周期 | 利用策略 |
|----------|------|----------|----------|
| 突发事件型 | 爆发快、衰退快 | 2-48小时 | 2-4小时内快速产出 |
| 周期性热点 | 可预测、持续长 | 数周至数月 | 提前规划、系列化产出 |
| 趋势型热点 | 发展慢、影响深 | 数月至数年 | 深度内容、长期布局 |
| 宗教文化型 | 固定日期、重复 | 年度周期 | 提前6个月规划 |

| 优势维度 | 具体表现 | 选题应用方向 |

| 时区优势 | UTC+3，覆盖亚洲-欧洲黄金时段 | 跨国内容传播、多时区受众覆盖 |
