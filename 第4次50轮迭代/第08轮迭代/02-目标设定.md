# 02-目标设定：SMART原则与目标分解

## 核心概念

### SMART目标
```
S-Specific：具体
M-Measurable：可衡量
A-Achievable：可达成
R-Relevant：相关
T-Time-bound：有时限
```

---

## 操作步骤

### 目标设定
```markdown
【年度目标设定】
1. 粉丝目标：年底粉丝数
2. 收入目标：年度总收入
3. 内容目标：发布数量/爆款率
4. 能力目标：技能提升

【季度目标分解】
- Q1：基础建设期
- Q2：加速成长期
- Q3：稳定维护期
- Q4：冲刺收官期

【月度目标】
- 月度KPI设定
- 周任务分解
- 周度检查
```
