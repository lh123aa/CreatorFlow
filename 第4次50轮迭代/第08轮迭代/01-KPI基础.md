# 01-KPI基础：创作者核心指标体系

## 核心概念

### 创作者KPI体系
```
流量指标：播放/曝光/点击
互动指标：点赞/评论/分享/收藏
增长指标：粉丝/净增
变现指标：收入/转化/客单价
```

---

## 操作步骤

### 指标定义
```markdown
【流量指标】
- 播放量：内容被播放次数
- 曝光量：内容被展示次数
- 点击率(CTR)：点击/曝光×100%

【互动指标】
- 点赞率：点赞/播放×100%
- 评论率：评论/播放×100%
- 分享率：分享/播放×100%
- 收藏率：收藏/播放×100%

【增长指标】
- 净增粉丝：新增-取关
- 涨粉率：涨粉/播放×100%
- 粉丝留存：留存/新增×100%

【变现指标】
- 收入总额
- 转化率
- 客单价
- 复购率
```
