# 05-使用建议

## 快速上手

### 第一步：了解框架

花30分钟通读：
- 本文档（使用指南）
- 第48轮：V61.0框架设计

### 第二步：确定起点

根据自己当前阶段，选择入口：
- 新手：模块一（执行体系）
- 有经验：模块二（商业体系）
- 想扩张：模块三（团队体系）
- 想出海：模块四（全球化）

### 第三步：制定计划

- 选择3-5个最需要的SOP
- 制定30天执行计划
- 每周复盘一次

---

## 深度应用

### 建立个人知识库

1. 挑选最适用的模板
2. 根据自己情况修改
3. 建立个人SOP文档
4. 持续迭代更新

### 实践-复盘循环

```
学习 → 实践 → 复盘 → 优化 → 固化
```

每周：
- 选择1个方法实践
- 记录结果
- 总结改进

每月：
- 回顾本月实践
- 调整下月计划
- 补充相关知识

---

## 持续迭代

### 知识系统更新

- 根据实践经验补充案例
- 根据市场变化更新方法
- 根据用户反馈优化内容

### 贡献与分享

- 实践出真知，欢迎反馈
- 优秀案例可纳入下一版
- 共同完善知识系统
