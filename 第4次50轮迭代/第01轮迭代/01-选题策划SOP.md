# 01-选题策划SOP：从灵感捕捉到爆款选题的完整流程

## 核心概念

### 什么是选题策划SOP
选题策划SOP是一套将"灵感火花"转化为"可执行选题"的标准化流程。它不是限制创意，而是让创意在框架内自由流动，同时确保每个选题都与你的账号定位和变现目标保持一致。

### 多哈创作者的选题优势
在多哈做跨境内容创作，你有独特的视角：
- **东西方交汇点**：可以同时理解中国、中东、西方受众
- **沙漠中的现代城市**：现代化与传统文化并存，天然的内容素材
- **国际化社群**：来自全球的外籍人士，多元文化碰撞
- **时区桥梁**：GMT+3时区覆盖亚洲晚间和欧美白天

### 选题的三层漏斗
```
灵感层 → 验证层 → 执行层
  ↓        ↓        ↓
随意性   数据支撑   可落地
```

## 操作步骤

### Step 1：灵感捕捉系统（每日10分钟）

**时间安排**：每天固定时间捕捉灵感，建议在以下时段：
- 早间浏览（多哈时间7:00-7:10）
- 晚间复盘（多哈时间21:00-21:10）

**灵感来源清单**：
| 来源类型 | 具体渠道 | 记录方式 |
|---------|---------|---------|
| 社交媒体 | TikTok trending、Instagram探索、小红书热榜 | 截图+一句话评论 |
| 新闻资讯 |半岛电视台、Al Jazeera、Reuters | 标题+切入角度 |
| 社区讨论 | Reddit、Quora、Discord群组 | 问题原文+你的回答思路 |
| 同行竞品 | 同领域Top 100账号 | 爆款视频标题+数据 |
| 私信评论 | 粉丝问题、评论区诉求 | 原始问题+情绪标签 |
| 个人生活 | 多哈见闻、工作感悟、旅行经历 | 场景描述+情感共鸣点 |

**工具推荐**：
- **Flomo浮墨**：快速记录，带标签功能
- **Notion数据库**：结构化存储灵感
- **Telegram收藏夹**：临时保存，适合移动端

**执行动作**：
1. 打开灵感记录工具
2. 填写：日期 | 来源平台 | 内容摘要 | 情绪标签 | 可延伸性评估
3. 标记：🔥即时执行 / 📅纳入选题库 / ❌放弃

### Step 2：选题验证系统（每周二/周五30分钟）

**验证维度评分表**：
| 维度 | 权重 | 评分标准（1-10分） | 最低门槛 |
|-----|-----|-------------------|---------|
| 市场需求 | 25% | 目标受众搜索量和讨论热度 | 7分 |
| 差异化 | 20% | 与竞品的角度差异程度 | 6分 |
| 可执行性 | 20% | 所需时间/设备/技能 | 7分 |
| 变现潜力 | 20% | 与变现产品的关联度 | 6分 |
| 情绪共鸣 | 15% | 能否引发强烈情感反应 | 7分 |

**验证工具清单**：
- **Google Trends**：搜索热度趋势
- **微信指数**：中文内容热度（跨境华人受众）
- **TikTok Creative Center**：热门音频和标签
- **BuzzSumo**：社媒内容热度分析
- **AnswerThePublic**：用户问题可视化

**执行动作**：
1. 打开选题验证表
2. 对候选选题逐一打分
3. 计算加权总分
4. 筛选总分≥7.5的选题进入选题库
5. 按热度排序，优先处理高分选题

### Step 3：爆款选题策划（发布前48小时）

**选题卡模板**：
```
【选题卡 #XXX】
日期：[YYYY-MM-DD]
标题：[至少3个备选标题，含数字和情绪词]
格式：[短视频15-60秒/长视频3-10分钟/图文]
核心信息：[一句话说清楚这个内容要传达什么]
钩子设计：[黄金3秒/封面文字/开头问题]
内容框架：
  - 开场（0-5秒）：[具体动作和话术]
  - 主体（5-50秒）：[3个要点/故事线]
  - 结尾（50-60秒）：[CTA行动号召]
情绪标签：[愤怒/惊喜/好奇/恐惧/温暖/搞笑]
BGM/音乐：[具体名称或类型]
预期数据：
  - 目标播放量：[___]
  - 目标点赞：[___]
  - 目标评论：[___]
关联变现：[这个内容如何连接产品/服务]
风险评估：[可能被限流/投诉的敏感点]
替代方案：[如果主选题失败，备选选题]
```

**多哈本地化提示**：
- 涉及中东内容时，注意文化敏感性
- 避免宗教、政治敏感话题的高风险选题
- 善用"沙漠""骆驼""石油财富"等本地元素增加亲近感
- 斋月期间调整内容调性，展现文化尊重

### Step 4：选题排期系统（每周日晚30分钟）

**30天选题日历模板**：
| 周 | 主题方向 | 发布平台 | 发布日期 | 选题卡编号 | 状态 |
|---|---------|---------|---------|-----------|-----|
| 第1周 | [主题] | TikTok/小红书/YouTube | [具体日期] | #001-#003 | ✅ |
| 第2周 | [主题] | 同上 | 同上 | #004-#006 | 🔄 |
| ... | ... | ... | ... | ... | ... |

**排期原则**：
1. **流量型内容**（周二/四/六）：蹭热点、娱乐性强
2. **价值型内容**（周一/三/五）：干货分享、专业性强
3. **变现型内容**（周日）：产品推广、转化导向
4. **休息日**（斋月/节假日）：提前储备内容，灵活调整

### 选题评估计算器
```python
# 选题评分计算
def 选题评分(市场需求, 差异化, 可执行性, 变现潜力, 情绪共鸣):
    权重 = {'需求': 0.25, '差异': 0.20, '执行': 0.20, '变现': 0.20, '情绪': 0.15}
    总分 = (市场需求*权重['需求'] + 
            差异化*权重['差异'] + 
            可执行性*权重['执行'] + 
            变现潜力*权重['变现'] + 
            情绪共鸣*权重['情绪'])
    return round(总分, 2)

# 示例
选题A = 选题评分(8, 7, 9, 6, 8)  # 7.65分
选题B = 选题评分(9, 5, 6, 8, 7)  # 7.15分
# 选题A优先执行
```

## 避坑清单

### ❌ 常见错误
1. **灵感来了不记录**：好点子转瞬即逝，没有建立即时记录习惯
2. **只追热点不顾定位**：蹭热点没有结合账号定位，导致粉丝流失
3. **选题未经验证**：凭感觉做内容，发布后数据惨淡
4. **选题与变现脱节**：流量很高但无法变现
5. **排期过于理想化**：高估自己的产能，导致断更

### ✅ 正确做法
1. **10秒记录法**：灵感来时立刻用手机记录关键词
2. **定位护城河**：每个选题必须回答"为什么这个选题适合我"
3. **数据验证**：发布前用工具验证选题热度
4. **变现前置**：选题策划阶段就设计变现路径
5. **缓冲机制**：每周预留2条备选内容，防止意外断更

### ⚠️ 多哈特殊注意事项
1. **斋月内容调整**：斋月前2周开始降低娱乐内容比例，增加温馨、团圆主题
2. **周五特殊性**：伊斯兰教周五是主麻日，谨慎发布娱乐内容
3. **夏季高温话题**：6-9月多哈40-50°C，夏季内容可结合避暑主题
4. **赛事借势**：F1大奖赛、世界杯等赛事期间，提前1个月规划借势内容
5. **文化敏感性**：避免涉及宗教仪式、政治立场的深度讨论
