# 04-合作资源库建设

## 资源库架构

### 创作者资源类型

**信息资源**：
- 平台政策与规则
- 行业趋势与数据
- 竞品动态分析
- 用户反馈信息

**人脉资源**：
- 创作者同行
- 品牌方/MCN
- 服务商（剪辑/翻译/设计）
- 行业专家/KOL

**工具资源**：
- 效率工具推荐
- 付费服务折扣
- 免费资源分享
- 教程与课程

**商业资源**：
- 品牌合作机会
- 广告联盟资源
- 变现渠道信息
- 投资/孵化机会

---

## 人脉管理系统

### 联系人分级

**A级（核心关系）**
- 合作密切、信任度高
- 定期维护、深度合作
- 利益共享、长期绑定

**B级（重要关系）**
- 有过合作或深度互动
- 潜在合作机会
- 定期联系、价值交换

**C级（一般关系）**
- 初步接触
- 保持关注
- 视情况发展

## 资源对接方法

### 需求匹配策略

**1. 明确自己的资源**
- 我能提供什么？
- 我的独特价值？
- 我想链接什么？

**2. 寻找资源缺口**
- 我缺什么？
- 谁有这些资源？
- 如何建立联系？

**3. 创造交换价值**
- 我能用什么交换？
- 互惠互利模式
- 长期关系投资

### 资源交换模式

```
【能力互换】
你：内容制作能力
对方：推广渠道
→ 合作内容换曝光

【信息互换】
你：中东市场洞察
对方：国内市场资源
→ 市场信息互通

【人脉互换】
你：创作者A介绍给B
对方：品牌方C介绍给你
→ 人脉网络扩展
```

## 资源维护

### 定期维护机制

**月度维护**：
- 核心关系：每月至少1次互动
- 重要关系：每月检查、更新信息
- 一般关系：按需联系

**年度整理**：
- 清理无效联系人
- 更新信息
- 评估关系价值
- 制定下年维护计划

### 维护话术

**节日问候**：
```
"Hi [名字], [节日名称]快乐！很感恩认识你，希望新的一年我们能有更多合作机会。"
```

**价值分享**：
```
"Hi [名字], 刚看到这个[相关信息]，想到你之前说对这个感兴趣，分享给你。"
```

**合作回顾**：
```
"Hi [名字], 我们的[合作]已经[时间]了，效果[评价]，想听听你的想法，顺便聊聊后续合作。"
```
