# 03-Burnout识别与预防：早期信号与应对

## 核心概念

### Burnout三阶段
```
早期信号：疲惫、效率下降、创意枯竭
中期信号：失去兴趣、拖延、社交减少
严重信号：恐惧创作、身体症状、持续抑郁
```

---

## 操作步骤

### 早期信号识别
```markdown
【每日自检】
□ 今天创作感到快乐吗？
□ 感到疲惫吗？
□ 有抵触情绪吗？
□ 睡眠质量如何？

【周度评估】
- 工作热情如何？
- 效率如何？
- 对未来期待？
- 身体状态？
```

### 预防措施
```markdown
【建立边界】
- 固定工作/休息时间
- 不在休息时间工作
- 允许自己说不

【节奏管理】
- 每周1天完全休息
- 每月1个轻松周
- 每季度有假期

【恢复活动】
- 与创作无关的事
- 大自然活动
- 朋友聚会
- 新爱好
```

## 模板工具

### Burnout自检表
```markdown
# Burnout自检

## 过去一周症状
身体：☐疲劳 ☐睡眠差 ☐头痛
情绪：☐无力 ☐烦躁 ☐无成就感
行为：☐拖延 ☐效率低 ☐回避创作

## 评分
0-5分：良好
6-10分：警告
11-15分：需要调整
16-20分：立即休息

## 行动
□ 增加休息
□ 减少任务
□ 寻求帮助
□ 完全休息
```
