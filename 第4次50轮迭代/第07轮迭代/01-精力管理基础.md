# 01-精力管理基础：体能/情感/专注/意义四维度

## 核心概念

### 精力管理四维度
```
体能精力：睡眠/饮食/运动/恢复
情感精力：情绪/人际关系/自我接纳
专注精力：心流/目标聚焦/避免干扰
意义精力：使命/价值观/内在动力
```

---

## 操作步骤

### 体能精力管理
```markdown
【睡眠管理】
- 固定作息时间
- 每晚7-8小时
- 睡前1小时不看手机

【饮食管理】
- 早餐必吃
- 少食多餐
- 充足水分

【运动管理】
- 每周3-5次
- 每次30-60分钟
```

### 情感精力管理
```markdown
【情绪维护】
- 晨间冥想
- 压力释放
- 情绪记录

【人际关系】
- 家人时间
- 朋友联系
- 同行交流
```

### 专注精力管理
```markdown
【进入心流】
- 消除干扰
- 明确目标
- 技能-挑战平衡

【避免干扰】
- 手机静音
- 关闭通知
- 固定时间查看
```

### 意义精力管理
```markdown
【使命确认】
- 创作初心
- 目标受众
- 长期愿景

【意义感来源】
- 帮助他人
- 自我成长
- 成就感
```
