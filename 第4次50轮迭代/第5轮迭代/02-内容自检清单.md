# 02-内容自检清单：从标题到结尾的全流程检查

## 核心概念

### 自检是最后防线

内容自检是发布前最重要的环节：
- 防止低级错误
- 提升内容质量
- 保护账号安全
- 节省后续精力

### 自检时间分配

```markdown
【标准自检时间】
- 视频内容：15-20分钟
- 图文笔记：10-15分钟
- 长视频：20-30分钟

【时间分配】
- 完整观看/阅读：40%
- 问题标记：20%
- 修改调整：30%
- 最终确认：10%
```

## 操作步骤

### 第一步：标题自检

#### 标题质量检查

```markdown
【标题自检清单】
□ 标题清晰表达内容
□ 核心关键词包含
□ 无错别字/语法错误
□ 无夸大误导
□ 无敏感词/违规词
□ 长度适中（25字以内）
□ 符合平台风格

【标题优化检查】
□ 数字是否准确
□ 悬念是否合理
□ 价值是否明确
□ 是否有吸引力

【违规词检查】
- 最全/最强/第一
- 绝对化用语
- 虚假夸大
- 政治敏感词
- 平台禁词
```

#### 常见标题问题

```markdown
【问题标题类型】
1. 标题党
   - 问题：夸大与内容不符
   - 后果：用户流失，影响信任
   - 修复：如实描述，突出价值

2. 无关键词
   - 问题：没有搜索流量
   - 后果：曝光受限
   - 修复：加入目标关键词

3. 无吸引力
   - 问题：平淡无奇
   - 后果：点击率低
   - 修复：制造好奇/痛点/数字

4. 违规风险
   - 问题：包含敏感词
   - 后果：限流/下架
   - 修复：替换合规词汇
```

### 第二步：开头自检

#### 视频开头检查

```markdown
【视频开头自检】
□ 前3秒是否有钩子
□ 核心问题/价值是否明确
□ 是否引起好奇心
□ 用户是否会继续看
□ 背景/声音是否正常

【开头质量评估】
| 问题 | 评估 |
|-----|-----|
| 能否在3秒内抓住注意力？ | ☐是 ☐否 |
| 是否快速进入主题？ | ☐是 ☐否 |
| 是否有价值承诺？ | ☐是 ☐否 |
| 是否设置悬念/期待？ | ☐是 ☐否 |

【常见开头问题】
1. 废话太多
   - 问题：说了很多但没内容
   - 修复：直接进入主题

2. 场景混乱
   - 问题：一开始画面/声音问题
   - 修复：重新剪辑开头

3. 价值不清
   - 问题：用户不知道能得到什么
   - 修复：明确价值承诺
```

#### 图文开头检查

```markdown
【图文开头自检】
□ 开头是否有吸引力
□ 是否快速切入主题
□ 是否有悬念/痛点
□ 配图是否吸引人
□ 排版是否清晰

【开头优化建议】
- 开头30字内出现关键词
- 用痛点/问题/数字开头
- 避免冗长的背景铺垫
```

### 第三步：正文自检

#### 内容完整性检查

```markdown
【正文自检清单】
□ 核心信息是否完整
□ 逻辑是否清晰
□ 重点是否突出
□ 案例/数据是否准确
□ 是否有信息增量
□ 是否解决用户问题

【结构检查】
□ 是否有清晰框架
□ 层次是否分明
□ 过渡是否自然
□ 详略是否得当

【信息检查】
□ 数据来源是否可靠
□ 案例是否有代表性
□ 观点是否有依据
□ 建议是否可行
```

#### 表达质量检查

```markdown
【表达自检】
□ 语言流畅无病句
□ 专业术语使用恰当
□ 无错别字/标点错误
□ 避免重复啰嗦
□ 节奏控制得当

【常见表达问题】
1. 语句不通顺
   - 问题：语法错误
   - 修复：朗读检查

2. 专业术语堆砌
   - 问题：用户看不懂
   - 修复：解释说明

3. 过于口语化
   - 问题：不够专业
   - 修复：适度调整

4. 逻辑跳跃
   - 问题：跳跃太快
   - 修复：补充过渡
```

### 第四步：结尾自检

#### 视频结尾检查

```markdown
【视频结尾自检】
□ 是否总结核心要点
□ 是否有价值承诺
□ CTA是否清晰
□ 引导是否自然
□ 是否留下深刻印象

【结尾质量检查】
□ 结尾是否有升华
□ 是否引导互动
□ 是否引导关注
□ 是否预告后续

【常见结尾问题】
1. 戛然而止
   - 问题：没有收尾
   - 修复：增加总结

2. CTA生硬
   - 问题：要求太直接
   - 修复：自然融入

3. 虎头蛇尾
   - 问题：结尾草草了事
   - 修复：精心设计结尾
```

### 第五步：视觉自检

#### 视觉质量检查

```markdown
【视觉自检清单】
□ 画面清晰度
□ 光线是否正常
□ 声音是否清晰
□ 字幕是否完整准确
□ 封面图是否吸引
□ 排版是否美观

【技术检查】
□ 无画面抖动
□ 无噪点杂音
□ 无色差问题
□ 无卡顿现象
□ 导出格式正确

【品牌检查】
□ 品牌元素统一
□ 水印位置合适
□ 风格一致
```

## 避坑清单

### ❌ 自检常见错误

1. **自检走过场**
   - 正确：认真逐项检查

2. **只看不修**
   - 正确：发现问题立即修复

3. **自检依赖工具**
   - 正确：工具+人工结合

4. **急于发布跳过自检**
   - 正确：留足自检时间

5. **只修不改**
   - 正确：彻底解决问题
