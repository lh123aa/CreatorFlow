# 03-合作关系管理

## 日常合作模式

### 理想合作状态

**创作者职责**：
- 内容创作（主导）
- 粉丝互动
- 内容发布

**MCN职责**：
- 品牌对接
- 商务谈判
- 资源提供
- 策略建议

### 沟通机制

**定期沟通**：
- 周度：快速进展同步
- 月度：数据复盘与规划
- 季度：战略回顾与调整

**沟通渠道**：
- 商务事项：邮件/微信
- 紧急事项：电话
- 日常对接：专属对接群

## 冲突解决

### 常见冲突类型

**类型1：资源分配不均**
- 表现：MCN资源倾向其他创作者
- 解决：明确资源承诺条款

**类型2：品牌选择分歧**
- 表现：MCN推的品牌你不认可
- 解决：建立品牌筛选标准

**类型3：分成结算争议**
- 表现：对账金额有出入
- 解决：建立透明结算机制

**类型4：沟通不畅**
- 表现：对接人不专业/响应慢
- 解决：明确沟通预期

### 解决流程

```
Step 1：私下沟通解决
→ 直接与对接人沟通

Step 2：升级沟通
→ 联系MCN管理层

Step 3：合同条款对照
→ 对照合同执行

Step 4：第三方调解
→ 行业协会/律师

Step 5：法律行动
→ 走法律程序（最后手段）
```

## 合作评估

### 定期评估维度

| 维度 | 评估标准 | 评估频率 |
|------|---------|---------|
| 资源获取 | 获得了多少有价值资源？ | 季度 |
| 收入增长 | 收入是否比独立时增长？ | 季度 |
| 成长支持 | MCN提供了哪些成长支持？ | 半年 |
| 合作体验 | 沟通/配合是否顺畅？ | 持续 |

### 评估决策

```
资源丰富 + 收入增长 + 体验良好 = 继续合作
资源一般 + 收入持平 + 体验尚可 = 续约谈判
资源匮乏 + 收入下降 + 体验糟糕 = 考虑解约
```
