# 02-合同谈判要点

## 合同核心条款

### 必须明确的条款

**1. 分成比例**
```
常见分成：
MCN 20-30% / 创作者 70-80% → 可接受
MCN 40-50% / 创作者 50-60% → 需谈判
MCN 50%+ / 创作者 <50% → 拒绝

注意：区分不同收入来源
- 平台广告：分成比例
- 品牌合作：分成比例
- 带货销售：分成比例
```

**2. 合同期限**
- 建议：1年+续约选项（而非长期绑定）
- 注意：提前解约条款
- 警惕：超长合约期（5年+）

**3. 内容控制权**
- 问：内容创意谁决定？
- 问：账号归属谁？
- 问：MCN能否单方面操作账号？

**4. 竞业条款**
- 问：解约后能否立即签约其他MCN？
- 问：解约后能否从事同类内容？
- 注意：竞业限制范围要合理

---

## 谈判策略

### 谈判原则

**1. 底线清晰**
- 确定自己的底线（分成、期限、权利）
- 不突破底线

**2. 筹码运用**
- 你的流量/影响力是筹码
- 可替代选项是筹码
- 专业形象是筹码

**3. 交换思维**
- 放弃一些对你不重要的
- 争取你真正在乎的

### 谈判话术

**开场**：
```
"我对合作很感兴趣，但有几个条款想讨论一下..."
```

**争取分成**：
```
"我的账号是我独立运营长大的，MCN的贡献主要是资源对接。
我建议按XX%/YY%分成，可以接受吗？"
```

**争取期限**：
```
"第一年合作后，我们双向选择续约，这样对双方都公平。"
```

**争取权利**：
```
"内容创意我希望能主导，毕竟账号是我的。
MCN提供资源支持，最终内容决策权在我这边。"
```

## 必须争取的条款

### 保护性条款

**必须有的**：
1. **内容终审权**：自己决定发布内容
2. **账号控制权**：账号属于你
3. **合理分成**：MCN不超30%
4. **灵活期限**：1年+续约
5. **清晰退出**：解约条件明确

**最好有的**：
- 最低保底收入
- MCN资源承诺
- 独家范围限定

**最好没有的**：
- 内容审核权归MCN
- 账号归属MCN
- 超高违约金
- 无限竞业限制

## 法律建议

### 签约前必做

1. **找律师看合同**（尤其是第一条合同）
2. **逐条确认理解**
3. **不签"理解空白"的条款**
4. **保留沟通记录**

### 常见陷阱

**陷阱1**：模糊分成定义
- 问题："商业收入"包括哪些？
- 要求：明确定义收入范围

**陷阱2**：无限续约权
- 问题：MCN单方面决定续约
- 要求：双向同意续约

**陷阱3**：高额违约金
- 问题：解约要赔几十万
- 要求：违约金上限合理
