# 04-退出机制设计

## 退出时机

### 正常退出

**合约期满不续**：
- 提前30-60天通知
- 完成在途合作项目
- 友好交接

### 提前退出

**正当理由**：
- MCN违约（资源未提供）
- 双方协商一致
- 不可抗力因素

**被动退出**：
- MCN单方面解约
- 严重违约被终止

---

## 退出注意事项

### 关键问题

**账号归属**：
- 账号是否归你？
- MCN是否会删除内容？
- 粉丝数据如何处理？

**收入结算**：
- 在途收入如何结算？
- 未付款项如何追讨？
- 分成比例是否追溯？

**竞业限制**：
- 解约后多久能签约其他MCN？
- 能从事什么类型内容？
- 地域限制如何？

**违约责任**：
- 提前解约是否需要赔偿？
- 赔偿金额是否合理？

---

## 退出流程

### 标准退出流程

```
1. 提前通知（30-60天）
   → 书面通知对方

2. 盘点现状
   → 梳理合作项目/收入/关系

3. 协商交接
   → 确定账号/资源/数据归属

4. 完成结算
   → 结清所有款项

5. 正式解约
   → 签署解约协议

6. 后续处理
   → 通知合作方/更新信息
```

### 解约协议要点

```
【解约协议内容】
1. 双方确认解约
2. 账号归属确认
3. 收入结算确认
4. 竞业限制约定（如有）
5. 保密条款延续
6. 双方免责条款
```

---

## 预防性措施

### 签约时就要考虑退出

**合同必备条款**：
- 清晰的解约条件
- 合理的违约金上限
- 账号归属明确
- 竞业限制范围合理

**日常风险控制**：
- 保留所有合作记录
- 定期核对收入账目
- 维护独立运营能力
- 建立备用资源渠道
