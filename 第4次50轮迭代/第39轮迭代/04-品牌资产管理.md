# 04-品牌资产管理

## 知识产权基础

### 创作者常见IP类型

| 类型 | 内容 | 保护方式 |
|------|------|---------|
| 商标 | 品牌名/Logo | 商标注册 |
| 版权 | 内容/文章/视频 | 自动产生+登记 |
| 专利 | 发明/方法 | 专利申请 |
| 域名 | 网站地址 | 域名注册 |

### 国际化保护策略

**核心资产识别**：
1. 品牌名称（中文+英文）
2. Logo/视觉标识
3. 内容版权（原创内容）
4. 域名资产

---

## 商标注册

### 全球商标策略

**马德里体系**（推荐国际注册）：
- 一次申请，多国保护
- 覆盖120+国家
- 成本效率高

**申请流程**：
1. 确定商标标识
2. 选择商品/服务类别
3. 提交申请
4. 审查公告
5. 注册发证

**重点注册国家**：
- 中国（品牌来源地）
- 美国（国际影响）
- 阿联酋（区域中心）
- 欧盟（欧洲市场）

### 注册类别建议

**创作者相关类别**：
- Class 35：广告、商业管理
- Class 41：教育娱乐、内容制作
- Class 42：网站、技术服务
- Class 9：APP、软件

## 内容版权保护

### 版权登记

**为什么要登记**：
- 确权证明
- 维权依据
- 商业变现

**登记途径**：
- 中国：版权登记中心
- 美国：Copyright Office
- 数字存证：时间戳+区块链

### 版权管理

**内容确权清单**：
- [ ] 每条视频/文章完成记录
- [ ] 建立内容发布档案
- [ ] 保留创作证据（草稿、修改记录）
- [ ] 定期备份存储

### 侵权应对

**预防措施**：
- 水印标识
- 平台举报机制
- 定期监测

**维权流程**：
1. 发现侵权（监测）
2. 证据保全（截图/公证）
3. 沟通删除（优先）
4. 平台投诉（次选）
5. 法律行动（必要时）

---

## 域名资产

### 域名策略

**核心域名**：
- 品牌名.com（必须）
- 品牌名.net
- 品牌名.cn

**域名管理**：
- 使用专业域名管理（阿里云/GoDaddy）
- 开启自动续费
- 保护隐私注册
- 考虑多个后缀

### 社媒账号保护

**核心平台占位**：
- 所有主要平台注册账号
- 即使暂时不用
- 保持活跃防抢注
