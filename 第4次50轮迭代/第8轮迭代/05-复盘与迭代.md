# 05-复盘与迭代：持续改进机制

## 核心概念

### 复盘的重要性

复盘是持续改进的基础：
- 总结经验教训
- 识别问题原因
- 固化成功做法
- 持续优化提升

### 复盘类型

```markdown
【复盘类型】
1. 日复盘
   - 快速回顾
   - 10-15分钟
   - 每日坚持

2. 周复盘
   - 深度总结
   - 30-60分钟
   - 每周固定

3. 月复盘
   - 系统评估
   - 1-2小时
   - 月底进行

4. 季复盘
   - 战略复盘
   - 半日/一日
   - 季度末进行
```

## 操作步骤

### 第一步：日复盘

#### 日复盘流程

```markdown
【日复盘四步】
1. 回顾目标（2分钟）
   - 今日目标是什么？
   - 完成情况如何？

2. 评估结果（5分钟）
   - 做得好的？
   - 做的不好的？
   - 有何差距？

3. 分析原因（5分钟）
   - 成功原因？
   - 失败原因？
   - 关键因素？

4. 总结经验（3分钟）
   - 学到什么？
   - 下次改进？
   - 记录要点？

【日复盘模板】
今日完成：
-
-
今日问题：
-
-
明日计划：
-
-
```

#### 日复盘要点

```markdown
【日复盘要点】
1. 快速简洁
   - 10-15分钟
   - 不要过度分析

2. 聚焦重点
   - 关键任务
   - 关键问题

3. 记录要点
   - 成功经验
   - 失败教训
   - 改进行动

4. 持续坚持
   - 每天进行
   - 养成习惯
```

### 第二步：周复盘

#### 周复盘流程

```markdown
【周复盘六步】
1. 数据回顾（10分钟）
   - KPI完成情况
   - OKR周进度
   - 关键指标变化

2. 目标回顾（5分钟）
   - 本周目标是什么？
   - 完成情况？

3. 亮点总结（10分钟）
   - 做得好的是什么？
   - 成功的关键因素？

4. 问题分析（10分钟）
   - 做不好的什么？
   - 失败的根本原因？

5. 经验提炼（10分钟）
   - 学到什么？
   - 可复制经验？

6. 下周计划（10分钟）
   - 下周目标
   - 重点任务
   - 改进措施
```

### 第三步：月/季度复盘

#### 月度复盘流程

```markdown
【月度复盘八步】
1. 月度数据汇总
   - KPI完成情况
   - OKR月度评估
   - 重大事件

2. 目标达成评估
   - 完成/未完成
   - 完成度百分比
   - 差距分析

3. 成功经验总结
   - 做得好的
   - 成功因素
   - 可复制经验

4. 问题深度分析
   - 失败的问题
   - 根本原因
   - 系统性问题

5. 根本原因挖掘
   - 5Why分析
   - 避免表面原因

6. 经验教训提炼
   - 固化成功
   - 避免失败

7. 下月计划制定
   - 目标设定
   - 策略调整
   - 资源规划

8. OKR评估更新
   - 评估完成度
   - 分析差距原因
   - 调整下月OKR
```

## 避坑清单

### ❌ 复盘常见误区

1. **形式主义**
   - 正确：认真复盘有收获

2. **只总结不行动**
   - 正确：必须有改进行动

3. **不分析根本原因**
   - 正确：深挖根本原因

4. **不记录不追踪**
   - 正确：记录并追踪执行

5. **不复盘复盘本身**
   - 正确：优化复盘方法
