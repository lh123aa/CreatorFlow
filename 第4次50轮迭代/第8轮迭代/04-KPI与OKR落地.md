# 04-KPI与OKR落地：执行与追踪

## 核心概念

### 落地执行的重要性

好的KPI和OKR需要有效执行：
- 执行才能创造价值
- 追踪才能发现问题
- 沟通才能保持对齐
- 调整才能持续改进

### 执行追踪框架

```markdown
【执行追踪循环】
制定计划 → 执行行动 → 数据追踪 → 评估反馈 → 调整优化

【追踪频率】
- 日追踪：关键日指标
- 周追踪：KPI/OKR周进度
- 月追踪：OKR月度评估
- 季追踪：OKR季度复盘
```

---

## 操作步骤

### 第一步：制定执行计划

#### 任务分解

```markdown
【OKR任务分解】
1. OKR → 月目标
   - 季度KR → 月度KR
   - 设定月度里程碑

2. 月目标 → 周任务
   - 月度目标 ÷ 4 = 周目标
   - 每周关键任务

3. 周任务 → 日行动
   - 周任务 ÷ 5 = 日任务
   - 每日优先事项

【任务分解表】
| OKR/KPI | 月目标 | 周目标 | 日任务 |
|---------|-------|-------|-------|
| 涨粉2万 | 2万 | 5000 | 1000 |
| 发布20条 | 20条 | 5条 | 1条 |
| 收入10万 | 10万 | 2.5万 | 5000 |
```

#### 资源配置

```markdown
【资源规划】
1. 时间资源
   - 每日可用时间
   - 任务时间分配
   - 优先级排序

2. 人力资源
   - 自我执行
   - 团队协作
   - 外包支持

3. 财务资源
   - 预算分配
   - 投入产出
   - 投资回报

【资源配置原则】
- 把资源集中在最重要的OKR上
- 预留缓冲应对意外
- 定期评估资源配置
```

### 第二步：执行追踪

#### 日常追踪

```markdown
【每日追踪】
1. 晨会/晨间规划（10分钟）
   - 今日重点任务
   - OKR进度确认
   - 优先级排序

2. 日中检查（5分钟）
   - 任务进展
   - 问题识别
   - 调整需要

3. 晚间复盘（10分钟）
   - 今日完成情况
   - 明日计划
   - 记录问题

【日常追踪工具】
- 待办清单
- 日程表
- 专注计时器
```

#### 周度追踪

```markdown
【周度追踪】
1. 周一：周计划（15分钟）
   - 本周OKR进度
   - 关键任务确认
   - 资源协调

2. 周中检查（10分钟）
   - 进度追踪
   - 问题处理
   - 风险预警

3. 周五：周复盘（30分钟）
   - 本周完成情况
   - KPI/OKR进度
   - 下周计划

【周度追踪内容】
- KPI完成情况
- OKR周进度
- 风险和问题
- 需要的支持
```

### 第三步：沟通协调

#### 内部沟通

```markdown
【自我沟通】
1. 与自己对齐
   - 清晰理解目标
   - 保持动机
   - 自我激励

2. 与团队对齐
   - 如果有团队
   - 目标一致
   - 互相支持

【沟通频率】
- 每日：快速同步
- 每周：深度复盘
- 每月：战略对齐
- 每季：全面评估
```

#### 问题升级

```markdown
【问题升级机制】
1. 问题分类
   - 自我解决：日常问题
   - 团队协作：需要支持
   - 战略调整：重大问题

2. 升级标准
   - 风险影响目标达成
   - 需要额外资源
   - 目标需要调整

3. 升级流程
   - 清晰描述问题
   - 说明影响
   - 提出建议
   - 寻求支持
```

## 避坑清单

### ❌ 执行追踪误区

1. **只追踪不行动**
   - 正确：追踪是为了改进

2. **追踪过于频繁**
   - 正确：适度追踪，重点执行

3. **忽视问题**
   - 正确：及时处理问题

4. **不调整计划**
   - 正确：根据情况灵活调整

5. **不与目标对齐**
   - 正确：时刻对标OKR
