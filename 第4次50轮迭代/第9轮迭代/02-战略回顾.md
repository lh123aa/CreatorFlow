# 02-战略回顾：方向与目标的重新审视

## 核心概念

### 战略回顾的意义

战略回顾是对大方向的审视：
- 验证战略方向是否正确
- 评估目标是否仍然合理
- 判断策略是否需要调整
- 确保走在正确的路上

### 战略回顾框架

```markdown
【战略回顾三问】
1. 我们是否在做正确的事？
   - 市场定位
   - 目标用户
   - 核心价值

2. 我们是否在做有效的事？
   - 策略有效性
   - 执行到位性
   - 资源配置合理性

3. 我们是否在做可持续的事？
   - 商业模式
   - 能力积累
   - 竞争优势
```

## 操作步骤

### 第一步：战略方向审视

#### 市场定位审视

```markdown
【市场定位审视】
1. 定位是否清晰
   - 用户是否清楚你是做什么的？
   - 定位是否与目标用户匹配？

2. 定位是否有差异
   - 与竞品有什么不同？
   - 用户为什么选择你？

3. 定位是否可持续
   - 定位能支撑长期发展吗？
   - 定位能抵御竞争吗？

【审视结论】
☐ 定位清晰且正确
☐ 定位需要微调
☐ 定位需要重大调整
```

#### 目标用户审视

```markdown
【目标用户审视】
1. 用户画像是否清晰
   - 用户是谁？
   - 用户需求是什么？
   - 用户行为特点？

2. 用户是否在扩大
   - 用户规模增长？
   - 用户需求变化？

3. 用户是否需要调整
   - 现有用户是否还有价值？
   - 是否需要拓展新用户？
   - 是否需要聚焦细分用户？

【审视结论】
☐ 用户定位准确
☐ 用户需要调整范围
☐ 用户需要重新定义
```

### 第二步：目标合理性审视

#### 目标达成评估

```markdown
【目标达成分析】
1. 为什么达成了？
   - 目标设定合理？
   - 执行到位？
   - 市场机会好？

2. 为什么没达成？
   - 目标过高？
   - 执行不力？
   - 环境变化？

3. 目标是否需要调整？
   - 基于复盘发现
   - 基于环境变化
   - 基于能力评估
```

#### 目标合理性判断

```markdown
【目标合理性四维度】
1. 外部环境
   - 市场空间是否够大？
   - 增长趋势是否持续？
   - 竞争格局是否有利？

2. 内部能力
   - 能力是否支撑？
   - 资源是否充足？
   - 执行是否有力？

3. 历史表现
   - 历史增长率？
   - 达成规律？
   - 波动情况？

4. 发展潜力
   - 边际成本？
   - 增长极限？
   - 突破机会？

【判断结论】
☐ 目标合理，可保持
☐ 目标略高，可微调
☐ 目标过高，需下调
☐ 目标过低，可上调
```

### 第三步：战略有效性审视

#### 策略有效性评估

```markdown
【策略有效性评估】
1. 内容策略

3. 变现策略

   - 商业模式是否可持续？
```

### ❌ 战略审视误区

1. **路径依赖**
   - 正确：跳出惯性思考

2. **过度自信**
   - 正确：保持谦逊开放

3. **只看到自己想看的**
   - 正确：客观看待现实

4. **不质疑前提**
   - 正确：挑战基本假设

5. **调整过于频繁**
   - 正确：区分调整和摇摆
