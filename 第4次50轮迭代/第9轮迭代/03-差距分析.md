# 03-差距分析：深度挖掘问题根源

## 核心概念

### 差距分析的意义

差距分析是找到问题的根本原因：
- 不只是看到表面问题
- 更要找到深层原因
- 避免头痛医头
- 找到系统性解决方案

### 差距类型

```markdown
【差距分类】
1. 执行差距
   - 知道但没做到
   - 执行不到位

2. 能力差距
   - 不知道怎么做
   - 能力不足

3. 资源差距
   - 没有足够资源
   - 资源分配不当

4. 目标差距
   - 目标设定不合理
   - 目标过高或过低

5. 环境差距
   - 市场环境变化
   - 外部因素影响
```

## 操作步骤

### 第一步：识别关键差距

#### 差距识别方法

```markdown
【差距识别矩阵】
| 目标 | 实际 | 差距 | 重要性 | 紧迫性 |
|-----|-----|-----|-------|-------|
| | | | | |

【差距优先级】
- P0：重要且紧急，必须解决
- P1：重要但不紧急，规划解决
- P2：不重要但紧急，委托解决
- P3：不重要不紧急，考虑放弃

【关键差距选择】
- 选择影响最大的差距
- 选择根本性的差距
- 选择有能力解决的差距
```

#### 差距量化

```markdown
【差距量化方法】
1. 绝对差距
   - 差距 = 目标 - 实际
   - 量化差距大小

2. 相对差距
   - 完成率 = 实际/目标 × 100%
   - 量化完成程度

3. 趋势差距
   - 趋势方向
   - 差距变化

【差距量化表】
| KPI | 目标 | 实际 | 绝对差距 | 完成率 | 优先级 |
|-----|-----|-----|---------|-------|-------|
| | | | | | |
```

### 第二步：深度分析原因

#### 5Why分析法

```markdown
【5Why分析】
层层追问，找到根本原因

【示例】
问题：季度涨粉未达标

Why1：为什么涨粉没达标？
→ 因为爆款内容太少

Why2：为什么爆款内容少？
→ 因为选题不够吸引人

Why3：为什么选题不吸引人？
→ 因为没有做用户调研

Why4：为什么没做用户调研？
→ 因为时间都花在制作上

Why5：为什么时间都花在制作上？
→ 因为没有建立选题流程

根本原因：没有建立选题流程

【解决方案】
→ 建立选题策划流程
→ 每周做用户需求调研
→ 提前规划爆款选题
```

#### 鱼骨图分析法

```markdown
【鱼骨图分析】
从多个维度分析原因

【人】      【机】      【料】
   ↑          ↑          ↑
   └──────────┼──────────┘
              ↓
          【问题】
              ↑
   ┌──────────┼──────────┐
   ↓          ↓          ↓
【法】      【环】      【测】

【维度】
- 人：人员、能力、态度
- 机：工具、设备、系统
- 料：资源、材料、信息
- 法：方法、流程、制度
- 环：环境、时机、氛围
- 测：标准、测量、评估
```

### 第三步：制定根因解决方案

#### 解决方案制定

```markdown
【解决方案框架】
1. 针对根本原因
   - 不是症状，而是原因
   - 解决根本才能根除

2. 可执行可落地
   - 有具体行动
   - 有资源支持
   - 可量化结果

3. 成本效益合理
   - 投入产出比
   - 优先级排序

【解决方案模板】
问题：[描述问题]
根本原因：[分析出的根本原因]
解决方案：[具体解决方案]
行动项：[可执行的动作]
责任人：[谁负责]
完成时间：[何时完成]
预期效果：[解决后的状态]
```

#### 解决方案优先级

```markdown
【优先级矩阵】
| 解决方案 | 效果 | 成本 | 优先级 |
|---------|-----|-----|-------|
| | 高/中/低 | 高/中/低 | |
| | | | |

【优先级原则】
- 效果好+成本低 → 立即执行
- 效果好+成本高 → 规划执行
- 效果低+成本低 → 考虑执行
- 效果低+成本高 → 放弃
```

## 避坑清单

### ❌ 差距分析误区

1. **只看表面**
   - 正确：深挖根本原因

2. **归因于外**
   - 正确：从自身找原因

3. **找借口**
   - 正确：客观分析

4. **分析过度**
   - 正确：抓住关键原因

5. **有分析无行动**
   - 正确：必须有解决方案和行动
