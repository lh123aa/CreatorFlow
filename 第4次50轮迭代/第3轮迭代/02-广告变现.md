# 02-广告变现：品牌合作与广告接单

## 核心概念

### 广告变现原理

广告变现是通过内容为品牌创造价值，获得报酬：
- 按曝光计费（CPM）
- 按点击计费（CPC）
- 按转化计费（CPA/CPS）

### 广告类型

```markdown
【广告类型分类】
1. 品牌广告
   - 深度合作
   - 品牌调性契合
   - 报价高
   - 案例：定制视频、专场直播

2. 植入广告
   - 内容中自然植入
   - 软性推广
   - 中等报价
   - 案例：口播、道具植入

3. 贴片广告
   - 固定位置广告
   - 标准化报价
   - 报价低
   - 案例：片头片尾

4. 效果广告
   - 按效果付费
   - 风险共担
   - 佣金模式
   - 案例：带货分佣
```

## 操作步骤

### 第一步：准备广告报价

#### 报价体系设计

```markdown
【报价计算公式】
基础报价 = 单条平均播放 × CPM系数 × 互动系数

【参考报价参数】
| 指标 | 系数 |
|-----|-----|
| 基础CPM | $5-20 |
| 互动加成 | 1.2-2.0倍 |
| 粉丝量加成 | 1.0-1.5倍 |
| 垂直度加成 | 1.3-2.0倍 |

【报价示例】
账号数据：
- 粉丝：5万
- 平均播放：2万
- 互动率：5%

单条视频报价：
- 基础报价：20000 × $10/1000 = $200
- 互动加成：$200 × 1.3 = $260
- 粉丝加成：$260 × 1.2 = $312
- 最终报价：$300-500/条
```

#### 报价单制作

```markdown
【报价单要素】
1. 账号信息
   - 平台/账号名
   - 粉丝数量
   - 主要数据

2. 服务项目
   - 视频植入
   - 定制内容
   - 直播合作
   - 长期合作

3. 报价明细
   - 单次合作
   - 套餐优惠
   - 长期折扣

4. 服务说明
   - 交付时间
   - 修改次数
   - 版权归属
```

### 第二步：寻找广告主

#### 主动获客渠道

```markdown
【品牌主动对接】
1. 平台官方
   - TikTok Creator Marketplace
   - Instagram Branded Content
   - YouTube BrandConnect

2. MCN机构
   - 平台认证MCN
   - 代理品牌需求
   - 资源整合服务

3. 品牌官网
   - 官网联系表单
   - 社媒官方账号
   - 邮箱直投

【主动出击】
1. 品牌匹配
   - 梳理潜在合作品牌
   - 研究品牌调性
   - 评估匹配度

2. 主动联系
   - 邮件营销
   - 私信自荐
   - LinkedIn连接

3. 行业活动
   - 品牌活动参与
   - 行业展会
   - 线下对接
```

#### 品牌筛选标准

```markdown
【合作品牌评估】
| 因素 | 权重 | 评估标准 |
|-----|-----|---------|
| 品牌调性 | 30% | 与账号契合度 |
| 产品合规 | 20% | 无违规风险 |
| 报价合理 | 25% | 符合市场水平 |
| 付款信誉 | 15% | 按时付款记录 |
| 合作体验 | 10% | 沟通顺畅度 |

【拒绝合作情况】
- 产品违规/虚假
- 报价低于成本
- 品牌调性冲突
- 要求数据造假
- 合同条款苛刻
```

### 第三步：广告合作执行

#### 合作沟通流程

```markdown
【沟通流程】
1. 需求了解
   - 品牌目标
   - 产品信息
   - 内容要求
   - 预算范围

2. 方案报价
   - 内容创意
   - 合作形式
   - 报价明细
   - 时间安排

3. 合同确认
   - 合作条款
   - 交付标准
   - 付款方式
   - 违约责任

4. 内容制作
   - 脚本确认
   - 产品寄送
   - 拍摄制作
   - 初稿审核

5. 交付结算
   - 最终修改
   - 内容发布
   - 数据反馈
   - 款项结算
```

#### 合作注意事项

```markdown
【必须明确事项】
□ 内容创意控制权
□ 修改次数限制
□ 发布时间安排
□ 数据反馈标准
□ 款项结算方式
□ 版权归属问题
□ 竞品排他期

【风险规避】
- 预付款原则（≥50%）
- 书面合同
- 交付标准明确
- 违约条款清晰
```
