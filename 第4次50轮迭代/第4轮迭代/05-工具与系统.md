# 05-工具与系统：提效必备武器

## 核心概念

### 工具选型原则

高效创作者善用工具：
- 选对工具，事半功倍
- 工具不是目的，效率才是
- 善用免费工具降低成本
- 定期优化工具组合

### 工具分类

```markdown
【创作者工具矩阵】
1. 内容创作
   - 写作：ChatGPT/Notion
   - 视频：剪映/Premiere
   - 图片：Canva/Figma

2. 运营管理
   - 排期：Notion/Airtable

   - 支付：PayPal/Wise

```

## 避坑清单

### ❌ 工具使用误区

1. **工具收集癖**
   - 问题：收藏很多但不用
   - 正确：精选2-3个核心工具

2. **工具依赖**
   - 问题：没有工具就不会工作
   - 正确：工具是辅助，核心在能力

3. **忽视成本**
   - 问题：工具费用累积
   - 正确：评估ROI，善用免费

4. **不学习高级功能**
   - 问题：只用到10%功能
   - 正确：深入学习核心工具

5. **工具不更新**
   - 问题：效率停滞
   - 正确：定期学习新功能
