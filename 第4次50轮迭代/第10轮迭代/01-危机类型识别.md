# 01-危机类型识别：常见创作者危机

## 核心概念

### 创作者危机分类
```
平台危机：限流/封号/内容下架
内容危机：负面舆论/内容争议
个人危机：身心健康/法律风险
商业危机：合作纠纷/品牌危机
```

---

## 操作步骤

### 平台危机识别
```markdown
【限流危机】
- 流量突然下降>50%
- 内容推荐减少
- 账号权重降低

【封号危机】
- 部分功能限制
- 内容被批量删除
- 账号被封禁

【投诉危机】
- 内容被举报
- 收到平台警告
- 要求整改
```

### 内容危机识别
```markdown
【负面舆论】
- 评论失控
- 话题发酵
- 媒体介入

【内容争议】
- 信息失实
- 观点偏激
- 侵权纠纷
```
