# 03-内容复盘与优化：发布后数据分析

## 核心概念

### 内容复盘价值
内容复盘是通过分析发布后数据，识别成功因素和失败原因，持续优化内容质量的过程。

### Step 2：原因分析

**成功内容分析**：
```markdown
【分析维度】
1. 选题
   - 为什么这个选题受欢迎
   - 有没有可以复制的点

2. 形式
   - 封面/标题有什么特点
   - 内容结构有何不同

3. 时机
   - 发布时机是否合适
   - 有没有蹭到热点

4. 运营
   - 互动做得好不好
   - 有没有引导传播
```

**失败内容分析**：
```markdown
【分析维度】
1. 选题
   - 选题是否有问题
   - 时效性是否过差

2. 形式
   - 封面/标题是否不吸引
   - 内容是否有断层

3. 时机
   - 发布时机是否错误
   - 是否错过热点

4. 运气
   - 是否有运气因素
   - 平台推荐是否不利
```
