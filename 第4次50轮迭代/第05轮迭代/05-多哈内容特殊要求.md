# 05-多哈内容特殊要求：文化与合规

## 核心概念

### 多哈内容合规要求
在多哈创作内容需要遵守卡塔尔法律法规和伊斯兰文化规范，避免触碰文化红线。

---

## 操作步骤

### Step 1：文化红线识别

**宗教相关内容**：
```markdown
【避免内容】
✗ 宗教人物不敬
✗ 宗教仪式嘲笑
✗ 宗教信仰评判
✗ 宗教符号不当使用
✗ 宗教敏感节日恶搞

【建议做法】
✓ 尊重宗教信仰
✓ 展示文化理解
✓ 分享正面内容
✓ 节日祝福适当
```

**社会文化相关内容**：
```markdown
【避免内容】
✗ 政治敏感话题
✗ 皇室/政府不当言论
✗ 种族/文化歧视
✗ 女性地位争议性话题
✗ 酒精/赌博相关内容（敏感处理）

【建议做法】
✓ 展示多元文化包容
✓ 分享正面生活
✓ 尊重当地习俗
```

### Step 2：平台合规检查

**中东平台规范**：
```markdown
【TikTok中东规范】
- 遵守当地法律法规
- 尊重宗教文化
- 避免政治敏感
- 禁止暴力/极端内容

【阿拉伯语内容规范】
- 注意宗教敏感性
- 避免方言歧视
- 尊重文化差异
```

### Step 3：斋月内容指南

**斋月内容调整**：
```markdown
【内容调性】
- 减少娱乐性内容
- 增加温馨/家庭内容
- 尊重斋戒者
- 祝福内容适当

【发布时机】
- 日间活跃度下降
- 日落后（Iftar后）活跃
- 凌晨1-3点最活跃

【视觉风格】
- 斋月主题颜色（绿色/金色）
- 适当斋月元素
- 温馨氛围
```

## 避坑清单

### ❌ 常见文化错误
1. **宗教玩笑**：不当涉及宗教内容
2. **文化歧视**：不当评价当地文化
3. **政治话题**：涉及敏感政治内容
4. **斋月冒犯**：斋月期间不尊重

### ✅ 正确文化态度
1. **尊重第一**：尊重宗教和文化
2. **了解学习**：了解当地文化
3. **正向展示**：展示正面形象
4. **谨慎处理**：敏感话题避开
