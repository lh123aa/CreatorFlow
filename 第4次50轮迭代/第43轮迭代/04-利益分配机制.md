# 04-利益分配机制

## 分配模式

### 常见模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 免费带教 | 无利益交换 | 公益/人情 |
| 内容分成 | 收入比例分成 | 深度合作 |
| 股权合作 | 公司股份 | 合资公司 |
| 资源换流量 | 资源换导流 | 互惠互利 |

### 推荐模式

**初期（验证阶段）**：
- 免费带教 + 导流交换
- 积累经验

**成熟期**：
- 内容分成（10-20%）
- 或联合品牌合作

---

## 分成设计

### 合理分成参考

```
孵化者 vs 被孵化者：
- 收入分成：10-30% vs 70-90%
- 合同时长：1-2年
- 递减机制：随时间减少分成
```

### 分成考量因素

- 孵化投入程度
- 资源提供价值
- 合作深度
- 赛道潜力
