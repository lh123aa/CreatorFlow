# 03-日程管理策略

## 多时区日程设计

### 日程规划原则

**1. 批量处理同类型工作**
- 会议集中安排
- 创作时间保护
- 回复时间固定

**2. 利用时区差**
- 早起处理亚洲事务（多哈早起=亚洲白天）
- 上午处理欧洲事务
- 下午处理本地/美洲事务

**3. 设置硬性边界**
- 工作与非工作界限
- 避免全天候待命
- 保护个人时间

---

## 典型周日程

### 多哈创作者周日程（GMT+3）

| 时段 | 周一-周四 | 周五 |
|------|----------|------|
| 05:00-07:00 | 中国/亚洲事务 | 休息 |
| 07:00-09:00 | 内容创作（晨间） | 休息 |
| 09:00-12:00 | 欧洲协作/会议 | 本地周礼 |
| 12:00-14:00 | 午休/社交 | 家庭时间 |
| 14:00-17:00 | 亚洲事务/回复 | 休息 |
| 17:00-19:00 | 本地业务 | 休息 |
| 19:00-22:00 | 内容制作（晚间） | 休息 |
| 22:00-23:00 | 规划/整理 | 休息 |

### 周三为分隔点

多哈工作周：
- 周日至周四：工作日
- 周五-周六：周末

**调整建议**：
- 周四下午为周内收尾
- 周五上午处理紧急事务
- 周五下午-周六完全休息

## 会议管理

### 会议类型分类

| 会议类型 | 频率 | 时长 | 参与方式 |
|---------|------|------|---------|
| 1:1 Check-in | 每周 | 15-30min | 视频 |
| Team Standup | 每日 | 10-15min | 异步/视频 |
| 项目评审 | 按需 | 30-60min | 视频 |
| 头脑风暴 | 每月 | 60min | 视频 |
| 社交连接 | 每月 | 30min | 随意 |

### 会议效率提升

**会前**：
- 明确议程
- 提前发资料
- 确认参与人

**会中**：
- 准时开始/结束
- 记录要点
- 明确行动项

**会后**：
- 发送会议纪要
- 跟进行动项
- 评估会议效果

### 减少无效会议

**替代方案**：
- 信息同步 → 异步文档
- 简单确认 → 即时消息
- 进度汇报 → 看板更新
- 头脑风暴 → 书面讨论

## 时间块管理

### 时间块方法

**核心概念**：
- 将一天划分为固定块
- 每块专注特定类型工作
- 保护时间块不被入侵

**示例**：
```
时间块安排：

[05:00-07:00] 亚洲时间块
→ 处理中国邮件/消息
→ 亚洲社媒回复

[07:00-09:00] 创作时间块
→ 视频脚本/文章
→ 不看手机

[09:00-12:00] 会议时间块
→ 视频会议
→ 客户沟通

[14:00-17:00] 亚洲时间块2
→ 内容发布
→ 互动回复
```
