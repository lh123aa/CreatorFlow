# 01-时区基础与协调

## 多哈时区特点

### GMT+3的优势

**卡塔尔时区（Arabia Standard Time / GMT+3）**：
- 与欧洲时差：欧洲中部时间-2h（友好）
- 与亚洲时差：中国时间-5h（可接受）
- 与美洲时差：美国东部时间+8h（挑战较大）

## 时区协作策略

### "Golden Hours" 原则

**确定每日协作黄金时段**：
- 识别必须同步的工作
- 确定同步参与人
- 锁定黄金时段

**黄金时段使用原则**：
- 只用于真正需要同步的事项
- 提高每次会议效率
- 避免黄金时段碎片化

### 工作窗口设计

```
多哈创作者标准工作日（示例）：

05:00-07:00 晨间准备（可处理中国工作）
07:00-09:00 早间内容创作（安静时段）
09:00-12:00 欧洲协作窗口（会议/邮件）
12:00-14:00 午休/本地社交
14:00-17:00 亚洲协作窗口（回复中国消息）
17:00-19:00 本地业务/会议
19:00-21:00 内容制作（晚间创作）
21:00-22:00 异步工作（规划/整理）
```

## 时区冲突解决

### 典型冲突场景

**场景1：中国团队需要即时沟通**
- 问题：中国上班时间 = 多哈凌晨
- 方案：提前预约深夜通话 or 建立值班机制

**场景2：欧美客户需要电话会议**
- 问题：欧美工作时间 = 多哈凌晨
- 方案：付费咨询时段预约 or 书面异步沟通

**场景3：跨国协作项目**
- 问题：各时区分散，难以同步
- 方案：建立接力式工作流（handoff model）

### 解决原则

1. **同步优先用于高价值事项**：真正需要实时讨论的
2. **异步优先用于低价值事项**：信息传递类工作
3. **公平分担不便**：轮换承担不友好时段
4. **明确预期响应时间**：SLA沟通
