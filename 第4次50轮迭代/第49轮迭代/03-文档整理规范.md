# 03-文档整理规范

## README.md 模板

```markdown
# 自媒体创作者知识系统 V61.0

[Logo/徽章]

## 简介

这是一套专为自媒体创作者打造的知识系统，涵盖内容创作、涨粉变现、团队协作、全球化运营等全方位实战指南。

## 核心模块

- 模块一：执行体系
- 模块二：商业体系
- 模块三：团队体系
- 模块四：全球化体系
- 模块五：生态体系

## 快速开始

1. 克隆仓库
2. 选择感兴趣模块
3. 按指南执行

## 特色

- 多哈创作者视角
- 跨境变现优先
- 可操作的SOP
- 丰富的模板工具

## 贡献

欢迎提交Issue和Pull Request。

## 许可

本项目采用 CC BY 4.0 协议。
```

## CONTRIBUTING.md 模板

```markdown
# 贡献指南

## 如何贡献

1. Fork本仓库
2. 创建分支 (`git checkout -b feature/AmazingFeature`)
3. 提交更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 创建Pull Request

## 贡献类型

- 修正错误
- 补充案例
- 优化文档
- 新增内容

## 规范

- 使用中文
- Markdown格式
- 保持风格一致
```
