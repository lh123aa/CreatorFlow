# 02-开源协议选择

## 常见开源协议

### MIT License（推荐）

**特点**：
- 极其宽松
- 允许任何使用
- 仅要求保留版权声明

**适用**：希望广泛传播，无附加条件

### Apache 2.0

**特点**：
- 宽松
- 包含专利授权
- 要求保留版权声明

**适用**：商业使用较多的项目

### CC License

**适用内容创作**：
- CC BY：署名即可
- CC BY-SA：署名+相同方式共享
- CC BY-NC：署名+非商业使用

---

## 推荐选择

### 知识体系类项目

**推荐**：CC BY 4.0

**原因**：
- 允许自由使用
- 要求署名（保护原创）
- 不限制商业使用
- 适合知识传播

---

## 添加协议

```bash
# 创建LICENSE文件
touch LICENSE

# 或直接复制协议文本
# MIT: https://opensource.org/licenses/MIT
# CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
```
