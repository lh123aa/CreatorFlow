# 04-发布流程设计

## 发布步骤

### Step 1：内部测试

- [ ] 文档格式检查
- [ ] 链接可用性
- [ ] 内容完整性

### Step 2：版本标记

```bash
# 打标签
git tag -a v61.0 -m "V61.0 release"
git push origin v61.0
```

### Step 3：GitHub发布

1. 进入仓库 → Releases
2. 点击 "Draft a new release"
3. 填写版本信息
4. 发布

### Step 4：通知

- 社交媒体公告
- 相关社区分享
- 邮件通知（如有订阅者）

---

## 执行检查清单

- [ ] 内部测试完成
- [ ] 版本标记
- [ ] 发布Release
- [ ] 社区通知
