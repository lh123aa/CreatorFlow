# 01-季度复盘框架：系统化回顾与评估

## 核心概念

### 复盘四步法
```
回顾目标：当初目标是什么
评估结果：实际结果如何
分析原因：成功/失败原因
总结经验：学到了什么
```

---

## 操作步骤

### 复盘流程
```markdown
【第一步：回顾目标】
- 本季度目标是什么
- 分解到各月/周的子目标
- 当时对结果的预期

【第二步：评估结果】
- 各项目标实际达成情况
- 与目标对比的差距
- 亮点和不足

【第三步：分析原因】
- 成功的关键因素
- 失败的根本原因
- 外部因素影响

【第四步：总结经验】
- 学到的经验教训
- 可以复制的成功
- 需要改进的不足
```
