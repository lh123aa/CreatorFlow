# 02-平台规则与应对

## 主流平台政策

### YouTube政策要点

**变现政策**：
- 订阅数 ≥ 1000
- 过去12个月观看时长 ≥ 4000小时
- 无重大违规

**内容政策**：
- 社区准则（禁止仇恨/暴力/危险内容）
- 版权政策（避免版权声明）
- 广告主友好内容（适合广告投放）

**应对策略**：
- 定期检查YouTube Studio数据
- 关注政策更新通知
- 保持内容合规性

### 抖音/字节平台

**变现政策**：
- 抖音：粉丝 ≥ 1000可开商品分享
- 抖音电商：需资质审核
- 直播带货：需完成实名认证

**内容政策**：
- 医疗/金融等敏感行业需资质
- 禁止虚假宣传
- 限流规则（频繁操作/营销过重）

### 小红书

**变现政策**：
- 粉丝 ≥ 1000可开蒲公英平台
- 品牌合作需报备
- 带货需开通专业号

**内容政策**：
- 软广需标注
- 虚假宣传禁止
- 医疗/金融内容限制

## 政策风险应对

### 常见风险场景

**场景1：内容被限流**
- 检查是否违规
- 申诉（如有误判）
- 调整内容策略

**场景2：账号被警告**
- 了解警告原因
- 停止违规行为
- 申诉（如有误）

**场景3：收益被扣除**
- 查看违规记录
- 了解扣款原因
- 规范后续行为

### 预防措施

1. **定期学习平台政策**：关注官方公告
2. **建立内容审核流程**：发布前自查
3. **保持账号安全**：防止被盗
4. **备份重要内容**：防止丢失
