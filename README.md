# CreatorFlow - AI自媒体创作工作流

> 让学习的知识真正被应用到创作中

## 一、项目简介

CreatorFlow 是一套**自媒体创作知识管理系统**，解决AI学习知识与实际创作脱节的问题。

### 核心痛点
- 学了很多爆款技巧，写文案时想不起来用
- 每次创作都从零开始，没有知识积累
- 全量加载知识浪费Token，按需加载又容易遗漏

### 解决方案
通过**三层索引系统** + **主题分析框架**，实现：
- 知识模块化存储
- 按需精确加载
- 强制流程确保知识应用

## 二、系统架构

```
┌─────────────────────────────────────────────────────────┐
│                  第一层：知识索引                          │
│  存储位置：knowledge-index.md / MEMORY.md                │
│  内容：模块清单 + 快速检索表 + 核心公式速查                 │
│  Token消耗：约500 tokens                                 │
└─────────────────────────────────────────────────────────┘
                              ↓ 主题分析后匹配
┌─────────────────────────────────────────────────────────┐
│                  第二层：知识模块                          │
│  存储位置：knowledge-base/                               │
│  内容：选题模板库、标题模板库、正文模板库、设计模板库、钩子规范  │
│  Token消耗：每次约1000-3000 tokens                       │
└─────────────────────────────────────────────────────────┘
                              ↓ 创作时引用
┌─────────────────────────────────────────────────────────┐
│                  第三层：参考资源                          │
│  存储位置：examples/                                     │
│  内容：优秀案例、素材模板                                  │
│  Token消耗：按需                                         │
└─────────────────────────────────────────────────────────┘
```

## 三、创作流程

```
确定主题 → 主题分析 → 查知识索引 → 精确加载知识 → 套用公式创作 → 检查确认
```

### 步骤详解

1. **确定主题**：明确要写什么
2. **主题分析**：用 `templates/topic-analysis.md` 分析受众、痛点、调性
3. **查知识索引**：读取 `knowledge-index.md` 确定需要的模块
4. **精确加载**：只读取分析结果指定的知识模块
5. **套用创作**：按公式模板创作
6. **检查确认**：用检查清单确认各环节

## 五、核心公式速查

### 选题公式
| 类型 | 公式 |
|------|------|
| 痛点型 | `[具体痛点] + [情绪词] + [解决方案预告]` |
| 信息差型 | `[反常识观点] + [具体数据] + [新方法论]` |
| 逆袭型 | `[具体失败] + [真实情感] + [行动转变] + [可验证结果]` |

### 标题公式
| 类型 | 公式 |
|------|------|
| 数字型 | `[数字] + [时间/结果] + [利益点]` |
| 情绪化反转 | `[矛盾体] + [反问] + [情绪词] + [悬念]` |

### 正文结构
| 类型 | 结构 |
|------|------|
| 爆款万能 | `痛点引入(1-2句) → 价值输出(3-4句) → 细节拆解 → 引导互动(1句)` |
| AIDA | `注意 → 兴趣 → 欲望 → 行动` |

### 钩子公式
`钩子 + 价值/痛点 + 触发词`

## 六、Token消耗对比

| 方式 | Token消耗 | 知识应用率 |
|------|----------|-----------|
| 全量加载所有知识 | ~10000 tokens | 依赖记忆，约30% |
| CreatorFlow按需加载 | ~3000 tokens | 强制流程，90%+ |

## 七、适用场景

- 小红书图文创作
- 抖音短视频脚本
- 公众号文章写作
- 产品文案设计
- 自媒体内容运营

## 八、快速开始

1. Clone仓库
2. 将 `templates/knowledge-index.md` 内容加入你的AI Agent的长期记忆
3. 创作时按流程执行：主题分析 → 查索引 → 加载知识 → 创作

详见 [QUICK_START.md](./QUICK_START.md)
