## 一、AI视频脚本工具全景图

### 1.1 主流工具介绍

**通用AI助手**：
- **ChatGPT/Claude**：最强通用AI，可生成各类视频脚本，支持多轮对话迭代
- **豆包/文心一言**：国产AI，中文理解好，本地化内容生成优
- **Kimi**：长文本处理强，适合深度脚本创作

**平台AI工具**：
- **剪映AI脚本**：结合剪辑场景，生成匹配视频的脚本
- **抖音AI脚本**：针对抖音算法优化，生成高转化脚本
- **小红书AI**：针对种草场景优化，生成高互动脚本

**专业脚本工具**：
- **Jasper**：专业营销文案工具，模板丰富
- **Writesonic**：多类型内容生成，脚本能力强
- **Plotagon**：AI动画视频生成，适合教程类

### 1.2 AI脚本使用场景

**初稿生成**：
- 提供选题，快速获得脚本初稿
- 节省从零创作的时间
- 快速验证选题可行性

**灵感激发**：
- 获得不同角度的创意
- 打破创作瓶颈
- 发现意想不到的角度

**脚本润色**：
- 优化现有脚本的语言表达
- 增强感染力和节奏感
- 优化开头钩子和结尾CTA

**多版本生成**：
- 同一选题生成多个脚本版本
- 便于A/B测试
- 找到最优解

### 1.3 AI工具选择策略

```
工具选择原则：
- 中文内容 → 豆包/文心一言/Kimi
- 英文内容 → ChatGPT/Claude
- 多语言内容 → ChatGPT/Claude
- 专业营销 → Jasper/Writesonic
- 视频结合 → 剪映AI
```

## 二、AI脚本提示词工程

### 2.1 基础提示词模板

**通用脚本提示词**：
```
请为以下视频创作脚本：

主题：[视频主题]
时长：[时长要求，如1-3分钟]
目标受众：[受众描述，如25-35岁职场女性]
风格：[风格要求，如轻松幽默/专业严肃/情感共鸣]

脚本要求：
1. 前3秒必须有强钩子，吸引用户继续观看
2. 内容结构清晰，有明确的信息层次
3. 结尾有明确的行动号召
4. 符合目标受众的审美和表达习惯

请生成完整的视频脚本，包括：
- 开场钩子（约3秒）
- 内容主体（分点阐述）
- 结尾号召（约5秒）
```

**带货脚本提示词**：
```
请为以下带货视频创作脚本：

产品：[产品名称和特点]
目标受众：[受众描述]
核心卖点：[1-3个核心卖点]
价格策略：[如有优惠信息]

脚本要求：
1. 前3秒展示产品效果或痛点
2. 中间详细讲解产品卖点
3. 穿插用户评价或使用场景
4. 结尾明确购买引导和优惠信息
5. 控制在60-90秒内

请生成完整的带货脚本。
```

**教程脚本提示词**：
```
请为以下教程视频创作脚本：

教程主题：[主题]
目标受众：[受众基础水平]
预期效果：[学完后能达到的效果]

脚本要求：
1. 前3秒说明学完能得到什么
2. 分步骤详细讲解
3. 每个步骤有具体的操作说明
4. 中间穿插常见错误提醒
5. 结尾总结要点和鼓励行动

请生成完整的教程脚本。
```

### 2.2 提示词优化技巧

**提供详细背景**：
```
❌ 原始：写一个视频脚本
✅ 优化：为一个面向25-35岁多哈华人的美妆教程视频写脚本，主题是适合沙漠气候的夏季护肤，风格要轻松亲切，时长1-2分钟
```

**明确风格语气**：
```
❌ 原始：语气要专业
✅ 优化：语气要像朋友聊天，轻松自然，偶尔用口语化表达，但涉及专业知识点时保持严谨
```

**指定具体长度**：
```
❌ 原始：不要太长
✅ 优化：总时长控制在90秒内，开头3秒，中间80秒，结尾7秒
```

**给出参考示例**：
```
请参考以下脚本风格，创作类似风格的内容：
[粘贴优秀脚本片段]
```

### 2.3 多轮迭代技巧

**第一轮：获取基础脚本**：
- 提供基本信息，获取初稿
- 评估是否符合预期

**第二轮：针对性优化**：
- 指出需要改进的点
- 要求调整特定部分
- 示例："开头太啰嗦，请精简到3秒以内"

**第三轮：细节打磨**：
- 优化语言表达
- 增强节奏感
- 添加情绪词

**第四轮：本地化适配**：
- 翻译为阿拉伯语元素
- 添加本地场景描述
- 调整文化表达

## 三、AI脚本场景化应用

### 3.1 抖音脚本创作

**抖音爆款脚本结构**：
```
[3秒] 强钩子
- 抛出痛点/悬念/惊人数据
- 目的：留住用户

[7秒] 引发共鸣
- 确认用户问题
- 引发情绪共鸣

[40秒] 给出方案
- 分点讲解
- 案例佐证

[10秒] 强化价值
- 总结核心要点
- 强调效果

[7秒] 行动号召
- 关注引导
- 点赞引导
- 购买引导
```

**AI生成示例**：
```
提示词：
请为一个抖音口播视频创作脚本：
- 主题：多哈女生必知的5个护肤误区
- 目标：引发共鸣，提供价值，引导关注
- 时长：60-90秒
- 风格：真实亲切，像朋友聊天
```

### 3.2 小红书脚本创作

**小红书图文脚本**：
```
结构：
- 封面文案设计
- 标题文案设计
- 正文分点（每点配图建议）
- 结尾互动引导
```

**AI生成示例**：
```
提示词：
请为小红书图文笔记创作脚本：
- 主题：多哈周末好去处推荐
- 形式：图文笔记，6张图
- 风格：精致生活，分享感
- 包含具体的地点推荐和拍照建议
```

### 3.3 TikTok脚本创作

**TikTok短视频脚本**：
```
特点：
- 更短更快（前3秒决定生死）
- 文化差异感强
- 娱乐性强

结构：
[0-3秒] 强钩子
[3-15秒] 核心内容
[15-60秒] 完整展示（可选）
```

## 四、AI脚本质量把控

### 4.1 AI脚本评估维度

| 维度 | 评估标准 | 权重 |
|-----|---------|------|
| 开头钩子 | 3秒内能否吸引注意 | 25% |
| 内容价值 | 是否有干货、能否解决需求 | 30% |
| 结构清晰 | 逻辑是否清晰、节奏是否紧凑 | 20% |
| 语言表达 | 是否符合目标受众表达习惯 | 15% |
| 行动号召 | 结尾CTA是否明确有力 | 10% |

### 4.2 人工优化要点

**必须人工调整**：
- 开头的具体表达（确保有冲击力）
- 中间的案例和故事（加入个人真实经历）
- 结尾的个人风格（保持IP一致性）
- 涉及敏感话题的内容（避免违规）

**AI辅助环节**：
- 框架搭建
- 初稿生成
- 语言润色
- 多版本生成

### 4.3 效率提升方法

**建立模板库**：
```
模板类型：
- 教程类模板
- 带货类模板
- 剧情类模板
- 知识分享类模板

使用方法：
选定模板 → 填充变量 → AI生成 → 人工优化
```

**批量生成策略**：
- 每周批量生成下周的脚本
- 一次生成多个选题的脚本
- 建立脚本素材库
