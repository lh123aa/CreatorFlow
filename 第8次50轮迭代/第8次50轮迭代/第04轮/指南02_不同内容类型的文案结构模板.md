## 一、内容类型分类体系

### 1.1 按内容功能分类

根据内容的主要功能，可以将内容分为以下几大类型：

**信息传递型**：以传递客观信息为主要目的，如新闻、资讯、数据、事实等。
- 结构特点：信息清晰、来源可靠、层次分明
- 代表形式：科普文、资讯文、数据报告

**知识分享型**：以传授知识技能为主，如教程、指南、讲解等。
- 结构特点：由浅入深、步骤清晰、实例丰富
- 代表形式：教程文、攻略文、指南文

**观点表达型**：以表达观点看法为主，如评论、议论文等。
- 结构特点：观点明确、论据充分、逻辑严密
- 代表形式：评论文、观点文、议论文

**情感表达型**：以传达情感为主，如感悟、随笔、故事等。
- 结构特点：情感真挚、细节丰富、感同身受
- 代表形式：感悟文、故事文、随笔

**说服行动型**：以说服读者采取行动为主，如推广、招募等。
- 结构特点：价值明确、信任建立、行动引导清晰
- 代表形式：推广文、招募文、倡议文

### 1.2 按内容形式分类

根据内容的呈现形式，可以分为：

**图文内容**：以文字为主，配以图片说明
**视频脚本**：以视频播放为最终形式
**纯文字内容**：无图片，纯文字呈现
**音频内容**：以音频为最终形式

## 二、实用文案模板库

### 2.1 知识分享类模板

**模板一：教程式结构**

```
【开篇引入】
描述一个常见场景或问题
引出本文要解决的问题
简述本文将提供的方法/技巧

【背景说明】
必要的前置知识介绍
相关的注意事项或前提条件
帮助读者判断是否适合学习

【核心内容】
分步骤讲解（使用序号）
每个步骤：要点说明+具体操作+示例展示
注意步骤之间的逻辑关系

【总结回顾】
回顾本文主要内容
强调核心要点
提供进一步学习的建议
```

**模板二：清单式结构**

```
【开篇】
清单主题和数量预告
阅读本文能获得什么

【清单主体】
数字+标题（核心价值点）
展开说明（是什么、为什么、怎么做）
相关案例或示例

【总结】
清单核心价值总结
应用建议
互动引导
```

### 2.2 观点表达类模板

**模板：论证式结构**

```
【观点陈述】
明确表达核心观点
简要说明观点的意义

【论证展开】
论据一（事实/数据/案例）
论据二（事实/数据/案例）
论据三（事实/数据/案例）

【结论升华】
总结论证要点
重申核心观点
提出行动建议或思考题
```

### 2.3 情感故事类模板

**模板：叙事式结构**

```
【场景引入】
设定时间和地点
描述当下的状态或感受

【背景铺陈】
来到这个场景的原因
之前的经历或铺垫

【冲突呈现】
遇到的困难或挑战
内心的挣扎或变化

【转折高潮】
重要的转折点或启示
心态或行动的变化

【感悟总结】
从经历中获得的感悟
对读者的启发或建议
```

### 2.4 产品推广类模板

**模板：价值型推广结构**

```
【痛点切入】
描述目标受众的常见问题
让用户产生共鸣

【方案提出】
介绍产品/服务作为解决方案
简述其核心功能

【价值展示】
详细展示产品价值
使用案例或用户评价
对比说明优势

【行动引导】
限时优惠或特别福利
明确的购买/联系方式
信任背书
```

## 三、中东内容文案模板

### 3.1 多哈生活类模板

【经历展开】
这段时间的经历/发现

心态或认知的变化

可能遇到的问题及解决

【补充信息】
