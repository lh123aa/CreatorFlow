# 指南03：封面设计与视觉包装

## 前言

封面是视频的"脸面"，直接决定点击率。本指南将帮助你设计高点击率封面，建立统一的视觉风格。

---

## 第一部分：封面设计原则

### 1.1 点击率要素

**影响点击率的关键**：
```
✓ 人物表情（夸张/有趣）
✓ 色彩对比（鲜明醒目）
✓ 文字信息（清晰易懂）
✓ 画面构图（主体突出）
✓ 悬念感（引发好奇）
```

### 1.2 平台封面规格

**各平台封面尺寸**：
```
TikTok：1080×1920（9:16）
YouTube：1280×720（16:9）
Instagram：1080×1080（1:1）
小红书：1000×1000（1:1）
抖音：1080×1920（9:16）
```

## 第二部分：封面模板

### 2.1 文字模板

**高点击标题模板**：
```
【数字型】
"5个技巧"
"月薪X万"

【问题型】
"为什么...？"
"如何...？"

【对比型】
"国内 vs 国外"
"之前 vs 之后"

【悬念型】
"你绝对不知道..."
"最后一个太意外..."
```

### 2.2 视觉模板

**封面构图类型**：
```
✓ 人物居中+背景虚化
✓ 左右分栏对比
✓ 中心放射式
✓ 框架式构图
✓ 留白艺术型
```
