## 第三部分：限流原因与规避

### 3.1 常见限流原因

**内容违规**：
```
⚠️ 敏感话题（政治、宗教争议）
⚠️ 虚假信息/谣言
⚠️ 抄袭/搬运内容
⚠️ 低质量内容（模糊、过长）
⚠️ 过度营销（硬广）
```

**行为违规**：
```
⚠️ 刷量/买粉
⚠️ 多账号操作
⚠️ 频繁删除/隐藏视频
⚠️ 频繁修改资料
⚠️ 批量私信/评论
```

### 3.2 限流自查清单

```
□ 最近是否有违规内容？
□ 是否购买了粉丝/互动？
□ 是否使用第三方违规工具？
□ 是否发布频率异常？
□ 是否频繁切换账号？
□ 是否被多次举报？
```

### 3.3 限流解决方案

**限流应对步骤**：
```
1. 停止所有可疑行为
2. 检查近期内容，删除违规
3. 保持正常活跃（点赞、评论）
4. 等待3-7天观察
5. 如未恢复，联系官方客服
```
