## 一、Midjourney深度应用

### 1.1 Midjourney核心参数详解

Midjourney的参数系统是其强大能力的来源：

**基础参数**：

| 参数 | 作用 | 常用值 |
|------|------|--------|
| --ar | 长宽比 | 1:1(Instagram)、16:9(YouTube)、9:16(TikTok) |
| --v | 模型版本 | 6.1(最新)、5.2、6(测试中) |
| --s | 风格化程度 | 100(低)、250(中)、750(高) |
| --q | 质量 | 1(标准)、2(高) |
| --style | 风格预设 | raw(真实)、expressive(表现力)等 |

**高级参数**：

| 参数 | 作用 | 示例 |
|------|------|------|
| --no | 负面提示 | --no people text watermark |
| --iw | 图片权重 | 0-2，值越高图片参考越强 |
| :: | 元素权重 | "coffee::2 shop::1" |
| --seed | 种子值 | 固定随机种子保持一致性 |
| --stop | 停止生成 | --stop 80(80%时停止) |

### 1.2 Midjourney提示词工程

**结构化提示词框架**：

```
[主体描述] + [环境设定] + [构图指导] + [风格定义] + [技术参数]

示例：
A stylish woman wearing abaya sitting at a rooftop café in Doha, 
overlooking the Corniche with sunset sky, 
cinematic composition with shallow depth of field,
editorial fashion photography, warm golden tones,
shot on Sony A7RIV --ar 9:16 --v 6.1 --s 250 --q 2
```

### 1.3 Midjourney风格控制技巧

**风格代码应用**：

| --s值 | 效果 | 适用场景 |
|--------|------|----------|
| 50-100 | 低风格化，更接近描述 | 需要真实感的内容 |
| 100-300 | 中等风格化 | 平衡真实与艺术 |
| 300-600 | 高风格化，艺术感强 | 需要创意表达 |
| 600-1000 | 极高风格化 | 抽象艺术风格 |

**风格混合技巧**：

```
使用 --style 参数或描述组合

示例1：照片真实感
[描述] --style raw --v 6.1

示例2：杂志风格
[描述] --style expressive --v 6.1

示例3：电影感
[描述] cinematic lighting, film grain, anamorphic lens
```

### 1.4 Midjourney一致性管理

保持多个图像之间的一致性是关键挑战：

**一致性技巧**：

```markdown
【技巧一：使用相同seed】
1. 生成满意的图片后，记下seed值
2. 在后续图片中使用 --seed [相同值]
3. 注意：seed只能保证大致一致，不能完全相同

示例：
/imagine prompt: [描述] --seed 12345678
/imagine prompt: [相似描述] --seed 12345678

【技巧二：使用 --iw 控制图片参考】
1. 先生成满意的参考图片
2. 在生成新图片时引入参考图URL
3. 使用 --iw 参数控制参考强度

/imagine prompt: [图片URL] [新描述] --iw 1.5

【技巧三：描述标准化】
建立固定的描述元素组合
- 固定的摄影风格描述
- 固定的光线设定
- 固定的色调偏好
- 固定的技术参数

示例模板：
[主体] + [多哈相关环境] + [固定光线: warm golden hour] + [固定风格: cinematic lifestyle photography] + [固定参数: --ar 4:5 --v 6.1 --s 250]
```

## 二、DALL-E 3深度应用

### 2.1 DALL-E 3的独特优势

DALL-E 3与ChatGPT深度集成，具有独特的优势：

**优势一：强大的自然语言理解**
- 更准确理解复杂的描述
- 减少误解和意外结果
- 支持更自由的描述方式

**优势二：文字渲染能力**
- 能够在图像中准确渲染文字
- 适合生成信息图、海报、封面
- 文字拼写和排版相对准确

**优势三：安全性与版权**
- 内置安全过滤器
- 避免侵权内容
- 商业使用更安全

## 三、Stable Diffusion深度应用

### 3.1 Stable Diffusion的优势与挑战

**优势**：
- 开源免费，可本地部署
- 模型可自由定制和微调
- 插件生态丰富
- 生成速度快（本地部署时）

**挑战**：
- 需要较高的技术门槛
- 硬件配置要求高
- 界面友好度不如商业产品
- 需要自己管理模型和插件

### 3.2 Stable Diffusion核心概念

```markdown
【模型（Model）】
- Checkpoint：完整模型文件，影响整体风格
- LoRA：小型定制模块，用于特定风格或概念
- Textual Inversion： embedding文件，定义新概念

常用模型推荐：
- Realistic Vision（真实照片风格）
- DreamShaper（艺术与现实混合）
- Deliberate（高质量通用）
-anything-v5（动漫风格）

【提示词语法】
(word) - 增加权重
[word] - 降低权重
(word:1.5) - 自定义权重数值

示例：
(masterpiece, best quality:1.4), 1girl, (white dress:1.2), 
[blurry], sitting in a Doha café, warm lighting

【负面提示词】
通用负面提示词：
lowres, bad anatomy, bad hands, text, error, 
missing fingers, extra digit, fewer digits, 
cropped, worst quality, low quality, normal quality, 
jpeg artifacts, signature, watermark, username, blurry
```

### 3.3 LoRA模型应用

LoRA是Stable Diffusion生态中最强大的定制工具：

```markdown
【LoRA使用方法】
1. 下载LoRA文件（.safetensors格式）
2. 将文件放入 models/Lora 目录
3. 在提示词中使用 <lora:filename:权重> 语法

示例：
masterpiece, best quality, a stylish woman in Doha,
<lora:add_detail:0.8>, <lora:filmgrain:0.3>

【常用LoRA类型】
- 细节增强（add_detail, detail tweaker）
- 风格化（film grain, cinema style）
- 特定概念（特定服装、建筑风格）
- 画质提升（4d4d4d的4x放大系列）

【训练自定义LoRA】
如果你需要特定的风格或概念：
1. 收集10-20张高质量样本图片
2. 使用Kohya训练自定义LoRA
3. 调整训练参数（学习率、步数等）
4. 测试并优化

训练数据建议：
- 图片质量要高
- 主题要一致
- 背景要简洁
- 张数10-20张足够
```
