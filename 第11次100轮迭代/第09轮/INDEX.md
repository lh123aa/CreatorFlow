## 认知框架总览

本轮系统探讨了概率思维和实验方法在内容创作中的应用：

### 1. 概率思维基础（专项指南01）
- **核心概念**：基础概率 / 条件概率 / 期望值 / 贝叶斯思维
- **应用场景**：设定预期 / 决策优化 / 接受不确定性
- **常见误区**：后见之明 / 赌徒谬误 / 幸存者偏差

### 2. 贝叶斯思维（专项指南02）
- **核心公式**：更新后的判断 = 先验判断 + 新证据
- **实践步骤**：设定先验 → 收集证据 → 更新判断 → 做出决策 → 循环
- **常见错误**：忽视先验 / 过度依赖 / 不更新 / 过度调整

### 3. AB测试（专项指南03）
- **测试设计**：明确目标 → 提出假设 → 设计方案 → 确定样本 → 运行测试 → 分析结果
- **应用场景**：封面测试 / 标题测试 / 形式测试 / 时间测试 / 互动测试
- **常见错误**：变量太多 / 样本太小 / 时间太短 / 提前停止

### 4. 实验设计（专项指南04）
- **基本要素**：研究问题 / 假设 / 变量 / 实验组 / 对照组 / 样本
- **设计类型**：对照实验 / 前后对比 / 时间序列 / 案例研究
- **执行步骤**：定义问题 → 提出假设 → 设计 → 执行 → 分析 → 结论 → 迭代

### 5. 统计思维（专项指南05）
- **核心概念**：均值 / 中位数 / 标准差 / 分布 / 相关性 / 显著性
- **常见陷阱**：只看均值 / 忽视样本量 / 相关当因果 / 确认偏误 / 忽视时间
- **高级应用**：置信区间 / 统计功效 / 贝叶斯统计

## 核心公式汇总

### 贝叶斯更新
```
更新后的判断 = 先验判断 + 新证据
```

### 期望值
```
期望值 = Σ(概率 × 结果)
```

### AB测试判断
```
统计显著 + 实际提升 → 采纳新方案
统计显著 + 实际下降 → 保持原方案
统计不显著 → 需要更多信息
```

## 方法论整合

### 概率思维框架
```
                    ┌─────────────┐
                    │  设定先验   │
                    │   判断     │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │  收集新证据 │
                    │  (实验/数据)│
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │  更新判断   │
                    │ (贝叶斯思维)│
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │  做出决策   │
                    │  (概率有利) │
                    └─────────────┘
```

### 实验方法层次
1. **观察**：收集数据，了解现状
2. **假设**：提出可检验的假设
3. **实验**：设计并执行实验
4. **分析**：统计检验，得出结论
5. **迭代**：基于结论优化策略
