# Prompt场景实战库：面向多哈创作者的200+核心场景模板

## 引言：场景化Prompt的价值

知道Prompt原理是一回事，能在实际创作中快速写出高质量Prompt是另一回事。本文档作为"场景化Prompt实战库"，将覆盖多哈创作者日常工作中的200+核心场景，提供可直接使用的Prompt模板，让你的AI辅助创作效率提升10倍。

使用说明：本文档按照内容创作流程编排，从选题策划到内容发布，涵盖所有关键环节。每个场景包含完整的Prompt模板和详细的使用指南，可以直接复制使用，也可以根据个人风格微调后使用。

【任务要求】

基于提供的数据，请识别：
1. 高互动率的内容主题（Top 5）
2. 增长最快的内容类别

### 1.2 选题生成Prompt

**场景3：多哈主题批量选题**

```
【角色定义】
你是一位创意充沛的多哈生活方式内容创作者，对本地热点和文化有敏锐洞察。

【背景信息】
- 我的账号定位：[你的账号定位描述]
- 目标受众：[描述你的目标受众]
- 本月大事件：[如"斋月即将来临"或"夏季旅游旺季"]
- 内容形式：[短视频/图文/长视频]

【任务要求】
请为我生成30个选题创意，覆盖以下类别：

A类选题（实用价值型）- 10个
→ 提供实用信息、技巧、攻略的内容

B类选题（情感共鸣型）- 10个
→ 引发情感共鸣、分享个人体验的内容

C类选题（热点蹭热度型）- 5个
→ 紧跟当前热点或趋势的内容

D类选题（差异化探索型）- 5个
→ 挖掘小众话题、独特视角的内容

【约束条件】
- 每个选题需要包含：标题、核心信息点、目标受众反应预期
- 优先选择多哈本地相关、竞品较少覆盖的选题
- 避免宗教敏感话题（除非明确是正面文化展示）
- 考虑英语和阿拉伯语受众的接受度差异

【输出格式】
请按类别分组输出，每组选题包含：
标题：[标题]
核心信息：[2-3个关键点]
预期反应：[用户可能的评论或互动]
```
